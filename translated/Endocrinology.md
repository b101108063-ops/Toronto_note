## 內分泌學概論

### Multiple Endocrine Neoplasia (MEN)

MEN 為罕見的遺傳性疾病，分為以下類型：

#### MEN1 (Wermer syndrome)

**定義**：三個部位的腫瘤或增生
- **Parathyroid**：最常見（95%），導致 hypercalcemia
- **Pancreatic islet cell tumors**：gastrinoma、insulinoma、glucagonoma、somatostatinoma
- **Pituitary tumors**：prolactinoma 最常見

**實驗室檢查**：
- Parathyroid PTH、Calcium
- Pancreatic hormones（gastrin、insulin、glucagon）
- Pituitary hormones（PRL、GH、ACTH、TSH）

**治療**：
- **藥物治療**：octreotide（Somatostatin analogue）用於控制 hormone secretion
- **手術治療**：針對 hyperparathyroidism、functional pancreatic tumors、functioning pituitary tumors

#### MEN2A (Sipple syndrome)

**腫瘤類型**：
- **Medullary thyroid carcinoma (MTC)**：100% 發生
- **Pheochromocytoma**：50% 發生
- **Primary hyperparathyroidism**：20-30% 發生

**實驗室檢查**：
- Calcitonin levels（MTC）
- 24h urine 與 serum metanephrines（pheochromocytoma）
- Serum Ca²⁺ 與 PTH levels（hyperparathyroidism）
- Pentagastrin + calcium stimulation test（若 calcitonin 在正常範圍）

**影像學**：
- Neck U/S 或 CT，甲狀腺結節與 lymphadenopathy
- CT 或 MRI 肾上腺定位 pheochromocytoma
- Cross-sectional imaging 評估轉移

**治療**：
- 手術切除 Pheochromocytoma（術前需給予 α-blocker 至少 10-21 天）
- 甲狀腺切除術（MTC）
- Hyperparathyroidism：切除 parathyroid adenoma

#### MEN2B

**腫瘤類型**：
- Medullary thyroid carcinoma
- Pheochromocytoma
- 无 parathyroid involvement

**特殊表徵**：
- Mucosal neuromas
- Marfanoid habitus

**治療**：
- 甲狀腺切除術
- Pheochromocytoma 手術切除

## Calcium 恆定

### 正常值

| 項目 | 正常範圍 |
|------|----------|
| Total serum Ca²⁺ | 2.2-2.6 mmol/L |
| Ionized/free Ca²⁺ | 1.15-1.31 mmol/L |

### Calcium 的分布

- **40%**：與蛋白質結合（主要為 albumin）
- **45%**：游離離子態
- **15%**：與 PO₄³⁻ 和 citrate 結合

### 調控機制

主要受 **PTH** 和 **Vitamin D** 調控，作用於三個主要器官：
- **胃腸道 (GI tract)**
- **骨骼 (Bone)**
- **腎臟 (Kidney)**

### Major Regulators in Calcium Homeostasis

| Regulator | Source | Regulation | Net Effect |
|-----------|--------|------------|-----------|
| **PTH** | Parathyroid glands | Stimulated by ↓ serum Ca²⁺ and ↑ serum Ca²⁺ | ↑ Ca²⁺, ↓ PO₄³⁻ |
| | | Inhibited by ↑ serum Ca²⁺, high calcitriol, ↑ FGF23, chronic low Mg²⁺ | |
| **Calcitriol (1,25-(OH)₂D₃)** | Kidney (from 25-OH vitamin D) | Stimulated by ↓ serum PO₄³⁻, ↑ PTH | ↑ Ca²⁺, ↑ PO₄³⁻ absorption |
| | | Inhibited by ↑ serum PO₄³⁻, ↓ PTH | |
| **Calcitonin** | Thyroid C cells | Stimulated by ↑ Ca²⁺, pentagastrin | ↓ Ca²⁺ (pharmacologic doses) |
| **Mg²⁺** | Major intracellular divalent cation | Cofactor for PTH secretion | - |
| **PO₄³⁻** | Intracellular anion | See Nephrology, NPT3 | - |

### PTH 調控圖示

```
UV light → Vitamin D₃ → 25-OH vitamin D → [Kidney] → 1,25-(OH)₂D₃ (Calcitriol)
                                              ↑
                                        1-α-hydroxylase
                                              ↑
                                        ← PTH ↑ ← Ca²⁺ ↓
                                              ↓
                                     [Bone] → Ca²⁺ release ↑ (via osteoclast)
```

## 高血鈣 (Hypercalcemia)

### 定義

- **Total corrected serum Ca²⁺ > 2.6 mmol/L**
- **Ionized Ca²⁺ > 1.35 mmol/L**

### 臨床表徵

高血鈣的經典症狀：**"Bones, stones, groans, and psychiatric overtones"**

| 系統 | 症狀 |
|------|------|
| **Cardiovascular** | HTN, Arrhythmia, Short QT |
| **GI** | Constipation, Anorexia, Nausea, Vomiting, PUD, Pancreatitis |
| **Renal** | Polyuria (Nephrogenic DI), Polydipsia, Nephrolithiasis, Renal failure |
| **Rheumatological** | Gout, Pseudogout, Chondrocalcinosis |
| **MSK** | Weakness, Bone pain |
| **Psychiatric** | Anxiety, Depression, Cognitive dysfunction, Psychosis |
| **Neurologic** | Hypotonia, Hyporeflexia, Paresis, Myopathy |

### Hypercalcemic Crisis

- 通常 Ca²⁺ > 4 mmol/L
- 主要症狀：oliguria/anuria、mental status changes、somnolescence、coma
- **屬於醫療緊急情況，需立即治療！**

### 鑑別診斷

**Step 1**：PTH 高或低？

| PTH 正常或升高 | PTH 低 |
|----------------|--------|
| Primary hyperparathyroidism | PTHrP 相關（ malignancy） |
| Familial hypocalciuric hypercalcemia (FHH) | Vitamin D 相關 |
| Tertiary hyperparathyroidism | Granulomatous disease |
| Lithium | Immobilization |
| Thiazide diuretics | |

**Step 2**：若 PTH 低，phosphate 高或低？

| PO₄³⁻ 正常或升高 | PO₄³⁻ 低 |
|------------------|----------|
| PTHrP, Humoral mediation | Vitamin D deficiency |
| Granulomatous disease | |
| Milk-alkali syndrome | |

### 治療

**輕度（< 3.0 mmol/L）**：通常無症狀，不需緊急校正

**中度（3.0-3.5 mmol/L）**：視症狀而定，通常需要治療

**重度（> 3.5 mmol/L）**：需緊急校正，預防心律不整和昏迷

#### 急性高血鈣治療

| 治療方式 | 藥物/劑量 | 注意事項 |
|----------|----------|----------|
| **靜脈輸液** | Isotonic saline (4-6 L over 24h) | 首選治療 |
| **Furosemide** | 20-40 mg IV q12h | 僅用於 volume overload，維持尿量 > 200 mL/h |
| **Calcitonin** | 4-8 IU/kg SC q12h | 48小時內有效，可能產生 tachyphylaxis |
| **Bisphosphonates**（首選） | Zoledronic acid 4 mg IV 或 Pamidronate 60-90 mg IV | 4-48小時後見效 |
| **Corticosteroids** | 適用於 Vitamin D 過量、granulomatous disease | 抑制 1-α-hydroxylase |
| **Dialysis** | 最後手段 | 適用於嚴重 malignancy 相關高血鈣合併腎功能不全或心衰竭 |

> ⚠️ **使用 Calcitonin 前請詢問是否有魚類過敏**

## 低血鈣 (Hypocalcemia)

### 定義

- **Total corrected serum Ca²⁺ < 2.2 mmol/L**
- **輕度**：serum Ca²⁺ < 1.9 mmol/L，ionized Ca²⁺ > 0.8 mmol/L
- **重度**：serum Ca²⁺ < 1.9 mmol/L 和/或有症狀

### 臨床表徵

**急性低血鈣**：
- **感覺異常**：perioral、hands、feet
- **Chvostek's sign**：敲擊面神經引起眼輪匝肌痙攣
- **Trousseau's sign**：血壓袖充氣超過收縮壓引起腕痙攣
- **Tetany**
- **Laryngospasm**
- **Seizures**

**慢性低血鈣**：
- CNS：lethargy、seizures、psychosis、Parkinson's、basal ganglia calcification
- CVS：prolonged QT → Torsades de pointes
- GI：steatorrhea
- ENDO：impaired insulin release
- Skin：dry、scaling、alopecia、brittle nails
- Ocular：cataracts
- MSK：muscle weakness

### 鑑別診斷流程

**Step 1**：PTH 高或低？

| PTH 正常或升高 | PTH 低 |
|----------------|--------|
| Vitamin D related | Hypoparathyroidism |
| Chronic kidney disease | Post-thyroidectomy |
| Pseudohypoparathyroidism | Infiltrative disease |
| Mg²⁺ 低 | Idiopathic/autoimmune |

### 治療

**輕度無症狀**：
- Calcium supplementation：elemental calcium 1 g → 500 mg PO TID

**重度有症狀**（屬於醫療緊急情況）：
- IV calcium gluconate 1-2 g over 10-20 min → slow infusion
- 若有 Chvostek's/Trousseau's sign 或 seizures：先給予 1 amp IV push，再給 Ca²⁺ IV drip at 1-2 mg/kg/h

**維生素 D 補充**：
- 需用 1,25 vitamin D（若 PTH 低，如 hypoparathyroidism）
- 需同時治療低鎂血症，否則鈣無法恢復正常

**目標**：Hypoparathyroidism 患者，將 Ca²⁺ 維持在 low normal range (2.0-2.1 mmol/L)

## Metabolic Bone Disease

### 骨質疏鬆症 (Osteoporosis)

#### 定義

- 骨質流失伴隨微觀結構惡化，導致骨折風險增加
- **BMD T-score ≤ -2.5** 確診骨質疏鬆
- **Osteopenia**：T-score between -1.0 and -2.5

#### 病因

**藥物**：
- Glucocorticoid steroids
- Aromatase inhibitors
- Anticonvulsants
- GnRH agonists/antagonists
- Androgen-deprivation agents

**內分泌疾病**：
- Hyperparathyroidism
- Hyperthyroidism
- Hypercortisolism/Cushing's syndrome
- Diabetes mellitus

**其他**：
- Rheumatoid arthritis
- IBD、Celiac disease
- Multiple myeloma
- Chronic kidney disease

#### 臨床表徵

- 通常無症狀
- 身高下降（脊椎壓迫性骨折）
- 骨折：hip、vertebrae、humerus、wrist 最常見
- Kyphosis
- Fragility fractures（跌倒或站立高度以下摔倒造成的骨折）

#### 診斷流程

1. **風險評估**：病史和身體評估
2. **BMD 檢測**：DEXA（男性和停經後女性 > 70 歲，或較年輕但有風險因子）
3. **實驗室檢查**：Ca²⁺、phosphate、creatinine、ALP、TSH、SPEP、25-OH vitamin D
4. **10 年骨折風險**：使用 FRAX 或 CAROC

#### BMD 檢測適應症

| 年齡/族群 | 適應症 |
|----------|--------|
| 50-64 歲 | 有骨質疏鬆相關骨折史或 ≥2 個臨床風險因子 |
| ≥ 65 歲 | 有 ≥1 個臨床風險因子 |
| ≥ 70 歲 | 無特殊條件 |

#### 骨折風險分層

| 風險等級 | 標準 |
|----------|------|
| **Low** | 10 年骨折風險 < 15% 且所有 T-score > -2.5 |
| **Medium** | 10 年骨折風險 15-19.9% 或任何 T-score < -2.5 且年齡 < 70 |
| **High** | 10 年骨折風險 > 20% 或任何 T-score < -2.5 且年齡 > 70 |

#### 治療

**生活型態**：
- Calcium：1000 mg/day（51-70 歲男性）、1200 mg/day（停經後女性和 > 70 歲男性）
- Vitamin D：600-800 IU/day
- Exercise：平衡訓練每週 2 次 + 阻力訓練每週 2 次
- 戒菸、減少咖啡因

**藥物治療**：

| 藥物類別 | 代表藥物 | 作用 |
|----------|----------|------|
| **Bisphosphonates** | Alendronate、Risedronate、Zoledronic acid | 抑制蝕骨細胞 |
| **RANKL Inhibitors** | Denosumab | 抑制蝕骨細胞形成 |
| **PTH Analogue** | Teriparatide | 刺激骨質生成 |
| **Sclerostin Inhibitors** | Romosozumab | 增加骨質生成 |

**停經後女性特殊治療**：
- **SERM**：Raloxifene（預防脊椎骨折）
- **HRT**：雌激素/黃體素合併治療

> ⚠️ **Denosumab 不應突然停用**，否則有 multiple vertebral fractures 風險

### 軟骨病 (Osteomalacia) 與佝僂症 (Rickets)

#### 定義

- Osteomalacia：Osteopenia 合併 disordered calcification，導致 osteoid（未礦化骨基質）比例增加
- Rickets：發生於生長板閉合前（孩童時期）
- Osteomalacia：發生於成年人

#### 病因

**維生素 D 缺乏**：
- 攝取不足或吸收不良
- 肝臟疾病（25-hydroxylation 缺陷）
- 腎臟疾病（1-α-hydroxylation 缺陷）
- Nephrotic syndrome（vitamin D binding protein 流失）
- Anticonvulsant therapy

**礦化缺陷**：
- Osteogenesis imperfecta
- Hypophosphatasia

**鈣缺乏**：
- 營養不足
- 吸收不良

**低磷血症**：
- GI：攝取不足、慢性腹瀉
- Renal phosphate wasting：tumour-induced osteomalacia、Fanconi syndrome、X-linked hypophosphatemic rickets

#### 臨床表徵

| Rickets | Osteomalacia |
|---------|--------------|
| 骨骼疼痛和變形、O 型腿 | 不如 Rickets 嚴重 |
| 骨折易感性 | 瀰散性骨骼疼痛 |
| 軟弱和張力減退 | 骨折 |
| 生長障礙 | 步態異常（搖擺） |
| Rachitic rosary（肋軟骨交界處突出） | 近端肌肉無力 |
| Harrison's groove（肋骨下緣凹陷） | 張力減退 |
| 低血鈣 | |

#### 實驗室發現

| 疾病 | 血清 Phosphate | 血清 Calcium | 血清 ALP | 其他 |
|------|----------------|-------------|----------|------|
| Vitamin D 缺乏 | ↓ | ↓ 至正常 | ↑ | Calcitriol 可能降低 |
| 低磷血症 | ↓ | 正常 | ↑ | |
| 近端腎小管酸中毒 | ↓ | 正常 | 正常 | 高氯性代謝性酸中毒 |
| 異常基質形成 | 正常 | 正常 | 正常 | |

#### 治療

- 維生素 D 補充
- Phosphate 補充（若血清 PO₄³⁻ 低）
- Calcium 補充（單純鈣缺乏）
- Bicarbonate（慢性代謝性酸中毒）

### 腎性骨病變 (Renal Osteodystrophy)

#### 定義

- CKD 引起的礦物質代謝和骨骼結構改變
- 混合四種類型的骨病：
  - **Osteomalacia**：低骨周轉率 + osteoid 增加
  - **Adynamic bone disease**：蝕骨細胞過度抑制
  - **Osteitis fibrosa cystica**：次發性副甲狀腺功能亢進
  - **Mixed uremic osteodystrophy**：高低骨周轉率混合

#### 病理生理

- Hyperphosphatemia（抑制 1,25(OH)₂ vitamin D 合成）
- 腎臟 mass 減少（減少 1-α-hydroxylase）

#### 臨床表徵

- 軟組織鈣化
- 骨骼疼痛和骨折
- 搔癢
- 低血鈣時的神經肌肉易感性

#### 治療

- 限制磷酸鹽攝取（≤ 1 g/day）
- Calcium supplements、phosphate binding agents
- Activated vitamin D (calcitriol)
- **注意**：Bisphosphonates 和 denosumab 在低 eGFR 時禁用

### Paget 氏骨病 (Paget's Disease of Bone)

#### 定義

- 代謝性骨骼疾病，特徵為過度的骨骼破壞和修復

#### 流行病學

- 人口中 3%，> 80 歲達 10%
- 建議在 elevated ALP 但正常 GGT 的老年人中考慮此病

#### 病理生理

- 可能與 osteoclasts 的慢病毒感染（可能是副黏液病毒）有關
- 強家族聚集性
- 開始於蝕骨細胞活性增加 → 骨吸收增加 → 骨母細胞活性代償性增加 → 結構異常的新骨形成

#### 臨床表徵

- 通常無症狀（常規 X 光或 elevated ALP 發現）
- **三個特徵性發現**：osteolytic lesions、cortical thickening、pseudofractures
- 最常影響：skull、thoracolumbar spine、pelvis、下肢長骨
- 嚴重骨骼疼痛
- 骨骼變形：bowed tibias、kyphosis、頻繁骨折
- Osteosarcoma 和 giant cell tumors 風險增加

#### 診斷

**實驗室**：
- 血清 ALP 高，Ca²⁺ 正常或高，PO₄³⁻ 正常
- Procollagen type I N-terminal propeptide (PINP) 升高

**影像**：
- X 光：確診所需
- 骨掃描：評估疾病範圍

#### 治療

**目標**：減少疼痛、降低重建率

**藥物治療**（若有症狀或 ALP > 3x normal）：
- **Bisphosphonates**：Zoledronic acid 5 mg IV/年（首選）、Alendronate 40 mg PO QD × 6 個月、Risedronate 30 mg PO QD × 3 個月
- **Calcitonin**：若無法耐受 bisphosphonates

## 男性生殖內分泌

### 下視丘-腦下垂體-性腺軸

```
下視丘 → GnRH → 腦下垂體前葉 → FSH、LH
                          ↓
                    Sertoli cells → Inhibin → 抑制 FSH
                    Leydig cells → Testosterone → 抑制 LH、 GnRH
```

### 睪丸功能檢查

- **睪丸大小**：正常下限 = 4 cm × 2.5 cm（成人）
- **LH、FSH、total/bioavailable/free testosterone**
- **精液分析**：volume、sperm concentration、morphology、motility
- **睪丸切片**：僅用於 FSH 正常但無精子症/寡精子症

### 男性不孕症

**定義**：規律性交 12 個月未避孕（< 35 歲女性）或 6 個月（≥ 35 歲女性）仍無法懷孕

### Hypogonadism 分類

| 類型 | 定義 | LH/FSH | Testosterone | 精子數 |
|------|------|--------|-------------|--------|
| **原發性** | 睪丸衰竭 | ↑ | ↓ | ↓ |
| **次發性** | 下視丘-腦下垂體軸衰竭 | ↓ 或正常 | ↓ | ↓ |

#### 原發性原因

- 染色體異常（Klinefelter、Noonan）
- Cryptorchidism
- 睪丸發育不良
- 感染（睪丸炎、結核病、腮腺炎）
- 藥物（cannabis、alcohol、chemotherapy）
- 創傷、熱、輻射

#### 次發性原因

- Kallmann's syndrome
- Prader-Willi syndrome
- 下視丘-腦下垂體疾病（腫瘤、hyperprolactinemia、hypopituitarism）
- 全身性疾病（肝硬化、慢性腎衰竭、AIDS）
- 藥物

### Testosterone 缺乏診斷

1. **症狀和徵象**：libido 降低、能量減少、情緒改變、肌肉量減少、骨質減少
2. **實驗室確認**： Fasting morning total testosterone < 實驗室參考範圍（需兩次確認）
3. **排除次發性原因**

### 治療

**目標**：睾酮替代（改善 libido、肌肉量、力量、骨量）

**禁忌症**：
- 前列腺或乳癌
- Palpable prostate nodule
- PSA > 4 ng/mL
-  elevated hematocrit
- 未治療的嚴重 OSA
- 過去 6 個月有 MI 或 stroke

**注意**：Testosterone 治療會抑制 spermatogenesis，影響生育能力

**若目標為生育**：
- 治療根本原因
- GnRH agonist（若下視丘功能障礙）
- hCG + rFSH（若下視丘或腦下垂體病灶）
- Dopamine agonist（若有 prolactinoma）
- TESE 或 MICROTESE

### 男性女乳症 (Gynecomastia)

#### 定義

- 男性乳房良性增殖，形成乳頭周圍同心圓狀、橡膠感的硬塊

#### 病因

- **生理性**：新生兒、青春期、老年男性
- **藥物**：Spironolactone、Cimetidine、Digoxin、Ketoconazole、hCG、Estrogens、Antiandrogens、Anabolic steroids
- **疾病**：Hypogonadism、肝硬化、CKD、甲狀腺功能亢進
- **腫瘤**：睪丸/生殖細胞腫瘤

#### 治療

- 多數男性初始觀察（停用致病藥物、治療根本原因）
- **藥物**：Tamoxifen（證據最充分）
- **手術**：長期（> 12 個月，纖維化）、不適或心理困擾

## Paraneoplastic Syndrome

### 定義

- 伴随惡性疾病的非轉移性全身效應的臨床症候群
- 由於針對腫瘤的抗體與正常組織交叉反應，或腫瘤產生生理活性物質

### 常見相關惡性腫瘤

- Lung、Breast、Ovarian、Lymphatic system cancer

### 臨床表徵

| 症候群類型 | 症狀 | 相關惡性腫瘤 | 機轉 |
|-----------|------|-------------|------|
| **Cushing's syndrome** | 體重增加、近端肌肉無力、easy bruising | Small cell lung cancer、Pancreatic carcinoma | Ectopic ACTH |
| **SIADH** | 低血鈉、噁心、頭痛、意識模糊 | Small cell lung cancer | ADH 分泌 |
| **Hypercalcemia** | 「石頭、骨頭、腹部抱怨、精神症狀」 | Lung cancer、Breast carcinoma、Renal cell carcinoma | PTHrP、TGF-α、TNF |
| **Hypoglycemia** | 心悸、頭痛、顫抖、盜汗、頭暈 | Hepatocellular carcinoma、 Fibrosarcoma | Insulin 或 insulin-like 物質 |
| **Carcinoid** | 潮紅、腹瀉、呼吸困難、心悸 | GI neuroendocrine tumors | Serotonin、Bradykinin |
| **Lambert-Eaton** | 四肢肌肉無力 | Small cell lung cancer | Ab 干擾 ACh 釋放 |
| **Erythrocytosis** | - | Renal cell carcinoma、Hepatocellular carcinoma | Erythropoietin |

### 治療

- **治療根本腫瘤**：手術、放療、化療
- **免疫介導疾病**：IVIG、Steroids、immunosuppressive drugs、plasmapheresis

### 糖尿病預防

| 試驗 | 結果 |
|------|------|
| **DPP** | Lifestyle 干預減少 58% 糖尿病發生率；Metformin 減少 31% |
| **Look AHEAD** | Intensive lifestyle intervention 未顯著減少 CV events |

| 試驗 | 主要發現 |

## 重要參考數值

### 血糖診斷標準

| 診斷 | 標準 |
|------|------|
| **Normal** | FPG < 5.6 mmol/L |
| **IFG** | FPG 5.6-6.9 mmol/L |
| **IGT** | 2h PG 7.8-11.0 mmol/L |
| **Diabetes** | FPG ≥ 7.0 mmol/L 或 2h PG ≥ 11.1 mmol/L 或 HbA1c ≥ 6.5% |

### 骨質疏鬆治療閾值

| 風險等級 | 10 年骨折風險 | 建議 |
|----------|---------------|------|
| Low | < 15% | 可能不需藥物治療 |
| Medium | 15-19.9% | 考慮治療 |
| High | ≥ 20% | 建議治療 |

### 甲狀腺功能

| 狀態 | TSH | fT4 | fT3 |
|------|-----|-----|-----|
| **正常** | 0.4-4.0 mIU/L | 12-22 pmol/L | 3.5-6.5 pmol/L |
| **原發性甲狀腺低下** | ↑ | ↓ | ↓ |
| **原發性甲狀腺亢進** | ↓ | ↑ | ↑ |

### Diabetic Emergencies

**DKA 診斷標準**：
- 血糖 > 13.9 mmol/L
- 血漿 bicarbonate < 15 mmol/L
- pH < 7.3
- Anion gap > 12

**HHS 診斷標準**：
- 血糖 > 33.3 mmol/L
- 血漿 osmolality > 320 mOsm/kg
- 無顯著 ketoacidosis
