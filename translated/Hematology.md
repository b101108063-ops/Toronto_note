# Hematology 血液學

> Toronto Notes 2025 - Hematology 章節

## 導讀摘要

- **貧血（Anemia）**：依 MCV 分類（Microcytic/Normocytic/Macrocytic）；包括 Iron deficiency anemia、Anemia of chronic disease、Thalassemia、Sickle cell disease、Megaloblastic anemia；診斷流程與治療原則
- **凝血障礙（Coagulation Disorders）**：原發性止血障礙（ITP、HIT、von Willebrand disease）與續發性止血障礙（Hemophilia、DIC）；Virchow's Triad 與靜脈血栓栓塞症（VTE）
- **血液惡性腫瘤**：Myeloid malignancy（AML、MDS、MPNs）與 Lymphoid malignancy（ALL、HL、NHL、MM）；症狀、診斷、分期與治療
- **血球異常**：Thrombocytopenia、Thrombocytosis、Pancytopenia、Neutropenia、Neutrophilia；涵蓋紅血球增多症（Erythrocytosis）
- **輸血醫學**：Blood products 種類與適應症、輸血反應處置、Tumor lysis syndrome

## 血液學概論（Introduction to Hematology）

### 血液學範疇

血液學（Hematology）涵蓋血液及造血器官疾病的診斷與治療，包括：

- **紅血球疾病**：Anemia、Erythrocytosis
- **白血球疾病**：Neutropenia、Neutrophilia、Leukemia、Lymphoma
- **血小板及凝血疾病**：Thrombocytopenia、Thrombocytosis、Coagulation disorders、Thrombophilia
- **造血系統腫瘤**：Myeloproliferative neoplasms、Lymphoproliferative disorders

### 血液學診斷工具

| 檢驗項目 | 臨床意義 |
|:---------|:---------|
| CBC with differential | 評估各血球數值、MCV、MCH、MCHC |
| Peripheral blood film | 觀察紅血球、白血球、血小板形態 |
| Reticulocyte count | 區分生成減少與破壞增加的貧血 |
| Coagulation studies | PT/INR、aPTT、Fibrinogen、D-dimer |
| Bone marrow biopsy | 確診白血病、骨髓增生異常、淋巴瘤 |
| Flow cytometry | 免疫分型診斷白血病與淋巴瘤 |
| Cytogenetics/FISH | 染色體異常與基因突變分析 |

## 貧血（Anemia）

### 定義

+ RBC mass 減少，可由 Hb concentration、Hct、RBC count 檢測出來
  - Adult males：Hb <130 g/L 或 Hct <38%
  - Adult females：Hb <120 g/L 或 Hct <37%（懷孕及孕期階段有變化）

### 臨床表現

**病史詢問**：
- Anemia 症狀：fatigue、headache、light-headedness、malaise、weakness、decreased exercise tolerance、dyspnea、palpitations、dizziness、tinnitus、syncope
- 急性 vs. 慢性、失血、系統性疾病、旅遊史、用藥史、飲食（Fe、B12 來源）、酒精、家族史
- Hemolysis 症狀：jaundice、icterus
- 月經史：menorrhagia、menometrorrhagia
- 排除 pancytopenia（復發性感染、黏膜出血、容易瘀青）

**理學檢查**：
- HEENT：Hb <90 g/L 時黏膜與結膜蒼白；Hb <55 g/L 時眼眶雜音；angular cheilitis；jaundice
- 心臟：tachycardia、orthostatic hypotension、systolic flow murmur、wide pulse pressure、CHF 徵象
- 皮膚：ecchymosis、petechiae、Hb <75 g/L 時掌紋蒼白、hemolysis 導致 jaundice、指甲變化（spooning）、glossitis
- 脾臟與淋巴結：splenomegaly、lymphadenopathy

### 診斷檢查

+ 排除稀釋性貧血（循環容量增加導致 Hb 降低）

+ **CBC with differential、reticulocyte count、blood film**

+ 排除營養缺乏：Iron deficiency anemia 需檢查胃腸道與泌尿生殖道疾病

+ 視情況進行 additional laboratory investigations（見各貧血亞型章節）

+ **注意**：可能同時有多種營養缺乏，導致混合型貧血

### 治療原則

+ 治療根本原因（見各貧血亞型章節）

### 網狀紅血球（Reticulocytes）

Reticulocytes 是未成熟的紅血球，是紅血球生成的指標。

**判讀要點**：
- Reticulocyte count 應結合 Hb concentration 一起判讀
- 正常情況下，RBC 減少時 reticulocytes 會增加
- 失血後：初始增加 2-3 倍，隨後一週內增加 5-7 倍
- 貧血時 reticulocyte count 正常應視為生成減少的徵象，可能原因為 BM infiltration、營養缺乏或其他原因
- 貧血合併 reticulocytosis 提示骨髓有適當反應

## 紅血球增多症（Erythrocytosis）

### 定義

+ Hb 及/或 Hct 增加：Males Hb >165 g/L 或 Hct >49%；Females Hb >160 g/L 或 Hct >48%

### 病因分類

**Table 1. Erythrocytosis 的病因**

| 類型 | 病因 |
|:-----|:-----|
| **原發性** | Polycythemia Vera（見 PV 章節） |
| **繼發性（生理性缺氧）** | CO poisoning、Heavy smoking、High altitude、Pulmonary disease（COPD）、Sleep apnea、Pulmonary hypertension、Cardiovascular disease（右向左分流，如 Eisenmenger syndrome）、Hemoglobinopathy（High-affinity Hb、Methemoglobinemia） |
| **紅血球生成素不當分泌** | 腫瘤（Hepatocellular carcinoma、Renal cell carcinoma、Cerebellar hemangioblastoma、Pheochromocytoma、Uterine leiomyoma、Ovarian tumour）、Polycystic kidney disease、Renal artery stenosis、Post-kidney transplant、Androgens、EPO |
| **相對性/假性** | 利尿劑、嚴重脫水、燒傷、"Stress"（Gaisböck's syndrome） |

### 臨床表現

+ 高紅血球 mass 與高血液黏滯度導致：
  - Headache、Dyspnea、Dizziness、Tinnitus、Visual disturbances、Hypertensive symptoms、Paresthesia
  - 心絞痛、CHF、Aquagenic pruritus 症狀（僅見於 MPNs）
+ 血栓（靜脈或動脈）或出血（MPNs 合併 acquired VWD 或 acquired platelet dysfunction）
+ 理學發現：Splenomegaly + hepatomegaly、面部發紺/紅潤（70%）或掌心發紅、Gout

### 診斷檢查

+ **血清 EPO**：區分原發性（低/正常）與其他病因（升高）
  - 視情況搜尋腫瘤作為 EPO 來源（如腹部 U/S、CT head）
+ **JAK-2 mutation 分析**：PV 病例中 >96% 為陽性
  - 僅在 EPO 低/正常時送檢
+ **Ferritin**：Iron deficiency 可能掩盖診斷；Iron deficiency 合併 reticulocytosis 提示 PV

### 治療

+ **原發性**：見 Polycythemia Vera 章節
+ **繼發性**：治療根本原因
  - 缺氧：CPAP 治療 sleep apnea、腫瘤手術切除、戒菸諮詢、避免職業暴露、Androgen 治療使用最低劑量
  - 有症狀且 Hct >55%：考虑 phlebotomy
  - Cyanotic heart disease 患者的高 Hct，心臟科醫師通常會保守處理

## 血小板減少症（Thrombocytopenia）

### 定義

+ Platelet count <150 × 10⁹/L

### 臨床表現

+ **病史**：Mucocutaneous bleeding（容易瘀青、齒齦出血）、Epistaxis、術後出血（包括牙科處置）、月經過多、圍產期出血、GI bleeding
+ **理學檢查**：Bruising、Petechiae、Ecchymoses、Non-palpable purpura、Wet purpura

### 診斷檢查

+ **CBC and differential**
+ **Blood film**
  - 排除 pseudothrombocytopenia（platelet clumping 或 platelet satellitism）
  - 生成減少：其他血球系異常、Blasts（提示 myeloid malignancy）、Hypersegmented PMNs（提示 megaloblastic anemia）、Leukoerythroblastic changes（提示 BM infiltration 或 fibrosis）
  - 破壞增加：Large platelets（常見於 ITP）、Schistocytes（見於 MAHA/TMA）
+ **營養缺乏檢查**：B12、RBC folate
+ **懷疑 DIC**：PT/INR、aPTT、Fibrinogen
+ **肝臟疾病**：LFTs

**經驗法則**：
- 所有血球系減少 → 生成減少、sequestration 或 hemodilution
- 血小板和 RBC 減少 → 非免疫性破壞或 Evan's syndrome
- 單獨血小板減少 → 免疫媒介process
- 住院患者：藥物與感染是最常見原因

### 治療

+ **危及生命的出血**：Platelet transfusion（輸注後 1 小時重複 CBC 確認計數上升）
+ **繼發性**：治療根本原因
+ ITP：見 Immune Thrombocytopenia 章節
+ HIT：見 HIT 章節

## 血小板增多症（Thrombocytosis）

### 定義

+ Platelet count >450 × 10⁹/L

### 病因分類

+ **原發性血小板增多（罕見）**：MPNs 引起（如 CML、PV、Primary MF、ET；少見於 MDS）
+ **反應性/次發性血小板增多（常見）**：急性期反應（手術、發炎、感染、外傷、出血、Iron deficiency、腫瘤、缺血性損傷、Hyposplenia/Asplenia）

### 臨床表現

+ **病史**：外傷、手術、脾切除、感染、發炎、出血、Iron deficiency、慢性血液疾病病史、 constitutional symptoms（恶性肿瘤）
+ **血管運動症狀**：Headache、Visual disturbances、Lightheadedness、Atypical chest pain、Acral dysesthesia、Erythromelalgia、Livedo reticularis、Aquagenic pruritus
+ 血栓風險、出血風險（罕見）
+ **理學檢查**：MPNs 患者常見 splenomegaly

### 診斷檢查

+ CBC and differential、Peripheral blood film、Serum ferritin
+ 發炎或感染的非特異標記（CRP、ESR、Ferritin）
+ 排除反應性過程後，可能需要 BM biopsy 排除 MPN/MDS

### 治療

+ **原發性**：Aspirin + Cytoreductive agents（hydroxyurea、anagrelide、interferon-α）
+ **次發性**：治療根本原因

## 全血球減少症（Pancytopenia）

### 定義

+ 所有造血細胞系低於正常參考範圍

### 臨床表現

+ **Anemia**：Fatigue（見 Anemia 章節）
+ **Leukopenia**：復發性感染（見 Neutropenia 章節）
+ **Thrombocytopenia**：Mucocutaneous bleeding（見 Thrombocytopenia 章節）

### 診斷檢查

+ CBC and differential、Peripheral blood film、Serum ferritin、Reticulocyte count、PT、PTT、Blood type and screen、Complete metabolic panel、B12、Folate
+ 發炎或感染的非特異標記
+ 視臨床症狀與理學檢查進行檢查
+ 排除次發性過程後，可能需要 BM biopsy

---

## 嗜中性球增多症（Neutrophilia）

### 定義

+ Variable definition，一般 ANC >7.7 × 10⁹/L（WHO 定義）

### 病因分類

**Table 2. Neutrophilia 的病因**

| 類型 | 病因 |
|:-----|:-----|
| **原發性** | CML、Chronic neutrophilic leukemia、其他 MPNs（PV、ET、MF）、Hereditary neutrophilia（自體顯性）、Chronic idiopathic neutrophilia、Leukocyte adhesion deficiency |
| **繼發性** | Stress/運動/Epinephrine：neutrophils 從 marginated pool 移至循環池；肥胖；感染；發炎（RA、IBD、Chronic hepatitis、MI、PE、Burns）；惡性腫瘤（骨髓侵犯或實體腫瘤，尤其大細胞肺癌）；藥物（glucocorticoids、β-agonists、Lithium、G-CSF） |

### 臨床表現

+ 評估發燒、發炎、惡性腫瘤症狀以決定進一步檢查（包括 LAD 與 organomegaly）
+ 檢查口腔、牙齒、肛門周圍、生殖器、皮膚是否有感染跡象

### 診斷檢查

+ CBC and differential：Mature neutrophils 或 bands >20% 提示感染/發炎
+ Blood film：Left shifted WBCs、Döhle bodies（由聚集核糖體組成的胞質內結構）、Toxic granulation、Cytoplasmic vacuoles（感染時）
+ 疑似 MPN 時可能需要 BM biopsy

### 治療

+ 針對根本原因治療

## 嗜中性球減少症（Neutropenia）

### 定義

| 程度 | ANC |
|:-----|:----|
| 輕度 | 1.0-1.5 × 10⁹/L |
| 中度 | 0.5-1.0 × 10⁹/L（感染風險開始增加）|
| 重度 | <0.5 × 10⁹/L |
| 極重度 | <0.1 × 10⁹/L 超過 >7 天 |

**ANC 計算**：ANC = WBC count × (%PMNs + %Bands)

**注意**：發燒合併 ANC <0.5 × 10⁹/L = **febrile neutropenia**，需要緊急處理

### 病因分類

**Table 3. Neutropenia 的病因**

| 生成減少 | 破壞/隔離增加 | 過度邊緣化（短暫性）|
|:---------|:-------------|:-------------------|
| **感染**：Viral hepatitis、EBV、HIV、TB、Typhoid、Malaria | **自體免疫疾病**：RA（Felty syndrome）、SLE、Granulomatosis with polyangiitis | **藥物**：Haptens（如 α-methyldopa）|
| **血液疾病**：Idiopathic、Aplastic anemia、MF、BM infiltration、Cyclic、PNH、MDS、Large granular lymphocyte leukemia、Hairy cell leukemia、Immune mediated | **脾臟或肺臟滯留** | **Hemodialysis** |
| **藥物引起**：Alkylating agents、Antimetabolites、Anticonvulsants、Antipsychotics、Anti-inflammatory agents、Antithyroid drugs | **特發性（最常見）** | |
| **毒素/化學物質**：High dose radiation、Benzene、DDT | **過度使用性細菌感染** | |
| **營養缺乏**：B12、Folate | | |
| **特發性**：Constitutional neutropenia、Benign cyclic neutropenia | | |

### 治療

+ 針對根本原因治療
+ 重度/極重度 neutropenia：見 Neutropenic Fever 章節（感染科）

## 微小球性貧血（Microcytic Anemia）

+ MCV <80 fL
+ 常見原因：**Iron deficiency**、Anemia of chronic disease、Thalassemia、Sideroblastic anemia、Lead poisoning

### 鐵缺乏性貧血（Iron Deficiency Anemia）

**病因**：
- 慢性失血（月經、GI bleeding、泌尿道失血）
- 攝取不足（營養不良、素食主義者）
- 吸收不良（Celiac disease、Inflammatory bowel disease、Gastric bypass）
- 需求量增加（懷孕、兒童生長發育期）

**臨床表現**：
- Anemia 一般症狀（見 H6）
- Plummer-Vinson syndrome（舔炎、口腔黏膜萎縮、匙狀甲）
- 反甲（Koilonychia）

**診斷檢查**：
+ **血清鐵蛋白（Ferritin）**：診斷 iron deficiency 最敏感的單一指標
  - 低 ferritin（<30-45 μg/L）確診 iron deficiency
  - 注意：Ferritin 是急性期發炎蛋白，發炎/感染/惡性腫瘤時可能正常或升高
+ **血清鐵（Serum iron）**、**TIBC**、**轉鐵蛋白飽和度（Transferrin saturation）**
  - Iron deficiency：Low serum iron、High TIBC、Low transferrin saturation
+ **網狀紅血球**：生成減少時降低
+ **糞便潛血反應**：排除 GI bleeding
+ **排除其他原因的微小球性貧血**：見 Table 4

**Table 4. 微小球性貧血的鑑別診斷**

| 參數 | Iron Deficiency | Anemia of Chronic Disease | Thalassemia | Sideroblastic |
|:-----|:----------------|:--------------------------|:------------|:--------------|
| MCV | 降低 | 正常/輕度降低 | 降低 | 降低 |
| Ferritin | 降低 | 正常/升高 | 正常/升高 | 正常/升高 |
| 血清鐵 | 降低 | 降低 | 正常 | 升高 |
| TIBC | 升高 | 降低 | 正常 | 正常 |
| Transferrin saturation | 降低 | 降低/正常 | 正常 | 升高 |

**治療**：
+ **口服鐵劑**：
  - Ferrous sulfate 325 mg QD（65 mg elemental iron）、Ferrous gluconate 300 mg QD（35 mg elemental iron）、Ferrous fumarate 300 mg QD（100 mg elemental iron）、Polysaccharide iron complex 150 mg、Heme iron polypeptide 11 mg
  - 補充至 anemia 恢復，然後繼續治療 3+ 個月直至血清 ferritin 恢復正常
  - 最近研究顯示 alternate day vs. daily dosing 差異不顯著，選擇應以病人偏好為主
  - 口服鐵劑一日多次無益處：會導致 hepcidin 上調、吸收減少、副作用增加而無臨床效益
+ **靜脈鐵劑**：用於無法耐受或吸收口服鐵、需快速康復者（如口服鐵無法控制的慢性出血）
+ **監測療效**：
  - Reticulocyte count 一週後開始增加
  - Hb 每週增加 10 g/L（若無失血）

### 慢性病貧血（Anemia of Chronic Disease）

**又稱**：Anemia of inflammation

**病因**：
- 感染、惡性腫瘤、發炎性、風濕性疾病
- 慢性腎病與肝病
- 內分泌疾病（Diabetes mellitus、甲狀腺功能減退、性腺功能減退、腦下垂體功能減退）

**病理生理學**：
- Hepcidin 是關鍵調節肽，肝臟在發炎過程中增加 hepcidin 產生
- Hepcidin 透過抑制 ferroportin 將鐵困在腸細胞與巨噬細胞中
- 血漿鐵相對不足，無法供新的 Hb 合成使用
- 骨髓對正常或輕度升高的 EPO 無反應
- 常伴有輕度 hemolytic component（RBC 存活輕度減少）

**診斷檢查**：
+ 排除性診斷
+ 急性期發炎標記升高（ESR、CRP、Fibrinogen、Platelets）
+ **周邊血液**：
  - 輕度：通常 normocytic 和 normochromic
  - 中度：可能微小球性和 normochromic
  - 重度：可能微小球性和 hypochromic
  - 絕對 reticulocyte count 通常偏低，反映 RBC 生成整體減少
+ **經典型血清鐵指數**：見 Table 10
+ **骨髓**：
  - 鐵儲存正常或增加
  - 紅血球前驅細胞的鐵染色減少或缺如

**治療**：
+ 治療根本疾病；僅在 Hb 較高對患者有益時治療
+ 若 PO 鐵無效，使用 IV 鐵（在 CKD 伴 EPO 使用時）
+ EPO 適用於慢性腎衰竭；確保 Hb 目標 <110 g/L（目標較高會增加血管事件/缺血性中風風險）

### 鐵粒幼紅血球性貧血（Sideroblastic Anemia）

**定義**：
- 因紅血球前驅細胞中 heme 生合成缺陷導致
- 骨髓中鐵以異常大的顆粒圍繞細胞核（環狀鐵粒幼紅血球）

**病因**：
- **遺傳性（罕見）**：X-染色體連鎖；中位存活 10 年
- **特發性（後天）**：
  - Refractory anemia with ringed sideroblasts（MDS 的亞型）
  - 可能為白血病前期現象（1-2% 轉化為 AML）
- **可逆性**：Isoniazid、Chloramphenicol、酒精、鉛、銅缺乏、Zinc toxicity、甲狀腺功能減退

**臨床表現**：
- Anemia 症狀（見 H6）
- 肝脾腫大

**診斷檢查**：
+ 血清鐵指數：見 Table 10
+ CBC and blood film
  - Ring sideroblasts（診斷特異性標誌）
  - RBCs hypochromic；可為 micro-、normo- 或 macrocytic
  - Anisocytosis、Poikilocytosis、Basophilic stippling
+ BM biopsy

**治療**：
+ 依病因治療
  - X-染色體連鎖：部分病例高劑量 pyridoxine（維生素 B6）
  - 後天型：EPO 和 G-CSF
  - 可逆性：去除誘發因素
+ 嚴重貧血時支持性輸血
+ 監測 Iron overload（無效紅血球生成和/或輸血驅動）

### 鉛中毒（Lead Poisoning）

**定義/病因**：
+ Blood lead levels >80 μg/dL，症狀可能在 50 μg/dL 出現
+ 確認來源：職業史、暴露史、器具史

**臨床表現**：
+ Pallor、Abdominal pain、Constipation、Irritability、專注力困難

**治療**：
+ 螯合治療：Dimercaprol 和 EDTA 一線用藥

**鉛中毒特徵（LEAD）**：
- **L**：Lead lines on gingivae and epiphyses of long bones on X-ray
- **E**：Encephalopathy and Erythrocyte basophilic stippling
- **A**：Abdominal colic and microcytic Anemia（sideroblastic）
- **D**：Drops（wrist and foot drop）

## 正球性貧血（Normocytic Anemia）

+ MCV 80-100 fL

### 再生不良性貧血（Aplastic Anemia）

**定義**：
+ 骨髓造血細胞破壞導致 pancytopenia 和 hypocellular marrow

**病因**：

**Table 5. Aplastic Anemia 的病因**

| 先天性 | 後天性 |
|:-------|:-------|
| Fanconi syndrome | 特發性（通常為 T-cell 媒介）|
| Shwachman-Diamond syndrome | 離子輻射 |
| Telomeropathies（dyskeratosis congenita）| 病毒感染（Parvovirus B19、EBV、HDV、HEV、HBV、HHV-6、HIV）|
| | 藥物（劑量相關化療；特異性反應如 chloramphenicol、antimalarials、phenylbutazone）|
| | 毒素（Benzene/有機溶劑、DDT、殺蟲劑）|
| | 自體免疫（SLE、Graft-versus-host disease）|
| | 懷孕、Anorexia nervosa、胸腺瘤 |

**臨床表現**：
+ 可急性或隱匿發病
+ Anemia、Thrombocytopenia、Neutropenia 症狀（見各章節）
+ 依病因可能出現 splenomegaly 和 lymphadenopathy

**診斷檢查**：
+ 排除其他 pancytopenia 原因，包括 PNH（50% aplastic anemia 患者有 PNH）
+ **CBC**：
  - Anemia、Neutropenia 或 Thrombocytopenia（任何組合包括 pancytopenia）
  - Reticulocytes 減少（<總 RBC 的 1%）
+ **Blood film**：正常 RBC 數量減少
+ **BM aspirate and biopsy**：
  - Hypocellular marrow（<25%）細胞減少或發育不全，脂肪組織替代
  - 無惡性細胞浸潤或纖維化證據

**治療**：
+ 去除致病因
+ 支持性照護（RBC 和血小板輸血、抗生素）
  - 審慎使用血液製品以減少免疫敏感化風險
  - 若多次輸血 >20 單位，進行鐵螯合治療
+ 免疫抑制治療（特發性 aplastic anemia）
  - Horse 或 rabbit anti-thymocyte globulin：40-50% 患者有反應
  - Cyclosporine（改善反應與存活）
+ 自體 BM 移植
+ Eltrombopag（TPO 受體激動劑）證實有效；G-CSF 和 EPO 無效

## 溶血性貧血（Hemolytic Anemia）

### 定義

+ 因 RBC 破壞導致壽命縮短（通常 <100 天）的貧血
+ 罕見病因（<5%）但病因眾多（>200 種）

### 分類

**Table 6. Hemolytic Anemia 的分類**

| 類型 | 病因 |
|:-----|:-----|
| **遺傳性** | 膜異常（Spherocytosis、Elliptocytosis）；酶異常（Pyruvate kinase deficiency、G6PD deficiency）；Hb 異常（Hemoglobinopathies）|
| **後天性-免疫性** | 自體免疫：Warm vs. Cold AIHA；同種免疫：胎兒/新生兒溶血病、輸血後溶血 |
| **後天性-非免疫性** | TMA（MAHA）：DIC、HUS、aHUS、TTP、Preeclampsia/HELLP、Vasculitis、Malignant hypertension；其他：PNH、Hypersplenism、March hemoglobinuria（運動性溶血）、感染（如 Malaria）、蛇毒、機械心臟瓣膜 |

### 血管內 vs. 血管外溶血

- **Intravascular**：TMA 和 PNH（補體媒介）
- **Extravascular**：RBCs 被 Ab 覆蓋或膜結構/形狀異常或有包涵體
- 感染可引起血管內（Clostridium）、血管外或兩者（Malaria）

**Blood film 特徵**：Schistocytes 反映血管內溶血；Spherocytes 通常反映血管外溶血

### 臨床表現

+ Jaundice
+ Dark urine（Hemoglobinuria、Bilirubinuria）
+ Cholelithiasis（色素結石）
+ Aplastic crisis 風險（嚴重感染時骨髓抑制）
+ Extravascular hemolysis：Iron overload
+ Intravascular hemolysis：Iron deficiency

### 診斷檢查

**Table 7. Hemolytic Anemia 的檢查**

| 篩檢檢驗 | 血管內溶血的特異檢驗 |
|:---------|:-------------------|
| LDH 升高 | Blood film 上的 Schistocytes（MAHA）|
| Haptoglobin 減少 | 血清游離 Hb |
| 未結合膽紅素升高 | Hemoglobinuria（立即）|
| Urobilinogen 升高 | Hemosiderinuria（延遲）- 最敏感 |
| Reticulocytosis | |

**血管外溶血的特異檢驗**：
- **Direct Antiglobulin Test（Direct Coombs）**：檢測 RBC表面的 IgG 或補體
  - 適應症：新生兒溶血病、AIHA、溶血性輸血反應
- **Indirect Antiglobulin Test（Indirect Coombs）**：檢測血清中能識別 RBC 抗原的 Ab
  - 適應症：捐血者交叉配血、非典型血型、孕婦血型 Ab、AIHA

## 海洋性貧血（Thalassemia）

### 定義

+ α 或 β 鏈 Hb 生產缺陷
+ 球蛋白鏈不平衡導致無效紅血球生成和溶血
- 臨床表徵和治療取決於受影響的特定基因和等位基因數目

**共同特徵**：
- 受影響等位基因越多，嚴重程度越重
- Hypochromic microcytic anemia
- Blood film：Basophilic stippling、形狀異常 RBCs
- CBC：低 MCV、低 Hb、高 RBC 計數、高 reticulocyte count

**病理生理學**：
- 正常：4 個 α 基因（染色體 16 各 2 個）；2 個 β 基因（染色體 11 各 1 個）
- 胎兒 Hb、HDF（α₂γ₂）在 3-6 個月大時轉換為成人 HbA（α₂β₂）和 HbA₂（α₂δ₂）
- HbA 占成人 Hb 的 97%；HbA₂ 占 3%

**地理分布**：
- β-thalassemia：地中海（South Asia 也常見）
- α-thalassemia：東南亞（SEA）和非洲

### β-地中海型輕型（β-Thalassemia Minor / Trait）

**定義**：
+ 單一 β 基因等位基因缺陷（異型合子）

**臨床表現**：
+ 通常無症狀；很少出現可觸及的脾臟

**診斷檢查**：
+ Hb（100-140 g/L）、MCV（<70 fL）、Fe（正常）、RBC count（正常/升高）
+ Peripheral blood film：Microcytosis、Basophilic stippling
+ Hb electrophoresis：
  - 特定：HbA₂ 升高至 3.5-5%（正常 1.5-3.5%）
  - 非特異：50% HbF 輕度升高

**治療**：
+ 不需治療
+ 為患者和家屬提供遺傳諮詢

---

### β-地中海型重型（β-Thalassemia Major）

**定義**：
+ 兩個 β 基因等位基因均缺陷（homzygous，自體隱性）

**病理生理學**：
+ 無效 α 鏈合成導致紅血球生成減少、RBC 溶血、HbF 增加

**臨床表現**：
+ 在 6-12 個月大時初次表現（正常此時 HbF 應被 HbA 取代）
  - 嚴重貧血、Jaundice
+ 補償性胃腸道鐵吸收導致 Iron overload（進展為 hemochromatosis）
  - 來自重複輸血和無效紅血球生成（經 erythroferrone 媒介機制）
  - 導致器官鐵誘導損傷
+ 生長發育遲緩（性腺功能減退導致）
+ 嚴重肝脾腫大（髓外造血）
+ 放射學變化（骨髓腔擴張）和髓外造血團塊（erythroid tissue tumors）
+ 顱骨 X 光顯示「hair-on-end」外觀
+ 病理性骨折常見
+ 膽紅素增加代謝增加的證據（如膽結石）
+ 死亡原因：
  - 未治療的貧血（應輸血）
  - 感染（應早期識別和治療）
  - Iron overload（常見，晚發併發症）

**診斷檢查**：
+ CBC 和 iron studies
+ 嚴重微小球性貧血（Hb <60 g/L）
+ Peripheral blood film：Teardrop、Target、Hypochromic、Microcytic RBCs
+ Hb electrophoresis：
  - HbA：0-10%（正常 >95%）
  - HbA₂：2-5%
  - HbF：90-100%

**治療**：
+ 終身定期 RBC 輸血以抑制內源性紅血球生成
+ 鐵螯合（如 deferoxamine、deferasirox、deferiprone）預防器官鐵過載和自由基形成
+ 若未輸血：補充 folic acid
+ 自體 BM 移植（潛在可治癒）或臍帶血移植
+ 基因治療（編碼成人 HbA）或 CRISPR-Cas9 基因編輯（增加 HbF 生成）
+ 脾切除（現在較少執行）

---

### α-地中海型貧血（α-Thalassemia）

**定義**：
+ α 基因缺陷
+ 地理分布類似 β-thalassemia，但東南亞人和非洲人頻率更高

**Table 8. α-Thalassemia 的臨床分類**

| 缺陷基因數 | 基因型 | 臨床表徵 |
|:----------|:-------|:---------|
| 1 | αα/α- | 臨床上無症狀；正常 Hb、正常 MCV |
| 2 | αα/-- 或 α-/α- | 正常 Hb、MCV 降低 |
| 3 | α-/-- | HbH（β4）疾病；成人發病，Hb 降低、MCV 降低、Splenomegaly |
| 4 | --/-- | Hb Barts（γ4）疾病（Hydrops fetalis）；通常與生命不相容 |

**診斷檢查**：
+ CBC 和 iron studies
+ Peripheral blood film：使用 supravital stain 篩檢 HbH 包涵體
+ Hb electrophoresis 可用於識別 HbH 疾病，但可能漏掉 1-或 2-基因缺失；確診需 DNA genotyping

**治療**：
+ 轉介遺傳/產前諮詢
+ 取決於貧血程度
  - 1 或 2 個缺陷基因：不需治療
  - HbH 疾病：類似 β-thalassemia intermedia
  - Hb Barts：無確切治療；多數妊娠終止（胎兒/母體死亡風險）
  - 宮內輸血、造血幹細胞移植

## 鐮刀型紅血球疾病（Sickle Cell Disease）

### 定義

+ 自體隱性 sickling disorder，最常見原因是 β-球蛋白鏈第 6 位的 Glu → Val 取代
  - 導致 HbS 變異而非正常成人 HbA
+ HbS 等位基因在 Sub-Saharan African、Indian、Middle Eastern 或 Mediterranean 遺產患者中發生率較高（被认为對瘧疾有保護作用）
+ SCD 發生於個體有兩個 HbS 基因（homozygous，HbSS）或一個 HbS 基因 + 另一個突變 β-球蛋白基因（compound heterozygote）- 最常見 HbS-β-thal 和 HbSC disease

### 病理生理學

+ 在低 pO₂ 時，deoxyHbS 聚合導致剛性水晶樣桿狀結構扭曲細胞膜成為「sickles」
+ Sickling 程度與存在的 HbS 百分比相關
+ Sickling 因酸血症、CO₂ 增加、2,3-DPG 增加、發燒、滲透壓增加而加重
+ 脆弱的鐮刀型細胞以兩種主要方式造成損傷：
  1. 脆弱的鐮刀型細胞溶血（一氧化氮耗竭）
  2. 小血管阻塞（缺氧、缺血再灌流損傷）

### 臨床表現

**Sickle Cell Trait（HbAS）**：
+ 無症狀（除非極端缺氧或感染）
+ Renal medullary carcinoma 風險增加

**SCD-SS（HbSS）**：
+ 慢性 hemolytic anemia
+ 第一年出現 Jaundice
+ 生長發育遲緩 + 骨骼變化
+ 童年時脾腫大；成年後脾萎縮
+ SCD-SS 常表現為急性疼痛發作

**Table 9. SCD 的急性發作類型**

| 類型 | 特徵 |
|:-----|:-----|
| Aplastic crisis | 毒素和感染（尤其 Parvovirus B19）暫時抑制骨髓 |
| Splenic sequestration crisis | 通常在兒童；血液在脾臟大量滯留導致急性 Hb 下降和休克；成人少見（因反覆梗塞後 asplenia）|
| Vaso-occlusive crisis | 影響各器官造成缺血再灌流損傷（背、胸、腹、四肢）、發燒、Leukocytosis；可導致中風或無症狀心肌梗塞；感染、脫水、溫度快速變化、懷孕、月經、酒精為誘發因素 |
| Acute chest syndrome | 急性發燒和/或呼吸道症狀；胸部 X 光新發現肺部浸潤；由肺部感染、脂肪栓塞、肺梗塞誘發 |

**SCD-SC（HbSC）**：
+ 非洲裔美國人活產中 1/833，西非常見
+ 比 HbSS 貧血更輕
+ 併發症類似 HbSS 但通常更輕、更少（例外：增生性鐮刀型視網膜病變、腎小球腎炎、avascular necrosis）

### 診斷檢查

+ **Sickle cell prep**：檢測 RBC 在降低 O₂ 劑下的 sickling；確定 HbS 等位基因存在，但無法區分 HbAS 與 HbSS
+ **CBC**：Hb、Hct、RBC count、網狀紅血球
+ **Peripheral blood film**：Sickle cells、Target cells、Polychromasia
+ **Hb electrophoresis**：
  - HbS：確診
  - 可區分 HbSS、HbAS、HbSC

### 治療

+ **急性疼痛處理**：Hydration、Pain control、氧氣（若缺氧）
+ **Hydroxicarbamide（Hydroxyurea）**：增加 HbF 產生；減少疼痛 crisis 和 acute chest syndrome
+ **Voxelotor**：抑制 HbS 聚合
+ **Crizanlizumab**：抗 P-selectin Ab；減少疼痛 crisis 頻率
+ **输血**：考慮用於 stroke prevention、acute chest syndrome、splenic sequestration、手術前
+ **所有 SCD 患者應補充 folic acid**
+ 避免觸發因素：脫水、極端溫度、、感染、高海拔
+ **BM 移植**：可治癒（年輕患者、有完全匹配的捐贈者）

## 巨球性貧血（Macrocytic Anemia）

+ MCV >100 fL

### 維生素 B12 缺乏（B12 Deficiency）

**病因**：

| 攝取不足 | 吸收不良 | 其他 |
|:---------|:---------|:-----|
| 素食主義者（無動物製品攝取）| Pernicious anemia（最常見）、Gastric bypass、Ileal resection、Crohn's disease | Parasitic infection（魚絛蟲）|

+ **Hematologic**：Fatigue、Weakness、Pallor、Jaundice（無效造血導致）
+ **Neurologic**（僅 B12 缺乏）：
  - Subacute combined degeneration（脊髓後索和側索受損）
  - Symmetric peripheral neuropathy（感覺異常、本體感覺減退）

  - Psychiatric：Depression、Psychosis

+ Anti-parietal cell Ab（更敏感）
+ Anti-intrinsic factor Ab（更特異）
+ Gastrin level（升高）
+ Upper endoscopy（切片：萎縮性胃炎；也篩檢胃癌）

**治療**：
+ 治療劑量：B12 1000-1200 μg PO QD（若腸道吸收完整）或 1000 μg IM 每週一次；時間和途徑取決於病因
+ 維持劑量（補足後）：B12 1000 μg PO QD 或 1000 μg IM 每月一次
+ 治療嚴重 megaloblastic anemia 時注意低血鉀和反彈性血小板增多

## 凝血概論（Hemostasis）

### 止血階段

**1. 原發性止血（Primary Hemostasis）**

+ 由血小板和 VWF 媒介
+ 目標是快速止血的；主要影響 mucocutaneous bleeding
+ 血管損傷導致膠原蛋白/內皮下基質暴露和血管收縮劑釋放
+ 血小板與受損血管壁接觸
  - **Adhesion**：血小板透過 VWF 黏附於內皮下層
  - **Activation**：血小板活化，形態改變，顆粒釋放
  - **Aggregation**：活化的 GPIIb/IIIa 與可溶性配體結合，形成血小板 plug

**2. 續發性止血（Secondary Hemostasis）**

+ 血小板 plug 由 fibrin clot 強化
+ **Extrinsic（initiation）pathway**：啟動
+ **Intrinsic（amplification）pathway**：啟動後透過正回饋放大
+ 兩條路徑會聚於共同途徑，導致 thrombin 生成和 fibrin 形成

**3. Fibrin 穩定**

+ 從可溶性轉變為不可溶性、交聯的 clot

**4. Fibrinolysis**

+ 傷口癒合後，clot 溶解由 fibrinolytic system 媒介

### 常用凝血檢驗

**Table 12. 常用凝血檢驗**

| 檢驗 | 參考範圍 | 用途 | 相關疾病 |
|:-----|:---------|:-----|:---------|
| **PT/INR** | 28-38 sec（PT）；0.9-1.2（INR）| 測量 extrinsic pathway（Factor VII）和共同途徑 | PT 延長：Hemophilia A/B（共同途徑低於試劑檢測閾值）；Lupus anticoagulant；維生素 K 缺乏；Warfarin 治療；Factor VII 缺乏 |
| **aPTT** | 0-85 sec | 測量 intrinsic pathway（Factors VIII、IX、XI、XII）和共同途徑 | aPTT 延長：Hemophilia A/B（Factor VIII 或 IX 缺乏）；von Willebrand disease；Heparin 治療；Lupus anticoagulant |
| **Fibrinogen** | 1.5-4.0 g/L | 共同途徑 | 降低：DIC；嚴重肝病 |
| **D-dimer** | <0.5 μg/mL | 纖溶增加 | 升高：DIC、VTE、創傷、心肌梗塞、惡性腫瘤 |

### 凝血因子

**參與 PT 的因子**：III（Tissue factor）、VII
**參與 aPTT 的因子**：XII、XI、IX、VIII、X、V、II（Prothrombin）、I（Fibrinogen）
**共同途徑**：X、V、II、I

### 出血性疾病的臨床表現

**Table 13. 原發性 vs. 續發性止血障礙的特徵**

| 特徵 | 原發性（血小板、VWF）| 續發性（凝血因子）|
|:-----|:--------------------|:-----------------|
| 表面傷口 | 過度、持續出血 | 正常/輕度延長 |
| 受傷後發作 | 立即 | 延遲 |
| 出血部位 | 淺層如黏膜（鼻、牙齦、GI、陰道、皮膚）| 深層如創傷 |
| 病灶 | Petechiae、Ecchymoses | Hemarthroses、Hematomas |

## 原發性止血障礙（Disorders of Primary Hemostasis）

### 免疫性血小板減少紫斑症（Immune Thrombocytopenia, ITP）

**定義**：
+ 因異常免疫反應導致血小板減少（見 Thrombocytopenia 章節）的疾病

**分類**：
- **原發性**：ITP（Platelet count <100 × 10⁹/L）且無其他原因
- **次發性**：ITP 與其他疾病相關（HIV、HCV、SLE、CLL）
- **藥物引起**：藥物暴露導致抗血小板 Ab 引起的血小板破壞

### 肝素誘發血小板減少症（Heparin-Induced Thrombocytopenia, HIT）

**定義**：
+ 肝素暴露後出現血小板減少
+ HIT 是 prothrombotic（非出血性）狀態

**類型**：
- **Type I（非免疫性）**：輕度血小板減少（罕見 <100 × 10⁹/L）；自限性；不需要停藥
- **Type II（免疫性）**：通常在肝素使用後 5-10 天發生；血小板通常降低 >50% 或绝对值 <150 × 10⁹/L；高度血栓風險

**診斷**：
+ **4T score**：
  - Thrombocytopenia（血小板減少程度）
  - Timing（肝素使用至血小板減少發生的時間）
  - Thrombosis（血栓併發症）
  - oTher causes（其他原因）
+ **Anti-PF4/heparin Ab 檢測**
+ **Serotonin release assay**（金標準）

**治療**：
+ 立即停用所有 heparin（包括 heparin flushes）
+ 替代為非 heparin 抗凝劑（Argatroban、Bivalirudin、Dabigatran、Rivaroxaban、Apixaban）
+ **禁止warfarin**（在血小板 <50 × 10⁹/L 時會導致 warfarin-induced skin necrosis）
+ 若血栓存在：考慮 DOAC 或 direct thrombin inhibitor
+ 若有血栓或極高風險：考虑 fondaparinux 或 DOAC
+ 避免血小板輸血（可能加劇血栓）

## 續發性止血障礙（Disorders of Secondary Hemostasis）

### 血友病（Hemophilia A and B）

**定義**：
+ X-染色體隱性遺傳的凝血因子缺乏
- Hemophilia A：Factor VIII 缺乏
- Hemophilia B：Factor IX 缺乏

**臨床表現**：
+ 輕度創傷或自發性出血
+ 好發部位：關節（Hemarthrosis）、肌肉（Iliopsoas）、顱內、口腔、泌尿生殖道
+ 關節出血：急性疼痛、腫脹、活動受限；反覆出血導致 hemophilic arthropathy
+ 深度組織出血和血腫

**診斷檢查**：
+ **aPTT 延長**；PT 正常
+ **Factor VIII 或 IX 活性檢測**：
  - 正常：50-150%
  - 輕度：5-40%
  - 中度：1-5%
  - 重度：<1%

**治療**：
+ **輕度 Hemophilia A**：Desmopressin（DDAVP）
+ **中重度 Hemophilia A/B**：Factor VIII 或 IX 濃縮製劑
+ **預防性治療**：用於重度患者預防關節出血和 arthropathy
+ **急性出血處理**：早期因子替代、休息、固定、冰敷、壓迫、抬高（RICE）
+ **併發症管理**：關節出血後康復；抑制物（inhibitors）形成時免疫耐受誘導

---

### 彌散性血管內凝血（Disseminated Intravascular Coagulation, DIC）

**定義**：
+ 全身性凝血和纖溶系統活化，導致廣泛微血管血栓和消耗性凝血病

**病因（OMITS）**：
- **O**：Obstetric complications（胎盤早剝、羊水栓塞、死胎、子癲前期）
- **M**：Malignancy（胰臟癌、肺癌、前列腺癌、急性白血病）
- **I**：Infection（Gram-negative sepsis、敗血症）
- **T**：Trauma（嚴重創傷、脂肪栓塞）
- **S**：Shock（敗血症休克、心源性休克）

**臨床表現**：
+ **出血**：多部位（靜脈穿刺部位、黏膜、伤口）；可能大量
+ **血栓**：微血管血栓導致器官功能障礙（腎衰竭、肺功能不全、CNS 障礙）
+ **休克**：消耗性凝血病導致循環衰竭

**診斷檢查**：
+ **PT 和 aPTT 延長**
+ **Fibrinogen 降低**（因為消耗）
+ **D-dimer 升高**（纖溶增加）
+ **血小板減少**
+ **血塗片**：Schistocytes（微血管病性溶血）
+ **ISTH DIC calculator**：評估是否存在潜在誘因、凝血檢驗異常

**治療**：
+ **治療根本原因**（最關鍵）
+ **支持性輸血**：Platelet transfusion（若 PLT <20 × 10⁹/L 或有出血）、Cryoprecipitate（若 fibrinogen <1.0-1.5 g/L）、FFP（補充凝血因子）
+ **肝素**：僅用於血栓為主且無顯著出血時
+ **血栓溶解**：一般不建議

## 血栓形成傾向（Hypercoagulable Disorders）

### 血栓形成傾向的檢查

**何時考慮檢查**：
- 多次復發性血栓
- Warfarin 誘導的皮膚壞死或新生兒 purpura fulminans（Protein C 或 S 缺乏）
- 不常見靜脈部位血栓（Cerebral、Jugular、Splanchnic、Portal、Upper extremity veins）
- 異常血液檢查、constitutional symptoms 或理學檢查發現提示惡性腫瘤

**檢查項目（如有適應症）**：
- **初始**：CBC、Blood smear、Coagulation studies、紅斑性狼瘡抗凝血劑、肝/腎功能、Urinalysis、溶血標記（貧血時）、惡性腫瘤史、年齡相關癌症篩檢、APLA血清學
- **治療後（或 ≥6 週）**：Antithrombin 活性、Protein C、S 活性

### 遺傳性血栓形成傾向

**Factor V Leiden（Activated Protein C Resistance）**：
+ 最常見的遺傳性血栓形成傾向
+ 白種人 3-7% 為異型合子
+ Factor V 基因點突變（R506Q）導致 Factor Va 對 activated protein C 的去活化產生抗性

**Prothrombin Gene Mutation（PT G20210A）**：
+ 白種人 1-3% 為異型合子
+ Prothrombin 基因啟動子區域核苷酸 20210 處 G→A 轉位導致 prothrombin 水平升高，進而增加 thrombin 生成

**Protein C 和 Protein S 缺乏**：
+ Protein C 使用 Protein S 作為輔因子去活化 Factor Va 和 VIIIa
+ Protein C 缺乏：Homzygous 或 compound heterozygous 導致新生兒 purpura fulminans；Heterozygous 導致靜脈血栓
+ Protein S 缺乏：增加靜脈血栓風險

**Antithrombin 缺乏**：
+ Antithrombin 緩慢去活化 thrombin，肝素可加速此過程
+ 自體顯性遺傳；Nephrotic syndrome 尿液丟失；肝病合成減少
+ 可能對 UFH 產生抗性（LMWH 可能有效，需監測 anti-Xa）

### 抗磷脂抗體症候群（Antiphospholipid Syndrome）

**診斷標準（Sapporo Criteria）**：
- **臨床**：動靜脈血栓、不明原因復發性早期流產（<10 週 ≥3 次）、晚期胎兒死亡（>10 週）、因子癲前期或胎盤功能不全導致 <34 週早產
- **實驗室（需確認，間隔 >12 週）**：Anticardiolipin IgG/IgM、Anti-β2 glycoprotein-I Ab、Lupus anticoagulant

## 靜脈血栓栓塞症（Venous Thromboembolism, VTE）

### 定義

+ 淺層或深層靜脈中血栓形成及後續發炎反應
+ 包括淺層靜脈血栓、DVT 和 PE
+ 血栓沿血流方向蔓延（通常起源於小腿靜脈）
+ DVT 在下肢比上肢更常見（上肢 DVT 因中央靜脈導管增加而增加）
+ 發生率：>60 歲約 1%
+ DVT 最重要後遺症：PE（約 50% 近端 DVT 併發）和 post-thrombotic syndrome（慢性靜脈功能不全）

### 病因（Virchow's Triad）

1. **內皮損傷**：
   - 內皮功能障礙暴露 procoagulant 蛋白促進血栓形成
   - 局部 fibrinolysis 抑制減少
   - 血管壁完整性改變導致血流紊亂

2. **靜脈瘀滯**：
   - 固定（如術後、心肌梗塞、心衰竭、中風）抑制凝血因子清除和稀釋

3. **高凝狀態**：
   - **遺傳性**（見 Hypercoagulable Disorders）
   - **後天性**：年齡、手藝（尤其是骨科、胸腔、胃腸、泌尿生殖）、創傷（尤其是脊椎、骨盆、股骨、脛骨骨折、脊髓損傷）、惡性腫瘤（胰、胃、肺、淋巴瘤、膀胱、睪丸、結直腸、婦科 - 依 Khorana score）、血液疾病（MPNs，尤其 PV、ET）、PNH、Hyperviscosity（多發性骨髓瘤、PV、白血病、SCD）、溶血性貧血

### 臨床表現

**DVT**：
+ 小腿或大腿疼痛、腫脹、壓痛
+ Homans' sign（小腿被動背屈時疼痛 - 不敏感）
+ 單側水腫
+ 淺層靜脈擴張

**PE**：
+ 呼吸困難（最常見）、胸痛（肋膜性、胸悶）、咳嗽、咯血
+ Tachycardia、Tachypnea、Low-grade fever
+ Massive PE：Dyspnea、缺氧、Low blood pressure（Tachycardia）、右心衰竭徵象

### 診斷檢查

+ **DVT**：
  - **Compression ultrasonography**（首選）：準確率高
  - **D-dimer**：陰性可排除（但特異性低）
  - **Venography**（傳統）：現少用

+ **PE**：
  - **CT pulmonary angiography（CTPA）**（首選）：確診
  - **V/Q scan**：當 CT 不適用時（如對比劑過敏、孕婦）
  - **D-dimer**：排除價值高（wells score 低時）
  - **ABG**：可能低氧血症、Respiratory alkalosis

### 治療

**急性 DVT/PE 治療（初始）**：
+ **Anticoagulation**：
  - **LMWH**（如 Enoxaparin）：首選門診和住院患者
  - **Fondaparinux**：替代選擇
  - **DOACs**（Dabigatran、Rivaroxaban、Apixaban、Edoxaban）：越來越常用
  - **Warfarin**：需要重疊使用（需橋接直到 INR 達標）
  - **UFH**：用於嚴重腎功能不全或即將手術患者
+ **療程**：
  - 暫時性誘因：3-6 個月
  - 無誘因或輕度誘因：至少 3-6 個月，考慮延長抗凝
  - 癌症相關：LMWH 至少 3-6 個月，然後繼續 LMWH 或 DOAC/Warfarin
  - 復發：延長/終身抗凝

**血栓溶解治療（Thrombolysis）**：
+ 僅用於大規模 DVT/PE 伴血流動力學不穩定
+ tPA（Reteplase、Tenecteplase）+ Heparin
+ 顯著出血風險

**下腔靜脈濾器（IVC Filter）**：
+ 绝对抗凝禁忌（如活動性出血）時放置
+ 不應常规用於急性 VTE

**術後/創傷後 VTE 預防**：
+ **Mechanical**：IPC（Intermittent pneumatic compression）、Graduated compression stockings
+ **Pharmacologic**（術後確認止血後）：LMWH、UFH、DOAC

## 骨髓增生性腫瘤（Myeloproliferative Neoplasms, MPNs）

### 概述

+ 克隆性骨髓幹細胞異常導致一個或多個血球系過度增殖（紅血球、血小板、骨髓系細胞）
- 主要影響中年人和老年人（巔峰 60-80 歲）
- 所有疾病可能進展為 AML

**Table 14. 慢性骨髓增生性腫瘤的鑑別**

| 特徵 | CML | Polycythemia Vera | Primary Myelofibrosis | Essential Thrombocythemia |
|:-----|:----|:-------------------|:----------------------|:--------------------------|
| 主要異常 | ↑WBC | ↑RBC | ↑RBC（貧血期）/↑WBC | ↑Platelets |
| WBC | 升高 | 正常/升高 | 正常/升高 | 正常/升高 |
| Platelets | 正常/升高 | 升高 | 減少/升高 | >450 × 10⁹/L |
| 骨髓纖維化 | 無/輕度 | 無 | 有 | 無 |
| 脾腫大 | 有 | 有 | 有 | 有 |
| 肝脾腫大 | 有 | 有 | 有 | 無/輕度 |
| 遺傳關聯 | BCR-ABL 突變 | JAK2 突變（96%）| JAK2（50%）、CALR（30%）、MPL（5-10%）| JAK2（50%）、CALR（30%）、MPL（3-5%）|

### 慢性骨髓性白血病（Chronic Myeloid Leukemia, CML）

**定義**：
+ 粒細胞系增殖增加的骨髓增生性疾病，不喪失分化能力

**流行病學**：
+ 任何年齡（主要中年至老年）；中位年齡 65 歲

**病理生理學**：
+ **Ph 染色體**：
  - 9 號和 22 號染色體之間的轉位是必要且充分條件
  - c-Abl proto-oncogene 從 9 號染色體轉位至 22 號染色體的「breakpoint cluster region」（BCR），產生 BCR-ABL fusion gene（組成性活性酪氨酸激酶）

**臨床表現**：
+ **三個臨床分期**：
  - **慢性期**：85% 在此確診；外周血中 blasts <10%；嗜酸性粒細胞和嗜鹼性粒細胞輕度升高；無明顯症狀
  - **加速期**：中性粒細胞分化受損；循環 blasts（10-20%）伴外週嗜鹼性粒細胞增加（pruritus）；CBC：血小板減少 <100 × 10⁹/L 或血小板增多；克隆演化的細胞遺傳學證據；全身症狀和脾腫大惡化（髓外造血）
  - **Blast crisis**：更具侵襲性病程，blasts 不分化；外周血或骨髓中 blasts（>20%）；反映急性白血病（1/3 ALL、2/3 AML）
+ **20-50% 患者確診時無症狀**（偶然發現）
+ **非特異症狀**：Fatigue、Weight loss、Malaise、 Excessive sweating、Fever
+ **脾臟浸潤**：早期飽足感、LUQ 疼痛/腹脹、肩尖疼痛（牽涉痛）；脾腫大（最常見理學發現）
+ **貧血**
+ **血小板功能異常導致出血**
+ **Pruritus、PUD**（組胺增加）
+ **WBC 極高時**：Leukostasis、 Priapism、Encephalopathy（罕見）

**診斷檢查**：
+ **CBC with differential**：WBC 升高、RBC 正常/減少、Platelets 升高/減少、Basophils 升高；WBC differential 呈雙峰分布，以 myelocytes 和 neutrophils 為主
+ **Peripheral blood film**：Leukoerythroblastic picture（未成熟紅血球和粒細胞）；不同成熟階段前驅細胞存在區別於 AML
+ **BM biopsy**：骨髓增生伴 left shift、巨核細胞增加、輕度纖維化
+ **分子和細胞遺傳學研究**：BM 或外周血的 Ph 染色體或 BCR-ABL transcripts
+ 腹部影像評估脾臟大小

**治療**：
+ **預防性**：Allopurinol
+ **慢性期**：
  - **Imatinib mesylate**：抑制 BCR-ABL 陽性細胞的酪氨酸激酶活性並誘導凋亡；可作為第一線治療
  - 若反應喪失或無法耐受（約 40%）：嘗試 2nd/3rd generation TKIs（Dasatinib、Nilotinib、Bosutinib）；Ponatinib 僅用於 T315I 突變
  - **Interferon-α**：可能改善 TKI 反應；現在通常只用於孕婦
  - **羥基尿素**（Palliative）：減少 WBC
+ **加速期或 Blast 期**：
  - 對 Imatinib-naive 患者使用 Imatinib
  - 轉介臨床試驗或 2nd/3rd generation TKI，考虑自體造血幹細胞移植

### 骨髓增生異常症候群（Myelodysplastic Syndromes, MDS）

**定義**：
+ 異質性惡性幹細胞疾病，特徵為發育異常和無效血液細胞生成，導致外週血球減少，轉化為急性白血病的風險不同

**病理生理學**：
+ 成熟障礙：儘管骨髓中祖細胞數量足夠（通常 hypercellular），造血無效；形成的細胞有形態和功能缺陷
+ 骨髓內凋亡：骨髓內程序性細胞死亡
+ 兩種過程都導致外週成熟細胞減少
+ <30% 進展為 AML

**風險因素**：
+ 老年人、化療後、接觸（Benzene、菸草、輻射）、遺傳異常
+ 發生率：每年每百萬人 50 人，70 歲以上上升至每年每百萬人 200-400 人

**臨床表現**：
+ 高度變異；常見表現：Anemia 症狀（Fatigue、Dyspnea）、Thrombocytopenia（Bruising、Bleeding、Petechiae）、Neutropenia（復發性感染）持續數月至數年

**診斷檢查**：
+ **CBC 和 Peripheral blood film**：
  - RBC：通常為 macrocytic，卵形紅血球（macro-ovalocytes），reticulocyte count 減少
  - WBC：粒細胞減少和形態異常（如雙葉或未分葉核 = Pelger 異常）
  - Platelets：血小板減少、大小異常、細胞質異常（如巨大顆粒減少血小板）
+ **BM aspirate and biopsy**（形態學和細胞遺傳學分析）：骨髓發育異常且通常為 hypercellular；細胞遺傳學：高風險（7 號染色體部分或全部缺失）和 complex（>3 種異常）

**治療**：
+ **低風險（IPSS-R Very Low 或 Low）**：
  - EPO 刺激劑每週一次是一線減少輸血需求的治療（EPO level 必須 <500 IU/L）
  - 若細胞遺傳學有 5q deletion：Lenalidomide PO
  - 若有 ringed sideroblasts：Luspatercept（EPO 刺激劑失敗後）
  - 支持性照護：RBC 和血小板輸血（若頻繁 RBC 輸血，考虑鐵螯合）
+ **高風險（IPSS-R Intermediate、High 或 Very High）**：
  - 支持性照護（輸血支持）
  - 表觀遺傳治療：DNA methyltransferase inhibitors（如 5-azacitidine）
  - 根据患者因素（年齡、虛弱、整體健康）考虑造血幹細胞移植

**預後**：
+ **IPSS-R** 使用 5 個因素估計平均存活：細胞學、BM blasts %、Hb、血小板、ANC
+ 計算分數後，患者 MDS 預後風險為「Very Low」、「Low」、「Intermediate」、「High」或「Very High」，平均存活分別為 8.7、5.3、3.0、1.6、0.8 年
+ **IPSS-M** 整合突變分析以獲得更好的預後信息

## 急性骨髓性白血病（Acute Myeloid Leukemia, AML）

### 定義

+ **WHO 定義**：外周血或骨髓中 ≥20% blast cells
+ 分類：根據 blasts 為 myeloid（AML）還是 lymphoid（ALL）分為兩類

### 典型白血病發病年齡

| 類型 | 發病年齡 |
|:-----|:---------|
| ALL | 兒童和老年成人 |
| CML | 40-60 歲 |
| AML、CLL | >60 歲 |

**Auer rods 是 AML 的 pathognomonic 標誌**

### 病理生理學

+ **病因細分**：
  - **原發性（de novo）**
  - **繼發性**：先前血液疾病（如骨髓增生性疾病和 MDS）或先前化療藥物（如 alkylating agents）
+ 骨髓中 blasts 不受控增殖導致：
  - 正常造血細胞受到抑制
  - Blasts 出現在外周血 — Leukostasis 風險
  - Blasts 在其他部位積累（如皮膚、牙齦）
  - 代謝後果：TLS

### 臨床表現

+ 症狀在數週內發展
+ **骨髓衰竭表現**：
  - Anemia、Thrombocytopenia（APL 合併 DIC）、Neutropenia（感染/發燒）
+ **Blasts 在骨髓積累**：
  - 骨骼疼痛、骨壓痛（尤其胸骨）
  - 器官浸潤：牙齦肥厚（尤其是 myelomonocytic leukemia）
  - CNS 髓外侵犯：Confusion 或精神狀態改變
  - 肝脾腫大（ALL 也有）
  - 淋巴結病變
  - 皮膚：Leukemia cutis
  - 眼睛：出血和/或白色斑塊、Roth spots、Cotton wool spots、視力變化（罕見）
+ **Leukostasis/Hyperleukocytosis syndrome**（醫療急症）：
  - 大量 blasts 干擾循環導致缺氧和出血 — 可導致瀰漫性肺浸潤、CNS 出血、呼吸窘迫、精神狀態改變、Priapism
  - AML 比 ALL 更常見
+ **代謝效應**：
  - **TLS**：Uric acid 增加 > 腎病變、痛風；磷酸鹽釋放 > 低鈣、低鎂；Procoagulant 釋放 > DIC（APL 風險更高）
  - 治療前高鉀血症（blastic 增殖和自發性 TLS）；治療後進一步高鉀血症（細胞溶解）。注意某些 AML 可因分泌 muramidase 導致低鉀血症（腎小管 K⁺ 丟失）

### 診斷檢查

+ **血液檢查**：
  - **CBC**：Anemia、Thrombocytopenia、Variable WBC（最常見 cytopenias + blasts）
  - 評估 DIC：INR 升高、aPTT 升高、Fibrinogen 降低
  - 評估 TLS：LDH 升高、Uric acid 升高、PO₄³⁻ 升高（白血病 blasts 釋放）、Ca²⁺ 降低、K⁺ 升高/降低
  - 基準腎功能和肝功能檢查
  - 若考虑治療：HBV、HCV、HIV、CMV 血清學
+ **Peripheral blood film**：Auer rods（azurophilic granules）的循環 blasts 是 AML 的 pathognomonic 標誌
+ **BM aspirate/biopsy**：確診
  - Blast count：AML >20%（正常 <5%）
  - 形態學、細胞遺傳學和/或免疫表型特徵用於確定譜系和成熟度
+ **CXR**排除肺炎；化療前 ECG、MUGA scan

### 治療

+ **化療是主要治療**（不接受治療會迅速死亡）
+ 不適合強化療的患者可用低劑量 cytarabine 和 hypomethylating agents 合併 venetoclax（BCL-2 抑制劑）
+ 除 APL（t(15:17)易位）外，所有 AML 亞型治療相似
  1. **Induction**：化療誘導完全緩解
     - 若干方案可選
     - 初始誘導反應差的患者 — 預後較差
     - 支持性照護：TLS 和 DIC 管理、Febrile neutropenia/感染、輸血支持（若 PLT <10 × 10⁹/L 需血小板輸血）
  2. **Consolidation**：防止復發
     - 強化鞏固化療
     - 造血幹細胞移植 — 自體（年輕患者、較好 performance status 和/或不良細胞遺傳學）

+ **支持性照護**：
  - 發燒：全套培養、CXR、開始廣效抗生素
  - 血小板和 RBC 輸血
  - 預防和治療代謝異常
  - Allopurinol、Rasburicase 預防/處理高尿酸血症
+ **Leukostasis**：需要立即細胞減少治療（即 hydroxyurea）

**APL 治療**：
+ APL 是急症，因為 DIC 通常在確診時就存在。支持性輸血需以血小板 >30（無出血）或 >50（有出血）為目標，Fibrinogen >1.5 為目標
+ 若 APL 在鑑別診斷中，應盡快開始 ATRA 誘導分化；Arsenic trioxide 和 ATRA 合併治療優於傳統化療

### 預後

+ **達到第一完全緩解**：
  - ≤60 歲 70-80%；>60 歲 50%
  - 中位存活 12-24 個月
  - 預後取決於細胞遺傳學、年齡、performance status、先前細胞毒素或放射治療

## 急性淋巴性白血病（Acute Lymphoblastic Leukemia, ALL）

### 定義

+ 骨髓中早期淋巴前驅細胞惡性增殖並替代正常造血細胞的惡性疾病；巔峰年齡 40 歲
+ WHO 將 ALL 分為兩類（依細胞來源）：
  - B-cell：Precursor B lymphoblastic leukemia
  - T-cell：Precursor T lymphoblastic leukemia
+ FAB 分類（L1、L2、L3）因形態學無預後意義而不再鼓勵使用

### 臨床表現

+ 區分 ALL 與 AML（見 Table 31）
+ 症狀通常繼發於：
  - **骨髓衰竭**：Anemia、Neutropenia（50% 發燒就診；也有口腔、肺、肛門周圍感染）、Thrombocytopenia
  - **器官浸潤**：Bone pain、Lymphadenopathy、Hepatosplenomegaly、Meningeal signs（頭痛、噁心/嘔吐、視力症狀；ALL 復發時特別）

### 診斷檢查

+ **BM 或外周血 >20% lymphoblasts**；收集 flow cytometry、細胞遺傳學、分子研究樣本
+ Ph 染色體：~25% 成人 ALL
+ **CBC**：WBC >100 × 10⁹/L（50% 患者）；Neutropenia、Anemia、Thrombocytopenia
+ 篩檢 TLS：Uric acid、K⁺、PO₄³⁻、Ca²⁺、LDH 升高
+ 篩檢 DIC：PT、aPTT、Fibrinogen
+ **CXR**：ALL 患者可能有縱隔腫塊
+ CT C/A/P 和睪丸超聲篩檢結外病變
+ 治療開始時強制腰椎穿刺評估 CNS 侵犯（確保血小板和 PT/PTT 充足，並延遲至 blasts 清除外周血）
+ HIV、HBV、HCV 血清學；CMV Ab 檢測

### 治療

+ 消除異常克隆細胞
  1. **誘導化療**：誘導完全緩解，<5% blasts（恢復正常造血）
  2. **鞏固和/或強化化療**
     - Consolidation：繼續相同化療消除亞臨床白血病細胞
     - Intensification：高劑量不同（非交叉反應）化療藥物消除對初始治療有抗性的細胞
  3. **維持化療**：長期低劑量間歇化療（1 年）防止復發
  4. **預防**：CNS 放射治療（現在不再用於預防）或 Methotrexate/Cytarabine/Dexamethasone（鞘內或全身）
+ **造血幹細胞移植**（特定適應症）：潛在可治癒（因移植前骨髓清除性化放療和移植後 graft-versus-leukemia 效應），但復發和非復發死亡率較高
  - 若 BCR-ABL 陽性：一線開始 tyrosine kinase inhibitors 並持續給予
  - 復發時：CAR T-cell therapy、Inotuzumab 或 Blinatumomab

**CAR T-cell therapy**：
+ 提取患者自身 T 細胞，基因改造 T 細胞產生能識別癌細胞表面抗原的 Chimeric Antigen Receptors（CARs）（ALL 中常為 CD19）
+ 治療瀰漫性大 B 細胞淋巴瘤和 CD19 陽性 ALL 最有效

### 預後

+ 取決於初始誘導反應、Minimal residual disease testing 或復發後是否達到緩解
+ **良好預後因素**：年輕、WBC <30 × 10⁹/L、T-cell phenotype、無 Ph 染色體、早期達到完全緩解
+ **達到第一完全緩解**：60-90%
+ 兒童 ALL：75% 長期緩解（>5 年）
+ 成人 ALL：30-40% 5 年存活

**AML vs. ALL 鑑別要點**：

| 特色 | AML | ALL |
|:-----|:----|:----|
| 大小 | 大（成人）| 小（兒童）|
| Blasts | 大 | 小 |
| 細胞質 | 多 | 少 |
| Nucleoli | 多（3-5）| 少（1-3）|
| Granules/Auer rods | 有 | 無 |
| 染色的 | Myeloperoxidase、Sudan black | PAS |
| 成熟障礙 | 超過 myeloblast 或 promyelocyte | 超過 lymphoblast |

## 淋巴瘤（Lymphomas）

### 定義

+ 淋巴細胞惡性增殖，惡性淋巴細胞聚集在淋巴結和淋巴組織
+ 導致淋巴結病變、結外病變、constitutional symptoms

**Table 15. Ann Arbor 分期系統**

| 分期 | 描述 |
|:-----|:-----|
| I | 單一淋巴結區域或淋巴結外器官/部位（Stage IE）|
| II | ≥2 個淋巴結區域或 1 個淋巴結外器官/部位及同側橫膈膜一側 ≥1 淋巴結區域 |
| III | 橫膈膜兩側都有淋巴結區域受累 |
| IV | 瀰漫性累及一個或多個淋巴結外器官，包括骨髓 |

+ **A**：無 B-symptoms
+ **B**：有 B-symptoms

## 霍奇金淋巴瘤（Hodgkin Lymphoma, HL）

### 定義

+ 淋巴細胞惡性增殖，伴有 Reed-Sternberg cells

### 流行病學

+ 雙峰分布：20 歲和 >50 歲
+ 高達 50% 與 Epstein-Barr 病毒相關，因果關係未確定

### 臨床表現

+ **無症狀淋巴結病變**（70%）：
  - Non-tender、rubbery consistency
  - Cervical/supraclavicular（60-80%）、Axillary（10-20%）、Inguinal（6-12%）
+ **脾腫大**（50%）+ **肝腫大**
+ **縱隔腫塊**：
  - 常规 CXR 發現，可能有症狀（咳嗽）
  - 很少表現為上腔靜脈症候群和胸腔積液
+ **全身症狀**：
  - **B-symptoms**：6 個月內非故意體重減少 >10%、體溫 >38°C、盜汗 >2 週（無感染證據）；晚期疾病還有 extreme fatigue
  - Pruritus（非特異/副腫瘤）
+ 從單一淋巴結部位（淋巴結）開始，首先擴散至相鄰淋巴結

### 診斷檢查

+ **CBC**：
  - Anemia（慢性病，罕見 hemolytic）、Eosinophilia、Lymphopenia、疾病早期血小板正常或增加、晚期疾病減少
+ **Biochemistry**：
  - HIV、HBV、HCV 血清學
  - 肝酶和/或 LFTs（肝臟侵犯）
  - 腎功能檢查（開始化療前）
  - ALP、Ca²⁺（骨侵犯）
  - ESR（預後）、LDH（分期、監測疾病進展）
+ **Imaging**：
  - CT chest（淋巴結、縱隔腫塊）、CT abdomen/pelvis（肝或脾侵犯）、PET scan
  - 心功能評估（MUGA 或心臟超聲）：高風險患者（年齡 >60、HTN、CHF、PUD、CAD、MI、CVA 史）
  - PFTs：有肺病史時（COPD、吸菸、先前肺部放射）
+ **Excisional lymph node 或 core biopsy**確診
+ **BM biopsy**評估骨髓浸潤（僅在有 B-symptoms、PET 顯示骨髓影像陽性或血球減少時必要）

### 治療

+ **Stage I-II**：化療（ABVD）後進行 involved field 或 involved site 放射治療（XRT）
+ **Stage III-IV**：化療（ABVD、Brentuximab-AVD 或 BEACOPP）+ 有大塊疾病時 XRT
+ **復發、化療抵抗**：高劑量化療和自體幹細胞移植、抗 CD30 Ab 療法、Pembrolizumab
+ **PET scan**結果對於評估疾病治療反應至關重要

**ABVD**：Adriamycin、Bleomycin、Vinblastine、Dacarbazine
**BEACOPP**：Bleomycin、Etoposide、Adriamycin、Cyclophosphamide、Vincristine、Procarbazine、Prednisone

### 治療併發症

+ **心臟疾病**：XRT 和 adriamycin cardiomyopathy（1% 患者）的後遺症
+ **肺部疾病**：Bleomycin（間質性肺炎）的後遺症
+ **不孕**：ABVD <3%（開始化療前討論精子銀行/取卵很重要）
+ **放射區域內第二腫瘤**：
  - 肺癌或乳腺癌（治療後 >8 年）
  - 非霍奇金淋巴瘤
+ 甲狀腺功能減退：XRT 後

### 預後

**Hasenclever 不良預後因素**（晚期疾病）：
1. 血清白蛋白 <40 g/L
2. Hb <108 g/L
3. 男性
4. Stage IV 疾病
5. 年齡 ≥45 歲
6. Leukocytosis（WBC >15 × 10⁹/L）
7. Lymphocytopenia（淋巴細胞 <0.06 × 10⁹/L 或 <8% WBC count 或兩者）

每增加一個不良預後因素，5 年無病存活（FFP）降低。

## 非霍奇金淋巴瘤（Non-Hodgkin Lymphoma, NHL）

### 定義

+ 淋巴細胞（progenitor 或成熟 B- 或 T-細胞）惡性增殖

### 分類

+ 可起源於 B-（85%）或 T-/NK-（15%）細胞
+ **B-cell NHL**：如瀰漫性大 B 細胞淋巴瘤、滤泡性淋巴瘤、Burkitt 淋巴瘤、套細胞淋巴瘤
+ **WHO/REAL 分類**（基於自然病史）：
  1. **Indolent**（35-40% NHL）：如滤泡性淋巴瘤、小淋巴細胞淋巴瘤/CLL、套細胞淋巴瘤
  2. **Aggressive**（~50% NHL）：如瀰漫性大 B 細胞淋巴瘤
  3. **Highly aggressive**（~5% NHL）：如 Burkitt 淋巴瘤
+ **T-cell NHL**：如蕈樣黴菌病（皮膚 indolent TCL）、外周 T 細胞淋巴瘤-NOS、間變性大細胞淋巴瘤

### 臨床表現

+ **無痛性淺表淋巴結病變**，通常 >1 淋巴結區域；侵襲性 NHL 生長快速
+ 可局部或廣泛淋巴結病變（indolent NHL 更常見）
+ NHL 中 constitutional symptoms 不如 HL 常見
+ 骨髓侵犯時：Anemia + Neutropenia + Thrombocytopenia
+ 腹部徵象 + 肝脾腫大、腹膜後和腸系膜侵犯
+ 5-10% 口咽侵犯（咽痛和阻塞性睡眠呼吸暫停）
+ **結外侵犯**：最常見於 GI 道、睪丸、骨、腎
+ 1% CNS 侵犯（常與 HIV、睪丸 DLBCL 或 >2 結外部位相關）

### 診斷檢查

+ **CBC**：
  - Normocytic normochromic anemia
  - 晚期疾病：Thrombocytopenia、Neutropenia、Leukoerythroblastic blood film
  - 可能有淋巴瘤細胞
  - 僅在有淋巴細胞增多時做 flow cytometry
+ **Biochemistries、HIV、HBV、HCV 血清學**：
  - Uric acid 升高
  - 肝轉移時 LFTs 異常
  - LDH 升高（快速進展疾病和不良預後因素）
+ **SPEP 和免疫球蛋白定量**（indolent lymphomas，特別是淋巴漿細胞淋巴瘤的高 IgM 單克隆蛋白和 hyperviscosity 篩檢）
+ 分期：CT neck、chest、abdomen、pelvis、BM biopsy
+ **PET imaging**：侵襲性淋巴瘤治療前後確保治療後緩解

### 治療

+ **Indolent NHL，局部疾病（如 Stage I 或 II）**：
  - 放射治療至主要部位和相鄰淋巴結區域
  - 脾臟邊緣區淋巴瘤：脾切除
+ **Stage III 或 IV Indolent NHL** 治療目標是症狀管理：
  - 觀察等待
  - 局部有症狀疾病：放射治療
  - **Bendamustine + rituximab** 優於 CHOP + rituximab（CHOP-R）治療晚期疾病
  - **Obinutuzumab**（新型抗 CD20 Ab）優於 rituximab 治療晚期滤泡性淋巴瘤（GALLIUM Trial）
+ **侵襲性淋巴瘤**：治療目標是根治
  - 聯合化療：**CHOP** 是主要方案，B-cell lymphoma 加 rituximab
  - 局部/大塊疾病：放射治療
  - 特定部位（如睪丸）有 CNS 侵犯風險時：高劑量 methotrexate CNS 預防
  - 復發、化療抵抗：高劑量化療、自體 SCT、CAR T-cell therapy（二線復發）
+ **Highly aggressive lymphoma**：
  - **Burkitt lymphoma**：短期高強度化療；常使用 CODOX-M 化療方案 + IVAC + rituximab
  - CNS 預防和 TLS 預防

### 併發症

+ Hypersplenism
+ 感染
+ 自體免疫 hemolytic anemia 和 thrombocytopenia
+ 血管阻塞（擴大淋巴結）
+ 腸穿孔
+ TLS（特別是侵襲性淋巴瘤）

### 預後

+ **滤泡性淋巴瘤**：使用 Follicular Lymphoma International Prognostic Index：年齡 >60；>4 淋巴結區域；>6 cm 淋巴結區域；LDH 升高；Lugano Stage III-IV；Hb <120 g/L；高 β-2 微球蛋白；BM 侵犯
  - 依計算風險，5 年平均存活範圍 53-91%
  - 很少可根治，通常復發緩解，有轉化為侵襲性淋巴瘤（如 DLBCL）的風險
+ **瀰漫性大 B 細胞淋巴瘤**：使用 International Prognostic Factor Index（5 個不良預後因素）：年齡 >60；Ann Arbor Stage（III-IV）；Performance status（ECOG/Zubrod 2-4）；LDH 升高；>1 結外部位
  - 依計算風險，5 年平均存活範圍 26-73%
  - ~40% 可根治

## 漿細胞疾病（Plasma Cell Dyscrasias）

### 多發性骨髓瘤（Multiple Myeloma, MM）

**定義**：
+ 漿細胞的惡性增殖
+漿細胞浸潤骨髓導致：
  - 骨病變（骨痛、病理性骨折）
  - 貧血、感染、腎功能衰竭
+ 單克隆（M）蛋白由增生的漿細胞產生

**診斷標準（SLIM CRAB）**：
- **S**：BM 中 ≥60% plasma cells
- **L**：Light chain ratio >100（涉及受累/未受累血清游離輕鏈）
- **M**：MRI、PET/CT 上 >1 個溶骨性病變
- **C**：Calcium 升高（Hypercalcemia）
- **R**：Renal insufficiency
- **A**：Anemia（Hb <100 g/L）
- **B**：Bone lesions（X-ray、CT 或 PET 顯示）

**分期（Durie-Salmon Plus 系統和 ISS）**：

**Table 16. ISS 分期**

| 分期 | β2-microglobulin | Albumin | 平均存活 |
|:-----|:-----------------|:--------|:---------|
| I | <3.5 mg/L | ≥35 g/L | >5 年 |
| II | 3.5-5.5 mg/L | 不適用 | 3-4 年 |
| III | >5.5 mg/L | 不適用 | 1-2 年 |

修訂 ISS 使用原始 ISS + 細胞遺傳學特徵（p53 突變與不良存活和化療抗性相關）+ LDH

### 意義未明單克隆丙種球蛋白病（MGUS）

**定義**：
+ 血清中存在 M 蛋白但無漿細胞疾病或淋巴增生病臨床或實驗室證據
+ 發生率：一般人口 0.15%，>70 歲 5%

**診斷**：
- 血清 M 蛋白 <30 g/L
- 骨髓漿細胞 <10%
- 無 SLIM CRAB
- 每年 0.3-1% 患者進展為血液系統惡性腫瘤
- M 蛋白峰值 ≥15 g/L、異常游離輕鏈比值或 IgA/IgM MGUS 惡性轉化風險較高
- 異常血清游離輕鏈比值增加惡性轉化風險

**監測**：q6-12 個月病史和身體、CBC、Cr、Calcium、Albumin、LDH、SPEP

### 淋巴漿細胞淋巴瘤（Waldenström's Macroglobulinemia）

**定義**：
+ 淋巴漿細胞增增殖；存在單克隆 IgM 副蛋白

**臨床表現**：
+ 慢性病；老年人；中位年齡 64 歲
+ **症狀**：Weakness、Fatigue、Bleeding（口鼻）、Weight loss、復發性感染、Dyspnea、CHF（貧血、hyperviscosity、血漿容量擴張三聯徵）、神經系統症狀、周邊神經病變、腦功能障礙
+ **理學發現**：Pallor、Splenomegaly、Hepatomegaly、Lymphadenopathy、視網膜病變
+ **主要併發症**：Hyperviscosity syndrome（因為 IgM 较大，主要局限於血管內空間）

**診斷檢查**：
+ BM 顯示漿細胞樣淋巴細胞
+ 通常無骨病變
+ 很少有 Hypercalcemia
+ Hyperviscosity 未出現時：Normocytic anemia、Rouleaux、ESR 很高
+ Cold hemagglutinin disease 可能：Raynaud's phenomenon、寒冷天氣誘發的 hemolytic anemia
+ HBV、HCV 血清學（與 HCV 相關；HCV 根除可使 LPL 緩解）

### 高黏滯症候群（Hyperviscosity Syndrome）

**定義**：
+ 相對血清黏滯度 >5-6 單位時，由循環血清 Ig 或高增殖性疾病（MM、白血病、PV）中細胞成分增加引起的臨床後遺症
+ Waldenström's macroglobulinemia 占 85% 病例

**臨床表現**：
+ **高血容量**：CHF、Headache、Lethargy、稀釋性貧血
+ **CNS 症狀**（腦血流減少）：Headache、Vertigo、Ataxia、中風
+ **視網膜**：靜脈充血和出血
+ **出血素質**：
  - 血小板功能受損、可溶性凝血因子吸收受損（如鼻出血、牙齦滲血）
+ ESR 通常非常低

**治療**：
+ Plasmapheresis、化療

## 腫瘤溶解症候群（Tumour Lysis Syndrome, TLS）

### 定義

+ 腫瘤細胞自發性或治療相關裂解引起的代謝併發症群
+ 更常見於大腫瘤負荷和高增殖率的疾病（高階淋巴瘤、急性白血病）

### 臨床表現

+ **代謝異常**：
  - 細胞裂解，釋放 K⁺、Uric acid、PO₄³⁻（水平升高）
  - PO₄³⁻ 結合 Ca²⁺（Ca²⁺ 降低）
+ **併發症**：
  - 致命心律不整（K⁺ 升高）
  - 急性腎損傷（見腎臟科 NP21）

### 治療

+ **預防**：
  - 積極靜脈水化
  - **不建議鹼化尿液**（鈣磷酸鹽或黃嘌呤在腎小管沉澱的風險）
  - Allopurinol（預防尿酸積累）或 Rasburicase（降低現有尿酸）
  - 糾正已存在的代謝異常
+ **透析**

## 血液製品與輸血（Blood Products and Transfusion）

### 血液製品

+ **RBCs、Platelets、凝血因子**（FFP、Cryoprecipitate、Fibrinogen concentrate、Factor concentrates）
+ 捐血（1 Unit = 450-500 mL）被分離成各種成分
+ **FP（以前稱 FFP）**：收集後 24 小時內冷凍的血漿
+ **Cryoprecipitate**：FP 在低溫下解凍時生成的高分子量沉澱物

### 特殊製品

+ **照射血液製品**：
  - 防止捐贈者 T 細胞在 recipients 增殖，預防 GVHD
  - 用於嚴重 T 細胞免疫缺陷患者、接受嘌呤類似物化療者、Hodgkin lymphoma、BM 移植候選者、或接受一等親捐贈者定向輸血者
+ **CMV 陰性血液製品**：
  - 血清陰性孕婦
  - 宮內輸血

### 紅血球

**Packed Red Blood Cells**：
+ 保存於 4°C
+ 有效期為收集後 42 天
+ 每單位輸注 >2 小時（最長 4 小時）

**適應症**：
+ Hb <70 g/L；可根據患者耐受性或症狀調整
+ 活動性出血期間維持 Hb 在 70-90 g/L
+ 考虑為以下患者維持較高 Hb：
  - CAD/不穩定冠狀動脈症候群
  - 無法控制、不可預測的出血

**輸血前選擇**：
+ **Group and screen**：確定受血者血型和 Rh 狀態，以及血漿中對主要/次要血型抗原的自體或同種抗體
+ **Cross-match**：混合受血者血液與潛在捐贈者血液，觀察凝集（需 30-45 分鐘）
+ 所需時可用選項：
  - 第一線：完全交叉配對的血液
  - 第二線：與受血者相同血型和 Rh 狀態的捐贈者血液
  - 第三線：育齡女性用 O- 血；其他用 O+ 血

### 血小板

**Table 17. 血小板製品適應症**

| 製品 | 適應症 |
|:-----|:-------|
| Random donor（Pooled）| 血小板減少伴出血 |
| Single donor platelets | 潛在 BMT recipients、對 pooled platelets 無效者 |
| HLA matched platelets | 對 pooled 或 single donor platelets 無效、存在 HLA Abs 者 |

+ 保存於 20-24°C
+ Random donor platelets 為 4 單位 pool；apheresis platelets 來自單一捐贈者
+ 1 單位血小板 pool 應使血小板計數增加 ≥15 × 10⁹/L

**血小板輸血適應症**：

| PLT（× 10⁹/L）| 適應症 |
|:-------------|:-------|
| <20 | 非免疫性血小板減少症 |
| <50 | 不伴顯著失血的手術 |
| <50 | 伴失血或大手術（估計失血 >500 mL）的程序 |
| <100 | 神經外科或頭部創傷 |
| Any | 血小板功能障礙（或抗血小板藥物）且有顯著出血 |

**血小板輸血的相對禁忌症**：
+ TTP、HIT、Post-transfusion purpura、HELLP

### 凝血因子製品

**Table 18. 凝血因子製品**

| 製品 | 適應症 |
|:-----|:-------|
| FFP | 多種凝血因子缺乏（如敗血症、DIC、稀釋、TTP/HUS、肝病）、危及生命的出血且無因子濃縮製劑時緊急逆轉 warfarin 過量 |
| Cryoprecipitate | Hemophilia（Factor VIII 缺乏）和 von Willebrand disease — 緊急時無特異因子濃縮製劑使用；Hypofibrinogenemia |
| Fibrinogen Concentrate | Hypofibrinogenemia |
| Humate P/VWF | von Willebrand disease 和 Hemophilia A |
| Factor VIII concentrate | Factor VIII 缺乏伴出血/手術；Hemophilia A 或 B 伴抑制物 |
| Factor IX concentrate | Factor IX 缺乏（Hemophilia B）|
| Recombinant factor VIIa | 有抑制物的 Hemophilia A 或 B；Glanzmann's thrombasthenia |
| PCC | Warfarin 治療或維生素 K 缺乏的出血患者或需要 <6 小時緊急手術的患者；Direct Xa 抑制劑的緊急非特異「逆轉」|

## 急性輸血反應（Acute Transfusion Reactions）

### 免疫性反應

**急性溶血性輸血反應（Acute Hemolytic Transfusion Reactions）**：
+ ABO 不相容導致補體活化引起的血管內溶血，輸血後立即發生
+ 最常見原因是患者識別錯誤
+ 每單位血液風險 <1/40000
+ **表現**：發燒、寒顫、低血壓、背或腰痛、呼吸困難、Hemoglobinuria
+ 急性腎衰竭（<24 小時）和 DIC
+ **治療**：停止輸血、通知血庫確認沒有 clerical error、發新標本至血庫重複檢驗並抽取溶血實驗室（Hematocrit、膽紅素、LDH、Reticulocytes、DAT）、用大量靜脈輸液和強心劑維持血壓、用利尿劑、晶體液、多巴胺維持尿量

**發燒非溶血性輸血反應（Febrile Nonhemolytic Transfusion Reactions）**：
+ 由對 WBC、血小板或其他捐贈者血漿抗原的同種抗體及血液製品細胞釋放的細胞激素引起
+ 輸血後 6 小時內發生
+ 每單位風險 1/100（輕微）；1/10000-40000（嚴重）
+ **表現**：發燒 + 寒顫、面部充血、頭痛、肌肉疼痛、腹痛、噁心/嘔吐
+ **治療**：
  - 排除溶血反應或感染
  - 若體溫 <39°C 且無嚴重症狀：繼續輸血但減慢速度並給予退燒藥
  - 若體溫 ≥39°C 或有嚴重症狀：停止輸血、調查反應並開始支持性措施

**過敏非溶血性輸血反應（Allergic Nonhemolytic Transfusion Reactions）**：
+ 由對捐贈者血漿蛋白質的 IgE 同種抗體引起，導致肥大細胞活化和組胺釋放
+ 主要見於有多次輸血史或經產婦女
+ 每單位風險 1/100
+ **表現**：主要為蕁麻疹，有時發燒
+ 可見於部分 IgA 缺乏患者（抗 IgA）
+ **治療**：
  - 輕度：減慢輸血速度並給予 diphenhydramine
  - 中度至重度：停止輸血，給予 IV diphenhydramine、類固醇、Epinephrine、IV 輸液、支氣管擴張劑

**輸血相關急性肺損傷（TRALI）**：
+ 輸血期間或完成後 6 小時內發生的急性肺損傷新發
+ 顯著缺氧（PaO₂/FiO₂ <300 mmHg）
+ 影像學雙側肺部水腫
+ 無左心房高血壓臨床證據，或若存在則判斷非主要因素
+ 可能機制：捐贈者 Ab 與受血者 WBC 結合，釋放增加肺毛細血管通透性的介質
+ 通常在輸血後 2-4 小時發生，24-72 小時內消退
+ 每單位風險 1/10000
+ **目前是輸血相關 morbidity 和 mortality 的主要原因**
+ **治療**：支持性治療（氧氣）；通知血庫；將安排患者和捐贈者檢驗

### 非免疫性反應

**輸血相關循環超負荷（TACO）**：
+ 心臟功能受損和/或輸血過快導致
+ **表現**：呼吸困難、端坐呼吸、高血壓、心搏過速、肺底囉音、靜脈壓升高
+ 發生率 1/100
+ **風險因素**：年齡 >70 歲、心衰竭、心肌梗塞史、腎衰竭、正液體平衡
+ **治療**：停止輸血，給予利尿劑和氧氣；預防：減慢速度輸血 + 利尿劑

**敗血症（Bacterial Contamination）**：
+ 血小板製品（室溫保存）比 RBC 製品（冷藏）更常見
+ **表現**：發燒、寒顫、低血壓、敗血症休克
+ **治療**：停止輸血、化驗、廣效抗生素

**術後輸血反應鑑別診斷**：
- 急性溶血性輸血反應
- 發燒非溶血性輸血反應
- 敗血症
- 過敏反應
- TACO
- TRALI
