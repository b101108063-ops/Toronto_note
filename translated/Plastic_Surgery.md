# Plastic Surgery 整形外科

---

## 導讀摘要

- **美容手術涵蓋範圍廣**：包括面部（hair transplant、otoplasty、rhytidectomy、blepharoplasty、rhinoplasty、genioplasty）、皮膚（chemical peel、dermabrasion、laser resurfacing、injectable fillers、neuromodulators），以及身體輪廓（abdominoplasty、liposuction、brachioplasty、thighplasty）等多元化程序
- **Gender-Affirming Surgery 需跨專科合作**：手術前需確認性別認同、評估心理健康、術後需長期追蹤；MtF 執行乳房增大、面部女性化、甲狀軟骨縮小；FtM 執行胸部男性化、甲狀軟骨增強；所有手術皆為不可逆性
- **兒童先天性異常早期介入關鍵**：cleft lip/palate（唇顎裂）手术时机分别在 3-6 个月和 6-9 个月；craniosynostosis（顱縫早閉）早期手術可預防次發性畸形；congenital hand anomalies（先天性手部異常）需根據分類型別制定個別化治療計畫
- **唇顎裂分類與治療複雜**：cleft lip 影響上頜骨與鼻側突融合，單側左側最常見；cleft palate 為軟硬顎與鼻中隔融合失敗；Veau classification 將 cleft palate 分為四群，手術採 Millard/Fisher (lip) 及 Von Langenbeck/Furlow-Plasty (palate)
- **先天性手部異常 ASSH 分類系統**：依發育障礙類型分為 Formation failure、Differentiation failure、Duplication、Overgrowth、Undergrowth、Constriction band syndrome、Generalized skeletal abnormality；治療涵蓋復健、軟組織手術、骨骼手術及顯微手術

## 美容手術（Aesthetic Surgery）

### 美容程序概述

**Table 34. 美容程序**

| 部位 | 手術名稱 | 說明 |
|------|----------|------|
| **頭頸部** | Hair transplant（植髮） | 使用毛囊移植或皮瓣改善毛髮生長模式 |
| | Otoplasty（耳廓整形） | 耳廓外部的手術重建 |
| | Forehead/brow lift（前額提眉） | 提拉前額與眉毛的手術 |
| | Rhytidectomy（臉部拉皮） | 減少面部與頸部皺紋與下垂；俗稱「facelift」|
| | Blepharoplasty（眼瞼整形） | 移除過多眼瞼皮膚與脂肪墊以改善眼瞼外觀 |
| | Rhinoplasty（鼻整形） | 鼻部與鼻腔通道的手術重建 |
| | Genioplasty（下巴整形） | 透過截骨術或人工植入物墊下巴以改善輪廓 |
| **皮膚** | Chemical peel（化學換膚） | 塗抹一種或多種剝離劑於皮膚，破壞部分表皮與真皮，隨後組織再生 |
| | Dermabrasion（皮膚磨皮） | 使用高速旋轉之研磨工具進行皮膚 resurfacing；常用於減少疤痕、不平皮膚表面及細紋 |
| | Laser resurfacing（雷射煥肤） | 雷射應用於皮膚，最终導致膠原蛋白重新排列，隨後皮膚緊縮；常用於減少疤痕與皺紋 |
| | Injectable fillers（注射填充物） | 注射物質以改善面部容積/輪廓；可使嘴唇豐滿；常見物質包括膠原蛋白、脂肪、hyaluronic acid、calcium hydroxyapatite |
| | Neuromodulators（如 Botox）（神經調節劑） | 源自 Clostridium botulinum 產生之神經毒素；抑制神經末梢與肌肉纖維間之神經傳遞，使骨骼肌軟弱或癱瘓；常用於抗衰老與面部回春 |
| **其他** | Abdominoplasty（腹部整形） | 移除過多皮膚並修復腹直肌鬆弛（rectus diastasis）；俗稱「tummy tuck」|
| | Calf augmentation（小腿增大） | 使用植入物增大小腿肌肉 |
| | Liposuction（抽脂） | 手術移除脂肪組織以改善身體輪廓（非減重程序）|
| | Brachioplasty（手臂整形） | 重塑並改善上臂與胸壁連接處的輪廓 |
| | Thighplasty（大腿整形） | 透過減少過多皮膚與脂肪來重塑大腿，使皮膚更平滑、大腿與下身比例更佳 |
| | Flankplasty（腰側整形） | 改善腰部與背部下方（特別是臀部與下背部）外觀的手術，向兩側延伸 |
| | Labiaplasty（陰唇整形） | 減少小陰唇長度的手術 |
| | Vaginoplasty（陰道整形） | 緊實陰道的手術 |

## 變性手術（Gender-Affirming Surgery）

### 手術原則

- 與患者確認偏好的性別代名詞
- 術前需求差異大，包括（但不限於）：1 年賀爾蒙治療試驗、術前心理健康專業人員的評估信函與文件（依據 WPATH Standards of Care 第 7 版指南）

### 跨性別女性（MtF）的手術選項

**Table 35. 跨性別女性的手術選項**

| 手術 | 說明 | 術後注意事項 |
|------|------|--------------|
| Breast Augmentation（乳房增大） | 植入物為主、脂肪移植或 combined surgery 以增加乳房尺寸 | 監測植入物破裂；除性別特定醫療維護外，需遵守乳房癌症篩檢指引 |
| Contouring Procedures（輪廓雕塑） | 使用抽脂或脂肪移植改變身體區域的脂肪分布（腹部、腰側、臀部和股部），受自體脂肪可用性限制 | 脂肪移植區域短期限制承重（<2 週）；長期而言注入的脂肪容積不會 100% 維持 |
| Facial Feminization（面部女性化） | + Hairline surgery、+ 前額增大或截骨術、+ Rhinoplasty、+ Genioplasty（單獨墊下巴通常不足） | 墊下巴可能影響嘴唇感覺與下門牙感覺 |
| Chondrolaryngoplasty（軟骨喉切除） | 移除軟骨以減少甲狀軟骨大小 | 基於甲狀軟骨附近喉返神經的手術位置，有長期聲音嘶啞風險；所有手術均為不可逆（如 cricothyroid approximation）|
| Vocal Cord Surgery（聲帶手術） | 改變聲帶長度以提高音調 | 部分手術可能縮窄氣道（如 anterior vocal web formation）；不保證達到確切的期望音調變化 |
| Vaginoplasty（陰道重建） | 見 Urology, Transition-Related Surgeries | — |

### 跨性別男性（FtM）的手術選項

**Table 36. 跨性別男性的手術選項**

| 手術 | 說明 | 術後注意事項 |
|------|------|--------------|
| Chest Masculinization（胸部男性化） | 最常見技術為 double incision free nipple graft；periareolar incision 也常用 | 乳頭感覺喪失；對於有過多皮下組織的患者，可能需要抽脂（取決於術前大小與下垂程度）|
| Contouring Procedures（輪廓雕塑） | 見 Table 35 | — |
| Facial Masculinization（面部男性化） | + 前額增大、+ 上頜增大、+ 下頜增大、+ Rhinoplasty、+ Genioplasty | 墊下巴可能影響嘴唇感覺與下門牙感覺 |
| Thyroid Cartilage Enhancement（甲狀軟骨增強） | 軟骨添加以增加甲狀軟骨突出 | 手術有聲帶癱瘓風險 |
| Vocal Cord Surgery（聲帶手術） | 改變聲帶長度以降低音調 | 不保證達到確切的期望音調變化 |
| Phalloplasty, Metoidioplasty | 見 Urology, Transition-Related Surgeries | — |

> 更多性別肯定手術技術資訊，見 Urology, Transition-Related Surgeries。

## 兒童整形外科（Pediatric Plastic Surgery）

### 顱顏部異常（Craniofacial Anomalies）

**Table 37. 兒童顱顏部異常**

| 疾病 | 定義 | 流行病學 | 臨床特徵 | 治療 |
|------|------|----------|----------|------|
| **Cleft Lip（唇裂）** | 上頜骨與鼻側突融合失敗 | 每 1000 活產約 1 例（亞洲人發生率較高，非裔美人發生率較低）| 分類為 incomplete/complete 與 unilateral/bilateral；2/3 為單側，左側為主；男性較常見 | 手術（3-6 個月：Millard 或 Fisher；必要時日後進行額外整形手術，特別是鼻部）|
| **Cleft Palate（顎裂）** | 軟硬顎與鼻中隔的顎突融合失敗 | 單獨顎裂：每 1000 活產約 0.5 例（無腭裂的情況下）；女性較常見 | 分類為 incomplete/complete 與 unilateral/bilateral；若父母或手足有顎裂，4% 機率；若父母與手足都有則 20% | 特殊奶瓶餵養；語言治療；手術（6-9 個月：Von Langenbeck 或 Furlow-Plasty）；耳鼻喉科會診——常見復發性中耳炎，可能需要置入通氣管 |
| **Craniosynostosis（顱縫早閉）** | 顱縫過早融合 | 每 2000 活產兒約 1 例；M:F = 5:2 | 分為原發性（無已知原因）或續發性（與已知原因或症候群相關）；類型包括：冠狀、矢狀、人字形等；常見症候群： Crouzon、Apert、Saethre-Chotzen、Carpenter、Pfeiffer、Jackson-Weiss、Boston 型症候群 | 早期手術預防續發性畸形 |

**Figure 48. Veau Classification of Cleft Lip and Palate（唇顎裂的 Veau 分類）**

- **Group I**：僅軟顎缺陷
- **Group II**：涉及硬顎與軟顎的缺陷
- **Group III**：涉及軟顎到齒槽的缺陷，通常涉及嘴唇
- **Group IV**：完全雙側裂

### 先天性手部異常（Congenital Hand Anomalies）

**Table 38. 美國手外科學會（ASSH）先天性手部異常分類**

| 分類 | 範例 | 特徵 | 治療 |
|------|------|------|------|
| **Formation Failure（形成失敗）** | | | |
| — Transverse absence（橫向缺失） | 先天性截肢 | 任何平面（常見於肘部/腕部以下）| 早期義肢 |
| — Longitudinal absence（縱向缺失） | 缺肱骨（phocomelia） | Thalidomide 相關 | — |
| — Radial deficiency（橈側缺失，radial club hand） | | 橈側偏移；拇指發育不全 | 物理治療 + 副木；軟組織放鬆（若副木無效）；lizarov distraction；楔形截骨術；肌腱轉移；功能性拇指重建（pollicization）|
| **Differentiation/Separation Failure（分化/分離失敗）** | | | |
| — Thumb hypoplasia（拇指發育不全） | | 程度從有完整組件的拇指到完全缺失；常見於 Fanconi anemia、Holt-Oram、CHARGE 症候群 | 取決於程度——可能不需要治療、webspace deepening、肌腱轉移、或 index finger pollicization |
| — Ulnar club hand（尺側 club hand） | | 罕見（相對於橈側）；穩定手腕 | 副木與軟組織伸展治療；軟組織放鬆（上述無效時）；lizarov distraction 矫正角度 |
| — Cleft hand（裂手） | | 自體顯性遺傳；常功能正常（取決於程度）| First web space syndactyly release；若有拇指發育不全則進行 osteotomy + 肌腱轉移 |
| **Duplication（重複）** | | | |
| — Syndactyly（併指）| | 短指伴隨指尖指甲；常見於 Apert、Poland、Holt-Oram 症候群 | 手指分離；可能需要植皮覆蓋手指；通常效果良好 |
| — Symbrachydactyly / Brachysyndactyly | | 短指骨；短蹼狀手指；多樣化表現 | 數位分離；webspace deepening |
| — Polydactyly（多指）| | 先天性手指重複；可為橈側（亞洲人與美洲原住民較常見）、中央或尺側（非裔美人較常見）| 早期副木；掌側放鬆；arthroplasty（罕見）|
| — Macrodactyly（大指）| | 罕見；手指變大 | 若嚴重則 osteotomy with grafting；否則觀察 |
| — Camptodactyly（屈曲指）| | 先天性手指屈曲攣縮（通常在 PIP，特別是第五指）| 通常不需要治療（輕度）；軟組織/骨骼縮小 |
| — Clnodactyly | | 放射性或尺側偏移；常見中節指骨異常 | 移除無功能殘肢；osteotomies/肌腱轉移；lizarov distraction |
| **Overgrowth（過度生長）** | | | |
| — Macrodactyly（大指）| | 手指過度生長 | 軟組織/骨骼縮小；嚴重時考慮截肢 |
| **Undergrowth（發育不全）** | | | |
| — Brachydactyly（短指）| | 短指骨 | 通常不需要治療；嚴重時 osteotomy + grafting |
| **Constriction Band Syndrome（約束帶症候群）** | | | |
| — Amniotic annular band syndrome | | 多樣化表現；羊膜約束帶纏繞 | 新生兒緊急釋放急性、進行性水腫；其他重建視個案而定 |
| **Generalized Skeletal Abnormality（全身性骨骼異常）** | | | |
| — Achondroplasia、MARFAN syndrome、Madelung's deformity | | 1 in 3000 活產；M:F = 2:4 | 治療取決於病因 |
