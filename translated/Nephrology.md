# 腎臟學 (Nephrology)

*Toronto Notes 2025*

---

## 導讀摘要

- **急性腎損傷（AKI）**：定義、分期、病因（Prerenal/Renal/Postrenal）、診斷與治療；Prerenal azotemia 與 ATN 的鑑別診斷
- **腎小球疾病**：從無症狀尿液化異常、腎炎症候群、腎病症候群到末期腎病的疾病譜系；包括 Glomerulonephritis、Rapidly Progressive GN、Nephrotic Syndrome
- **電解質失衡**：水與鈉平衡障礙、鉀、鈣、磷、Magnesium 異常；糖尿病腎病變的分期與治療
- **慢性腎病（CKD）**：KDIGO 分期、併發症管理（貧血、骨病變、電解質）、SGLT2 抑制劑與 RAAS 阻斷劑的腎臟保護
- **透析與腎移植**：Hemodialysis、Peritoneal Dialysis 的適應症與併發症；腎移植的免疫抑制治療與常見藥物

## 急性腎損傷（Acute Kidney Injury）

### 定義

+ 腎功能急劇下降，導致氮質廢物堆積
+ 舊稱：急性腎衰竭（Acute Renal Failure）

### 臨床表現

+ GFR 下降
+ 可能出現水腫與體重增加
+ Azotemia（血中 BUN、Cr 升高）
+ 尿量異常：正式定義為 >6 小時尿量 <0.5 ml/kg/h，但臨床上可表現為無尿、寡尿或多尿

### 分期（KDIGO）

| 分期 | 血清 Creatinine | 尿量 |
|:----:|:--------------|:-----|
| 1 | 基準值 1.5-1.9 倍 或 增加 ≥26.5 μmol/L | <0.5 ml/kg/h，持續 6-12 小時 |
| 2 | 基準值 2.0-2.9 倍 | <0.5 ml/kg/h，持續 ≥12 小時 |
| 3 | 基準值 3.0 倍 或 增加至 ≥353.6 μmol/L 或 開始腎替代治療 | <0.3 ml/kg/h 達 24 小時 或 無尿 ≥12 小時 |

### 病因分類

**Prerenal（腎前性）**：腎臟灌注不足
- 原因：低血壓、脫水、心輸出量減少
- 特點：Urine Na⁺ <10-20 mmol/L，Urine osmolality >500 mOsm/kg

**Renal（腎性）**：實質性腎損傷
- 原因：ATN（缺血或毒素引起）、AIN、GN、Vasculitis
- 特點：Urine Na⁺ >40 mEq/L，Urine osmolality <350 mOsm/kg

**Postrenal（腎後性）**：尿液出口阻塞
- 原因：結石、狹窄、前列腺肥大
- 特點：兩側腎臟或單一功能腎臟受影響

### Prerenal vs. ATN 鑑別

| 項目 | Prerenal | ATN |
|:----:|:---------|:----|
| 尿顯微鏡 | 正常 | 顆粒圓柱（muddy brown casts） |
| Urine Na⁺ | <20 mEq/L | >40 mEq/L |
| Urine osmolality | >500 mOsm/kg | <350 mOsm/kg |
| FeNa | <1% | >2% |
| BUN/Cr | >20:1 | 10-15:1 |
| 對輸液反應 | 恢復 | 持續或部分恢復 |

### 治療

**初步處置**：
+ Prerenal：優化容量狀態與心輸出量，使用等張生理食鹽水、白蛋白或血液製品；停用 ACEI/ARB、NSAIDs
+ Renal：去除可逆因素，停用腎毒性藥物，治療感染，糾正電解質
+ Postrenal：放置導尿管、膀胱引流、腎造口術或支架

**併發症治療**：
+ 液體過多：鈉限制、高劑量利尿劑
+ 電解質失衡（高血鉀、高磷、低鈣、鎂異常）
+ 酸鹼失衡
+ 透析治療

## 腎小球疾病（Glomerular Diseases）

### 組織學術語

**影響範圍**：
+ Diffuse：大多數腎小球異常
+ Focal：部分腎小球異常

**個別腎小球受影響程度**：
+ Global：整個腎小球異常
+ Segmental：僅部分腎小球異常

### 病變類型

+ **增生（Proliferation）**：腎小球細胞增生
+ **新月體形成（Crescent formation）**：腎炎特徵，腎絲球囊內有新月體
+ **膜性病變（Membranous changes）**： capillary wall thickening
+ **足細胞病變（Podocytopathy）**：足細胞損傷導致 foot-processes 消失

### 臨床表現譜系

腎小球疾病可表現為從 pure nephritic 到 pure nephrotic 的連續譜系：

**腎炎症候群（Nephritic Syndrome）**：
+ 血尿（顯微或巨觀）、RBC casts
+ 蛋白尿（<3.5 g/24h）
+ 高血壓
+ 寡尿
+ 腎功能下降（Azotemia）

**腎病症候群（Nephrotic Syndrome）**：
+ 大量蛋白尿（>3.5 g/24h）
+ 低白蛋白血症（<3 g/dL）
+ 水腫
+ 高血脂
+ 尿液中有脂肪圓柱與卵圓形脂肪體

### 蛋白尿分類

| 每日蛋白排出量 | 分期 | ACR |
|:-------------|:-----|:-----|
| <150 mg（<30 mg 白蛋白）| 正常 | <2.0 mg/mmol |
| 30-300 mg 白蛋白 | Microalbuminuria | 2.0-20 mg/mmol |
| >3500 mg/m² | 腎病範圍蛋白尿 | >220 mg/mmol |

### 常見腎小球疾病

**IgA 腎病變（IgA Nephropathy/Berger's Disease）**：
+ 全球最常見的原發性腎小球疾病
+ 常在上呼吸道感染後出現
+ 治療：RAAS 阻斷劑、類固醇、免疫抑制劑

**快速進展性腎小球腎炎（RPGN）**：
+ 病程數天至數週內進展
+ 免疫螢光分型：
  - Type I：抗 GBM 抗體介導（15%）
  - Type II：免疫複合體介導（24%）
  - Type III：Pauci-immune，ANCA 相關血管炎（60%）

**腎病症候群常見病理類型**：
| 類型 | 治療 |
|:-----|:-----|
| Minimal Change Disease | 類固醇、rituximab |
| Membranous Glomerulopathy | 類固醇、免疫抑制劑 |
| Focal Segmental Glomerulosclerosis (FSGS) | 類固醇、Calcineurin inhibitors |
| Membranoproliferative GN | 免疫抑制治療 |

## 腎小管間質疾病（Tubulointerstitial Diseases）

### 急性間質性腎炎（Acute Tubulointerstitial Nephritis, AIN）

**病因**：
+ 藥物過敏：β-lactam antibiotics、Sulfonamides、Rifampin、NSAIDs、PPIs
+ 感染：Pyelonephritis、CMV、EBV、HIV
+ 免疫：SLE、Sjögren's 症候群、Sarcoidosis

**臨床表現**：
+ AKI
+ 藥物過敏：發燒、皮疹、嗜酸性球增多
+ 膿尿、嗜酸性球尿

**治療**：
+ 去除病因（停用致病藥物）
+ 早期類固醇治療

### 慢性間質性腎炎（Chronic Tubulointerstitial Nephritis）

**病因**：
+ 尿路阻塞
+ 慢性腎盂腎炎
+ 腎毒素：NSAIDs、Cisplatin、Lithium、重金屬
+ 血管疾病：缺血性腎病、動脈粥樣栓塞

### 急性腎小管壞死（Acute Tubular Necrosis, ATN）

**病因**：
+ 缺血：低血壓、敗血症
+ 毒素： aminoglycosides、Contrast、Myoglobin

**臨床表現**：
+ 缺血事件後 Cr 急劇上升
+ 三階段：寡尿期 → 利尿期 → 恢復期
+ 尿液：高 FENa（>2%）、顆粒圓柱

**治療**：
+ 支持治療
+ 透析如有適應症（頑固性液體過多、代謝性酸中毒、高血鉀、尿毒症腦病）

## 腎臟血管疾病（Vascular Diseases of the Kidney）

### 腎血管疾病分類

| 大血管疾病 | 中血管疾病 | 小血管疾病 |
|:---------|:---------|:---------|
| 急性腎动脉栓塞 | Kawasaki 疾病 | 高血壓性腎硬化 |
| 腎动脉狹窄（缺血） | 結節性多發性血管炎 | 動脈粥樣栓塞性腎病 |
| 腎靜脈血栓 | ANCA 相關血管炎 | 血栓性微血管病 |
|  |  | 硬皮病 |
|  |  | Calcineurin inhibitor 腎病變 |

### 腎动脉狹窄（Renal Artery Stenosis）

**病因**：
+ 粥樣硬化（90%）：proximal 1/3 renal artery，常見於 >55 歲男性
+ 纖維肌發育不良（10%）：distal 2/3 renal artery，常見於年輕女性

**臨床表現**：
+ 難治性高血壓
+ 腎功能惡化
+ 自發性低血鉀
+ ACEI/ARB 使用後 Cr 上升

**治療**：
+ 藥物治療：ACEI、Statins、抗血小板藥物
+ 血管重建：對於嚴重個案可考慮

### 血栓性微血管病（Thrombotic Microangiopathy, TMA）

**病因**：TTP-HUS、DIC、子癇前症、藥物引起、補體介導

**治療**：
+ 血漿置換（TTP-HUS）
+ Eculizumab（補體介導 HUS）

## 全身性疾病的腎臟表現

### 糖尿病腎病變（Diabetic Nephropathy）

**分期**：
| 分期 | 特徵 |
|:----:|:-----|
| 1 | GFR 補償性增加（120-150%） |
| 2 | 微量白蛋白尿（A2）|
| 3 | 明顯白蛋白尿（A3）|
| 4 | 腎硬化 |

**治療原則**：
+ 嚴格血糖控制（HbA1c <7%）
+ 血壓控制（目標 <130/80 mmHg）
+ ACEI 或 ARB（首選，即使無高血壓）
+ SGLT2 抑制劑（Canagliflozin、Dapagliflozin、Empagliflozin）
+ Finerenone（mineralocorticoid receptor antagonist）
+ 戒菸

### 多發性骨髓瘤（Multiple Myeloma）的腎臟併發症

+ Light chain cast nephropathy（骨髓瘤腎病）
+ 高血鈣
+ 淀粉樣變性（AL、AA）
+ Monoclonal Ig 沉積疾病

### 全身性紅斑狼瘡（SLE）

狼瘡腎炎的 ISN/RPS 分類：
| Class | 描述 |
|:----:|:-----|
| I | 最小間質性病變 |
| II | 節段性/全域性間質增生 |
| III | 局灶性狼瘡腎炎 |
| IV | 瀰漫性狼瘡腎炎 |
| V | 膜性狼瘡腎炎 |
| VI | 晚期硬化性 |

## 囊腫性疾病（Cystic Diseases of the Kidney）

### 體染色體顯性多囊腎（ADPKD）

**遺傳學**：
+ PKD1（chromosome 16p）- 發生率 1:400
+ PKD2（chromosome 4q）- 發生率 1:1000

**臨床表現**：
+ 腹部/腰部疼痛
+ 血尿
+ 高血壓（60-75%）
+ 夜尿
+ 腎結石（5-15%）

**腎外表現**：
+ 肝囊腫（33%）
+ 心臟瓣膜疾病（25%）
+ 顱內动脉瘤（10%）
+ 憩室症、疝氣

**治療**：
+ 嚴格血壓控制（目標 <110/75 mmHg）
+ 鼓勵飲水 >2-3 L/d
+ Tolvaptan（V2 receptor antagonist）可減緩囊腫生長
+ 透析或腎移植

## 末期腎病（End Stage Renal Disease, ESRD）

### 定義

+ 腎功能不可逆的衰退，需要腎替代治療
+ GFR <15 mL/min/1.73 m²

### 臨床表現

**尿毒症症狀**：
+ 認知障礙
+ 胃腸症狀（厭食、嘔吐、口味改變）
+ 呼吸困難
+ 搔癢、肌肉痙攣
+ 週邊水腫

**併發症**：
+ CNS：腦病、意識障礙、癲癇
+ 心血管：心肌病變、心衰竭、心律不整、心包膜炎
+ 血液：貧血、出血素質、感染
+ 內分泌：性激素異常、胰島素阻抗
+ 骨骼：腎性骨病變（secondary hyperparathyroidism）

## 透析（Dialysis）

### 透析適應症

**絕對適應症**：
+ 容量過多
+ 高血鉀
+ 嚴重代謝性酸中毒
+ 尿毒症腦病變/神經病變/癲癇
+ 尿毒症心包膜炎

**相對適應症**：
+ 頑固性高血壓
+ 持續嚴重瘙癢
+ 嚴重貧血對 EPO 反應不佳

### 血液透析（Hemodialysis）

+ 血液通過半透膜人工腎臟
+ 可在透析中心（3-6 次/週）或居家進行
+ 血管通路：Central venous catheter、AV graft、AV fistula
+ 併發症：透析不平衡症候群、感染、肌肉痙攣

### 腹膜透析（Peritoneal Dialysis）

+ 使用腹膜作為過濾膜
+ 優點：獨立性高、飲食限制較少、可在家進行
+ 形式：CAPD（連續性門診腹膜透析）或 APD（自動腹膜透析）
+ 併發症：腹膜炎、導管感染、代谢問題

### 透析治療選擇比較

| 特性 | 腹膜透析 | 血液透析 |
|:-----|:---------|:---------|
| 速度 | 慢 | 快 |
| 地點 | 居家 | 透析中心或居家 |
| 超濾 | 滲透壓 | 液壓 |
| 優選情況 | 保有殘餘腎功能、血流動力學不穩定 | 腹膜粘連、無法居家照護 |

## 腎臟移植（Renal Transplantation）

### 優點

+ 提供最佳的腎功能替代
+ 逆轉尿毒症症狀效果最佳
+ 長期存活率和生活品質優於透析

### 移植類型

+ 活體捐贈（親屬或非親屬）
+ 逝世捐贈
+ 活體捐贈腎臟短期和長期預後較佳

### 免疫抑制治療

**誘導治療**：
+ Thymoglobulin（抗淋巴細胞抗體）
+ Basiliximab（抗 IL-2 受體抗體）

**維持治療**：
+ 皮質類固醇
+ Calcineurin 抑制劑（Cyclosporine、Tacrolimus）
+ 抗增殖藥物（Mycophenolate mofetil、Azathioprine）
+ mTOR 抑制劑（Sirolimus）

### 併發症

+ 急性排斥反應
+ BK 病毒腎病變
+ 新發糖尿病
+ 感染（CMV、PJP）
+ 惡性腫瘤（皮膚癌、淋巴瘤）
+ 心血管疾病（移植後主要死因）

## 腎臟科常用藥物

### 利尿劑

| 藥物 | 作用位置 | 機制 | 適應症 | 不良反應 |
|:-----|:---------|:-----|:-------|:---------|
| Loop diuretics（Furosemide）| Henle 環上升支 | Na⁺/K⁺/2Cl⁻ 抑制 | CHF、水腫、HTN | 低血鉀、低血鈉 |
| Thiazides（Hydrochlorothiazide）| 遠曲小管 | Na⁺/Cl⁻ 抑制 | HTN、結石 | 低血鉀、高血鈣 |
| Potassium-sparing（Spironolactone）| 皮質集合管 | Aldosterone 拮抗 | CHF、Hypokalemia | 高血鉀 |
| Amiloride | 皮質集合管 | Na⁺ 通道阻斷 | 減少 K⁺ 流失 | 高血鉀 |

### RAAS 抑制劑

| 藥物 | 機制 | 適應症 | 不良反應 |
|:-----|:-----|:-------|:---------|
| ACEI（Ramipril, Lisinopril）| 抑制 ACE，減少 Angiotensin II | HTN、心血管保護、腎臟保護 | 咳嗽、高血鉀、AKI |
| ARB（Losartan, Valsartan）| 阻斷 Angiotensin II 受體 | HTN、心血管保護、腎臟保護 | 高血鉀、AKI |

### SGLT2 抑制劑

| 藥物 | 機制 | 適應症 | 不良反應 |
|:-----|:-----|:-------|:---------|
| Empagliflozin | 抑制近端小管 SGLT2 | T2DM、CKD、心衰竭 | 泌尿生殖道感染、DKA |
| Dapagliflozin | 同上 | 同上 | 同上 |
| Canagliflozin | 同上 | 同上 | 截肢風險、骨質流失 |
