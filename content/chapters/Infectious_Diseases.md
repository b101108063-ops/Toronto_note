## 章節導讀

本章節涵蓋傳染病學的核心內容，摘要如下：

- **微生物學概覽**：細菌、病毒、真菌、寄生蟲的基本形態與致病機制，包括革蘭氏染色分類、抗藥性機制
- **抗菌治療原則**：各類抗生素的抗菌譜、臨床適用範圍，以及常見的抗藥性菌種（如MRSA、VRE、ESBL、CRE）的治療策略
- **常見傳染病**：肺炎、流感、COVID-19、結核病、愛滋病/愛滋病毒的診斷與治療，以及旅行者腹瀉、熱帶傳染病的處置
- **特殊部位感染**：皮膚軟組織感染、骨關節感染、中樞神經系統感染（腦膜炎、腦炎）、心血管感染（感染性心內膜炎）的臨床特徵與治療
- **免疫缺陷宿主之感染**：發燒性嗜中性球減少、實體器官移植後感染、伺機性感染的預防與治療原則

## 傳染病學概論

### 微生物學

#### 細菌學基礎

+ 細菌為原核細胞，透過二分分裂進行無性分裂
+ **革蘭氏染色**將大多數細菌分為兩大類（依細胞壁結構）：
  - **革蘭氏陽性菌**：細胞壁含有厚而堅硬的肽聚醣層
  - **革蘭氏陰性菌**：細胞壁含薄層肽聚醣，外層為脂蛋白與脂多醣組成的外膜
  - 臨床上革蘭氏染色結果可用於引導經驗性治療（在培養與敏感性結果出來之前）
+ **抗酸性桿菌**：細胞壁含高濃度分枝菌酸（如分枝桿菌屬）
  - 稱為「抗酸性」是因為即使經過酸酒精沖洗仍能抵抗脫色
+ **部分抗酸性桿菌**：分枝菌酸含量中等，會被抗酸染色沖洗脫色，但可被改良抗酸染色染上顏色（如Nocardia）
+ **非典型細菌**：在革蘭氏染色下看不見，且難以培養
  - 絕對細胞內寄生（如披衣菌）
  - 無細胞壁的細菌（如黴漿菌）
  - 螺旋體（如梅毒螺旋體）
+ **氧氣需求**：
  - 絕對嗜氧菌：需要氧氣
  - 絕對厭氧菌：需要在無氧環境
  - 兼性厭氧菌：可在有或無氧氣環境中生存

#### 細菌致病機制

1. **附著與殖民**：纖毛穿透細胞壁附著於上皮細胞
2. **侵入或穿越上皮屏障**
3. **逃避免疫防禦**：
   - 多醣莢膜抑制吞噬作用
   - 表面蛋白
4. **毒素產生**：
   - **外毒素**：由活菌分泌，即使細菌不存在仍可致病
   - **內毒素**：為革蘭氏陰性菌細胞壁的結構成分
5. **細胞內生長**：
   - 絕對細胞內寄生
   - 兼性細胞內寄生
6. **生物膜**：
   - 細胞外多醣網絡包圍細菌，可附著於醫療器材如靜脈導管

#### 病毒學

##### 病毒基礎

+ 病毒為傳染性顆粒，由RNA或DNA加上蛋白質外套組成
+ 感染細胞並利用宿主細胞的代謝機器進行複製
+ 核酸可以是雙股或單股；可以是有外套膜或無外套膜
+ **病毒顆粒**：成熟後可釋放到細胞外環境的病毒顆粒

##### 病毒疾病模式

1. **急性感染**（如腺病毒）
   - 宿主細胞在病毒顆粒釋放過程中被裂解
2. **慢性感染>6個月**（如B型肝炎病毒、愛滋病毒）
   - 宿主細胞機器被用來持續產生並釋放病毒顆粒
3. **潛伏感染**
   - 病毒基因組保持在宿主細胞核中潛伏
   - 可重新活化（如單純皰疹病毒、水痘帶狀皰疹病毒）

##### 常見病毒一覽

| 核酸類型 | 外套膜 | 病毒家族 | 主要病毒 | 臨床重要性 |
|----------|--------|----------|----------|------------|

| 雙股DNA | 無 | Papillomaviridae | 人類乳突病毒6,11（疣）、16,18（癌） | 子宮頸/肛門發育不良與癌症 |

#### 真菌學

##### 真菌基礎

+ 真菌為真核生物，有以下形態：
  1. **酵母菌**（單細胞）
  2. **黴菌/絲狀真菌**（多細胞，含菌絲）
  3. **雙型性真菌**（室溫下為黴菌，體溫下為酵母樣）

##### 細胞膜與細胞壁組成

| | 細胞膜 Sterol | 細胞壁 |
|---|---|---|
| 細菌 | — | 肽聚醣 |
| 人類細胞 | 膽固醇 | — |
| 真菌 | 麥角固醇 | 幾丁質 |

##### 真菌致病機制

+ **原發性黴菌感染**：
  - 正常菌叢過度生長
  - 吸入黴菌孢子
  - 創傷接种到皮膚
+ **黴菌毒素**
+ **過敏反應**

#### 寄生蟲學

##### 寄生蟲基礎

+ **寄生蟲**：生活在另一生物體（宿主）內或表面並在過程中傷害宿主的生物
+ 有複雜生命週期的寄生蟲需要一個以上的宿主才能繁殖
+ 三大寄生蟲類群：**原蟲、蠕蟲、體外寄生蟲**

##### 原蟲與蠕蟲的差異

| | 原蟲 | 蠕蟲 |
|---|---|---|
| 結構 | 單細胞 | 多細胞 |
| 型態 | 活動性滋養體↔非活動性囊體 | 蟲卵、幼蟲 |
| 在人體內增殖 | 可以 | 不會 |
| 嗜伊紅性粒細胞增多 | 少見 | 常見 |

### 傳染病傳播方式

#### 傳播機制

| 機制 | 傳播方式 | 範例 | 預防措施 |
|------|----------|------|----------|
| **接觸傳播** | 皮膚對皮膚直接接觸，或間接接觸污染物 | MRSA、性傳染病（淋病、披衣菌、單純皰疹病毒、愛滋病毒、B型肝炎、C型肝炎） | 接觸防護、 barrier precautions、安全銳物處理 |
| **飛沫/接觸傳播** | 飛沫（>5微米）短距離（<2公尺）投射到黏膜 | 流感、腮腺炎、腦膜炎雙球菌、百日咳 | 接觸飛沫防護 |
| **空氣傳播** | 飛沫核（<5微米）可長時間、遠距離傳染 | 結核病、瀰漫性水痘、麻疹 | 空氣防護 |
| **食物/水源傳播** | 攝入受污染食物或水 | 霍亂、沙門氏菌、A型肝炎病毒 | 疫苗、清潔食物/水源供應 |
| **病媒傳播** | 動物到人類（直接或經昆蟲媒介），或人類到人類經昆蟲 | 狂犬病（直接動物）、瘧疾、萊姆病（壁蝨） | 防護藥物、疫苗、驅蟲劑、蚊帳 |
| **垂直傳播** | 母體到後代 | 先天性TORCH感染、愛滋病毒、B型肝炎、B群鏈球菌 | 產前篩檢、預防性治療 |

### 院內感染

+ **院內感染**：入院>48小時後或出院後30天內獲得的感染
+ **風險因素**：住院時間延長、抗生素使用、手術、血液透析、加護病房、免疫缺陷、抗藥菌的移生
+ **後果**：死亡率更高、住院時間更長、醫療成本增加
+ **防護措施**：手部衛生是基本防護

#### 常見院內感染病原體一覽

| 病原體 | 特徵 | 表現 | 檢查 | 治療 |
|--------|------|------|------|------|
| **MRSA** | 革蘭氏陽性球菌 | 皮膚/軟組織感染、菌血症、肺炎、心內膜炎、骨髓炎 | 入院篩檢（鼻孔、肛門周圍）、接觸防護 | Vancomycin、daptomycin或linezolid；移生：mupirocin鼻膏 |
| **VRE** | 多為屎腸球菌 | 健康人少見 | 直腸/糞便篩檢 | Ampicillin（若敏感）或linezolid |
| **困難梭狀芽孢桿菌** | 釋放外毒素A和B | 發燒、腹痛、水瀉、偽膜性結腸炎、中毒性巨結腸 | 糞便PCR或 immunoassay | 停用致病抗生素；口服vancomycin或fidaxomicin |
| **ESBL產生菌** | 對大多數β-lactam抗生素耐藥 | 泌尿道感染、菌血症、肺炎 | 培養 | 碳青黴烯類或非β-lactam抗生素 |

## 病毒感染

### 流行性感冒

#### 定義與病因

+ 流感病毒A和B
+ 流感A依外套膜糖蛋白（血凝素H和神經胺酸酶N）再細分亞型
+ **季節性流感**：
  - 主要流行株：流感A（H1N1）、流感A（H3N2）、流感B
  - 與抗原性漂變相關
  - 爆發主要在冬季
+ **流感大流行**：
  - 與抗原性轉變相關
  - 可能產生新病毒株導致全球大流行

#### 臨床特徵

+ 潛伏期1-4天，症狀通常在7-10天內緩解
+ 急性發作的全身性（發燒、發冷、肌肉疼痛、關節痛、頭痛、疲勞）和呼吸道症狀（咳嗽、呼吸困難、喉嚨痛）
+ **併發症**：呼吸道（病毒性肺炎、續發性細菌性肺炎、中耳炎、鼻竇炎）、肌肉（橫紋肌溶解症、肌炎）、神經（腦炎、腦膜炎、橫貫性脊髓炎、格林-巴利症候群）
+ 高風險族群：老年人、兒童、孕婦、免疫抑制患者、氣喘、慢性阻塞性肺病、心血管疾病、糖尿病、肥胖

#### 治療與預防

+ 輕症以支持性治療為主
+ **神經胺酸酶抑制劑**：Oseltamivir或Zanamivir，症狀發作48小時內使用可縮短病程約1天
+ **高風險族群**：住院患者、嚴重疾病/慢性疾病、免疫抑制、<2歲兒童、>65歲老年人、孕婦或產後2週內婦女
+ **疫苗**：每年接种流感A和B病毒疫苗（>6個月齡者）

### COVID-19

#### 定義與病因

+ 由SARS-CoV-2病毒引起的急性傳染性呼吸道疾病
+ 為有外套膜、正義單股RNA病毒
+ 傳播方式：飛沫和空氣傳播
+ 潛伏期2-14天，通常約5天

#### 病理生理

+ 病毒透過棘突蛋白結合並入侵表達ACE2之上皮細胞
+ 病毒誘導的細胞毒性損害，特別是肺泡上皮
+ 失調的免疫反應可導致細胞激素風暴，引起器官衰竭或死亡

#### 臨床特徵

+ 可無症狀（估計約1/3感染者）
+ 最常見：發燒、疲倦、乾咳
+ 常見：呼吸困難、嗅覺/味覺喪失、食慾不振、肌肉痛
+ 病程：從輕症（1-2週）到重症/危重症（3週以上）；可能併發新冠後遺症

#### 診斷

+ RT-PCR（金標準）；快速抗原檢測（敏感性較低）

#### 治療

+ **危重症住院成人（需呼吸/循環支持）**：
  - Dexamethasone口服或靜脈注射10天
  - Tocilizumab（確診後14天內）
  - 預防性低分子量肝素或普通肝素
+ **需低流量氧氣的住院成人**：
  - Dexamethasone加Remdesivir靜脈注射5天
  - 若CRP≥75毫克/公升且疾病進展：Tocilizumab
+ **輕中度COVID-19（門診）**：
  - 高住院風險：Nirmatrelvir/ritonavir（Paxlovid，症狀發作5天內）或Remdesivir（7天內）

### 狂犬病

#### 定義

+ 由RNA病毒引起的急性進行性腦炎

#### 病因與病理生理

+ 任何哺乳動物都可能傳播狂犬病病毒
+ 最常見：浣熊、臭鼬、蝙蝠、狐狸、貓、狗
+ 傳播：牙齒穿透皮膚，或傳染性組織接觸皮膚或黏膜
+ 病毒經逆行軸突運輸從周邊神經系統到中樞神經系統

#### 臨床特徵

1. **潛伏期**：平均1-3個月
2. **前驅期**：低燒、不適、厭食、噁心/嘔吐、頭痛、喉嚨痛；傷口處疼痛、搔癢、感覺異常
3. **急性神經症候群**：
   - **腦炎型（最常見）**：過動、意識混亂、恐水症、氣流恐懼症、流涎過多、發燒、癲癇
   - **癱瘓型**：四肢癱瘓、肛門括約肌張力喪失、發燒
4. **昏迷**
5. **死亡**

#### 治療

+ **暴露後預防**：
  - 若未曾免疫：傷口清潔加狂犬病免疫球蛋白浸潤傷口加HDCV疫苗（第0、3、7、14天各一劑）
  - 若曾免疫：傷口清潔加HDCV疫苗（第0、3天各一劑），不需免疫球蛋白
+ 一旦出現臨床症狀，治療以支持性為主

### 皰疹病毒感染

#### 單純皰疹病毒

+ **第一型**：口腔、眼部、腦炎
+ **第二型**：生殖器
+ 可引起皰疹性腦炎：
  - 急性壞死性、非對稱性出血性病變，常侵犯顳葉和額葉
  - 治療：Acyclovir靜脈注射

#### 水痘-帶狀皰疹病毒

+ 原發感染：水痘
+ 復發：帶狀皰疹（沿皮節分布的疼痛性水皰）
+ 併發症：腦膜炎、腦炎、Ramsay Hunt症候群

#### EB病毒

+ 引起傳染性單核球增多症
+ 表現：發燒、喉嚨痛、淋巴結腫大、肝脾腫大
+ 實驗室：淋巴球增多、非典型淋巴球、heterophile antibody（Monospot）陽性

#### 巨細胞病毒

+ 可引起：單核球增多症、肝炎、視網膜炎、免疫抑制患者肺炎

## 細菌感染

### 肺炎

#### 定義

+ 肺實質的感染

#### 病因與風險因素

+ **肺部防禦受損**：
  - 咳嗽/嘔吐反射受損
  - 黏液纖毛運輸受損
  - 免疫抑制
+ **吸入風險增加**：吞嚥機制受損、意識障礙

#### 臨床特徵

+ 咳嗽（含痰）、發燒、胸膜炎性胸痛、呼吸困難、呼吸急促、心搏過速

| 情境 | 治療 |

### 皮膚與軟組織感染

#### 蜂�性組織炎

+ **定義**：皮膚感染，主要侵犯真皮和皮下組織
+ **病因**：β溶血性鏈球菌（非化膿性最常見）、金黃色葡萄球菌
+ **臨床特徵**：疼痛、水腫、紅斑（邊界不清）加區域性淋巴腺病變、發燒/寒顫、不適
+ **治療**：
  - Cephalexin
  - 若疑似MRSA：Vancomycin

#### 壞死性筋膜炎

+ **定義**：侵犯深層筋膜、進展快速的危及生命和肢體的感染
+ **類型**：
  - 第一型：多菌種感染
  - 第二型：單菌種感染
+ **臨床特徵**：
  - 疼痛程度與臨床發現不成比例
  - 水腫加捻髮感（皮下氣體）
  - 快速進展的全身症狀
  - 晚期：皮膚變藍/黑（血栓形成和壞死）
+ **治療**：
  - 液體復甦
  - **緊急手術清創**
  - 抗生素：
    - 未知菌種：Meropenem或Piperacillin-tazobactam加Clindamycin靜脈注射加Vancomycin
    - 第一型（多菌種）：Piperacillin-tazobactam加Clindamycin靜脈注射
    - 第二型（單菌種，A群鏈球菌）：Penicillin G加Clindamycin靜脈注射

### 骨髓炎與化膿性關節炎

#### 化膿性關節炎

+ **定義**：一個或多個關節被致病微生物感染
+ **屬於醫療急症**：若未治療，關節會快速破壞
+ **感染途徑**：
  - 血行傳播（最常見）
  - 直接接种：創傷、關節注射
  - 連續蔓延：來自隔壁骨髓炎

#### 病因

| 類型 | 常見病原 |
|------|----------|
| 淋球菌關節炎 | 淋病雙球菌 |
| 非淋球菌 | 金黃色葡萄球菌（所有年齡，進展快速）、鏈球菌種、A群、B群鏈球菌、革蘭氏陰性桿菌（新生兒、老年人、注射藥物使用者）、肺炎鏈球菌（兒童）、Kingella kingae（<4歲兒童）、凝固酶陰性葡萄球菌（人工關節）|

#### 臨床特徵

+ 急性發作的疼痛、腫脹、溫熱、活動範圍減少加發燒和寒戰
+ 最常侵犯大關節（膝、髖、踝）和手腕
+ 通常單關節

#### 診斷

+ **診斷性關節抽吸是必要的**：
  - 關節液：渾濁、白血球>15,000/立方毫米、多形核嗜中性球>90%、培養陽性
+ X光：評估骨髓炎、提供治療基準
+ 血液培養

#### 治療

+ **抗生素**：
  - 經驗性靜脈注射：依臨床情境，Cefazolin加Vancomycin（成人）
  - 淋球菌：Ceftriaxone加Azithromycin治療合併披衣菌
  - 非淋球菌：
    - 鏈球菌：2-3週靜脈注射後改口服
    - 金黃色葡萄球菌：至少4週靜脈注射
    - 革蘭氏陰性桿菌：4週
+ **手術介入**：人工關節、髖關節（特別是兒童）

### 糖尿病足感染

#### 病因

+ 神經病變、周邊血管疾病、高血糖導致足部潰場難以癒合，易受感染
+ 輕度感染：鏈球菌種、金黃色葡萄球菌
+ 中度/重度感染：多菌種（嗜氧菌加厭氧菌）

#### 臨床特徵

+ 並非所有潰場都有感染
+ 感染疑似情況：probe to bone test陽性、潰場>30天、創傷、周邊血管疾病、失去保護性感覺、腎病
+ **感染徵象**：>2個發炎主徵（紅、溫、腫、痛）或膿液存在

#### 治療

+ 輕度：Cloxacillin或Cephalexin
+ 中度或重度：Amoxicillin-clavulanate或Ceftriaxone
+ 控制血糖、減壓、傷口護理、必要時手術清創

### 感染性心內膜炎

#### 定義

+ 心內膜（尤其是瓣膜）的感染
+ 分類：急性vs.亞急性/慢性、原生瓣膜vs.人工瓣膜、右側vs.左側
+ 疣狀物由血小板-纖維蛋白血栓、白血球和細菌組成

#### 風險因素

| 風險層級 | 狀況 |
|----------|------|
| 高風險 | 人工心臟瓣膜、既往感染性心內膜炎、先天性心臟病（未修復、6個月內修復或修復後仍有缺陷）、心臟移植後瓣膜病變 |
| 中度風險 | 其他先天性心臟缺陷、後天性瓣膜功能障礙、肥厚性心肌病 |
| 低風險 | 第二孔型房間隔缺損或手術修復的房間隔缺損、心室中膈缺損、開放性導管、僧帽瓣脫垂、缺血性心臟病、冠狀動態繞道移植 |

#### 臨床特徵

+ **全身性**：發燒（80-90%）、寒戰、虛弱、僵直、盜汗、體重減輕、厭食
+ **心臟**：呼吸困難、胸痛、杵狀指（亞急性）、新發或增強的反流性心臟雜音、心衰竭徵象
+ **栓塞/血管性**：
  - Janeway損害（無痛性，掌蹠部5毫米紅色/出血性斑塊）
  - 指甲下線狀出血
  - 中樞神經系統栓塞（局灶性神經學徵候）
  - 脾腫大（亞急性）
  - 顯微鏡血尿、腰痛（腎栓塞）
+ **免疫複合體**：Osler結節（疼痛性）、腎絲球腎炎、關節炎、Roth斑點（視網膜出血伴蒼白中心）

#### Modified Duke Criteria

**主要標準**
1. **微生物學標準**：
   - 兩次獨立血液培養分離典型病原
   - 對非典型病原：3次或以上陽性血液培養
2. **影像學標準**：
   - 超音波或心臟電腦斷層顯示疣狀物、瓣膜穿孔、膿腫、假性動膜瘤、心內膜瘻
   - 新的顯著瓣膜逆流

**次要標準**
1. 既有心內膜炎、人工瓣膜或心臟結構異常的易感因素
2. 發燒
3. 血管現象
4. 免疫現象
5. 血液培養不符合主要標準

#### 治療

+ **抗生素**：
  - 原生瓣膜經驗性：Vancomycin加Ceftriaxone或Gentamicin
  - 人工瓣膜經驗性：Vancomycin加Gentamicin加Rifampin
  - 目標治療：依瓣膜、病原菌、感受性調整療程（通常4-6週）
+ **手術適應症**：難治性心衰竭、瓣膜環膿腫、瓣膜穿孔、不穩定修復、大疣狀物>1公分、反覆栓塞、藥物治療失敗、黴菌病因、人工瓣膜上的金黃色葡萄球菌

### 腦膜炎

#### 定義

+ 腦膜的發炎

#### 常見病原體

| | 細菌性 | 病毒性 | 真菌 | 其他 |
|---|---|---|---|---|
| 年齡0-4週 | B群鏈球菌、大腸桿菌、李斯特菌 | 皰疹病毒4,2 | | |
| 年齡1-3月 | 大腸桿菌、李斯特菌、腦膜炎雙球菌、肺炎鏈球菌 | 皰疹病毒 | | |
| 年齡>3月 | 腦膜炎雙球菌、肺炎鏈球菌、李斯特菌 | 腸病毒、 parechovirus、皰疹病毒、西尼羅病毒 | 隱球菌 | 萊姆病、神經梅毒 |

#### 臨床特徵

+ 新生兒/兒童：發燒、嗜睡、躁動、嘔吐、進食差
+ 較大兒童/成人：發燒、頭痛、頸部僵硬、意識混亂、嗜睡、意識改變、癲癇、局部神經學徵候、噁心/嘔吐、畏光
+ 腦膜炎球菌腦膜炎：瘀點性皮疹（紫癜）

#### 典型腦脊髓液分析

| | 細菌性 | 病毒性 |
|---|---|---|
| 葡萄糖 | 降低 | 正常 |
| 蛋白質 | 顯著增加 | 增加 |
| 白血球 | 500-10,000/立方毫米 | 10-5,000 |
| 主要白血球 | 多形核嗜中性球 | 淋巴球 |

#### 治療

+ **細菌性腦膜炎是急症**：不要為了電腦斷層或腰椎穿刺而延遲抗生素
+ **經驗性抗生素**：
  - <28天：Ampicillin加Cefotaxime
  - 29天-3個月：Ceftriaxone/Cefotaxime加Vancomycin加Ampicillin
  - >3個月：Ceftriaxone加Vancomycin
  - 若有李斯特菌風險因素：加Ampicillin
+ **類固醇**：Dexamethasone靜脈注射在第一次抗生素前或同時；確診肺炎球菌腦膜炎後繼續，其他菌種停用

#### 預後

+ 併發症：死亡、頭痛、癲癇、腦水腫、腦室積水、残餘神經學缺陷（特別是第八對顱神經）、耳聾
+ 死亡率：肺炎鏈球菌25%；腦膜炎雙球菌5-10%

### 腦炎

#### 定義

+ 腦實質的發炎

#### 病因

+ 僅40-70%可確定病因
+ 已知病因中最常見的是病毒
+ 細菌：李斯特菌、結核菌、螺旋體、黴漿菌
+ 寄生蟲：原蟲和蠕蟲
+ 真菌：如隱球菌
+ 感染後：如急性脫髓鞘性腦脊髓炎

#### 臨床特徵

+ 全身性：發燒，寒戰、不適、噁心/嘔吐
+ 腦膜侵犯：頸部僵硬
+ 實質侵犯：癲癇、意識改變、局部神經學徵候
+ **皰疹性腦炎**：
  - <1週內急性發作的局部神經學徵候
  - 顳葉侵犯：行為障礙
  - 常在數天內快速進展
  - 常見後遺症：記憶和行為障礙

#### 治療

+ 支持性治療
+ **Acyclovir靜脈注射經驗性**（直到皰疹性腦炎被排除）

### 破傷風

#### 病因與病理生理

+ 由破傷風梭狀芽孢桿菌引起：可動、產孢子、厭氧性革蘭氏陽性桿菌
+ 創傷性植入孢子到低氧組織
+ 破傷風毒素經逆行軸突運輸到中樞神經系統，與突觸前神經元不可逆結合，阻止抑制性神經傳導物質釋放

#### 臨床特徵

+ 最初表現：咬肌疼痛性痙攣（牙關緊閉）
+ 持續性骨骼肌收縮，伴隨疼痛性肌肉痙攣
+ 癱瘓向下侵犯大肌群（頸部、腹部）
+ 自主神經過度活躍：出汗、心搏過速、高血壓、發燒

#### 治療

+ 停止毒素產生：傷口清創
+ 抗生素：靜脈注射Metronidazole（或靜脈注射Penicillin G）
+ 中和游離毒素：破傷風免疫球蛋白
+ 支持性治療：插管、鎮痙劑
+ 控制自主神經功能障礙：α-和β-阻斷劑、硫酸鎂

### 萊姆病

#### 病因/流行病學

+ 螺旋體細菌
+ 透過Ixodes壁蝨傳播
+ 潛伏期7-14天

#### 臨床特徵

1. **早期局限期**：
   - 不適、疲倦、頭痛、肌肉疼痛
   - **遊走性紅斑**：在壁蝨咬部位出現擴展性牛眼病變
2. **早期散布期**（感染後數週）：
   - 中樞神經系統：無菌性腦膜炎、顱神經麻痺（顏面神經麻痺）
   - 心臟：心傳導阻斷或心肌炎
3. **晚期持續期**（感染後數月到數年）：
   - 肌肉骨骼：慢性單關節或寡關節關節炎
   - 神經：腦病變、腦膜炎、神經病變

#### 治療

+ 早期：Doxycycline或amoxicillin或cefuroxime
+ 晚期：Ceftriaxone或doxycycline

### 梅毒

#### 病因

+ 梅毒螺旋體：厚、可動的螺旋體
+ 透過性接觸、垂直或非經腸道傳播

#### 臨床特徵

1. **初期梅毒**（感染後3-90天）
   - 無痛性下疳
   - 區域性淋巴結病變
2. **第二期梅毒**（初期下疳後2-8週）
   - 瀰漫性斑丘疹，包括手掌和足底
   - 全身性淋巴結病變、發燒、不適、頭痛
3. **潛伏期梅毒**
   - 無症狀感染
4. **末期梅毒**（1-30年後）
   - 肉芽腫性梅毒
   - 主動脈瘤和主動脈瓣膜逆流
5. **先天性梅毒**
   - 導致自然流產、死產、先天性畸形、生長發育遲緩、耳聾
6. **神經梅毒**
   - 頭痛、癡呆、協調困難、癱瘓、感覺缺陷、Argyll Robertson瞳孔

#### 治療

+ **初期、第二期、早期潛伏**：Benzathine penicillin G 240萬單位肌肉注射×1
+ **晚期潛伏**：Benzathine penicillin G 240萬單位肌肉注射每週×3
+ 若對penicillin過敏：Doxycycline 100毫克口服每日2次×14天
+ **神經梅毒**：Aqueous penicillin G 1600-2400萬單位/天靜脈注射×14天

## 寄生蟲感染

### 腸道/泌尿生殖道原蟲感染

#### 阿米巴痢疾

+ **傳播**：糞口途徑（在衛生條件差的地區，經被感染者污染的水或食物傳播），或經性接觸
+ **臨床特徵**：
  - 無症狀携带者
  - 阿米巴性痢疾：腹痛、腹部絞痛、結腸炎、痢疾、低燒伴血性腹瀉
  - 阿米巴性肝膿腫：肝臟（最常見）
+ **診斷**：血清學、糞便/血清抗原檢測、顯微鏡檢查、糞便multiplex enteric parasite PCR
+ **治療**：Metronidazole；後續iodoquinol或paromomycin消除囊體

#### 梨形鞭毛蟲病

+ **傳播**：糞口途徑，攝入被感染者和其他哺乳動物污染的水/食物
+ **臨床特徵**：
  - 急性梨形鞭毛蟲病：水瀉、脂肪瀉、腹部絞痛、脹氣、疲倦、體重減輕
  - 無血便
  - 慢性：復發症狀、吸收不良症候群
+ **治療**：Tinidazole（單次劑量）或Nitazoxanide（3天療程）

#### 陰道滴蟲

+ **傳播**：性接觸
+ **臨床特徵**：常無症狀；陰道分泌物（大量、異味、黄綠色或灰色、泡沫狀）、搔癢、排尿困難、性交疼痛
+ **治療**：Metronidazole（患者和伴侶）

#### 隱孢子蟲症

+ **傳播**：糞口途徑，攝入被感染者和其他動物污染的水
+ **臨床特徵**：
  - 免疫功能正常：自限性水瀉
  - 免疫抑制：慢性、嚴重、非血性腹瀉
+ **治療**：支持性治療；在愛滋病患者，重新啟動或優化抗反轉錄病毒治療並增加CD4>100；若失敗，嘗試Nitazoxanide

### 血液與組織寄生蟲感染

#### 瘧疾

+ **傳播**：被感染雌性瘧蚊叮咬時，孢子體注入血液
+ **臨床特徵**：
  - 流感樣前驅症狀
  - 高熱和顫抖發作（因紅血球同步溶血）
  - 肝脾腫大和血小板減少（無白血球增多）
  - **惡性瘧併發症**：中樞神經系統侵犯（腦瘧）、嚴重貧血、急性腎損傷、ARDS，是最常見和最致命的病因
+ **診斷**：厚薄血抹片（Giemsa染色）q12-24h×3；快速抗原檢測
+ **治療**：
  - 惡性瘧（含氯奎因抗藥性區域）：青蒿素合併療法
  - 間日瘧、卵形瘧：氯奎因加伯氨喹消除肝臟形式
  - 三日瘧、諾氏瘧：氯奎因
+ **預防**：化學預防、覆蓋暴露皮膚、含殺蟲劑的蚊帳、驅蟲劑；primaquine或tafenoquine預防復發

#### 查加斯病

+ **發現於**：墨西哥、南美洲、中美洲
+ **傳播**：錐鼻蟲叮咬傳播
+ **臨床特徵**：
  - 急性：通常無症狀，叮咬部位局部腫脹
  - 慢性確定期：10-25年後導致慢性擴張型心肌病、食道巨大症、巨結腸
+ **治療**：Benznidazole或Nifurtimox（急性）

#### 弓形蟲病

+ **傳播**：接觸貓糞便（囊體）、攝入未煮熟的肉（組織囊體）、胎盤傳播、器官移植
+ **臨床特徵**：
  - **先天性**：脈絡膜視網膜炎、腦室積水、顱內鈣化
  - **後天（免疫功能正常）**：通常無症狀或單核球增多症樣症候群
  - **免疫抑制（CD4<200）**：腦炎伴局部中樞神經系統病變
+ **治療**：
  - 免疫功能正常：通常不需治療
  - 免疫抑制：Pyrimethamine加Sulfadiazine加Folinic acid
  - HIV：TMP/SMX

## 結核病

### 病因與病程

+ 結核分枝桿菌：慢生長的嗜氧菌，在巨噬細胞內複製
+ 吸入後在肺部沉積，可能導致：
  1. 立即清除病原體
  2. 結核菌感染（又稱潛伏結核：無症狀感染，由宿主免疫防禦控制）
  3. 原發性結核：症狀性活動性疾病
  4. 繼發性結核：之前休眠結核的症狀性復發（最常在感染後1-2年內發生）

### 風險因素

+ **社會/環境因素**：出生於或長期前往結核病高負擔國家；加拿大原住民結核病發病率較高
+ **宿主因素**：免疫抑制（尤其愛滋病毒）、TNF-α抑制劑、類固醇、慢性腎病需透析、糖尿病、惡性腫瘤和化療、物質使用

### 臨床特徵

1. **肺部結核**：
   - 慢性生產性咳嗽加咳血、發燒、盜汗、體重減輕、胸痛、食慾不振
   - 胸部X光：實質浸潤或空洞、淋巴結病變，主要在上肺
2. **粟粒性結核**：
   - 廣泛散布，尤其到肺、腹腔器官、骨髓、中樞神經系統
   - 胸部X光：整個肺部多個小的1-5毫米粟粒樣病變
3. **肺外結核**：
   - 可發生在任何器官——淋巴結炎、胸膜炎、心包炎、肝炎、腹膜炎、腦膜炎、骨髓炎（脊椎）、腎上腺（導致腎上腺功能不全）、腎、卵巢

### 診斷

+ **結核菌感染篩檢**：結核菌素皮膚試驗或干擾素-γ釋放試驗
+ **活動性肺結核診斷**：
  - 痰標本用於抗酸性桿菌抹片和培養
  - 支氣管肺泡灌洗
  - 胸部X光：經典型三聯症：上肺實質浸潤、肺容積減少，空洞
+ **結核菌素皮膚試驗陽性標準**：
  - >5毫米：免疫抑制者或與活動性結核密切接觸
  - >10毫米：其他所有人

### 預防

+ **原發預防**：活動性肺部疾病時空氣隔離；卡介苗疫苗
+ **預防潛伏感染復發**：
  - Rifampin 10毫克/公斤（最高600毫克）每日×4個月
  - 異菸肼加利福噴丁每週×3個月
  - 異菸肼 5毫克/公斤（最高300毫克）每日×9個月
  - 異菸肼加利福平每日×3個月

### 結核病治療

+ **肺部結核**：異菸肼加利福平Pyrazinamide加Ethambutol×2個月（起始期），然後異菸肼加利福平×4個月（持續期），共6個月
+ **肺外結核**：同肺部結核，但中樞神經系統、骨/關節、粟粒性/散布性結核延長至12個月加腦膜炎、心包炎用皮質類固醇
+ **多重抗藥性結核**（對異菸肼和利福平及其他耐藥）：需專科轉介
+ **超廣泛抗藥性結核**：極難治療

## 愛滋病/愛滋病毒

### 流行病學

+ **加拿大**：估計65,040名加拿大人感染愛滋病毒（2016年底），約20%不知道自己感染狀態
+ **全球**：2016年底估計3,670萬人感染，2016年新增180萬感染，2016年約100萬人死於愛滋病相關原因

### 病因

+ 愛滋病毒是一種逆轉錄病毒，導致免疫系統進行性功能障礙
+ 病毒包膜結合CD4和CCR5/CXCR4並進入細胞
+ RNA經逆轉錄酶轉換為雙股DNA，整合到宿主基因組
+ **愛滋病定義**：愛滋病毒陽性加臨床疾病或CD4<200

### 自然病史

+ **急性逆轉錄病毒症候群**（暴露後2-6週，40-90%）：
  - 急性非特異性疾病持續10-15天
  - 與高血漿病毒量相關，因此傳播風險高
+ **無症狀（潛伏）期**：
  - CD4計數正常：500-1100 cells/立方毫米
  - CD4計數每年下降60-100 cells/立方毫米
+ **愛滋病發作期**：

| CD4計數 | 可能表現 |
|----------|----------|
| <500 cells/立方毫米 | 常無症狀；全身症狀；黏膜皮膚病變；復發性細菌感染；肺和肺外結核；淋巴瘤 |
| <200 cells/立方毫米 | 肺孢子蟲肺炎；卡波西氏肉瘤；口腔鵝口瘡；散布性真菌感染 |
| <100 cells/立方毫米 | 漸進性多灶性白質腦病；弓形蟲病 |
| <50 cells/立方毫米 | 巨細胞病毒感染 |

### 實驗室診斷

+ 初始篩檢：第三代或第四代抗體試驗或p24抗原/愛滋病毒抗體合併試驗
+ 確認試驗：西方墨點
+ 快速（床邊）抗體檢測：假陽性較高，需傳統血清學確認
+ 窗口期：感染後到抗體可檢測的平均3週

### 伺機性感染預防

| 病原體 | 預防時機 | 首選預防方案 |
|--------|----------|--------------|
| 肺孢子蟲 | CD4<200 | TMP/SMX 1粒每日一次 |
| 弓形蟲 | 對弓形蟲抗體陽性且CD4<100 | TMP/SMX 1粒每日一次 |
| 結核分枝桿菌 | 結核菌素反應>5毫米或與活動性結核接觸 | 異菸肼加維生素B6每日一次×9個月 |
| 鳥型分枝桿菌複合體 | CD4<50 | 若患者開始抗反轉錄病毒治療則不需預防 |

### 抗反轉錄病毒治療

#### 治療原則

+ 所有愛滋病毒陽性患者建議開始合併抗反轉錄病毒治療
+ 目標：維持病毒量低於檢測限；病毒量應在4-8週內下降10倍，6個月內無法檢測
+ 病毒量無法檢測且持續抗反轉錄病毒治療的患者不會透過性接觸傳播愛滋病毒

#### 初始治療建議

1. Bictegravir/TAF/FTC
2. DTG/ABC/3TC（確認HLA-B*5701陰性患者）
3. DTG加(TAF或TDF)/(FTC或3TC)
4. Raltegravir加TAF或TDF/FTC
5. DTG/3TC

### 愛滋病毒預防

+ **接觸後預防**：暴露後立即（<72小時）開始，持續4週
+ **接觸前預防**：每日TDF/FTC或TAF/FTC；或「需時接觸前預防」

## 旅行醫學

### 旅行者發燒

#### 病因

+ 寄生蟲：瘧疾（20-30%）
+ 病毒：非特異性單核球增多症樣症候群（4-25%）、登革熱（5%）、病毒性肝炎（3%）
+ 細菌：傷寒（2-7%）、立克次體感染（3%）
+ 旅行者腹瀉（10-20%）、呼吸道感染（10-15%）
+ **來自瘧疾流行區的發燒旅行者：在排除瘧疾前視為瘧疾處理**

#### 診斷思路

| 疾病 | 地理/流行區 | 潛伏期 | 表現 | 診斷 | 治療 |

| 瘧疾 | 非洲、印度、中南美、東南亞 | 7-30天 | 發燒、寒顫、肌肉酸痛、疲倦 | 血抹片、快速診斷試驗、PCR | 青蒿素（重症）加Malarone、多西環素或clindamycin |

### 發燒待查

#### 定義

| 類型 | 標準 |
|------|------|
| 經典型發燒待查 | 體溫≥38.3°C數次；病程>3週；門診或住院3天或3次門診就診後診斷仍不確定 |
| 院內發燒待查 | 住院患者；入院時無感染；入院3天後診斷不確定 |
| 嗜中性球減少性發燒待查 | 中性球<500/立方毫米；門診患者病程>3天、住院患者3天後診斷仍不確定 |
| 愛滋病毒相關發燒待查 | 愛滋病毒感染；門診患者病程>4週、住院患者3天後診斷不確定 |

#### 病因

+ **感染（約30%）**：結核病（肺外最常見）、骨髓炎、感染性心內膜炎（培養陰性）、絲狀真菌（隱球菌）、寄生蟲（弓形蟲）
+ **發炎性疾病**：Still病、血管炎、結節病
+ **惡性腫瘤**：淋巴瘤、白血病、腎細胞癌
+ **其他**：藥物熱、深靜脈血栓、膽囊炎
