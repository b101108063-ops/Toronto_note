## 導讀摘要

- **月經失調**涵蓋 amenorrhea、abnormal uterine bleeding（AUB）、dysmenorrhea 等常見問題；AUB 的鑑別診斷使用 PALM-COEIN 結構（polyp、adenomyosis、leiomyoma、malignancy vs. coagulopathy、ovulatory dysfunction、endometrial、iatrogenic、not yet classified），治療原則為排除結構性病變後優先藥物治療
- ** endometriosis** 為子宫内膜組織生長於子宫腔外的慢性疾病，典型症狀包括 secondary dysmenorrhea、deep dyspareunia、dyschezia、不孕；診斷以 laparoscopy 為 gold standard，治療包括 NSAIDs、combined hormonal contraceptive、progestin、 GnRH agonist，手術適用於藥物治療失敗或有生育需求者
- **輸卵管的惡性腫瘤**（endometrial carcinoma）為北美最常見的婦科惡性腫瘤，典型症狀為 postmenopausal bleeding（PMB），診斷靠 endometrial biopsy，治療以手術（total hysterectomy + BSO）為主； 子宮平滑肌肉瘤（leiomyosarcoma）為罕見但預後較差的腫瘤
- **卵巢腫瘤**分為良性（functional cyst、dermoid cyst）及惡性（epithelial ovarian cancer 最常見，佔 85%）；CA-125 為最常用的腫瘤標記但敏感度及特異度有限；惡性卵巢腫瘤以手術減積（debulking）配合 platinum-based chemotherapy 為主要治療方式
- **HPV 與子宫頸癌**關係密切（>99% 子宮頸癌含有高風險 HPV），預防靠疫苗（Gardasil®9、Cervarix®）及定期 Pap test；子宫頸癌臨床分期使用 FIGO 分期系統（唯一使用臨床分期的婦科惡性腫瘤），治療方式依分期可選手術（radical hysterectomy）或 chemoradiation

## 婦科學概論

### 子宫切除術（Hysterectomy）

**適應症：**
- 子宮肌瘤（uterine fibroids）
- Endometriosis、adenomyosis
- 子宮脫垂（uterine prolapse）
- 骨盆腔疼痛（pelvic pain）
- Abnormal uterine bleeding（AUB）
- 惡性腫瘤（endometrium、ovaries、fallopian tubes、cervix）

**併發症：**
- 全身麻醉風險
- 出血
- 感染
- 鄰近器官損傷（ureter、bladder、rectum）
- 卵巢功能喪失（若切除卵巢則為 iatrogenic menopause）
- 靜脈血栓（venous thromboembolism）

**手術路徑：**

| 方式 | 說明 |
|------|------|
| 開腹（Open/Abdominal） | 經橫向（Pfannenstiel、Maylard）或正中切口剖腹 |
| 陰道式（Vaginal） | 全程經陰道操作，無腹部傷口 |
| 腹腔鏡輔助陰道式（LAVH） | 血管蒂以腹腔鏡及陰道方式結合處理 |
| 全腹腔鏡式（Total Laparoscopic） | 所有血管蒂及 colpotomy 皆經腹腔鏡完成 |
| 機器人輔助（Robotic） | 腹腔鏡的一種，對高 BMI 患者可能更有優勢 |

**Table 1. 子宮切除術分類**

| 分類 | 切除組織 | 適應症 |
|------|----------|--------|
| Subtotal Hysterectomy | 子宮 | 子宫頸無法觸及（如粘連）、患者偏好 |
| Total Hysterectomy（TH）| 子宮、子宮頸、子宮动脉結扎於子宫、輸卵管 | 子宮肌瘤 |
| TH + Bilateral Salpingo-Oophorectomy | 子宮、子宮頸、子宮动脉、輸卵管的、卵巢 | 子宮内膜癌、惡性卵巢腫瘤 |
| Modified Radical Hysterectomy（Type 2）| 子宮、子宮頸、近端 1/3 參數、子宮动脉於 ureter 內側結扎、輸卵管的、子宮骶骨韧带中點、上 1-3 cm 陰道 | 子宮内膜癌 |
| Radical Hysterectomy（Type 3）| 子宮、子宮頸、全參數、子宮动脉於 internal iliac artery 起源處結扎、子宮骶骨韧带、子宮骶骨韧带、子宮骶骨韧带、上 1-3 陰道 | 子宮頸癌（可達 stage IIB）|

## 月經失調（Disorders of Menstruation）

### Amenorrhea（無月經）

**Primary Amenorrhea 定義：**
- 13 歲無第二性徵且無月經，或
- 15 歲有第二性徵但無月經，或
- 初經後 2 年無月經

**Secondary Amenorrhea 定義：**
- 有初經記錄後連續 6 個月或 3 個週期無月經

**Table 2. Primary Amenorrhea 之鑑別診斷**

| 有第二性徵發育 | 無第二性徵發育 |
|----------------|----------------|
| 甲狀腺功能低下（Hypothyroidism）| 甲狀腺功能低下 |
| 高泌乳激素血症（Hyperprolactinemia）| 子宮發育不全（Müllerian agenesis）|
| 多囊性卵巢綜合症（PCOS）| 子宫陰道隔膜（Transverse vaginal septum）|
| 下視丘功能障礙（Hypothalamic dysfunction）| 無孔處女膜（Imperforate hymen）|
| 功能性下視丘無月經 | 性腺發育不全（Gonadal dysgenesis），如 Turner syndrome（45,XO）|
| Müllerian 發育不全 | Kallmann syndrome |

**Table 3. Secondary Amenorrhea 之鑑別診斷**

| 有雄性素過多（Hyperandrogenism）| 無雄性素過多 |
|-------------------------------|-------------|
| PCOS | 功能性下視丘無月經（最常見）|
| 先天性腎上腺增生（Late onset CAH）| 高泌乳激素血症 |
| 卵巢腫瘤（Ovarian tumour）| 甲狀腺功能障礙 |
| 腎上腺腫瘤 | 下丘腦-垂體功能減退（Hypogonadotropic hypogonadism）|
| | 原發性卵巢功能不全（Primary ovarian insufficiency，高 FSH）|
| | 子宮粘連（Asherman's syndrome）|

**Diagnostic Approach：**
- 2° amenorrhea → 優先排除懷孕
- 病史、理學檢查（有無第二性徵）
- 實驗室：B-hCG、FSH/LH、prolactin、甲狀腺功能、androgens
- Progestin challenge test（medroxyprogesterone acetate 10 mg PO QD × 10-14 d）
  - 有撤退性出血 → 子宮內膜有足夠雌激素
  - 無撤退性出血 → 可能為雌激素不足、子宮粘連、子宮頸狹窄等

**Treatment：**
| 病因 | 治療 |
|------|------|
| 解剖構造異常（無孔處女膜、子宮陰道隔膜）| 手術治療 |
| 高泌乳激素血症 | 確認 MRI，排除病變後使用 bromocriptine 或 cabergoline |
| PCOS | 見 PCOS 章節 |
| 原發性卵巢功能不全 | 賀爾蒙補充（estrogen + progestin）預防骨質疏鬆 |
| Asherman's syndrome | 子宮鏡（hysteroscopy）切除粘連 |
| 功能性下視丘無月經 | 找出可修正原因（體重、運動），補充雌激素 |

### Abnormal Uterine Bleeding（AUB，子宮異常出血）

**定義：** 月經的頻率、持續時間或量改變，影響生活品質

**評估重點：**
1. **規律性**：cycle-to-cycle variability <20 d 為規律，>20 d 為不規律
2. **出血量**：
   - 每次月經 >8 d
   - 衛生棉/棉條更換頻率高
   - 有血塊
   - 每次月經失血量 >280 cc
3. **結構性 vs. 非結構性**（PALM-COEIN）

**PALM-COEIN 分類：**

| 結構性（PALM）| 非結構性（COEIN）|
|----------------|-----------------|
| **P**olyp | **C**oagulopathy |
| **A**denomyosis | **O**vulatory dysfunction |
| **L**eiomyoma | **E**ndometrial |
| **M**alignancy/Hyperplasia | **I**atrogenic |
| | **N**ot yet classified |

**Investigations：**
- CBC、coagulation profile（青少年）
- B-hCG、甲狀腺功能、prolactin、FSH/LH、androgens
- Transvaginal sonography（TVS）
- Endometrial biopsy（>40 歲或有風險因子者）

**Table 5. AUB 病因、檢查與治療**

| 病因 | 檢查 | 治療 |
|------|------|------|
| Polyp（AUB-P）| TVS、sonohysterography | Polypectomy |
| Adenomyosis（AUB-A）| TVS、MRI | 見 Adenomyosis 章節 |
| Leiomyoma（AUB-L）| TVS、sonohysterography | 見 Fibroids 章節 |
| Malignancy（AUB-M）| TVS、endometrial biopsy | 依診斷 |
| Coagulopathy（AUB-C）| CBC、coagulation profile、VWF | Tranexamic acid |
| Ovulatory dysfunction（AUB-O）| 血液檢查、TVS | Hormonal modulation（OCP、Mirena® IUS）|
| Endometrial（AUB-E）| Endometrial biopsy | 見不孕症章節 |
| Iatrogenic（AUB-I）| 病史、回顧用藥 | 移除致病藥物 |

**AUB 藥物治療原則：**
- 輕度：NSAIDs、Mirena® IUD、糾正貧血
- 急性嚴重出血：
  - 抗纖維蛋白溶酶（tranexamic acid）
  - 合併荷爾蒙避孕藥（tapering regimen）
  - 必要時輸液、輸血
- 手術：polypectomy、myomectomy、uterine artery embolization、endometrial ablation、hysterectomy

### Dysmenorrhea（經痛）

**Table 6. Primary vs. Secondary Dysmenorrhea 比較**

| 特徵 | Primary Dysmenorrhea | Secondary Dysmenorrhea |
|------|---------------------|----------------------|
| 定義 | 無明確疾病的復發性經痛 | 有潛在疾病的經痛 |
| 病因 | 前列腺素相關 | Endometriosis、adenomyosis、子宮肌瘤等 |
| 疼痛特性 | 痙攣性下腹疼痛，放射至下背、會陰、大腿 | 類似 primary，伴有其他症狀 |
| 發作時間 | 月經來潮前數小時，持續 48-72 小時 | 不一定與月經相關 |
| 相關症狀 | 腹瀉、便習慣改變、頭痛、疲倦 | Dyspareunia、不孕、異常出血 |
| 理學檢查 | 正常（必要時做）| 子宮或附屬器壓痛、子宮後傾、子宮韌帶結節 |
| 治療 | 規則運動、NSAIDs、荷爾蒙治療 | 治療根本原因 |

## 子宮疾病（Uterine Disorders）

### Endometriosis

**定義：** 子宮內膜組織（腺體及間質）生長於子宫腔外，為慢性疾病，僅於更年期後緩解

**病因（不完全明確）：**
- 經血逆流（Sampson's theory，最獲支持）
- 免疫因素：NK 細胞活性降低
- 體腔上皮化生（Coelomic metaplasia）
- 子宮內膜細胞經血管/淋巴擴散

**流行病學：**
- 發生率：15-30% 的育齡女性
- 平均發病年齡：25-30 歲

**危險因子：**
- 家族史（直系親屬風險增加 7-10 倍）
- 生殖道阻塞性異常
- Nulliparity
- 早發初經（<11-13 歲）
- 月經週期較短（<27 d）
- Low BMI

**臨床表現（4D）：**
1. **Dysmenorrhea**（經痛）
2. **Dyspareunia**（性交疼痛，與 cul-de-sac、子宮骶骨韌帶病灶相關）
3. **Dyschezia**（排便疼痛，直腸、乙狀結腸病灶）
4. **Dysuria**（排尿疼痛，膀胱病灶）

**其他表現：**
- 不孕（25-40% endometriosis 患者有不孕問題）
- 骨盆腔囊腫（endometrioma，「巧克力囊腫」）

**診斷：**
- 確診：Laparoscopy（gold standard）直接可視化病灶 + 病理切片
- 超音波：卵巢 endometrioma（"chocolate cyst"）
- CA-125：可能升高，但不作為診斷工具

**治療：**
- **藥物治療**（主要治療方式）：
  - NSAIDs（如 naproxen sodium）
  - 第一線：cyclic/continuous combined OCP、progestin（DMPA 或 dienogest）、Mirena® IUS
  - 第二線：GnRH agonist（leuprolide、elagolix），>6 個月需 add-back therapy
  - GnRH antagonist（relugolix，Myfembree®）
  - Danazol（少用，因副作用多）
- **手術治療**：
  - 保守手術：laparoscopy 切除/電燒病灶、剝離卵巢囊腫
  - 根治手術：hysterectomy + bilateral salpingo-oophorectomy
  - 術後若有生育需求，應儘快嘗試懷孕
  - 若無生育計畫，術後建議持續藥物抑制

### Adenomyosis

**定義：** 子宮內膜腺體及間質向子宫肌層延伸，又稱「內在性子宮内膜異位」

**流行病學：**
- 35 歲以上女性約 15%
- 組織學上 20-40% 子宮切除標本中可見
- 平均發病年齡：40-50 歲

**臨床特徵：**
- 可能無症狀
- Heavy menstrual bleeding（HMB）
- Secondary dysmenorrhea
- 子宮對稱性增大（通常 <14 cm）
- Halban's sign：月經前理學檢查時子宫柔軟壓痛

**治療：**
- 藥物：NSAIDs、Mirena® IUS、combined hormonal contraceptive、GnRH agonist、danazol
- 手術：已完成生育者，子宮切除術為首選

---

### Leiomyoma（Uterine Fibroids，子宮肌瘤）

**定義：** 子宮之良性平滑肌肉瘤

**流行病學：**
- 35 歲以上育齡女性約 40-50%
- 黑人性較常見，且腫瘤較大、發病較早
- 停經後通常消退
- 惡性轉變機率極低

**分類（FIGO）：**
- **Submucosal**（黏膜下）：向子宫内膜腔生長（Type 0-2）
- **Intramural**（肌層內）：最常見，生長於子宫肌層（Type 3-4）
- **Subserosal**（漿膜下）：向子宫表面突出（Type 5-7）
- **Cervical**（子宫頸）：Type 8

**臨床特徵：**
- 多數無症狀，為理學檢查或超聲波意外發現
- **出血症狀**：HMB、經痛（AUB 最常見，佔 26-29%）
- **壓迫/佔位症狀**：骨盆腔壓迫感、頻尿、便秘
- **生殖功能障礙**：不孕、反覆流產

**治療（僅有症狀、迅速增大、或黏膜下影響生育者才需治療）：**

| 治療類型 | 方法 |
|----------|------|
| 藥物（針對 AUB-L）| NSAIDs、tranexamic acid、CHC、hormonal IUS、Depo-Provera® |
| GnRH agonist | 術前 3 個月使用，減少出血、縮小腫瘤、糾正貧血 |
| GnRH antagonist | Relugolix（Myfembree®）|
| 介入放射 | 子宮动脉栓塞（UAE）：術後 6 個月縮小 50%，但有較高再手術率 |
| 手術 | Myomectomy（宮腔鏡、腹腔鏡或開腹）、Hysterectomy |

**Submucosal leiomyomata 最易引起症狀（出血、不孕）**

- 機制：雌激素抑制 FSH 及濾泡發育；黃體激素抑制 LH 峰、抑制排卵、增厚宮頸黏液
- 失敗率 0.3-8.0%（依順從性）
- 副作用：乳房壓痛、噁心、腹脹、不規則出血、閉經
- 風險：靜脈血栓、高血壓、中風
- 非避孕益處：減少月經量、減少青春痘、降低卵巢及子宫内膜癌風險

**Progestin-Only Methods：**
- Slynd®（drospirenone 4 mg）：可延後 24 小時服藥
- Mirena® IUS（levonorgestrel 52 μg）：對經血過多效果好，20% 達到閉經
- Kyleena® IUS（levonorgestrel 19.5 μg）：適合未生產者
- Depo-Provera®：每 12 週注射一次，70% 使用者於 1-2 年後閉經
- Nexplanon®：4 cm etonogestrel 植入劑，有效 3 年

**Emergency Postcoital Contraception（事後緊急避孕）：**
| 方法 | 機制 | 效果 |
|------|------|------|
| Yuzpe 法 | 2 次口服（ethinyl estradiol 100 μg + levonorgestrel 500 μg），間隔 12 小時 | 72 小時內，失敗率 2% |
| Levonorgestrel | 750 μg q12h × 2 或 1 g 單次 | 72 小時內，>75 kg 效果降低 |
| Ulipristal（Ella®）| 選擇性黃體激素受體調節劑（SPRM），可延後排卵達 5 天 | 5 天內 |
| Copper IUD | 預防著床 | 7 天內，失敗率 <1% |

## 終止妊娠（Termination of Pregnancy）

**適應症：** 母親因素（健康、孕期疾病、胎兒異常）或社會因素

**法律：** 加拿大目前無相關聯邦法律，各省規範不同。CPSO 規定醫師無論個人信念為何，必須提供墮胎服務轉介

**藥物流產（Medical Abortion）：**
- 適用於妊娠 <9 週
- Mifepristone 200 mg PO（第 1 天）+ Misoprostol 800 μg PV/BUC（第 2 或第 3 天）
- 成功率 95-98%
- 副作用：出血、疼痛、噁心、腹瀉、寒顫（預期內）
- 禁忌：宮外孕、慢性腎上腺功能衰竭

**手術流產（Surgical Abortion）：**
- <14 週：手動真空吸引（MVA）或吸引擴張刮除術（D&C）
- 14-24 週：擴張及清除術（D&E），術前需用 Laminaria 準備宮頸

## 妊娠相關併發症

### First Trimester Bleeding（第一孕期出血）

**定義：** 妊娠 14 週內陰道出血或點狀出血，發生率約 25%

**鑑別診斷：**
- 生理性著床出血
- 流產（threatened、inevitable、incomplete、complete、missed）
- 宮外孕（Ectopic pregnancy）
- 葡萄胎（Hydatidiform mole）
- 創傷（性交後）
- 子宮頸病變（polyp、腫瘤）

**Spontaneous Abortions 分類（Table 13）：**

| 類型 | 病史/理學/超聲波 | 管理 |
|------|------------------|------|
| Threatened | 出血、痙攣、有胎心 | 觀察，<5% 會繼續流產 |
| Inevitable | 出血、痙攣、胎膜破裂、子宮頸張開 | 觀望或 Misoprostol |
| Incomplete | 組織通過、子宮頸張開 | Misoprostol 或觀望 |
| Complete | 完全排出胎塊、子宮頸關閉 | 無需處理 |
| Missed | 無出血、胎兒無心跳 | Mifepristone + Misoprostol |
| Recurrent | 連續 3 次自然流產 | 評估機械、基因、環境風險因子 |
| Septic | 感染、發燒、惡臭分泌物 | 靜脈抗生素 + Misoprostol |

### Ectopic Pregnancy（宮外孕）

**定義：** 胚胎著床於子宫内膜腔外

**發生率：** 1/100 懷孕，為第一孕期母親死亡主因

**常見部位：** 輸卵管的壺腹部（70%）> 峽部（12%）> 繖部（11%）

**病因：** 50% 為輸卵管纖毛受損（PID 後），主要為輸卵管的解剖結構異常

**風險因子：**
- 既往宮外孕
- PID（尤其是 C. trachomatis）
- 輸卵管手術
- 吸煙
- IVF

**臨床表現：**
- 腹痛、陰道出血、肩痛（表示腹腔積血）
- 若破裂：急性腹痛、血流動力學不穩

**診斷：**
- 追蹤 B-hCG：正常宮內妊娠每 48 小時倍增；上升 <35% 提示異常
- 超音波：宮內無妊娠囊、B-hCG >2000-3000 mIU/mL
- 腹腔鏡（最終確診）

**治療：**
- **手術**：laparoscopy（linear salpingostomy 或 salpingectomy）
- **藥物**：Methotrexate（適用條件：血流動力學穩定、輸卵管的未破裂、B-hCG 較低、患者可配合追蹤）
  - 劑量：50 mg/m² 肌肉注射，單次
  - 追蹤 B-hCG（第 4、7 天，之後每週一次直至陰性）
  - 成功率 82-95%，需注意可能需要第二劑

## 不孕症（Infertility）

**定義：** 規律無避孕性行為一年後仍無法懷孕或維持妊娠

**發生率：** 10-15% 伴侶

**Table 14. 女性不孕病因**

| 類別 | 病因 |
|------|------|
| 卵巢因素 | 卵巢儲備下降、年齡相關卵子減少、化療/放療、基因異常（Fragile X）、PCOS、原發性卵巢功能不全 |
| 輸卵管因素 | PID、輸卵管粘連、結紮後、輸水管水腫（hydrosalpinx）|
| 子宮因素 | 黏膜下肌瘤/瘜肉、先天異常（雙角子宫、隔膜子宫）、宮腔粘連（Asherman's）、DES 暴露 |
| 子宮頸因素 | 子宮頸黏液異常、抗精子抗體 |
| 其他 | 生活方式、endometriosis、藥物、全身性疾病 |

**Investigations：**
- 卵巢功能：Day 3 的 FSH、LH、estradiol、TSH、prolactin、testosterone、AMH
- 輸卵管通暢性：Hysterosalpingogram（HSG）、sonohysterogram
- 男性因素：精液分析（見泌尿科）

**Treatment：**
- 生活方式調整
- 排卵誘發：Clomiphene citrate、Letrozole、metformin
- 人工授精（IUI）
- 試管嬰兒（IVF）、ICSI
- 手術：輸卵管切除、粘連分離

### Polycystic Ovarian Syndrome（PCOS，多囊性卵巢綜合症）

**定義：** 慢性內分泌疾病，影響育齡女性；特徵為卵巢囊腫、排卵障礙/月經不規則、雄性素過多

**診斷（Rotterdam 標準，3 項中需有 2 項）：**
1. Oligomenorrhea/irregular menses >6 個月
2. 雄性素過多（臨床或生化）
3. 超音波顯示多囊性卵巢

**臨床表現：**
- 初經後女性，平均發病年齡 15-35 歲
- 月經失調（80%）、不孕（74%）
- 多毛（69%）、青春痘
- 肥胖（49%）
- Acanthosis nigricans（胰島素阻抗指標）
- 長期健康風險：血脂異常、第二型糖尿病、子宮内膜增生

**治療：**
- **月經周期控制**：生活形態調整、hormonal IUS、combined OCP、metformin
- **不孕**：Letrozole、clomiphene citrate、metformin、ovarian drilling
- **多毛**：任何 OCP、Diane-35®（cyproterone acetate）、spironolactone、finasteride

### Pelvic Inflammatory Disease（PID，骨盆腔炎）

**定義：** 上生殖道感染（子宫內膜、輸卵管的、卵巢、骨盆腔腹膜），主要影響年輕性活躍女性

**病因：**
- C. trachomatis（最常見）
- N. gonorrhoeae
- 常為多菌種混合感染

**臨床診斷標準：**
- 最低標準：宮頸移動壓痛、子宮壓痛、附屬器壓痛
- 額外標準：發燒 >38.3°C、異常分泌物、實驗室確診淋病/披衣菌

**治療：**
| | 門診治療 | 住院治療 |
|--|---------|---------|
| 適應症 | 輕至中度、可口服抗生素、追蹤順從 | 中至重度、輸液膿、不佳或失敗、免疫抑制、懷孕 |
| 抗生素 | Ceftriaxone 500 mg IM + Doxycycline 100 mg PO BID × 14d（+ Metronidazole）| Cefoxitin 2g IV q6h + Doxycycline 或 Clindamycin + Gentamicin |

**併發症（未治療）：**
- 慢性骨盆腔疼痛
- 輸输卵管阻塞→不孕（1 次 PID：13%；2 次：36%）
- 宮外孕
- Fitz-Hugh-Curtis 症候群

### 其他人員注意傳染病

**Chlamydia（披衣菌）：**
- 加拿大最常見的細性 STI
- 80% 無症狀
- 治療：Doxycycline 100 mg PO BID × 7d 或 Azithromycin 1 g 單次
- 追蹤：3 週後 test of cure

**Gonorrhea（淋病）：**
- Neisseria gonorrhoeae
- 治療：Ceftriaxone 250 mg IM + Azithromycin 1 g PO
- 同時治療披衣菌（高共感染率）

**HPV（人類乳突病毒）：**
- >200 型；6、11 與尖形濕疣（condylomata acuminata）相關；16、18 為高致癌型
- 治療（尖形濕疣）：Podofilox、imiquimod、冷凍、手术切除
- 預防：Gardasil®9（覆蓋 6、11、16、18、31、33、45、52、58）

**Herpes Simplex Virus（HSV）：**
- 90% 為 HSV-2，10% 為 HSV-1
- 治療：acyclovir、famciclovir、valacyclovir
- 復發頻繁者（>6 次/年）可考慮每日抑制療法

**Syphilis（梅毒）：**
- Treponema pallidum
- 治療：Benzathine penicillin G 2.4 million units IM（初期/二期）
- 為通報疾病

## 更年期（Menopause）

**定義：** 停經滿 1 年

**類型：**
- 生理性：平均 51 歲（濾泡萎縮）
- 早發性卵巢功能不全（<40 歲）
- 醫源性（手術/放療/化療）

**臨床表現（雌激素缺乏）：**
- 血管不穩定：熱潮紅（hot flashes）、夜間盜汗、睡眠障礙
- 泌尿生殖道萎縮（Genitourinary syndrome of menopause，GUSM）：性交疼痛、陰道乾澀、頻尿
- 骨骼：骨質疏鬆、關節肌肉疼痛
- 皮膚：乳房縮小、皮膚變薄
- 心理：焦慮、憂鬱、疲倦、性慾減退、記憶力減退

**治療（Table 18. 更年期治療）：**

| 症狀 | 治療 |
|------|------|
| 血管不穩定 | MHT（Menopausal Hormone Therapy）、SSRI、venlafaxine、gabapentin、針灸 |
| 陰道萎縮 | 局部雌激素（cream、tablet、ring）、潤滑劑 |
| 骨質疏鬆 | 鈣、維生素 D、負重運動、雙磷酸鹽 |
| 性慾減退 | 局部雌激素、雄激素替代 |
| 心血管疾病 | 風險因子管理 |

**MHT（更年期荷爾蒙治療）原則：**
- 主要適應症為治療更年期症狀
- 最安全的使用時機：停經後 <10 年或 <60 歲
- 使用最低有效劑量
- 有子宫者需同時給予黃體激素（預防子宫内膜增生）
- 雌激素-黃體激素制劑：乳腺癌風險在 4-5 年後輕微增加
- 單用雌激素（無子宫者）：乳腺癌風險不增加
- 需定期追蹤及諮詢

## 骨盆腔器官脫垂（Pelvic Organ Prolapse）

**定義：** 骨盆腔支撐結構減弱，導致膀胱/直腸/小腸/子宫向陰道脫垂

**病因：**
- 懷孕、陰道分娩
- 停經後雌激素減少
- 腹壓增加（肥胖、慢性咳嗽、便祕、提重物）
- 結締組織疾病

**POP-Q 分期：**
- Stage 0：無脫垂
- Stage 1：脫垂最遠端在 hymen 上方 >1 cm
- Stage 2：脫垂最遠端在 hymen 上方或下方 1 cm 內
- Stage 3：脫垂最遠端在 hymen 下方 >1 cm，但未超過陰道總長 -2 cm
- Stage 4：完全，子宮/陰道穹隆完全脫垂

**Table 21. 脫垂類型及治療：**

| 類型 | 臨床特徵 | 治療 |
|------|----------|------|
| 前陰道壁脫垂（Cystocele）| 頻尿、急尿、應力性尿失禁 | 保守治療、骨盆底訓練、前陰道修補術 |
| 後陰道壁脫垂（Rectocele）| 排便用力、便祕 | 保守治療、軟便劑、後陰道修補術 |
| 子宮脫垂 | 骨盆腔沉重感、壓力、加劇站立/提重物、潰瘍 | 保守治療、子宮切除術 + 陰道穹隆固定 |
| 陰道穹隆脫垂（Vault prolapse）| 子宮切除術後，與上述相似 | Sacrospinous fixulation、骶骨陰道固定 |

## 尿失禁（Urinary Incontinence）

### Stress Incontinence（應力性尿失禁）

**定義：** 腹壓增加（咳嗽、笑、打噴嚏、走路、跑步）時不自主漏尿

**診斷：** 病史、骨盆檢查、standing stress test、U/A、post-void residual

**治療：**
- 保守：骨盆底訓練（Kegel 運動）、減重
- 手術：midurethral sling（TVT、TOT）、Burch urethropexy

### Overactive Bladder（急迫性尿失禁）

**定義：** 突然尿急感，伴或不伴應力性尿失禁，常伴有頻尿及夜尿

**治療：**
- 行為調整（減少膀胱刺激物、規律排尿）
- 抗膽鹼藥物（oxybutynin、tolterodine、solifenacin）
- β-3 腎上腺素促效劑（mirabegron）
- 肉毒桿菌注射（逼尿肌）

## 婦科腫瘤（Gynecological Oncology）

### Endometrial Carcinoma（子宫内膜癌）

**流行病學：**
- 北美最常見的婦科惡性腫瘤（40%）
- 平均年齡 60 歲
- I 期 5 年存活率 85-90%

**Table 22. Type I vs. Type II 子宫内膜癌特徵：**

| | Type I（Endometrioid）| Type II（Non-endometrioid）|
|--|----------------------|---------------------------|
| 描述 | 雌激素相關（unopposed estrogen）| 非雌激素相關 |
| 比例 | 80% | 20% |
| 風險因子 | PCOS、肥胖、遲停經、早發初經、未生育、tamoxifen | 子宮內膜癌家族史、BRCA、 Lynch syndrome |
| 病理 | 分化良好（Grade 1-2）| 漿液性、透明細胞、未分化 |
| 預後 | 較好 | 較差 |

**臨床表現：**
- Postmenopausal bleeding（PMB）→ **PMB = endometrial cancer until proven otherwise**
- 停經前患者：AUB

**診斷：**
- Endometrial biopsy（門診，pipelle）
- Hysteroscopy（如持續出血但切片為良性）

**FIGO 分期（2023）：**
- I 期：腫瘤局限於子宫体
- II 期：腫瘤侵犯子宫頸
- III 期：局部/區域擴散
- IV 期：膀胱/直腸黏膜或遠處轉移

**治療：**
- 手術：Total hysterectomy + BSO（子宫切除術 + 雙側卵巢輸输卵管切除）
- 輔助治療：放射治療、化學治療（依分期及組織學）
- 荷爾蒙治療（保留生育功能者）

### Cervical Cancer（子宫頸癌）

**流行病學：**
- 90% 為鱗狀細胞癌（SCC）；腺癌漸增（10%）
- 加拿大每年約 405 人死亡
- 平均發病年齡 50 歲

**病因：**
- HPV 感染（>99% 子宮頸癌含高風險 HPV）
- 高風險 HPV 型：16、18、31、33、35、39、45、51、52、56、58 等

**高風險族群：**
- 免疫功能低下
- 吸煙
- 篩檢不足族群（偏遠地區、低社經地位）

**臨床分期（FIGO 2018）：**
- I 期：腫瘤局限於子宫頸
- II 期：腫瘤延伸至子宫外但未達骨盆腔壁或下 1/3 陰道
- III 期：腫瘤達骨盆腔壁、下 1/3 陰道、或造成腎積水/無功能腎
- IV 期：侵犯膀胱/直腸或遠處轉移

**臨床表現：**
- 早期：無症狀或陰道分泌物、性交後出血
- 晚期：骨盆腔或背部疼痛（腫瘤擴展）
- 80-90% 以出血表現

**診斷：**
- Colposcopy + 切片
- LEEP（loop electrosurgical excision procedure）用於治療性切除

**預防：**
- HPV 疫苗（Gardasil®9、Cervarix®）
- 定期 Pap test

**治療：**
- I 期：Radical hysterectomy + 骨盆腔淋巴結切除 或 放射治療
  - 保留生育功能（腫瘤 <2 cm）：Radical trachelectomy
- I 期高風險：輔助 chemoradiation
- >I 期：Primary chemoradiation（含 extended field RT 若有淋巴結轉移）

---

### 輸卵管的惡性腫瘤（Fallopian Tube Cancer）

- 發生率最低（<0.3%）
- 多為漿液性上皮癌
- 證據顯示部分漿液性卵巢癌起源於輸输卵管
- 治療原則同上皮性卵巢癌

### Vulvar Cancer（外陰癌）

**流行病學：** 佔生殖道惡性腫瘤 5%；90% 為 SCC

**分類：**
- Type I：HPV 相關（50-70%），常見於年輕患者
- Type II：非 HPV 相關，與 lichen sclerosus 相關，常見於停經後患者

**非腫瘤性上皮疾病：**
1. **Lichen sclerosus**：瘙癢、"figure of 8"分布、外陰變薄萎縮；治療：高強度外用類固醇
2. **Lichen simplex chronicus**：慢性搔抓導致外陰增厚；治療：中強度類固醇
3. **Lichen planus**：自體免疫疾病，3 種變型；治療：超強度外用類固醇

**治療：**
- VIN：局部切除、雷射、imiquimod
- 侵襲性 SCC：手術（vulvectomy）+ 淋巴結評估 ± 放射/化學治療
