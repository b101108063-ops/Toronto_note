## 導讀摘要

- **月經失調**涵蓋無月經、子宮異常出血、經痛等常見問題；，子宮異常出血的鑑別診斷使用PALM-COEIN結構（瘜肉、子宮腺肌症、子宮肌瘤、惡性腫瘤對比凝血病、排卵障礙、子宮內膜、醫源性、未分類），治療原則為排除結構性病變後優先藥物治療
- ** endometriosis** 為子宫内膜組織生長於子宫腔外的慢性疾病，典型症狀包括續發性經痛、性交疼痛、排便疼痛、不孕；診斷以腹腔鏡為gold standard，治療包括非類固醇消炎止痛藥、複合荷爾蒙避孕藥、黃體激素、促性腺激素釋放激素激動劑，手術適用於藥物治療失敗或有生育需求者
- **子宫内膜癌**為北美最常見的婦科惡性腫瘤，典型症狀為停經後出血；診斷靠子宫内膜切片，治療以手術（全子宫切除術加雙側卵巢輸卵管的切除）為主；子宫平滑肌肉瘤為罕見但預後較差的腫瘤
- **卵巢腫瘤**分為良性（功能性囊腫、良性畸胎瘤）及惡性（表面上皮性卵巢癌最常見，佔85%）；CA-125為最常用的腫瘤標記但敏感度及特異度有限；惡性卵巢腫瘤以手術減積配合白金類化學治療為主要治療方式
- **HPV與子宫頸癌**關係密切（>99%子宫頸癌含有高風險HPV），預防靠疫苗及定期抹片檢查；子宫頸癌臨床分期使用FIGO分期系統（唯一使用臨床分期的婦科惡性腫瘤），治療方式依分期可選手術（根除性子宮切除）或化放療

## 婦科學概論

### 子宫切除術

**適應症：**
- 子宮肌瘤
- 子宮內膜異位症、子宮腺肌症
- 子宮脫垂
- 骨盆腔疼痛
- 子宮異常出血
- 惡性腫瘤（子宫内膜、卵巢、輸卵管的、子宮頸）

**併發症：**
- 全身麻醉風險
- 出血
- 感染
- 鄰近器官損傷（輸尿管、膀胱、直腸）
- 卵巢功能喪失（若切除卵巢則為醫源性更年期）
- 靜脈血栓

**手術路徑：**

| 方式 | 說明 |
|------|------|
| 開腹 | 經橫向或正中切口剖腹 |
| 陰道式 | 全程經陰道操作，無腹部傷口 |
| 腹腔鏡輔助陰道式 | 血管蒂以腹腔鏡及陰道方式結合處理 |
| 全腹腔鏡式 | 所有血管蒂及陰道切開皆經腹腔鏡完成 |
| 機器人輔助 | 腹腔鏡的一種，對高身體質量指數患者可能更有優勢 |

**子宫切除術分類**

| 分類 | 切除組織 | 適應症 |
|------|----------|--------|
| 子宮次全切除術 | 子宮 | 子宮頸無法觸及（如粘連）、患者偏好 |
| 全子宫切除術 | 子宮、子宮頸、子宮动脉結扎於子宫、輸卵管的 | 子宮肌瘤 |
| 全子宫切除術加雙側卵巢輸卵管的切除 | 子宮、子宮頸、子宮动脉、輸卵管的、卵巢 | 子宮内膜癌、惡性卵巢腫瘤 |
| 改良根除性子宮切除術（第二型）| 子宮、子宮頸、近端三分之一宮旁組織、子宮动脉於輸尿管內側結扎、輸卵管的、子宮骶骨韌帶中點、上陰道1-3公分 | 子宮内膜癌 |
| 根除性子宮切除術（第三型）| 子宮、子宮頸、全宮旁組織、子宮动脉於內髂动脉起源處結扎、子宮骶骨韌帶、子宮、主韌帶、上陰道1-3公分 | 子宮頸癌（可達第二B期）|

## 月經失調

### 無月經

**原發性無月經定義：**
- 13歲無第二性徵且無月經，或
- 15歲有第二性徵但無月經，或
- 初經後2年無月經

**次發性無月經定義：**
- 有初經記錄後連續6個月或3個週期無月經

**原發性無月經之鑑別診斷**

| 有第二性徵發育 | 無第二性徵發育 |
|----------------|----------------|
| 甲狀腺功能低下 | 甲狀腺功能低下 |
| 高泌乳激素血症 | 子宮發育不全 |
| 多囊性卵巢綜合症 | 子宮陰道隔膜 |
| 下視丘功能障礙 | 無孔處女膜 |
| 功能性下視丘無月經 | 性腺發育不全，如透納氏症候群 |
| 子宮發育不全 | Kallmann症候群 |

**次發性無月經之鑑別診斷**

| 有雄性素過多 | 無雄性素過多 |
|-------------------------------|-------------|
| 多囊性卵巢綜合症 | 功能性下視丘無月經（最常見）|
| 遲發性先天性腎上腺增生 | 高泌乳激素血症 |
| 卵巢腫瘤 | 甲狀腺功能障礙 |
| 腎上腺腫瘤 | 下丘腦-垂體功能減退 |
| | 原發性卵巢功能不全（高濾泡刺激素）|
| | 子宮粘連 |

**診斷流程：**
- 次發性無月經→優先排除懷孕
- 病史、理學檢查（有無第二性徵）
- 實驗室：人類絨毛膜促性腺激素、濾泡刺激素/黃體成長激素、泌乳激素、甲狀腺功能、雄性素
- 黃體素挑戰試驗（medroxyprogesterone acetate 10毫克口服每日一次×10-14天）
  - 有撤退性出血→子宫内膜有足夠雌激素
  - 無撤退性出血→可能為雌激素不足、子宮粘連、子宮頸狹窄等

**治療：**
| 病因 | 治療 |
|------|------|
| 解剖構造異常（無孔處女膜、子宮陰道隔膜）| 手術治療 |
| 高泌乳激素血症 | 確認核磁共振，排除病變後使用bromocriptine或cabergoline |
| 多囊性卵巢綜合症 | 見多囊性卵巢綜合症章節 |
| 原發性卵巢功能不全 | 賀爾蒙補充（雌激素加黃體激素）預防骨質疏鬆 |
| Asherman's症候群 | 子宮鏡切除粘連 |
| 功能性下視丘無月經 | 找出可修正原因（體重、運動），補充雌激素 |

### 子宮異常出血

**定義：** 月經的頻率、持續時間或量改變，影響生活品質

**評估重點：**
1. **規律性**：cycle-to-cycle variability <20天為規律，>20天為不規律
2. **出血量**：
   - 每次月經>8天
   - 衛生棉/棉條更換頻率高
   - 有血塊
   - 每次月經失血量>280毫升
3. **結構性vs.非結構性（PALM-COEIN）**

**PALM-COEIN分類：**

| 結構性 | 非結構性 |
|----------------|-----------------|
| **P**olyp（瘜肉）| **C**oagulopathy（凝血病）|
| **A**denomyosis（腺肌症）| **O**vulatory dysfunction（排卵障礙）|
| **L**eiomyoma（肌瘤）| **E**ndometrial（子宫内膜）|
| **M**alignancy/Hyperplasia（惡性腫瘤/增生）| **I**atrogenic（醫源性）|
| | **N**ot yet classified（未分類）|

**檢查：**
- 全血球計數、凝血功能（青少年）
- 人類絨毛膜促性腺激素、甲狀腺功能、泌乳激素、濾泡刺激素/黃體成長激素、雄性素
- 經陰道超聲波
- 子宮内膜切片（>40歲或有風險因子者）

**子宫異常出血病因、檢查與治療**

| 病因 | 檢查 | 治療 |
|------|------|------|
| 瘜肉 | 經陰道超聲波、子宮腔超聲波顯影 | 瘜肉切除 |
| 腺肌症 | 經陰道超聲波、核磁共振 | 見腺肌症章節 |
| 肌瘤 | 經陰道超聲波、子宮腔超聲波顯影 | 見肌瘤章節 |
| 惡性腫瘤 | 經陰道超聲波、子宮内膜切片 | 依診斷 |
| 凝血病 | 全血球計數、凝血功能、血管性血友病指標 | 止血環酸 |
| 排卵障礙 | 血液檢查、經陰道超聲波 | 荷爾蒙調節（口服避孕藥、子宮內投藥系統）|
| 子宮內膜 | 子宮内膜切片 | 見不孕症章節 |
| 醫源性 | 病史、回顧用藥 | 移除致病藥物 |

**子宫異常出血藥物治療原則：**
- 輕度：非類固醇消炎止痛藥、子宮內投藥系統、糾正貧血
- 急性嚴重出血：
  - 抗纖維蛋白溶酶（止血環酸）
  - 合併荷爾蒙避孕藥（漸減療程）
  - 必要時輸液、輸血
- 手術：瘜肉切除、肌瘤切除、子宮动脉栓塞、子宮内膜 ablation、子宫切除術

### 經痛

**原發性與續發性經痛比較**

| 特徵 | 原發性經痛 | 續發性經痛 |
|------|---------------------|----------------------|
| 定義 | 無明確疾病的復發性經痛 | 有潛在疾病的經痛 |
| 病因 | 前列腺素相關 | 子宮內膜異位症、腺肌症、子宮肌瘤等 |
| 疼痛特性 | 痙攣性下腹疼痛，放射至下背、會陰、大腿 | 類似原發性，伴有其他症狀 |
| 發作時間 | 月經來潮前數小時，持續48-72小時 | 不一定與月經相關 |
| 相關症狀 | 腹瀉、排便習慣改變、頭痛、疲倦 | 性交疼痛、不孕、異常用血 |
| 理學檢查 | 正常（必要時做）| 子宮或附屬器壓痛、子宮後傾、子宮韌帶結節 |
| 治療 | 規則運動、非類固醇消炎止痛藥、荷爾蒙治療 | 治療根本原因 |

## 子宮疾病

### 子宮內膜異位症

**定義：** 子宮内膜組織（腺體及間質）生長於子宫腔外，為慢性疾病，僅於更年期後緩解

**病因（不完全明確）：**
- 經血逆流（Sampson's理論，最獲支持）
- 免疫因素：自然殺手細胞活性降低
- 體腔上皮化生
- 子宮内膜細胞經血管/淋巴擴散

**流行病學：**
- 發生率：15-30%的育齡女性
- 平均發病年齡：25-30歲

**危險因子：**
- 家族史（直系親屬風險增加7-10倍）
- 生殖道阻塞性異常
- 未生產
- 早發初經（<11-13歲）
- 月經週期較短（<27天）
- 低身體質量指數

**臨床表現：**
1. **經痛**
2. **性交疼痛**（與Douglas窩、子宮骶骨韌帶病灶相關）
3. **排便疼痛**（直腸、乙狀結腸病灶）
4. **排尿疼痛**（膀胱病灶）

**其他表現：**
- 不孕（25-40% endometriosis患者有不孕問題）
- 骨盆腔囊腫（endometrioma，「巧克力囊腫」）

**診斷：**
- 確診：腹腔鏡（gold standard）直接可視化病灶＋病理切片
- 超音波：卵巢endometrioma（「巧克力囊腫」）
- CA-125：可能升高，但不作為診斷工具

**治療：**
- **藥物治療**（主要治療方式）：
  - 非類固醇消炎止痛藥
  - 第一線：週期性/持續性複合口服避孕藥、黃體激素（迪皮質醇或dienogest）、Mirena®，子宮內投藥系統
  - 第二線：促性腺激素釋放激素激動劑（leuprolide、elagolix），>6個月需add-back療法
  - 促性腺激素釋放激素拮抗劑（relugolix，Myfembree®）
  - Danazol（少用，因副作用多）
- **手術治療**：
  - 保守手術：腹腔鏡切除/電燒病灶、剝離卵巢囊腫
  - 根治手術：子宫切除術加雙側卵巢輸卵管的切除
  - 術後若有生育需求，應儘快嘗試懷孕
  - 若無生育計畫，術後建議持續藥物抑制

### 腺肌症

**定義：** 子宮内膜腺體及間質向子宫肌層延伸，又稱「內在性子宮内膜異位」

**流行病學：**
- 35歲以上女性約15%
- 組織學上20-40%子宫切除標本中可見
- 平均發病年齡：40-50歲

**臨床特徵：**
- 可能無症狀
- 經血過多
- 續發性經痛
- 子宮對稱性增大（通常<14公分）
- Halban's徵象：月經前理學檢查時子宫柔軟壓痛

**治療：**
- 藥物：非類固醇消炎止痛藥、Mirena®，子宮內投藥系統、複合荷爾蒙避孕藥、促性腺激素釋放激素激動劑、danazol
- 手術：已完成生育者，子宫切除術為首選

---

### 子宮肌瘤

**定義：** 子宮之良性平滑肌肉瘤

**流行病學：**
- 35歲以上育齡女性約40-50%
- 黑人性較常見，且腫瘤較大、發病較早
- 停經後通常消退
- 惡性轉變機率極低

**分類：**
- **黏膜下型**：向子宫内膜腔生長
- **肌層內型**：最常見，生長於子宫肌層
- **漿膜下型**：向子宫表面突出
- **子宫頸型**

**臨床特徵：**
- 多數無症狀，為理學檢查或超聲波意外發現
- **出血症狀**：經血過多、經痛（子宫異常出血最常見，佔26-29%）
- **壓迫/佔位症狀**：骨盆腔壓迫感、頻尿、便秘
- **生殖功能障礙**：不孕、反覆流產

**治療（僅有症狀、迅速增大、或黏膜下影響生育者才需治療）：**

| 治療類型 | 方法 |
|----------|------|
| 藥物 | 非類固醇消炎止痛藥、止血環酸、複合荷爾蒙避孕藥、子宮內投藥系統、迪皮質醇 |
| 促性腺激素釋放激素激動劑 | 術前3個月使用，減少出血、縮小腫瘤、糾正貧血 |
| 促性腺激素釋放激素拮抗劑 | Relugolix（Myfembree®）|
| 介入放射 | 子宮动脉栓塞：術後6個月縮小50%，但有較高再手術率 |
| 手術 | 肌瘤切除（宮腔鏡、腹腔鏡或開腹）、子宫切除術 |

**黏膜下肌瘤最易引起症狀（出血、不孕）**

|------|------|--------------|--------------|
| 生理性 | 體外射精 | 96% | 77% |

## 終止妊娠

**適應症：** 母親因素（健康、孕期疾病、胎兒異常）或社會因素

**法律：** 加拿大目前無相關聯邦法律，各省規範不同。醫師無論個人信念為何，必須提供終止妊娠服務轉介

**藥物流產：**
- 適用於妊娠<9週
- Mifepristone 200毫克口服（第1天）加Misoprostol 800微克陰道/頰（第2或第3天）
- 成功率95-98%
- 副作用：出血、疼痛、噁心、腹瀉、寒顫（預期內）
- 禁忌：宮外孕、慢性腎上腺功能衰竭

**手術流產：**
- <14週：手動真空吸引或吸引擴張刮除術
- 14-24週：擴張及清除術，術前需用Laminaria準備宮頸

## 妊娠相關併發症

### 第一孕期出血

**定義：** 妊娠14週內陰道出血或點狀出血，發生率約25%

**鑑別診斷：**
- 生理性著床出血
- 流產（威脅性、不可避免、不完全、完全、稽留）
- 宮外孕
- 葡萄胎
- 創傷（性交後）
- 子宮頸病變（瘜肉、腫瘤）

**自然流產分類**

| 類型 | 病史/理學/超聲波 | 管理 |
|------|------------------|------|
| 威脅性 | 出血、痙攣、有胎心 | 觀察，<5%會繼續流產 |
| 不可避免 | 出血、痙攣、胎膜破裂、子宮頸張開 | 觀望或Misoprostol |
| 不完全 | 組織通過、子宮頸張開 | Misoprostol或觀望 |
| 完全 | 完全排出胎塊、子宮頸關閉 | 無需處理 |
| 稽留 | 無出血、胎兒無心跳 | Mifepristone加Misoprostol |
| 復發性 | 連續3次自然流產 | 評估機械、基因、環境風險因子 |
| 敗血性 | 感染、發燒、惡臭分泌物 | 靜脈抗生素加Misoprostol |

### 宮外孕

**定義：** 胚胎著床於子宫内膜腔外

**發生率：** 1/100懷孕，為第一孕期母親死亡主因

**常見部位：** 輸卵管的壺腹部（70%）>峽部（12%）>繖部（11%）

**病因：** 50%為輸卵管纖毛受損（骨盆腔炎後），主要為輸卵管的解剖結構異常

**風險因子：**
- 既往宮外孕
- 骨盆腔炎（尤其砂眼披衣菌）
- 輸水管手術
- 吸煙
- 試管嬰兒

**臨床表現：**
- 腹痛、陰道出血、肩痛（表示腹腔積血）
- 若破裂：急性腹痛、血流動力學不穩

**診斷：**
- 追蹤β-人類絨毛膜促性腺激素：正常宮內妊娠每48小時倍增；上升<35%提示異常
- 超音波：宮內無妊娠囊、β-人類絨毛膜促性腺激素>2000-3000毫國際單位/毫升
- 腹腔鏡（最終確診）

**治療：**
- **手術**：腹腔鏡（輸卵管的切開引流或輸卵管的切除）
- **藥物**：Methotrexate（適用條件：血流動力學穩定、輸卵管的未破裂、β-人類絨毛膜促性腺激素較低、患者可配合追蹤）
  - 劑量：50毫克/平方公尺肌肉注射，單次
  - 追蹤β-人類絨毛膜促性腺激素（第4、7天，之後每週一次直至陰性）
  - 成功率82-95%，需注意可能需要第二劑

## 不孕症

**定義：** 規律無避孕性行為一年後仍無法懷孕或維持妊娠

**發生率：** 10-15%伴侶

**女性不孕病因**

| 類別 | 病因 |
|------|------|
| 卵巢因素 | 卵巢儲備下降、年齡相關卵子減少、化療/放療、基因異常（脆弱X染色體）、多囊性卵巢綜合症、原發性卵巢功能不全 |
| 輸卵管的因子 | 骨盆腔炎、輸水管粘連、結紮後、輸水管水腫 |
| 子宮因素 | 黏膜下肌瘤/瘜肉、先天異常（雙角子宫、隔膜子宫）、宮腔粘連、DES暴露 |
| 子宮頸因子 | 子宮頸黏液異常、抗精子抗體 |
| 其他 | 生活方式、子宮內膜異位症、藥物、全身性疾病 |

**檢查：**
- 卵巢功能：第3天的濾泡刺激素、黃體成長激素、雌二醇、甲狀腺刺激素、泌乳激素、睪固酮、抗穆勒氏管激素
- 輸卵管的通暢性：輸卵管、子宮腔X光攝影、子宮腔超聲波顯影
- 男性因素：精液分析（見泌尿科）

**治療：**
- 生活方式調整
- 排卵誘發：Clomiphene citrate、Letrozole、二甲雙胍
- 人工授精
- 試管嬰兒、單精子胞質內注射
- 手術：輸水管切除、粘連分離

### 多囊性卵巢綜合症

**定義：** 慢性內分泌疾病，影響育齡女性；特徵為卵巢囊腫、排卵障礙/月經不規則、雄性素過多

**診斷（Rotterdam標準，3項中需有2項）：**
1. 寡月經/不規律月經>6個月
2. 雄性素過多（臨床或生化）
3. 超音波顯示多囊性卵巢

**臨床表現：**
- 初經後女性，平均發病年齡15-35歲
- 月經失調（80%）、不孕（74%）
- 多毛（69%）、青春痘
- 肥胖（49%）
- 黑色棘皮症（胰島素阻抗指標）
- 長期健康風險：血脂異常、第二型糖尿病、，子宫内膜增生

**治療：**
- **月經周期控制**：生活形態調整、，子宮內投藥系統、複合口服避孕藥、二甲雙胍
- **不孕**：Letrozole、clomiphene citrate、二甲雙胍、卵巢鑽孔術
- **多毛**：任何口服避孕藥、含cyproterone acetate的製劑、spironolactone、finasteride

## 婦科感染

### 生理性陰道分泌物

- 特徵：透明、白色、無異味、pH 4.0-4.5
- 含表皮細胞、乳酸桿菌
- 雌激素增加時會增多（懷孕、口服避孕藥、排卵前後）

### 外陰陰道炎

**孩童常見原因：**

| 病因 | 診斷 | 治療 |
|------|------|------|
| 蟯蟲 | 膠帶試驗 | Mebendazole |
| 異物 | 理學檢查 | 沖洗，必要時鎮靜下移除 |
| 硬化性苔癬 | 白色斑塊、皮膚變薄 | 外用類固醇 |

**感染性外陰陰道炎比較：**

| | 念珠菌 | 細菌性陰道炎 | 滴蟲 |
|--|---------------------|-------------------------|----------------------|
| 病原 | 白色念珠菌（90%）| Gardnerella vaginalis、 Mobiluncus | 陰道滴蟲 |
| 風險因子 | 免疫抑制、抗生素、懷孕 | 性交頻繁、吸煙、沖洗 | 性傳播 |

### 骨盆腔炎

**定義：** 上生殖道感染（子宫内膜、輸卵管的、卵巢、骨盆腔腹膜），主要影響年輕性活躍女性

**病因：**
- 砂眼披衣菌（最常見）
- 淋病雙球菌
- 常為多菌種混合感染

**臨床診斷標準：**
- 最低標準：宮頸移動壓痛、子宮壓痛、附屬器壓痛
- 額外標準：發燒>38.3°C、異常用分泌物、實驗室確診淋病/披衣菌

**治療：**

| | 門診治療 | 住院治療 |
|--|---------|---------|
| 適應症 | 輕至中度、可口服抗生素、追蹤順從 | 中至重度、膿毒症、不佳或失敗、免疫抑制、懷孕 |
| 抗生素 | Ceftriaxone 500毫克肌肉注射加Doxycycline 100毫克口服每日2次×14天（加Metronidazole）| Cefoxitin 2克靜脈注射每6小時加Doxycycline或Clindamycin加Gentamicin |

**併發症（未治療）：**
- 慢性骨盆腔疼痛
- 輸输卵管阻塞→不孕（1次骨盆腔炎：13%；2次：36%）
- 宮外孕
- Fitz-Hugh-Curtis症候群

### 其他人員注意傳染病

**披衣菌：**
- 加拿大最常見的性傳播感染
- 80%無症狀
- 治療：Doxycycline 100毫克口服每日2次×7天或Azithromycin 1克單次
- 追蹤：3週後test of cure

**淋病：**
- 淋病雙球菌
- 治療：Ceftriaxone 250毫克肌肉注射加Azithromycin 1克口服
- 同時治療披衣菌（高共感染率）

**人類乳突病毒：**
- >200型；6、11與尖形濕疣相關；16、18為高致癌型
- 治療（尖形濕疣）：Podofilox、imiquimod、冷凍、手術切除
- 預防：Gardasil®9（覆蓋6、11、16、18、31、33、45、52、58）

**單純皰疹病毒：**
- 90%為第二型，10%為第一型
- 治療：acyclovir、famciclovir、valacyclovir
- 復發頻繁者（>6次/年）可考慮每日抑制療法

**梅毒：**
- 梅毒螺旋體
- 治療：Benzathine penicillin G 240萬單位肌肉注射（初期/二期）
- 為通報疾病

## 更年期

**定義：** 停經滿1年

**類型：**
- 生理性：平均51歲（濾泡萎縮）
- 早發性卵巢功能不全（<40歲）
- 醫源性（手術/放療/化療）

**臨床表現（雌激素缺乏）：**
- 血管不穩定：熱潮紅、夜間盜汗、睡眠障礙
- 泌尿生殖道萎縮：性交疼痛、陰道乾澀、頻尿
- 骨骼：骨質疏鬆、關節肌肉疼痛
- 皮膚：乳房縮小、皮膚變薄
- 心理：焦慮、憂鬱、疲倦、性慾減退、記憶力減退

**更年期治療：**

| 症狀 | 治療 |
|------|------|
| 血管不穩定 | 更年期荷爾蒙治療、選擇性血清素再吸收抑制劑、venlafaxine、gabapentin、針灸 |
| 陰道萎縮 | 局部雌激素（乳膏、片劑、環）、潤滑劑 |
| 骨質疏鬆 | 鈣、維生素D、負重運動、雙磷酸鹽 |
| 性慾減退 | 局部雌激素、雄激素替代 |
| 心血管疾病 | 風險因子管理 |

**更年期荷爾蒙治療原則：**
- 主要適應症為治療更年期症狀
- 最安全的使用時機：停經後<10年或<60歲
- 使用最低有效劑量
- 有子宫者需同時給予黃體激素（預防子宫内膜增生）
- 雌激素-黃體激素製劑：乳腺癌風險在4-5年後輕微增加
- 單用雌激素（無子宫者）：乳腺癌風險不增加
- 需定期追蹤及諮詢

## 骨盆腔器官脫垂

**定義：** 骨盆腔支撐結構減弱，導致膀胱/直腸/小腸/子宫向陰道脫垂

**病因：**
- 懷孕、陰道分娩
- 停經後雌激素減少
- 腹壓增加（肥胖、慢性咳嗽、便祕、提重物）
- 結締組織疾病

**POP-Q分期：**
- Stage 0：無脫垂
- Stage 1：脫垂最遠端在處女膜上方>1公分
- Stage 2：脫垂最遠端在處女膜上方或下方1公分內
- Stage 3：脫垂最遠端在處女膜下方>1公分，但未超過陰道總長-2公分
- Stage 4：完全，子宮/陰道穹隆完全脫垂

**脫垂類型及治療：**

| 類型 | 臨床特徵 | 治療 |
|------|----------|------|
| 前陰道壁脫垂（膀胱脫垂）| 頻尿、急尿、應力性尿失禁 | 保守治療、骨盆底訓練、前陰道修補術 |
| 後陰道壁脫垂（直腸脫垂）| 排便用力、便祕 | 保守治療、軟便劑、後陰道修補術 |
| 子宮脫垂 | 骨盆腔沉重感、壓力、加劇站立/提重物、潰疡 | 保守治療、子宫切除術加陰道穹隆固定 |
| 陰道穹隆脫垂 | 子宮切除術後，與上述相似 | 骶棘固定術、骶骨陰道固定 |

## 尿失禁

### 應力性尿失禁

**定義：** 腹壓增加（咳嗽、笑、打噴嚏、走走路、跑步）時不自主漏尿

**診斷：** 病史、骨盆檢查、站立應力測試、尿液分析、排尿後剩餘尿量

**治療：**
- 保守：骨盆底訓練（凱格爾運動）、減重
- 手術：尿道中段吊帶（TVT、TOT）、Burch尿道固定術

### 急迫性尿失禁

**定義：** 突然尿急感，伴或不伴應力性尿失禁，常伴有頻尿及夜尿

**治療：**
- 行為調整（減少膀胱刺激物、規律排尿）
- 抗膽鹼藥物（oxybutynin、tolterodine、solifenacin）
- β-3腎上腺素促效劑（mirabegron）
- 肉毒桿菌注射（逼尿肌）

## 婦科腫瘤

### 子宮内膜癌

**流行病學：**
- 北美最常見的婦科惡性腫瘤（40%）
- 平均年齡60歲
- 第一期5年存活率85-90%

**第一型與第二型子宫内膜癌特徵：**

| | 第一型（類內膜型）| 第二型（非類內膜型）|
|--|----------------------|---------------------------|
| 描述 | 雌激素相關 | 非雌激素相關 |
| 比例 | 80% | 20% |
| 風險因子 | 多囊性卵巢綜合症、肥胖、遲停經、早發初經、未生育、tamoxifen | 子宮内膜癌家族史、BRCA、Lynch症候群 |
| 病理 | 分化良好 | 漿液性、透明細胞、未分化 |
| 預後 | 較好 | 較差 |

**臨床表現：**
- 停經後出血→停經後出血＝子宫内膜癌直到證明其他
- 停經前患者：子宫異常出血

**診斷：**
- 子宮内膜切片（門診，pipelle）
- 子宮鏡（如持續出血但切片為良性）

**FIGO分期：**
- 第一期：腫瘤局限於子宫体
- 第二期：腫瘤侵犯子宫頸
- 第三期：局部/區域擴散
- 第四期：膀胱/直腸黏膜或遠處轉移

**治療：**
- 手術：全子宫切除術加雙側卵巢輸卵管的切除
- 輔助治療：放射治療、化學治療（依分期及組織學）
- 荷爾蒙治療（保留生育功能者）

### 子宮肉瘤

**特點：** 罕見（3-9%子宫惡性腫瘤），預後差（5年存活率35%）

**子宫肉瘤亞型：**

| 類型 | 特徵 | 治療 |
|------|------|------|
| 平滑肌肉瘤 | 最常見，確診常為術後，預後差 | 子宫切除術，化學/放射治療 |
| 子宮内膜間質肉瘤 | 預後較好，荷爾蒙治療可能有效 | 子宫切除術加雙側卵巢輸卵管的切除 |
| 未分化肉瘤 | 高度惡性，預後差 | 手術為主 |
| 腺肉瘤 | 混合性，預後較好 | 子宫切除術 |

### 卵巢腫瘤

**流行病學：**
- 終身風險1.4%
- 為北美婦科惡性腫瘤死亡之首（超過其他所有婦科癌症總和）
- 85%上皮性；15%非上皮性
- 10-15%與遺傳素質相關（BRCA、Lynch症候群）

**卵巢腫瘤分類：**

| 類型 | 描述 | 超聲波/細胞學 | 治療 |

| 黃體囊腫 | 黃體未退化 | 較大 | 觀察 |

| **惡性胚細胞瘤**| | | |
| 發育不良瘤 | 對側卵巢常見 | 化學/手術 | 第一A期可不做輔助治療 |

- 手術減積：全子宫切除術加雙側卵巢輸卵管的切除加網膜切除加移除所有可見病灶
- 化學治療：卡鉑加紫杉醇
- 化學藥物敏感度高（尤其是漿液性）
- 低惡性潛能腫瘤：化學治療效果有限，可考慮荷爾蒙治療

**預防：**
- 高風險患者（BRCA突變）：預防性雙側卵巢輸卵管的切除
- 輸卵管的切除可能降低風險

### 子宮頸癌

**流行病學：**
- 90%為鱗狀細胞癌；腺癌漸增（10%）
- 加拿大每年約405人死亡
- 平均發病年齡50歲

**病因：**
- 人類乳突病毒感染（>99%子宫頸癌含高風險HPV）
- 高風險HPV型：16、18、31、33、35、39、45、51、52、56、58等

**高風險族群：**
- 免疫功能低下
- 吸煙
- 篩檢不足族群

**臨床分期：**
- 第一期：腫瘤局限於子宫頸
- 第二期：腫瘤延伸至子宫外但未達骨盆腔壁或下三分之一陰道
- 第三期：腫瘤達骨盆腔壁、下三分之一陰道、或造成腎積水/無功能腎
- 第四期：侵犯膀胱/直腸或遠處轉移

**臨床表現：**
- 早期：無症狀或陰道分泌物、性交後出血
- 晚期：骨盆腔或背部疼痛（腫瘤擴展）
- 80-90%以出血表現

**診斷：**
- 陰道鏡加切片
- 環形電切除術用於治療性切除

**預防：**
- 人類乳突病毒疫苗（Gardasil®9、Cervarix®）
- 定期抹片檢查

**治療：**
- 第一期：根除性子宮切除加骨盆腔淋巴結切除或放射治療
  - 保留生育功能（腫瘤<2公分）：根除性子宮頸切除術
- 第一期高風險：輔助化放療
- >第一期：主要化放療（含擴展野放射治療若有淋巴結轉移）

---

### 輸卵管的惡性腫瘤

- 發生率最低（<0.3%）
- 多為漿液性上皮癌
- 證據顯示部分漿液性卵巢癌起源於輸输卵管
- 治療原則同上皮性卵巢癌

### 外陰癌

**流行病學：** 佔生殖道惡性腫瘤5%；90%為鱗狀細胞癌

**分類：**
- 第一型：HPV相關（50-70%），常見於年輕患者
- 第二型：非HPV相關，與硬化性苔癬相關，常見於停經後患者

**非腫瘤性上皮疾病：**
1. **硬化性苔癬**：瘙癢、「8字形」分布、外陰變薄萎縮；治療：高強度外用類固醇
2. **慢性單純性苔癬**：慢性搔抓導致外陰增厚；治療：中強度類固醇
3. **扁平苔癬**：自體免疫疾病，3種變型；治療：超強度外用類固醇

**治療：**
- 外陰上皮內腫瘤：局部切除、雷射、imiquimod
- 侵襲性鱗狀細胞癌：手術（外陰切除）加淋巴結評估±放射/化學治療
