## 導讀摘要

- **貧血**：依平均紅血球容積分類（小球性/正球性/大球性）；包括缺鐵性貧血、慢性病貧血、海洋性貧血、鐮刀型紅血球疾病、巨球性貧血；診斷流程與治療原則
- **凝血障礙**：原發性止血障礙（免疫性血小板減少紫斑症、肝素誘發血小板減少症、血管性血友病）與續發性止血障礙（血友病、瀰散性血管內凝血）；Virchow's Triad與靜脈血栓栓塞症
- **血液惡性腫瘤**：骨髓性惡性腫瘤（急性骨髓性白血病、骨髓增生異常症候群、骨髓增生性腫瘤）與淋巴性惡性腫瘤（急性淋巴性白血病、霍奇金淋巴瘤、非霍奇金淋巴瘤、多發性骨髓瘤）；症狀、診斷、分期與治療
- **血球異常**：血小板減少、血小板增多、全血球減少、嗜中性球減少、嗜中性球增多；涵蓋紅血球增多症
- **輸血醫學**：血液製品種類與適應症、輸血反應處置、腫瘤溶解症候群

## 血液學概論

### 血液學範疇

血液學涵蓋血液及造血器官疾病的診斷與治療，包括：

- **紅血球疾病**：貧血、紅血球增多症
- **白血球疾病**：嗜中性球減少、嗜中性球增多、白血病、淋巴瘤
- **血小板及凝血疾病**：血小板減少、血小板增多、凝血障礙、血栓形成傾向
- **造血系統腫瘤**：骨髓增生性腫瘤、淋巴增生病

### 血液學診斷工具

| 檢驗項目 | 臨床意義 |
|:---------|:---------|
| 全血球計數附分類 | 評估各血球數值、平均紅血球容積、平均紅血球血紅蛋白量、平均紅血球血紅蛋白濃度 |
| 周邊血液抹片 | 觀察紅血球、白血球、血小板形態 |
| 網狀紅血球計數 | 區分生成減少與破壞增加的貧血 |
| 凝血檢查 | 凝血酶原時間/國際標準化比值、活化部分凝血活酶時間、纖維蛋白原、D-雙聚合體 |
| 骨髓切片 | 確診白血病、骨髓增生異常、淋巴瘤 |
| 流式細胞儀 | 免疫分型診斷白血病與淋巴瘤 |
| 細胞遺傳學/螢光原位雜交 | 染色體異常與基因突變分析 |

## 貧血

### 定義

+ 紅血球質量減少，可由血紅蛋白濃度、血球容積比、紅血球計數檢測出來
  - 成年男性：血紅蛋白<130克/公升或血球容積比<38%
  - 成年女性：血紅蛋白<120克/公升或血球容積比<37%（懷孕及孕期階段有變化）

### 臨床表現

**病史詢問**：
- 貧血症狀：疲倦、頭痛、頭暈、不適、虛弱、運動耐受力下降、呼吸困難、心悸、頭暈、耳鳴、暈厥
- 急性vs.慢性、失血、系統性疾病、旅遊史、用藥史、飲食（鐵、維生素B12來源）、酒精、家族史
- 溶血症狀：黃疸、鞏膜黃染
- 月經史：經血過多、經期延長
- 排除全血球減少（復發性感染、黏膜出血、容易瘀青）

**理學檢查**：
- 頭頸部：血紅蛋白<90克/公升時黏膜與結膜蒼白；血紅蛋白<55克/公升時眼眶雜音；口角炎；黃疸
- 心臟：心搏過速、姿勢性低血壓、收縮期血流雜音、脈壓差擴大、心衰竭徵象
- 皮膚：瘀斑、紫斑、血紅蛋白<75克/公升時掌紋蒼白、溶血導致黃疸、指甲變化（匙狀甲）、舌炎
- 脾臟與淋巴結：脾腫大、淋巴結病變

### 診斷檢查

+ 排除稀釋性貧血（循環容量增加導致血紅蛋白降低）

+ **全血球計數附分類、網狀紅血球計數、血液抹片**

+ 排除營養缺乏：缺鐵性貧血需檢查胃腸道與泌尿生殖道疾病

+ 視情況進行進一步實驗室檢查（見各貧血亞型章節）

+ **注意**：可能同時有多種營養缺乏，導致混合型貧血

### 治療原則

+ 治療根本原因（見各貧血亞型章節）

---

### 網狀紅血球

網狀紅血球是未成熟的紅血球，是紅血球生成的指標。

**判讀要點**：
- 網狀紅血球計數應結合血紅蛋白濃度一起判讀
- 正常情況下，紅血球減少時網狀紅血球會增加
- 失血後：初始增加2-3倍，隨後一週內增加5-7倍
- 貧血時網狀紅血球計數正常應視為生成減少的徵象，可能原因為骨髓浸潤、營養缺乏或其他原因
- 貧血合併網狀紅血球增多提示骨髓有適當反應

## 紅血球增多症

### 定義

+ 血紅蛋白及/或血球容積比增加：男性血紅蛋白>165克/公升或血球容積比>49%；女性血紅蛋白>160克/公升或血球容積比>48%

### 病因分類

| 類型 | 病因 |
|:-----|:-----|
| **原發性** | 真性紅血球增多症（見相關章節） |
| **繼發性（生理性缺氧）** | 一氧化碳中毒、大量吸菸、高海拔、肺部疾病、慢性阻塞性肺病、睡眠呼吸中止症、肺高壓、心血管疾病（右向左分流，如Eisenmenger症候群）、血紅蛋白病（高親和力血紅蛋白、正鐵血紅蛋白血症） |
| **紅血球生成素不當分泌** | 腫瘤（肝細胞癌、腎細胞癌、小腦血管母細胞瘤、嗜鉻細胞瘤、子宮肌瘤、卵巢腫瘤）、多囊性腎病、腎動脈狹窄、腎移植後、雄性素、紅血球生成素 |
| **相對性/假性** | 利尿劑、嚴重脫水、燒傷、「應激」 |

### 臨床表現

+ 高紅血球質量與高血液黏滯度導致：
  - 頭痛、呼吸困難、頭暈、耳鳴、視覺障礙、高血壓症狀、感覺異常
  - 心絞痛、心衰竭、用水後搔癢症狀（僅見於骨髓增生性腫瘤）
+ 血栓（靜脈或動脈）或出血（骨髓增生性腫瘤合併後天性血管性血友病或後天性血小板功能障礙）
+ 理學發現：脾腫大加肝腫大、面部發紺/紅潤（70%）或掌心發紅、痛風

### 診斷檢查

+ **血清紅血球生成素**：區分原發性（低/正常）與其他病因（升高）
  - 視情況搜尋腫瘤作為紅血球生成素來源（如腹部超聲波、頭部電腦斷層）
+ **JAK-2突變分析**：真性紅血球增多症病例中>96%為陽性
  - 僅在紅血球生成素低/正常時送檢
+ **鐵蛋白**：缺鐵可能掩蓋診斷；缺鐵合併網狀紅血球增多提示真性紅血球增多症

### 治療

+ **原發性**：見真性紅血球增多症章節
+ **繼發性**：治療根本原因
  - 缺氧：持續正壓呼吸治療睡眠呼吸中止症、腫瘤手術切除、戒菸諮詢、避免職業暴露、雄性素治療使用最低劑量
  - 有症狀且血球容積比>55%：考慮放血
  - 發紺性心臟病患者的血球容積比，心臟科醫師通常會保守處理

## 血小板減少症

### 定義

+ 血小板計數<150 × 10⁹/公升

### 臨床表現

+ **病史**：黏膜皮膚出血（容易瘀青、齒齦出血）、鼻出血、術後出血（包括牙科處置）、月經過多、圍產期出血、腸胃道出血
+ **理學檢查**：瘀傷、紫斑、瘀斑、非可觸及性紫斑、濕潤性紫斑

### 診斷檢查

+ **全血球計數附分類**
+ **血液抹片**
  - 排除假性血小板減少（血小板凝集或衛星現象）
  - 生成減少：其他血球系異常、原始細胞（提示骨髓性惡性腫瘤）、分葉過多嗜中性球（提示巨球性貧血）、白血病性變化（提示骨髓浸潤或纖維化）
  - 破壞增加：大型血小板（常見於免疫性血小板減少紫斑症）、裂紅血球（見於微血管病性溶血性貧血/血栓性微血管病變）
+ **營養缺乏檢查**：維生素B12、紅血球葉酸
+ **懷疑瀰散性血管內凝血**：凝血酶原時間/國際標準化比值、活化部分凝血活酶時間、纖維蛋白原
+ **肝臟疾病**：肝功能檢查

**經驗法則**：
- 所有血球系減少→生成減少、隔離或血液稀釋
- 血小板和紅血球減少→非免疫性破壞或Evans症候群
- 單獨血小板減少→免疫媒介過程
- 住院患者：藥物與感染是最常見原因

### 治療

+ **危及生命的出血**：血小板輸注（輸注後1小時重複全血球計數確認計數上升）
+ **繼發性**：治療根本原因
+ 免疫性血小板減少紫斑症：見免疫性血小板減少紫斑症章節
+ 肝素誘發血小板減少症：見相關章節

## 血小板增多症

### 定義

+ 血小板計數>450 × 10⁹/公升

### 病因分類

+ **原發性血小板增多（罕見）**：骨髓增生性腫瘤引起（如慢性骨髓性白血病、真性紅血球增多症、原發性骨髓纖維化、原發性血小板增多症；少見於骨髓增生異常症候群）
+ **反應性/次發性血小板增多（常見）**：急性期反應（手術、發炎、感染、外傷、出血、缺鐵、腫瘤、缺血性損傷、脾臟切除術後/無脾）

### 臨床表現

+ **病史**：外傷、手術、脾切除、感染、發炎、出血、缺鐵、慢性血液疾病病史、癌症消耗症狀
+ **血管運動症狀**：頭痛、視覺障礙、頭暈、非典型胸痛、肢端感覺異常、紅斑性肢痛、網狀青斑、用水後搔癢
+ 血栓風險、出血風險（罕見）
+ **理學檢查**：骨髓增生性腫瘤患者常見脾腫大

### 診斷檢查

+ 全血球計數附分類、周邊血液抹片、血清鐵蛋白
+ 發炎或感染的非特異標記（C反應蛋白、紅血球沉降率、鐵蛋白）
+ 排除反應性過程後，可能需要骨髓切片排除骨髓增生性腫瘤/骨髓增生異常症候群

### 治療

+ **原發性**：阿斯匹靈加細胞減少藥物（氫氧基尿素、anagrelide、干擾素-α）
+ **次發性**：治療根本原因

## 全血球減少症

### 定義

+ 所有造血細胞系低於正常參考範圍

### 臨床表現

+ **貧血**：疲倦（見貧血章節）
+ **白血球減少**：復發性感染（見嗜中性球減少章節）
+ **血小板減少**：黏膜皮膚出血（見血小板減少章節）

### 診斷檢查

+ 全血球計數附分類、周邊血液抹片、血清鐵蛋白、網狀紅血球計數、凝血酶原時間、活化部分凝血活酶時間、血型及篩檢、完全代謝面板、維生素B12、葉酸
+ 發炎或感染的非特異標記
+ 視臨床症狀與理學檢查進行檢查
+ 排除次發性過程後，可能需要骨髓切片

## 嗜中性球增多症

### 定義

+ 變異定義，一般嗜中性球絕對計數>7.7 × 10⁹/公升

### 病因分類

| 類型 | 病因 |
|:-----|:-----|
| **原發性** | 慢性骨髓性白血病、慢性嗜中性球白血病、其他骨髓增生性腫瘤（真性紅血球增多症、原發性血小板增多症、骨髓纖維化）、遺傳性嗜中性球增多（自體顯性）、慢性特發性嗜中性球增多、白血球黏附缺乏 |
| **繼發性** | 壓力/運動/腎上腺素：嗜中性球從邊緣池移至循環池；肥胖；感染；發炎（類風濕性關節炎、發炎性腸道疾病、慢性肝炎、心肌梗塞、肺栓塞、燒傷）；惡性腫瘤（骨髓侵犯或實體腫瘤，尤其大細胞肺癌）；藥物（糖皮質素、β-受體促效劑、鋰、顆粒球聚落刺激因子） |

### 臨床表現

+ 評估發燒、發炎、惡性腫瘤症狀以決定進一步檢查（包括白血病細胞黏附缺乏與器官腫大）
+ 檢查口腔、牙齒、肛門周圍、生殖器、皮膚是否有感染跡象

### 診斷檢查

+ 全血球計數附分類：成熟嗜中性球或桿狀核>20%提示感染/發炎
+ 血液抹片：左偏嗜中性球、Doehle體（聚集核糖體組成的胞質內結構）、毒性顆粒、細胞質空泡（感染時）
+ 疑似骨髓增生性腫瘤時可能需要骨髓切片

### 治療

+ 針對根本原因治療

## 嗜中性球減少症

### 定義

| 程度 | 嗜中性球絕對計數 |
|:-----|:----|
| 輕度 | 1.0-1.5 × 10⁹/公升 |
| 中度 | 0.5-1.0 × 10⁹/公升（感染風險開始增加）|
| 重度 | <0.5 × 10⁹/公升 |
| 極重度 | <0.1 × 10⁹/公升超過>7天 |

**嗜中性球絕對計數計算**：嗜中性球絕對計數 = 白血球計數 × (嗜中性球% + 桿狀核%)

**注意**：發燒合併嗜中性球絕對計數<0.5 × 10⁹/公升 = **發燒性嗜中性球減少**，需要緊急處理

### 病因分類

| 生成減少 | 破壞/隔離增加 | 過度邊緣化（短暫性）|
|:---------|:-------------|:-------------------|
| **感染**：病毒性肝炎、EB病毒、愛滋病毒、結核、傷寒、瘧疾 | **自體免疫疾病**：類風濕性關節炎（Felty症候群）、全身性紅斑狼瘡、多血管炎肉芽腫症 | **藥物**：Haptens（如α-甲基多巴）|
| **血液疾病**：特發性、再生不良性貧血、骨髓纖維化、骨髓浸潤、週期性、陣發性睡眠性血紅蛋白尿症、骨髓增生異常症候群、大顆粒淋巴細胞白血病、毛細胞白血病、免疫媒介 | **脾臟或肺臟滯留** | **血液透析** |
| **藥物引起**：烷化劑、抗代謝藥物、抗驚厥藥、抗精神病藥物、抗發炎藥物、抗甲狀腺藥物 | **特發性（最常見）** | |
| **毒素/化學物質**：高劑量輻射、苯、滴滴涕 | **過度使用性細菌感染** | |
| **營養缺乏**：維生素B12、葉酸 | | |
| **特發性**：體質性嗜中性球減少、良性週期性嗜中性球減少 | | |

### 治療

+ 針對根本原因治療
+ 重度/極重度嗜中性球減少：見嗜中性球減少性發燒章節（感染科）

## 小球性貧血

+ 平均紅血球容積<80飛公升
+ 常見原因：**缺鐵**、慢性病貧血、海洋性貧血、鐵粒幼紅血球性貧血、鉛中毒

### 缺鐵性貧血

**病因**：
- 慢性失血（月經、腸胃道出血、泌尿道失血）
- 攝取不足（營養不良、素食主義者）
- 吸收不良（乳糜瀉、發炎性腸道疾病、胃繞道手術）
- 需求量增加（懷孕、兒童生長發育期）

**臨床表現**：
- 貧血一般症狀
- Plummer-Vinson症候群（舌炎、口腔黏膜萎縮、匙狀甲）
- 反甲

**診斷檢查**：
+ **血清鐵蛋白**：診斷缺鐵最敏感的單一指標
  - 低鐵蛋白（<30-45微克/公升）確診缺鐵
  - 注意：鐵蛋白是急性期發炎蛋白，發炎/感染/惡性腫瘤時可能正常或升高
+ **血清鐵**、**總鐵結合能**、**轉鐵蛋白飽和度**
  - 缺鐵：血清鐵降低、總鐵結合能升高、轉鐵蛋白飽和度降低
+ **網狀紅血球**：生成減少時降低
+ **糞便潛血反應**：排除腸胃道出血
+ **排除其他原因的小球性貧血**

**治療**：
+ **口服鐵劑**：
  - 硫酸亞鐵325毫克每日一次（65毫克元素鐵）、葡萄糖酸亞鐵300毫克每日一次（35毫克元素鐵）、富馬酸亞鐵300毫克每日一次（100毫克元素鐵）、多醣鐵複合物150毫克、血紅素鐵多肽11毫克
  - 補充至貧血恢復，然後繼續治療3個月以上直至血清鐵蛋白恢復正常
  - 最近研究顯示隔日 vs.每日給藥差異不顯著，選擇應以病人偏好為主
  - 口服鐵劑一日多次無益處：會導致肝臟調節素上調、吸收減少、副作用增加而無臨床效益
+ **靜脈鐵劑**：用於無法耐受或吸收口服鐵、需快速康復者
+ **監測療效**：
  - 網狀紅血球計數一週後開始增加
  - 血紅蛋白每週增加10克/公升（若無失血）

### 慢性病貧血

**又稱**：發炎性貧血

**病因**：
- 感染、惡性腫瘤、發炎性、風濕性疾病
- 慢性腎病與肝病
- 內分泌疾病（糖尿病、甲狀腺功能減退、性腺功能減退、腦下垂體功能減退）

**病理生理學**：
- 肝臟調節素是關鍵調節肽，在發炎過程中增加產生
- 肝臟調節素透過抑制ferroportin將鐵困在腸細胞與巨噬細胞中
- 血漿鐵相對不足，無法供新的血紅蛋白合成使用
- 骨髓對正常或輕度升高的紅血球生成素無反應
- 常伴有輕度溶血成分（紅血球存活輕度減少）

**診斷檢查**：
+ 排除性診斷
+ 急性期發炎標記升高（紅血球沉降率、C反應蛋白、纖維蛋白原、血小板）
+ **周邊血液**：
  - 輕度：通常正球性和正染色
  - 中度：可能小球性和正染色
  - 重度：可能小球性和低色素
  - 絕對網狀紅血球計數通常偏低，反映紅血球生成整體減少
+ **經典型血清鐵指數**
+ **骨髓**：
  - 鐵儲存正常或增加
  - 紅血球前驅細胞的鐵染色減少或缺如

**治療**：
+ 治療根本疾病；僅在血紅蛋白較高對患者有益時治療
+ 若口服鐵無效，使用靜脈鐵（在慢性腎病伴紅血球生成素使用時）
+ 紅血球生成素適用於慢性腎衰竭；確保血紅蛋白目標<110克/公升

### 鐵粒幼紅血球性貧血

**定義**：
- 因紅血球前驅細胞中血紅素生合成缺陷導致
- 骨髓中鐵以異常大的顆粒圍繞細胞核（環狀鐵粒幼紅血球）

**病因**：
- **遺傳性（罕見）**：X-染色體連鎖；中位存活10年
- **特發性（後天）**：
  - 環狀鐵粒幼紅血球難治性貧血（骨髓增生異常症候群的亞型）
  - 可能為白血病前期現象（1-2%轉化為急性骨髓性白血病）
- **可逆性**：Isoniazid、氯黴素、酒精、鉛、銅缺乏、鋅中毒、甲狀腺功能減退

**臨床表現**：
- 貧血症狀
- 肝脾腫大

**診斷檢查**：
+ 血清鐵指數
+ 全血球計數和血液抹片
  - 環狀鐵粒幼紅血球（診斷特異性標誌）
  - 紅血球低色素；可為小球性、正球性或大球性
  - 紅血球大小不等、異形紅血球、嗜鹼性點彩
+ 骨髓切片

**治療**：
+ 依病因治療
  - X-染色體連鎖：部分病例高劑量維生素B6
  - 後天型：紅血球生成素和顆粒球聚落刺激因子
  - 可逆性：去除誘發因素
+ 嚴重貧血時支持性輸血
+ 監測鐵過載（無效紅血球生成和/或輸血驅動）

---

### 鉛中毒

**定義/病因**：
+ 血鉛水平>80微克/公升，症狀可能在50微克/公升出現
+ 確認來源：職業史、暴露史、器具史

**臨床表現**：
+ 蒼白、腹痛、便祕、易怒、專注力困難

**治療**：
+ 螯合治療：Dimercaprol和EDTA一線用藥

**鉛中毒特徵**：
- **L**：X光可見牙齦和長骨骨骺的鉛線
- **E**：腦病變和紅血球嗜鹼性點彩
- **A**：腹部絞痛和小球性貧血（鐵粒幼紅血球性）
- **D**：垂腕和足垂（腕和足下垂）

## 正球性貧血

+ 平均紅血球容積80-100飛公升

### 再生不良性貧血

**定義**：
+ 骨髓造血細胞破壞導致全血球減少和低細胞性骨髓

**病因**：

| 先天性 | 後天性 |
|:-------|:-------|
| Fanconi症候群 | 特發性（通常為T細胞媒介）|
| Shwachman-Diamond症候群 | 離子輻射 |
| 端粒疾病（先天性角化不全）| 病毒感染（人類微小病毒B19、EB病毒、HDV、HEV、HBV、HHV-6、HIV）|
| | 藥物（劑量相關化療；特異性反應如氯黴素、抗瘧藥、保泰松）|
| | 毒素（苯/有機溶劑、滴滴涕、殺蟲劑）|
| | 自體免疫（全身性紅斑狼瘡、移植對宿主病）|
| | 懷孕、神經性厭食、胸腺瘤 |

**臨床表現**：
+ 可急性或隱匿發病
+ 貧血、血小板減少、嗜中性球減少症狀（見各章節）
+ 依病因可能出現脾腫大和淋巴結病變

**診斷檢查**：
+ 排除其他全血球減少原因，包括陣發性睡眠性血紅蛋白尿症（50%再生不良性貧血患者有陣發性睡眠性血紅蛋白尿症）
+ **全血球計數**：
  - 貧血、嗜中性球減少或血小板減少（任何組合包括全血球減少）
  - 網狀紅血球減少（<總紅血球的1%）
+ **血液抹片**：正常紅血球數量減少
+ **骨髓吸引和切片**：
  - 低細胞性骨髓（<25%）細胞減少或發育不全，脂肪組織替代
  - 無惡性細胞浸潤或纖維化證據

**治療**：
+ 去除致病因
+ 支持性照護（紅血球和血小板輸血、抗生素）
  - 審慎使用血液製品以減少免疫敏感化風險
  - 若多次輸血>20單位，進行鐵螯合治療
+ 免疫抑制治療（特發性再生不良性貧血）
  - 馬或兔抗胸腺細胞球蛋白：40-50%患者有反應
  - 環孢靈素（改善反應與存活）
+ 自體骨髓移植
+ Eltrombopag（血栓激素受體激動劑）證實有效；顆粒球聚落刺激因子和紅血球生成素無效

## 溶血性貧血

### 定義

+ 因紅血球破壞導致壽命縮短（通常<100天）的貧血
+ 罕見病因（<5%）但病因眾多（>200種）

### 分類

| 類型 | 病因 |
|:-----|:-----|
| **遺傳性** | 膜異常（球形紅血球症、橢圓形紅血球症）；酶異常（丙酮酸激酶缺乏、葡萄糖-6-磷酸脫氫酶缺乏）；血紅蛋白異常（血紅蛋白病）|
| **後天性-免疫性** | 自體免疫：溫反應型vs.冷反應型自體免疫性溶血性貧血；同種免疫：胎兒/新生兒溶血病、輸血後溶血 |
| **後天性-非免疫性** | 血栓性微血管病變（微血管病性溶血性貧血）：瀰散性血管內凝血、溶血性尿毒症候群、非典型溶血性尿毒症候群、血栓性血小板減少紫斑症、子癲前症/HELLP、血管炎、惡性高血壓；其他：陣發性睡眠性血紅蛋白尿症、脾臟滯留、行軍性血紅蛋白尿（運動性溶血）、感染（如瘧疾）、蛇毒、機械心臟瓣膜 |

### 血管內vs.血管外溶血

- **血管內**：血栓性微血管病變和陣發性睡眠性血紅蛋白尿症（補體媒介）
- **血管外**：被抗體覆蓋或膜結構/形狀異常或有包涵體的紅血球被網狀內皮系統清除
- 感染可引起血管內（梭狀芽孢桿菌）、血管外或兩者（瘧疾）

**血液抹片特徵**：裂紅血球反映血管內溶血；球形紅血球通常反映血管外溶血

### 臨床表現

+ 黃疸
+ 深色尿（血紅蛋白尿、膽紅素尿）
+ 膽結石（色素結石）
+ 再生不良危象風險（嚴重感染時骨髓抑制）
+ 血管外溶血：鐵過載
+ 血管內溶血：缺鐵

### 診斷檢查

| 篩檢檢驗 | 血管內溶血的特異檢驗 |
|:---------|:-------------------|
| 乳酸脫氫酶升高 | 血液抹片上的裂紅血球（微血管病性溶血性貧血）|
| 結合球蛋白減少 | 血清游離血紅蛋白 |
| 未結合膽紅素升高 | 血紅蛋白尿（立即）|
| 尿膽素原升高 | 血鐵質尿（延遲）- 最敏感 |
| 網狀紅血球增多 | |

**血管外溶血的特異檢驗**：
- **直接抗球蛋白試驗（Coombs試驗）**：檢測紅血球表面的免疫球蛋白G或補體
  - 適應症：新生兒溶血病、自體免疫性溶血性貧血、溶血性輸血反應
- **間接抗球蛋白試驗**：檢測血清中能識別紅血球抗原的抗體
  - 適應症：捐血者交叉配血、非典型血型、孕婦血型抗體、自體免疫性溶血性貧血

## 海洋性貧血

### 定義

+ α或β鏈血紅蛋白生產缺陷
+ 球蛋白鏈不平衡導致無效紅血球生成和溶血
- 臨床表徵和治療取決於受影響的特定基因和等位基因數目

**共同特徵**：
- 受影響等位基因越多，嚴重程度越重
- 低色素小球性貧血
- 血液抹片：嗜鹼性點彩、形狀異常紅血球
- 全血球計數：低平均紅血球容積、低血紅蛋白、紅血球計數升高、網狀紅血球計數升高

**病理生理學**：
- 正常：4個α基因（染色體16各2個）；2個β基因（染色體11各1個）
- 胎兒血紅蛋白（α₂γ₂）在3-6個月大時轉換為成人血紅蛋白A（α₂β₂）和血紅蛋白A₂（α₂δ₂）
- 血紅蛋白A占成人血紅蛋白的97%；血紅蛋白A₂占3%

**地理分布**：
- β-海洋性貧血：地中海（南亞也常見）
- α-海洋性貧血：東南亞和非洲

### β-海洋性型輕型

**定義**：
+ 單一β基因等位基因缺陷（異型合子）

**臨床表現**：
+ 通常無症狀；很少出現可觸及的脾臟

**診斷檢查**：
+ 血紅蛋白（100-140克/公升）、平均紅血球容積（<70飛公升）、鐵（正常）、紅血球計數（正常/升高）
+ 周邊血液抹片：小球性、嗜鹼性點彩
+ 血紅蛋白電泳：
  - 特異：血紅蛋白A₂升高至3.5-5%（正常1.5-3.5%）
  - 非特異：50%胎兒血紅蛋白輕度升高

**治療**：
+ 不需治療
+ 為患者和家屬提供遺傳諮詢

---

### β-海洋性型重型

**定義**：
+ 兩個β基因等位基因均缺陷（同型合子，自體隱性）

**病理生理學**：
+ 無效α鏈合成導致紅血球生成減少、紅血球溶血、胎兒血紅蛋白增加

**臨床表現**：
+ 在6-12個月大時初次表現（正常此時胎兒血紅蛋白應被血紅蛋白A取代）
  - 嚴重貧血、黃疸
+ 補償性胃腸道鐵吸收導致鐵過載（進展為血鐵質沉積症）
  - 來自重複輸血和無效紅血球生成
  - 導致器官鐵誘導損傷
+ 生長發育遲緩（性腺功能減退導致）
+ 嚴重肝脾腫大（髓外造血）
+ 放射學變化（骨髓腔擴張）和髓外造血團塊
+ 顱骨X光顯示「毛髮直立」外觀
+ 病理性骨折常見
+ 膽紅素增加代謝增加的證據（如膽結石）
+ 死亡原因：
  - 未治療的貧血（應輸血）
  - 感染（應早期識別和治療）
  - 鐵過載（常見，晚發併發症）

**診斷檢查**：
+ 全血球計數和鐵研究
+ 嚴重小球性貧血（血紅蛋白<60克/公升）
+ 周邊血液抹片：淚滴狀細胞、靶細胞、低色素、小球性紅血球
+ 血紅蛋白電泳：
  - 血紅蛋白A：0-10%（正常>95%）
  - 血紅蛋白A₂：2-5%
  - 胎兒血紅蛋白：90-100%

**治療**：
+ 終身定期紅血球輸血以抑制內源性紅血球生成
+ 鐵螯合（如deferoxamine、deferasirox、deferiprone）預防器官鐵過載和自由基形成
+ 若未輸血：補充葉酸
+ 自體骨髓移植（潛在可治癒）或臍帶血移植
+ 基因治療或CRISPR-Cas9基因編輯（增加胎兒血紅蛋白生成）
+ 脾切除（現在較少執行）

---

### α-海洋性型貧血

**定義**：
+ α基因缺陷
+ 地理分布類似β-海洋性貧血，但東南亞人和非洲人頻率更高

**α-海洋性貧血的臨床分類**

| 缺陷基因數 | 基因型 | 臨床表徵 |
|:----------|:-------|:---------|
| 1 | αα/α- | 臨床上無症狀；正常血紅蛋白、正常平均紅血球容積 |
| 2 | αα/--或α-/α- | 正常血紅蛋白、平均紅血球容積降低 |
| 3 | α-/-- | 血紅蛋白H（β4）疾病；成人發病，血紅蛋白降低、平均紅血球容積降低、脾腫大 |
| 4 | --/-- | 血紅蛋白Bart's（γ4）疾病（胎兒水腫）；通常與生命不相容 |

**診斷檢查**：
+ 全血球計數和鐵研究
+ 周邊血液抹片：使用supravital染色篩檢血紅蛋白H包涵體
+ 血紅蛋白電泳可用於識別血紅蛋白H疾病，但可能漏掉1-或2-基因缺失；確診需DNA基因分型

**治療**：
+ 轉介遺傳/產前諮詢
+ 取決於貧血程度
  - 1或2個缺陷基因：不需治療
  - 血紅蛋白H疾病：類似β-海洋性中型
  - 血紅蛋白Bart's：無確切治療；多數妊娠終止
  - 宮內輸血、造血幹細胞移植

---

## 鐮刀型紅血球疾病

### 定義

+ 自體隱性鐮刀化疾病，最常見原因是β-球蛋白鏈第6位的麩胺酸→纈胺酸取代
  - 導致血紅蛋白S變異而非正常成人血紅蛋白A
+ 血紅蛋白S等位基因在撒哈拉以南非洲、印度、中東或地中海遺產患者中發生率較高
+ 鐮刀型紅血球疾病發生於個體有兩個血紅蛋白S基因（同型合子，血紅蛋白SS）或一個血紅蛋白S基因加另一個突變β-球蛋白基因（複合異型合子）- 最常見血紅蛋白S-β-海洋性和血紅蛋白SC疾病

### 病理生理學

+ 在低氧分壓時，去氧血紅蛋白S聚合導致剛性水晶樣桿狀結構扭曲細胞膜成為「鐮刀」
+ 鐮刀化程度與存在的血紅蛋白S百分比相關
+ 鐮刀化因酸血症、二氧化碳增加、2,3-二磷酸甘油酸增加、發燒、滲透壓增加而加重
+ 脆弱的鐮刀型細胞以兩種主要方式造成損傷：
  1. 脆弱的鐮刀型細胞溶血（一氧化氮耗竭）
  2. 小血管阻塞（缺氧、缺血再灌流損傷）

### 臨床表現

**鐮刀型紅血球特質（血紅蛋白AS）**：
+ 無症狀（除非極端缺氧或感染）
+ 腎髓質癌風險增加

**血紅蛋白SS（鐮刀型紅血球疾病）**：
+ 慢性溶血性貧血
+ 第一年出現黃疸
+ 生長發育遲緩加骨骼變化
+ 童年時脾腫大；成年後脾萎縮
+ 常表現為急性疼痛發作

**鐮刀型紅血球疾病的急性發作類型**

| 類型 | 特徵 |
|:-----|:-----|
| 再生不良危象 | 毒素和感染（尤其人類微小病毒B19）暫時抑制骨髓 |
| 脾臟滯留危象 | 通常在兒童；血液在脾臟大量滯留導致急性血紅蛋白下降和休克；成人少見 |
| 血管阻塞危象 | 影響各器官造成缺血再灌流損傷（背、胸、腹、四肢）、發燒、白血球增多；可導致中風或無症狀心肌梗塞；感染、脫水、溫度快速變化、懷孕、月經、酒精為誘發因素 |
| 急性胸腔症候群 | 急性發燒和/或呼吸道症狀；胸部X光新發現肺部浸潤；由肺部感染、脂肪栓塞、肺梗塞誘發 |

**血紅蛋白SC（鐮刀型紅血球疾病-血紅蛋白SC）**：
+ 比血紅蛋白SS貧血更輕
+ 併發症類似血紅蛋白SS但通常更輕、更少（例外：增生性鐮刀型視網膜病變、腎小球腎炎、骨頭缺血性壞死）

### 診斷檢查

+ **鐮刀型紅血球製備**：檢測紅血球在降低氧劑下的鐮刀化；確定血紅蛋白S等位基因存在，但無法區分血紅蛋白AS與血紅蛋白SS
+ **全血球計數**：血紅蛋白、血球容積比、紅血球計數、網狀紅血球
+ **周邊血液抹片**：鐮刀型細胞、靶細胞、多染色性
+ **血紅蛋白電泳**：
  - 血紅蛋白S：確診
  - 可區分血紅蛋白SS、血紅蛋白AS、血紅蛋白SC

### 治療

+ **急性疼痛處理**：輸液、疼痛控制、氧氣（若缺氧）
+ **氫氧基尿素**：增加胎兒血紅蛋白產生；減少疼痛危象和急性胸腔症候群
+ **Voxelotor**：抑制血紅蛋白S聚合
+ **Crizanlizumab**：抗P-選擇素抗體；減少疼痛危象頻率
+ **輸血**：考慮用於中風預防、急性胸腔症候群、脾臟滯留、手术前
+ **所有鐮刀型紅血球疾病患者應補充葉酸**
+ 避免觸發因素：脫水、極端溫度、感染、高海拔
+ **骨髓移植**：可治癒（年輕患者、有完全匹配的捐贈者）

## 大球性貧血

+ 平均紅血球容積>100飛公升

### 維生素B12缺乏

**病因**：

| 攝取不足 | 吸收不良 | 其他 |
|:---------|:---------|:-----|
| 素食主義者（無動物製品攝取）| 惡性貧血（最常見）、胃繞道手術、空腸迴腸切除、克隆氏症 | 寄生蟲感染（魚絛蟲）|
| 老年人（攝取不足）| 胰臟功能不足 | |
| 酒精使用障礙 | 細菌過度生長 | |
| | 轉鈷胺素缺乏（罕見）| |

**臨床表現**：
+ **血液學**：疲倦、虛弱、蒼白、黃疸（無效造血導致）
+ **神經學**（僅B12缺乏）：
  - 亞急性合併變性（脊髓後索和側索受損）
  - 對稱性周邊神經病變（感覺異常、本體感覺減退）
  - 認知：意識混亂、譫妄、癡呆
  - 精神：憂鬱、精神病
+ **胃腸道**：舌炎（牛肉色舌頭）、厭食、體重減輕

**診斷檢查**：
+ **全血球計數**：
  - 通常嚴重貧血（血紅蛋白30-70克/公升）、嗜中性球減少、血小板減少
  - 平均紅血球容積>110飛公升
  - 網狀紅血球計數偏低（<2%）
+ **血清B12和紅血球葉酸**
  - 注意：低血清B12導致紅血球葉酸降低
  - 或：兩者皆升高（甲基丙二酸和同型半胱胺酸是尿液代謝物）
+ **血液抹片**：橢圓形巨血球、分葉過多嗜中性球
+ **骨髓**：增生過多（多種骨髓細胞系異常增殖和成熟）、紅血球前驅細胞核質發育不同步

**確診檢查**：
+ 抗胃壁細胞抗體（更敏感）
+ 抗內在因子抗體（更特異）
+ 胃泌素水平（升高）
+ 上消化道內視鏡（切片：萎縮性胃炎；也篩檢胃癌）

**治療**：
+ 治療劑量：B12 1000-1200微克口服每日一次（若腸道吸收完整）或1000微克肌肉注射每週一次；時間和途徑取決於病因
+ 維持劑量（補足後）：B12 1000微克口服每日一次或1000微克肌肉注射每月一次
+ 治療嚴重巨球性貧血時注意低血鉀和反彈性血小板增多

**病因**：

| 飲食攝取不足 | 吸收不良 | 藥物 | 需求增加 |

| | | | |

**臨床表現**：

## 凝血概論

### 止血階段

**1. 原發性止血**

+ 由血小板和血管性血友病因子媒介
+ 目標是快速止血的；主要影響黏膜傷口出血
+ 血管損傷導致膠原蛋白/內皮下基質暴露和血管收縮劑釋放
+ 血小板與受損血管壁接觸
  - **黏附**：血小板透過血管性血友病因子黏附於內皮下層
  - **活化**：血小板活化，形態改變，顆粒釋放
  - **聚集**：活化的糖蛋白IIb/IIIa與可溶性配體結合，形成血小板栓塞

**2. 續發性止血**

+ 血小板栓塞由纖維蛋白凝塊強化
+ **外在（啟動）途徑**：啟動
+ **內在（放大）途徑**：啟動後透過正回饋放大
+ 兩條途徑會聚於共同途徑，導致凝血酶生成和纖維蛋白形成

**3. 纖維蛋白穩定**

+ 從可溶性轉變為不可溶性、交聯的凝塊

**4. 纖維蛋白溶解**

+ 傷口癒合後，凝塊溶解由纖維蛋白溶解系統媒介

### 常用凝血檢驗

| 檢驗 | 參考範圍 | 用途 | 相關疾病 |
|:-----|:---------|:-----|:---------|
| **凝血酶原時間/國際標準化比值** | 28-38秒（凝血酶原時間）；0.9-1.2（國際標準化比值）| 測量外在途徑（第七因子）和共同途徑 | 凝血酶原時間延長：血友病A/B；紅斑性狼瘡抗凝血劑；維生素K缺乏；Warfarin治療；第七因子缺乏 |
| **活化部分凝血活酶時間** | 0-85秒 | 測量內在途徑（第八、九、十一、十二因子）和共同途徑 | 活化部分凝血活酶時間延長：血友病A/B（第八或第九因子缺乏）；血管性血友病；肝素治療；紅斑性狼瘡抗凝血劑 |
| **纖維蛋白原** | 1.5-4.0克/公升 | 共同途徑 | 降低：瀰散性血管內凝血；嚴重肝病 |
| **D-雙聚合體** | <0.5微克/毫升 | 纖溶增加 | 升高：瀰散性血管內凝血、靜脈血栓栓塞、創傷、心肌梗塞、惡性腫瘤 |

### 凝血因子

**參與凝血酶原時間的因子**：第三（組織因子）、第七
**參與活化部分凝血活酶時間的因子**：第十二、十一、九、八、十、五、二（凝血酶原）、一（纖維蛋白原）
**共同途徑**：十、五、二、一

### 出血性疾病的臨床表現

| 特徵 | 原發性（血小板、血管性血友病因子）| 續發性（凝血因子）|
|:-----|:--------------------|:-----------------|
| 表面傷口 | 過度、持續出血 | 正常/輕度延長 |
| 受傷後發作 | 立即 | 延遲 |
| 出血部位 | 淺層如黏膜（鼻、牙齦、腸胃道、陰道、皮膚）| 深層如創傷 |
| 病灶 | 瘀點、瘀斑 | 關節血腫、血腫 |

## 原發性止血障礙

### 免疫性血小板減少紫斑症

**定義**：
+ 因異常免疫反應導致血小板減少的疾病

**分類**：
- **原發性**：免疫性血小板減少紫斑症（血小板計數<100 × 10⁹/公升）且無其他原因
- **次發性**：免疫性血小板減少紫斑症與其他疾病相關（愛滋病毒、C型肝炎、全身性紅斑狼瘡、慢性淋巴性白血病）
- **藥物引起**：藥物暴露導致抗血小板抗體引起的血小板破壞

### 肝素誘發血小板減少症

**定義**：
+ 肝素暴露後出現血小板減少
+ 是血栓前狀態（非出血性）

**類型**：
- **第一型（非免疫性）**：輕度血小板減少（罕見<100 × 10⁹/公升）；自限性；不需要停藥
- **第二型（免疫性）**：通常在肝素使用後5-10天發生；血小板通常降低>50%或絕對值<150 × 10⁹/公升；高度血栓風險

**診斷**：
+ **4T評分**：
  - 血小板減少程度
  - 時機（肝素使用至血小板減少發生的時間）
  - 血栓併發症
  - 其他原因
+ **抗血小板第四因子/肝素抗體檢測**
+ **血清素釋放試驗**（金標準）

**治療**：
+ 立即停用所有肝素（包括肝素沖洗）
+ 替代為非肝素抗凝劑（Argatroban、Bivalirudin、Dabigatran、Rivaroxaban、Apixaban）
+ **禁止warfarin**（在血小板<50 × 10⁹/公升時會導致warfarin誘導的皮膚壞死）
+ 若血栓存在：考慮直接口服抗凝劑或直接凝血酶抑制劑
+ 若有血栓或極高風險：考慮fondaparinux或直接口服抗凝劑
+ 避免血小板輸血（可能加劇血栓）

## 續發性止血障礙

### 血友病A和B

**定義**：
+ X-染色體隱性遺傳的凝血因子缺乏
- 血友病A：第八因子缺乏
- 血友病B：第九因子缺乏

**臨床表現**：
+ 輕度創傷或自發性出血
+ 好發部位：關節（關節血腫）、肌肉（髂腰肌）、顱內、口腔、泌尿生殖道
+ 關節出血：急性疼痛、腫脹、活動受限；反覆出血導致血友病關節病變
+ 深度組織出血和血腫

**診斷檢查**：
+ **活化部分凝血活酶時間延長**；凝血酶原時間正常
+ **第八或第九因子活性檢測**：
  - 正常：50-150%
  - 輕度：5-40%
  - 中度：1-5%
  - 重度：<1%

**治療**：
+ **輕度血友病A**：Desmopressin
+ **中重度血友病A/B**：第八或第九因子濃縮製劑
+ **預防性治療**：用於重度患者預防關節出血和關節病變
+ **急性出血處理**：早期因子替代、休息、固定、冰敷、壓迫、抬高
+ **併發症管理**：關節出血後康復；抑制物形成時免疫耐受誘導

---

### 瀰散性血管內凝血

**定義**：
+ 全身性凝血和纖溶系統活化，導致廣泛微血管血栓和消耗性凝血病

**病因**：
- **產科併發症**：胎盤早剝、羊水栓塞、死胎、子癲前期
- **惡性腫瘤**：胰臟癌、肺癌、前列腺癌、急性白血病
- **感染**：革蘭氏陰性菌敗血症、敗血症
- **創傷**：嚴重創傷、脂肪栓塞
- **休克**：敗血症休克、心源性休克

**臨床表現**：
+ **出血**：多部位（靜脈穿刺部位、黏膜、傷口）；可能大量
+ **血栓**：微血管血栓導致器官功能障礙（腎衰竭、肺功能不全、中樞神經系統障礙）
+ **休克**：消耗性凝血病導致循環衰竭

**診斷檢查**：
+ **凝血酶原時間和活化部分凝血活酶時間延長**
+ **纖維蛋白原降低**（因為消耗）
+ **D-雙聚合體升高**（纖溶增加）
+ **血小板減少**
+ **血塗片**：裂紅血球（微血管病性溶血）
+ **ISTH瀰散性血管內凝血計算機**：評估是否存在潛在誘因、凝血檢驗異常

**治療**：
+ **治療根本原因**（最關鍵）
+ **支持性輸血**：血小板輸血（若血小板<20 × 10⁹/公升或有出血）、冷沉澱（若纖維蛋白原<1.0-1.5克/公升）、新鮮冷凍血漿（補充凝血因子）
+ **肝素**：僅用於血栓為主且無顯著出血時
+ **血栓溶解**：一般不建議

## 血栓形成傾向

### 血栓形成傾向的檢查

**何時考慮檢查**：
- 多次復發性血栓
- Warfarin誘導的皮膚壞死或新生兒暴發性紫癜（蛋白質C或S缺乏）
- 不常見靜脈部位血栓（腦、頸、內臟、門靜脈、上肢靜脈）
- 異常血液檢查、癌症消耗症狀或理學檢查發現提示惡性腫瘤

**檢查項目（如有適應症）**：
- **初始**：全血球計數、血液抹片、凝血檢查、紅斑性狼瘡抗凝血劑、肝/腎功能、尿液分析、溶血標記（貧血時）、惡性腫瘤史、年齡相關癌症篩檢、抗磷脂抗體血清學
- **治療後（或≥6週）**：抗凝血酶活性、蛋白質C、S活性

### 遺傳性血栓形成傾向

**第五因子Leiden（活化蛋白C抗性）**：
+ 最常見的遺傳性血栓形成傾向
+ 白種人3-7%為異型合子
+ 第五因子基因點突變導致第五因子對活化蛋白C的去活化產生抗性

**凝血酶原基因突變**：
+ 白種人1-3%為異型合子
+ 凝血酶原基因啟動子區域核苷酸20210處G→A轉位導致凝血酶原水平升高，進而增加凝血酶生成

**蛋白質C和蛋白質S缺乏**：
+ 蛋白質C使用蛋白質S作為輔因子去活化第五因子和第八因子
+ 蛋白質C缺乏：同型合子或複合異型合子導致新生兒暴發性紫癜；異型合子導致靜脈血栓
+ 蛋白質S缺乏：增加靜脈血栓風險

**抗凝血酶缺乏**：
+ 抗凝血酶緩慢去活化凝血酶，肝素可加速此過程
+ 自體顯性遺傳；腎病症候群尿液丟失；肝病合成減少
+ 可能對普通肝素產生抗性（低分子量肝素可能有效，需監測抗第十因子）

### 抗磷脂抗體症候群

**診斷標準**：
- **臨床**：動靜脈血栓、不明原因復發性早期流產、晚期胎兒死亡、因子癲前期或胎盤功能不全導致34週前早產
- **實驗室（需確認，間隔>12週）**：抗心磷脂抗體、抗β2醣蛋白-I抗體、紅斑性狼瘡抗凝血劑

## 靜脈血栓栓塞症

### 定義

+ 淺層或深層靜脈中血栓形成及後續發炎反應
+ 包括淺層靜脈血栓、深層靜脈血栓和肺栓塞
+ 血栓沿血流方向蔓延（通常起源於小腿靜脈）
+ 深層靜脈血栓在下肢比上肢更常見
+ 發生率：>60歲約1%
+ 深層靜脈血栓最重要後遺症：肺栓塞（約50%近端深層靜脈血栓併發）和血栓後症候群（慢性靜脈功能不全）

### 病因（Virchow's Triad）

1. **內皮損傷**：
   - 內皮功能障礙暴露促凝蛋白促進血栓形成
   - 局部纖溶抑制減少
   - 血管壁完整性改變導致血流紊亂

2. **靜脈瘀滯**：
   - 固定（如術後、心肌梗塞、心衰竭、中風）抑制凝血因子清除和稀釋

3. **高凝狀態**：
   - **遺傳性**（見血栓形成傾向）
   - **後天性**：年齡、手藝（尤其是骨科、胸腔、胃腸、泌尿生殖）、創傷（尤其是脊椎、骨盆、股骨、脛骨骨折、脊髓損傷）、惡性腫瘤（胰、胃、肺、淋巴瘤、膀胱、睪丸、結直腸、婦科）、血液疾病（骨髓增生性腫瘤）、陣發性睡眠性血紅蛋白尿症、血液黏滯度過高（多發性骨髓瘤、真性紅血球增多症、白血病、鐮刀型紅血球疾病）、溶血性貧血

### 臨床表現

**深層靜脈血栓**：
+ 小腿或大腿疼痛、腫脹、壓痛
+ 單側水腫
+ 淺層靜脈擴張

**肺栓塞**：
+ 呼吸困難（最常見）、胸痛（肋膜性、胸悶）、咳嗽、咯血
+ 心搏過速、呼吸急促、低度發燒
+ 大面積肺栓塞：呼吸困難、缺氧、低血壓（心搏過速）、右心衰竭徵象

### 診斷檢查

+ **深層靜脈血栓**：
  - **壓迫超聲波**（首選）：準確率高
  - **D-雙聚合體**：陰性可排除（但特異性低）

+ **肺栓塞**：
  - **電腦斷層肺血管造影**（首選）：確診
  - **V/Q掃描**：當電腦斷層不適用時
  - **D-雙聚合體**：排除價值高
  - **血液氣體分析**：可能低氧血症、呼吸性鹼中毒

### 治療

**急性深層靜脈血栓/肺栓塞治療（初始）**：
+ **抗凝**：
  - **低分子量肝素**（如Enoxaparin）：首選門診和住院患者
  - **Fondaparinux**：替代選擇
  - **直接口服抗凝劑**：越來越常用
  - **Warfarin**：需要重疊使用（需橋接直到國際標準化比值達標）
  - **普通肝素**：用於嚴重腎功能不全或即將手術患者
+ **療程**：
  - 暫時性誘因：3-6個月
  - 無誘因或輕度誘因：至少3-6個月，考慮延長抗凝
  - 癌症相關：低分子量肝素至少3-6個月，然後繼續低分子量肝素或直接口服抗凝劑/Warfarin
  - 復發：延長/終身抗凝

**血栓溶解治療**：
+ 僅用於大面積深層靜脈血栓/肺栓塞伴血流動力學不穩定
+ 顯著出血風險

**下腔靜脈濾器**：
+ 絕對抗凝禁忌（如活動性出血）時放置
+ 不應常規用於急性靜脈血栓栓塞症

**術後/創傷後靜脈血栓栓塞症預防**：
+ **機械性**：間歇性氣壓加壓、段階壓力襪
+ **藥理學**（術後確認止血後）：低分子量肝素、普通肝素、直接口服抗凝劑

## 骨髓增生性腫瘤

### 概述

+ 克隆性骨髓幹細胞異常導致一個或多個血球系過度增殖（紅血球、血小板、骨髓系細胞）
- 主要影響中年人和老年人
- 所有疾病可能進展為急性骨髓性白血病

**慢性骨髓增生性腫瘤的鑑別**

| 特徵 | 慢性骨髓性白血病 | 真性紅血球增多症 | 原發性骨髓纖維化 | 原發性血小板增多症 |
|:-----|:----|:-------------------|:----------------------|:--------------------------|
| 主要異常 | 白血球升高 | 紅血球升高 | 紅血球升高（貧血期）/白血球升高 | 血小板升高 |
| 白血球 | 升高 | 正常/升高 | 正常/升高 | 正常/升高 |
| 血小板 | 正常/升高 | 升高 | 減少/升高 | >450 × 10⁹/公升 |
| 骨髓纖維化 | 無/輕度 | 無 | 有 | 無 |
| 脾腫大 | 有 | 有 | 有 | 有 |
| 肝脾腫大 | 有 | 有 | 有 | 無/輕度 |
| 遺傳關聯 | BCR-ABL突變 | JAK2突變（96%）| JAK2（50%）、CALR（30%）、MPL（5-10%）| JAK2（50%）、CALR（30%）、MPL（3-5%）|

### 慢性骨髓性白血病

**定義**：
+ 粒細胞系增殖增加的骨髓增生性疾病，不喪失分化能力

**流行病學**：
+ 任何年齡（主要中年至老年）；中位年齡65歲

**病理生理學**：
+ **費城染色體**：
  - 9號和22號染色體之間的轉位是必要且充分條件
  - 產生BCR-ABL融合基因（組成性活性酪氨酸激酶）

**臨床表現**：
+ **三個臨床分期**：
  - **慢性期**：85%在此確診；外周血中原始細胞<10%；無明顯症狀
  - **加速期**：中性粒細胞分化受損；循環原始細胞（10-20%）；全身症狀和脾腫大惡化
  - **原始細胞危象**：更具侵襲性病程，原始細胞不分化；外周血或骨髓中原始細胞（>20%）；反映急性白血病
+ **20-50%患者確診時無症狀**（偶然發現）
+ **非特異症狀**：疲倦、體重減輕、不適、過度出汗、發燒
+ **脾臟浸潤**：早期飽足感、左上腹疼痛/腹脹；脾腫大
+ **貧血**
+ **血小板功能異常導致出血**
+ **搔癢、消化性潰病**（組胺增加）

**診斷檢查**：
+ **全血球計數附分類**：白血球升高、嗜鹼性球升高；白血球分類呈雙峰分布，以髓細胞和嗜中性球為主
+ **周邊血液抹片**：白血病性變化（未成熟紅血球和粒細胞）
+ **骨髓切片**：骨髓增生伴左偏、巨核細胞增加、輕度纖維化
+ **分子和細胞遺傳學研究**：費城染色體或BCR-ABL轉錄本

**治療**：
+ **預防性**：Allopurinol
+ **慢性期**：
  - **Imatinib mesylate**：抑制BCR-ABL陽性細胞的酪氨酸激酶活性並誘導凋亡
  - 若反應喪失或無法耐受：嘗試第二/三代酪氨酸激酶抑制劑
  - **干擾素-α**：可能改善酪氨酸激酶抑制劑反應
  - **羥基尿素**（姑息）：減少白血球
+ **加速期或原始細胞危象**：
  - 轉介臨床試驗或考慮自體造血幹細胞移植

### 骨髓增生異常症候群

**定義**：
+ 異質性惡性幹細胞疾病，特徵為發育異常和無效血液細胞生成，導致外週血球減少，轉化為急性白血病的風險不同

**病理生理學**：
+ 成熟障礙：造血無效；形成的細胞有形態和功能缺陷
+ 骨髓內凋亡：骨髓內程序性細胞死亡
+ <30%進展為急性骨髓性白血病

**風險因素**：
+ 老年人、化療後、接觸（苯、菸草、輻射）、遺傳異常
+ 發生率：每年每百萬人50人，70歲以上上升至每年每百萬人200-400人

**臨床表現**：
+ 高度變異；常見表現：貧血症狀、血小板減少（瘀青、出血、紫斑）、嗜中性球減少（復發性感染）持續數月至數年

**診斷檢查**：
+ **全血球計數和周邊血液抹片**：
  - 紅血球：通常為大球性，卵形紅血球，網狀紅血球計數減少
  - 白血球：粒細胞減少和形態異常（如Pelger異常）
  - 血小板：血小板減少、大小異常
+ **骨髓吸引和切片**：骨髓發育異常且通常為增生過多；細胞遺傳學異常

**治療**：
+ **低風險**：
  - 紅血球生成素刺激劑每週一次是一線減少輸血需求的治療
  - 若有5q缺失：Lenalidomide口服
  - 支持性照護：紅血球和血小板輸血
+ **高風險**：
  - 表觀遺傳治療：DNA甲基轉移酶抑制劑
  - 考虑造血幹細胞移植

**預後**：
+ **修訂版國際預後評分系統**使用5個因素估計平均存活
+ **IPSS-M**整合突變分析以獲得更好的預後信息

## 急性骨髓性白血病

### 定義

+ **世界衛生組織定義**：外周血或骨髓中≥20%原始細胞
+ 分類：根據原始細胞為骨髓性或淋巴性分為兩類

### 典型白血病發病年齡

| 類型 | 發病年齡 |
|:-----|:---------|
| 急性淋巴性白血病 | 兒童和老年成人 |
| 慢性骨髓性白血病 | 40-60歲 |
| 急性骨髓性白血病、慢性淋巴性白血病 | >60歲 |

**Auer rods是急性骨髓性白血病的pathognomonic標誌**

### 病理生理學

+ **病因細分**：
  - **原發性（de novo）**
  - **繼發性**：先前血液疾病或先前化療藥物
+ 骨髓中原始細胞不受控增殖導致：
  - 正常造血細胞受到抑制
  - 原始細胞出現在外周血
  - 代謝後果：腫瘤溶解症候群

### 臨床表現

+ 症狀在數週內發展
+ **骨髓衰竭表現**：
  - 貧血、血小板減少（急性前骨髓性白血病合併瀰散性血管內凝血）、嗜中性球減少（感染/發燒）
+ **器官浸潤**：骨骼疼痛、牙齦肥厚、CNS侵犯、肝脾腫大、淋巴結病變、皮膚白血病
+ **白血病性高症候群**（醫療急症）：
  - 大量原始細胞干擾循環導致缺氧和出血
  - 急性骨髓性白血病比急性淋巴性白血病更常見
+ **代謝效應**：
  - **腫瘤溶解症候群**：尿酸增加導致腎病變、痛風；磷酸鹽釋放導致低鈣；促凝血劑釋放導致瀰散性血管內凝血

### 診斷檢查

+ **血液檢查**：
  - **全血球計數**：貧血、血小板減少、變異性白血球（最常見血球減少加原始細胞）
  - 評估瀰散性血管內凝血：國際標準化比值升高、活化部分凝血活酶時間升高、纖維蛋白原降低
  - 評估腫瘤溶解症候群：乳酸脫氫酶升高、尿酸升高、磷酸鹽升高、鈣降低
+ **周邊血液抹片**：Auer rods的循環原始細胞是急性骨髓性白血病的pathognomonic標誌
+ **骨髓吸引/切片**：確診
+ **胸部X光**排除肺炎；化療前心電圖、心臟超聲

### 治療

+ **化療是主要治療**
+ 不適合強化療的患者可用低劑量cytarabine和hypomethylating agents合併venetoclax
+ 除急性前骨髓性白血病（t(15:17)易位）外，所有急性骨髓性白血病亞型治療相似
  1. **誘導**：化療誘導完全緩解
  2. **鞏固**：防止復發
+ **支持性照護**：
  - 發燒：全套培養、胸部X光、開始廣效抗生素
  - 血小板和紅血球輸血
  - 預防和治療代謝異常
  - Allopurinol、Rasburicase預防/處理高尿酸血症
+ **白血病性高症候群**：需要立即細胞減少治療

**急性前骨髓性白血病治療**：
+ 是急症，因為瀰散性血管內凝血通常在確診時就存在
+ 若在鑑別診斷中，應盡快開始ATRA誘導分化；三氧化二砷和ATRA合併治療優於傳統化療

### 預後

+ **達到第一完全緩解**：
  - ≤60歲70-80%；>60歲50%
  - 中位存活12-24個月
  - 預後取決於細胞遺傳學、年齡、表現狀態、先前細胞毒素或放射治療

## 急性淋巴性白血病

### 定義

+ 骨髓中早期淋巴前驅細胞惡性增殖並替代正常造血細胞的惡性疾病
+ 世界衛生組織將急性淋巴性白血病分為兩類（依細胞來源）：
  - B細胞：前驅B淋巴母細胞白血病
  - T細胞：前驅T淋巴母細胞白血病

### 臨床表現

+ 區分急性淋巴性白血病與急性骨髓性白血病
+ 症狀通常繼發於：
  - **骨髓衰竭**：貧血、嗜中性球減少（50%發燒就診）、血小板減少
  - **器官浸潤**：骨骼疼痛、淋巴結病變、肝脾腫大、腦膜徵象

### 診斷檢查

+ **骨髓或外周血>20%淋巴母細胞**；收集流式細胞儀、細胞遺傳學、分子研究樣本
+ 費城染色體：~25%成人急性淋巴性白血病
+ **全血球計數**：白血球>100 × 10⁹/公升（50%患者）；嗜中性球減少、貧血、血小板減少
+ 篩檢腫瘤溶解症候群：尿酸、鉀、磷酸鹽、鈣、乳酸脫氫酶升高
+ 胸部X光：患者可能有縱隔腫塊
+ 治療開始時強制腰椎穿刺評估CNS侵犯
+ 愛滋病毒、B型肝炎、C型肝炎血清學

### 治療

+ 消除異常克隆細胞
  1. **誘導化療**：誘導完全緩解
  2. **鞏固和/或強化化療**
  3. **維持化療**：長期低劑量間歇化療防止復發
  4. **預防**：鞘內化學治療或全身性methotrexate/cytarabine/地塞米松
+ **造血幹細胞移植**（特定適應症）：潛在可治癒
  - 若BCR-ABL陽性：一線開始酪氨酸激酶抑制劑並持續給予
  - 復發時：CAR T細胞治療

**CAR T細胞治療**：
+ 提取患者自身T細胞，基因改造T細胞產生能識別癌細胞表面抗原的嵌合抗原受體
+ 治療瀰漫性大B細胞淋巴瘤和CD19陽性急性淋巴性白血病最有效

### 預後

+ 取決於初始誘導反應、極微小殘留疾病檢測或復發後是否達到緩解
+ **達到第一完全緩解**：60-90%
+ 兒童急性淋巴性白血病：75%長期緩解（>5年）
+ 成人急性淋巴性白血病：30-40% 5年存活

## 淋巴瘤

### 定義

+ 淋巴細胞惡性增殖，惡性淋巴細胞聚集在淋巴結和淋巴組織
+ 導致淋巴結病變、結外病變、全身症狀

**Ann Arbor分期系統**

| 分期 | 描述 |
|:-----|:-----|
| 第一期 | 單一淋巴結區域或淋巴結外器官/部位 |
| 第二期 | ≥2個淋巴結區域或1個淋巴結外器官/部位及同側橫膈膜一側≥1淋巴結區域 |
| 第三期 | 橫膈膜兩側都有淋巴結區域受累 |
| 第四期 | 瀰漫性累及一個或多個淋巴結外器官，包括骨髓 |

+ **A**：無B症狀
+ **B**：有B症狀

## 霍奇金淋巴瘤

### 定義

+ 淋巴細胞惡性增殖，伴有Reed-Sternberg細胞

### 流行病學

+ 雙峰分布：20歲和>50歲
+ 高達50%與EB病毒相關

### 臨床表現

+ **無症狀淋巴結病變**（70%）：
  - 無痛性橡皮樣一致性
  - 頸部/鎖骨上（60-80%）、腋窩（10-20%）、腹股溝（6-12%）
+ **脾腫大**（50%）加**肝腫大**
+ **縱隔腫塊**：
  - 常规胸部X光發現，可能有症狀
+ **全身症狀**：
  - **B症狀**：6個月內非故意體重減少>10%、體溫>38°C、盜汗>2週；晚期疾病還有極度疲倦
  - 搔癢（非特異/副腫瘤）

### 診斷檢查

+ **全血球計數**：
  - 貧血（慢性病，罕見溶血性）、嗜伊紅性粒細胞增多、淋巴球減少
+ **生物化學**：
  - 愛滋病毒、B型肝炎、C型肝炎血清學
  - 肝酶
  - 鹼性磷酸酶、鈣（骨侵犯）
  - 紅血球沉降率（預後）、乳酸脫氫酶（分期、監測疾病進展）
+ **影像**：
  - 胸部電腦斷層、腹部/骨盆腔電腦斷層、正電子發射斷層掃描
+ **切片**確診
+ **骨髓切片**評估骨髓浸潤

### 治療

+ **第一期-第二期**：化療（ABVD）後進行放射治療
+ **第三期-第四期**：化療（ABVD、Brentuximab-AVD或BEACOPP）
+ **復發、化療抵抗**：高劑量化療和自體幹細胞移植、抗CD30抗體療法
+ **正電子發射斷層掃描**結果對於評估疾病治療反應至關重要

**ABVD**：Adriamycin、Bleomycin、Vinblastine、Dacarbazine

### 治療併發症

+ **心臟疾病**：放射治療和adriamycin心肌病變的後遺症
+ **肺部疾病**：Bleomycin（間質性肺炎）的後遺症
+ **不孕**：ABVD<3%
+ **放射區域內第二腫瘤**：肺癌或乳腺癌；非霍奇金淋巴瘤
+ 甲狀腺功能減退

### 預後

**Hasenclever不良預後因素**（晚期疾病）：
1. 血清白蛋白<40克/公升
2. 血紅蛋白<108克/公升
3. 男性
4. 第四期疾病
5. 年齡≥45歲
6. 白血球增多（>15 × 10⁹/公升）
7. 淋巴球減少（<0.06 × 10⁹/公升或<8%白血球計數）

## 非霍奇金淋巴瘤

### 定義

+ 淋巴細胞惡性增殖

### 分類

+ 可起源於B-（85%）或T-/NK-（15%）細胞
+ **B細胞非霍奇金淋巴瘤**：如瀰漫性大B細胞淋巴瘤、濾泡性淋巴瘤、Burkitt淋巴瘤、套細胞淋巴瘤
+ **WHO分類**（基於自然病史）：
  1. **惰性**（35-40%）：如濾泡性淋巴瘤、小淋巴細胞淋巴瘤/慢性淋巴性白血病、套細胞淋巴瘤
  2. **侵襲性**（~50%）：如瀰漫性大B細胞淋巴瘤
  3. **高度侵襲性**（~5%）：如Burkitt淋巴瘤
+ **T細胞非霍奇金淋巴瘤**：如蕈樣黴菌病、外周T細胞淋巴瘤、間變性大細胞淋巴瘤

### 臨床表現

+ **無痛性淺表淋巴結病變**，通常>1淋巴結區域
+ 可局部或廣泛淋巴結病變
+ NHL中全身症狀不如霍奇金淋巴瘤常見
+ 骨髓侵犯時：貧血加嗜中性球減少加血小板減少
+ 腹部徵象加肝脾腫大
+ 5-10%口咽侵犯
+ **結外侵犯**：最常見於胃腸道、睪丸、骨、腎
+ 1% CNS侵犯

### 診斷檢查

+ **全血球計數**：
  - 正血紅素正常血色素性貧血
  - 晚期疾病：血小板減少、嗜中性球減少
+ **生物化學、愛滋病毒、B型肝炎、C型肝炎血清學**：
  - 尿酸升高
  - 乳酸脫氫酶升高（快速進展疾病和不良預後因素）
+ **分期**：頸部、胸部、腹部、骨盆腔電腦斷層、骨髓切片
+ **正電子發射斷層成像**：侵襲性淋巴瘤治療前後確保治療後緩解

### 治療

+ **惰性非霍奇金淋巴瘤，局部疾病**：
  - 放射治療至主要部位和相鄰淋巴結區域
+ **第三期或第四期惰性非霍奇金淋巴瘤**治療目標是症狀管理：
  - 觀察等待
  - **Bendamustine加rituximab**優於CHOP加rituximab
+ **侵襲性淋巴瘤**：治療目標是根治
  - 聯合化療：**CHOP**是主要方案，B細胞淋巴瘤加rituximab
  - 局部/大塊疾病：放射治療
+ **高度侵襲性淋巴瘤**：
  - **Burkitt淋巴瘤**：短期高強度化療
  - CNS預防和腫瘤溶解症候群預防

### 併發症

+ 脾臟滯留
+ 感染
+ 自體免疫溶血性貧血和血小板減少
+ 腸穿孔
+ 腫瘤溶解症候群

### 預後

+ **濾泡性淋巴瘤**：使用濾泡性淋巴瘤國際預後指數
  - 依計算風險，5年平均存活範圍53-91%
+ **瀰漫性大B細胞淋巴瘤**：使用國際預後指數
  - 依計算風險，5年平均存活範圍26-73%

## 漿細胞疾病

### 多發性骨髓瘤

**定義**：
+ 漿細胞的惡性增殖
+ 漿細胞浸潤骨髓導致：
  - 骨病變（骨痛、病理性骨折）
  - 貧血、感染、腎功能衰竭
+ 單克隆（M）蛋白由增生的漿細胞產生

**診斷標準（SLIM CRAB）**：
- **S**：骨髓中≥60%漿細胞
- **L**：游離輕鏈比>100
- **M**：磁振造影、正電子發射斷層/電腦斷層上>1個溶骨性病變
- **C**：鈣升高（高鈣血症）
- **R**：腎功能不全
- **A**：貧血（血紅蛋白<100克/公升）
- **B**：骨病變

**分期（修訂版國際分期系統）**：

| 分期 | β2微球蛋白 | 白蛋白 | 平均存活 |
|:-----|:-----------------|:--------|:---------|
| 第一期 | <3.5毫克/公升 | ≥35克/公升 | >5年 |
| 第二期 | 3.5-5.5毫克/公升 | 不適用 | 3-4年 |
| 第三期 | >5.5毫克/公升 | 不適用 | 1-2年 |

### 意義未明單克隆丙種球蛋白病

**定義**：
+ 血清中存在M蛋白但無漿細胞疾病或淋巴增生病臨床或實驗室證據
+ 發生率：一般人口0.15%，>70歲5%

**診斷**：
- 血清M蛋白<30克/公升
- 骨髓漿細胞<10%
- 無SLIM CRAB
- 每年0.3-1%患者進展為血液系統惡性腫瘤

**監測**：q6-12個月病史和身體、全血球計數、肌酸酐、鈣、白蛋白、乳酸脫氫酶、血清蛋白電泳

### 淋巴漿細胞淋巴瘤

**定義**：
+ 淋巴漿細胞增增殖；存在單克隆IgM副蛋白

**臨床表現**：
+ 慢性病；老年人；中位年齡64歲
+ **症狀**：虛弱、疲倦、出血（口鼻）、體重減輕、復發性感染、呼吸困難、心衰竭（貧血、血液黏滯、血漿容量擴張三聯徵）
+ **理學發現**：蒼白、脾腫大、肝腫大、淋巴結病變、視網膜病變
+ **主要併發症**：高黏滯症候群（因為IgM較大，主要局限於血管內空間）

**診斷檢查**：
+ 骨髓顯示漿細胞樣淋巴細胞
+ 通常無骨病變
+ 很少有高鈣血症
+ 血清蛋白電泳顯示M蛋白

### 高黏滯症候群

**定義**：
+ 相對血清黏滯度>5-6單位時，由循環血清免疫球蛋白或高增殖性疾病中細胞成分增加引起的臨床後遺症
+ Waldenström's macroglobulinemia占85%病例

**臨床表現**：
+ **高血容量**：心衰竭、頭痛、嗜睡、稀釋性貧血
+ **CNS症狀**（腦血流減少）：頭痛、眩暈、、共濟失調、中風
+ **視網膜**：靜脈充血和出血
+ **出血素質**：血小板功能受損

**治療**：
+ 血漿置换、化療

## 腫瘤溶解症候群

### 定義

+ 腫瘤細胞自發性或治療相關裂解引起的代謝併發症群
+ 更常見於大腫瘤負荷和高增殖率的疾病

### 臨床表現

+ **代謝異常**：
  - 細胞裂解，釋放鉀、尿酸、磷酸鹽（水平升高）
  - 磷酸鹽結合鈣（鈣降低）
+ **併發症**：
  - 致命心律不整（鉀升高）
  - 急性腎損傷

### 治療

+ **預防**：
  - 積極靜脈水化
  - **不建議鹼化尿液**
  - Allopurinol（預防尿酸積累）或Rasburicase（降低現有尿酸）
+ **透析**

## 血液製品與輸血

### 血液製品

+ **紅血球、血小板、凝血因子**（新鮮冷凍血漿、冷沉澱、纖維蛋白原濃縮製劑、因子濃縮製劑）
+ 捐血被分離成各種成分
+ **新鮮冷凍血漿**：收集後24小時內冷凍的血漿
+ **冷沉澱**：新鮮冷凍血漿在低溫下解凍時生成的高分子量沉澱物

### 特殊製品

+ **照射血液製品**：
  - 防止捐贈者T細胞在受贈者增殖，預防移植對宿主病
  - 用於嚴重T細胞免疫缺陷患者、接受嘌呤類似物化療者、何杰金淋巴瘤、骨髓移植候選者、或接受一等親捐贈者定向輸血者
+ **CMV陰性血液製品**：
  - 血清陰性孕婦
  - 宮內輸血

### 紅血球

**濃縮紅血球**：
+ 保存於4°C
+ 有效期為收集後42天
+ 每單位輸注>2小時

**適應症**：
+ 血紅蛋白<70克/公升；可根據患者耐受性或症狀調整
+ 活動性出血期間維持血紅蛋白在70-90克/公升
+ 考虑為以下患者維持較高血紅蛋白：
  - 冠狀動脈疾病/不穩定冠狀動脈症候群
  - 無法控制、不可預測的出血

**輸血前選擇**：
+ **血型鉴定和篩檢**：確定受血者血型和Rh狀態，以及血漿中對主要/次要血型抗原的自體或同種抗體
+ **交叉配合**：混合受血者血液與潛在捐贈者血液，觀察凝集

### 血小板

**血小板製品適應症**

| 製品 | 適應症 |
|:-----|:-------|
| 隨機捐贈者（池化）| 血小板減少伴出血 |
| 單一捐贈者血小板 | 潛在骨髓移植受赠者、對池化血小板無效者 |
| HLA配對血小板 | 對池化或單一捐贈者血小板無效、存在HLA抗體者 |

+ 保存於20-24°C
+ 1單位血小板池應使血小板計數增加≥15 × 10⁹/公升

**血小板輸血適應症**：

| 血小板（× 10⁹/公升）| 適應症 |
|:-------------|:-------|
| <20 | 非免疫性血小板減少症 |
| <50 | 不伴顯著失血的手術 |
| <50 | 伴失血或大手術的程序 |
| <100 | 神經外科或頭部創傷 |
| Any | 血小板功能障礙且有顯著出血 |

## 急性輸血反應

### 免疫性反應

**急性溶血性輸血反應**：
+ ABO不相容導致補體活化引起的血管內溶血，輸血後立即發生
+ 最常見原因是患者識別錯誤
+ **表現**：發燒、寒顫、低血壓、背或腰痛、呼吸困難、血紅蛋白尿
+ 急性腎衰竭和瀰散性血管內凝血
+ **治療**：停止輸血、通知血庫確認沒有 clerical error、支持性措施

**發燒非溶血性輸血反應**：
+ 由對白血球、血小板或其他捐贈者血漿抗原的同種抗體及血液製品細胞釋放的細胞激素引起
+ **表現**：發燒加寒顫、面部充血、頭痛、肌肉疼痛
+ **治療**：
  - 排除溶血反應或感染
  - 若體溫<39°C且無嚴重症狀：繼續輸血但減慢速度並給予退燒藥
  - 若體溫≥39°C或有嚴重症狀：停止輸血、調查反應

**過敏非溶血性輸血反應**：
+ 由對捐贈者血漿蛋白質的IgE同種抗體引起
+ **表現**：主要為蕁麻疹，有時發燒
+ **治療**：
  - 輕度：減慢輸血速度並給予diphenhydramine
  - 中度至重度：停止輸血，給予靜脈diphenhydramine、類固醇、Epinephrine

**輸血相關急性肺損傷**：
+ 輸血期間或完成後6小時內發生的急性肺損傷
+ 顯著缺氧
+ 影像學雙側肺部水腫
+ **治療**：支持性治療（氧氣）；通知血庫

### 非免疫性反應

**輸血相關循環超負荷**：
+ 心臟功能受損和/或輸血過快導致
+ **表現**：呼吸困難、端坐呼吸、高血壓、心搏過速
+ **治療**：停止輸血，給予利尿劑和氧氣

**敗血症（細菌污染）**：
+ 血小板製品（室溫保存）比紅血球製品（冷藏）更常見
+ **表現**：發燒、寒顫、低血壓、敗血症休克
+ **治療**：停止輸血、化驗、廣效抗生素
