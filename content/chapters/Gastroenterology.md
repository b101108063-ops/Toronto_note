## 導讀摘要

本章節涵蓋胃腸學的核心內容，摘要如下：

- **急性腹瀉（Acute Diarrhea）**：病因評估、補液治療、何時使用抗微生物製劑；旅客腹瀉、infectious diarrhea（細菌性、寄生蟲性、病毒性）之鑑別與處理
- **發炎性腸道疾病（IBD）**：Crohn's Disease 與 Ulcerative Colitis 的鑑別診斷、治療原則（5-ASA、corticosteroids、immunosuppressives、biologics）
- **肝臟疾病（Liver Disease）**：viral hepatitis（A/B/C/D 型）、alcoholic liver disease、cirrhosis、portal hypertension 併發症（esophageal varices、ascites、hepatic encephalopathy、SBP）
- **胰臟疾病（Pancreatic Disease）**：急性胰臟炎（I GET SMASHED 病因）、慢性胰臟炎、pancreatic cancer；膽結石（gallstones）
- **上消化道出血**：peptic ulcer disease、esophageal varices 的內視鏡處理；下消化道出血：diverticular bleeding、hematochezia

## 胃腸學概論

### 胃腸道檢查原則

- **內視鏡檢查**：EGD（上消化道）、colonoscopy（下消化道）、ERCP（膽胰管）、wireless capsule endoscopy（小腸）
- **影像學**：CT abdomen/pelvis、MRI/MRCP、腹部 X-ray（sentinel loop、colonic cut-off sign）
- **實驗室**：CBC、electrolytes、LFTs、amylase/lipase、coagulation profile、stool studies

## 急性腹瀉（Acute Diarrhea）

### 治療原則

+ 液體及電解質補充：大部分口服，嚴重症狀（低血壓、脱水、老人/昏迷）則靜脈注射
+ 抗腹瀉藥物
  * 抗蠕動劑：diphenoxylate、loperamide（Imodium®）應謹慎使用；黏膜發炎、血便患者禁忌
  * 副作用：腹部絞痛、toxic megacolon
  * 調整液體傳輸：bismuth subsalicylate（Pepto-Bismol®）可能有效（但血便或發燒時不應使用）
+ 抗生素：通常不需要
  * 適應症：敗血症、發燒合併血便或糞便 WBC
  * 明確需要：Shigella、V. cholerae、C. difficile、旅客腹瀉（ETEC）、Giardia、Entamoeba histolytica、Cyclospora
  * 視情況：Salmonella、Campylobacter、Yersinia、non-enterotoxigenic E. coli
+ 腹瀉疾病應向公共衛生單位通報

### 旅客腹瀉（Traveller's Diarrhea）

**流行病學**
+ 旅客最常見疾病：至開發中國家旅遊者前 2 週有達 50% 感染，返國後 10-20%

**病因**
+ 細菌（80-90%）：E. coli 最常見（ETEC）、Campylobacter、Shigella、Salmonella、Vibrio（非霍亂型）
+ 病毒：norovirus、rotavirus、astrovirus（5-8%）
+ 寄生蟲（長期旅客約 10%）：Giardia、Entamoeba histolytica、Cryptosporidium、Cyclospora

**治療**
+ 補液是主要治療
+ 症狀治療：antidiarrheal agents（rifamycin ABx、bismuth subsalicylate、loperamide）
+ 中重度：經驗性抗生素（ciprofloxacin、azithromycin、rifaximin）

**預防**
+ 注意飲食衛生：避免街邊小吃、無削皮生果、未煮熟肉類及海鮮
+ 避免未處理飲用水、散裝啤酒
+ Bismuth subsalicylate（Pepto-Bismol®）：60% 有效（2 粒 QID）
+ 不建議抗生素預防（抗藥性風險）
+ Dukoral® 口服疫苗：對 V. cholerae（~80%）及 ETEC（~50-67%）有保護效力

## 慢性腹瀉（Chronic Diarrhea）

**定義**：頻繁解軟便 >4 週（相較於持續性腹瀉 14-30 天）

**病因**
+ 大部分為非感染性（見 G4 鑑別診斷）

**檢查**
+ 糞便：C. difficile toxin、C&S、O&P + fecal fat、WBC、fecal calprotectin
+ 血液：CBC、electrolytes、CRP、TSH、celiac serology（IgA anti-tTG）
+ 大腸鏡切片檢查
+ 上消化道內視鏡及十二指腸切片
+ 嘗試無乳糖飲食

**治療**：取決於根本病因

## 消化不良與吸收不良（Maldigestion and Malabsorption）

**定義**
+ Maldigestion：無法將大分子分解為小分子
+ Malabsorption：無法將分子由腸黏膜運送至血液循環

**病因 - 消化不良**
+ 食物與酶混合不足（如胃切除術後）
+ 胰臟外分泌不足（囊腫纖維化CF、胰臟炎、胰臟癌）
+ 膽鹽缺乏（末端迴腸疾病、細菌過度生長、肝臟疾病）
+ 特定酶缺乏（如 lactase）

**病因 - 吸收不良**
+ 吸收表面積不足
+ 感染/寄生蟲（Whipple's disease、Giardia）
+ 免疫相關（celiac disease）
+ 浸潤（lymphoma、amyloidosis）
+ 纖維化（systemic sclerosis、輻射腸炎）
+ 小腸切除
+ 先天性（short bowel syndrome）
+ 發炎性：廣泛性 Crohn's disease（關鍵數字：<100 cm = 膽鹽腹瀉；>100 cm = 脂肪痢/steatorrhea）

+ Fecal elastase 篩檢胰臟功能

**治療**：取決於根本病因

## Celiac Disease（乳糜瀉）

**定義**：小腸黏膜對麩質（gluten）之異常免疫反應；麩質來自小麥、大麥、黑麥、可能燕麥

**病因**
+ 獨特自體免疫疾病：基因（HLA-DQ2/8）、自體抗原（tTG）、環境觸發因子（gluten）均已知
+ 與其他自體免疫疾病相關：Sjögren's syndrome、T1DM、甲狀腺疾病
+ 麩質分解為 gliadin（毒性蛋白）
+ HLA-DQ2（6 號染色體）：90% 患者攜帶（一般人口 20%）；亦與 HLA-DQ8（5%）相關

**流行病學**
+ 女性較常見
+ 盛行率：一等親 10%；二等親 20%

**臨床特徵**
+ 經典型：腹瀉、體重減輕、貧血、維生素/礦物質缺乏、生長遲緩
+ 現代表現：腹脹、排氣、缺鐵，或無症狀
+ 無麩質飲食可改善，重新攝入則復發
+ 近端腸道病變最嚴重：鐵、鈣、葉酸缺乏（近端小腸吸收）比 B12（遠端小腸）更常見
+ 可能伴發：Dermatitis herpetiformis、骨質疏鬆/骨折、不孕、癲癇、肌病、憂鬱、妄想、、運動失調

**檢查**
+ 血清學
  * Anti-tTG IgA：90-98% 敏感性、94-97% 特異性
  * 選擇性 IgA 缺乏者 anti-tTG 可能偽陰性，同時測血清 IgA
  * IgA 缺乏時測 tTG 及/或 DGP IgG
+ 小腸黏膜切片（通常十二指腸）= 診斷
  * 初期：上皮內淋巴球增加
  * 中期：隱窩增生
  * 末期：絨毛萎縮
+ 無麩質飲食後改善（但切片檢查前不應開始飲食）

**治療**
+ 無麩質飲食：避免大麥、黑麥、小麥；稻米及玉米粉可接受
+ 鐵、葉酸補充（必要時補充其他維生素）
+ 若飲食改變後反應不佳：考慮不遵從、非乳糜瀉疾病（顯微性結腸炎、胰臟功能不足）、lymphoma

**預後**
+ 淋巴瘤、腺癌（小腸及結腸）風險增加
+ 無麩質飲食可能降低淋巴瘤風險

## 發炎性腸道疾病（Inflammatory Bowel Disease, IBD）

**定義**：胃腸道發炎及潰瘍性疾病；主要包括 Crohn's disease（CD）及 Ulcerative colitis（UC）

**病因**
+ 複雜、多因素
+ 免疫系統對腸道菌叢持續過度反應
+ 感染後無法正常下調免疫反應，發生於基因易感個體

**基因學**
+ 親屬（尤其兄弟姊妹）風險增加；早發性疾病
+ 家族風險：CD > UC
+ 多基因模式：200+ 相關基因位點
+ CARD15/NOD2 基因突變與 CD 相關（異型合子相對風險 3；同型合子 40）；尤其 Ashkenazi 猶太人、早發、迴腸侵犯、瘻管/纖維狹窄疾病

### Crohn's Disease

**定義**：慢性透壁性發炎疾病，可侵犯口腔至肛門之整個腸道（「口到肛」）

**流行病學**
+ 全球發生率 3-15/100,000；135,000 加拿大人罹患 CD
+ 雙峰：30 歲前發病，60 歲左右次峰；M=F
+ CD 發生率持續增加（相對 UC），尤其年輕女性
+ 白種人、Ashkenazi 猶太人較常見；亞洲人移居西方國家後風險增加
+ 吸菸者比例高於一般人口

**病理**
+ 最常見部位：迴腸 + 右結腸
+ 線狀潰瘍叢集形成黏膜島或「鵝卵石」外觀
+ 肉芽腫：50% 手術標本、15% 黏膜切片

**臨床特徵**
+ 自然病程不可預測
+ 常見：復發性腹部絞痛、腹瀉（有或無出血）、疲倦、體重減輕
+ 迴腸炎：飯後疼痛、嘔吐、RLQ 疼痛；模擬急性闌尾炎
+ 腸道外表現（EIMs）：結腸侵犯時更常見
+ 常見：瘻管、裂隙、膿腫
+ 深裂隙有局部穿孔至鄰近臟器風險（導致瘻管及膿腫）

### Crohn's Disease 之治療

| 治療 | 說明 |
|------|------|
| **生活型態/飲食** | 戒菸（重要） |
| **抗腹瀉藥物** | loperamide（無狹窄時）；cholestyramine（膽鹽性腹瀉，末端迴腸<100cm 病變） |
| **抗生素** | Metronidazole、ciprofloxacin（膿腫、瘻管、肛門疾病） |
| **皮質類固醇** | 急性發作；budesonide（輕度迴腸/右結腸型）；prednisone（廣泛疾病） |
| **免疫調節劑** | Azathioprine、6-MP、Methotrexate（維持緩解、類固醇節減） |
| **Biologics** | Infliximab、adalimumab、vedolizumab、ustekinumab（抗 TNF-α/抗整合素/抗 IL-12/23） |
| **小分子藥物** | JAK inhibitors（tofacitinib、upadacitinib） |

### Ulcerative Colitis（潰瘍性結腸炎）

**定義**：始於直腸之瀰漫性黏膜發炎，連續性向近端發展，不侵犯小腸

**流行病學**
+ 加拿大發生率 6-15/100,000，盛行率 ~100/100,000
+ 男女相等或女>男；雙峰但 CD 相比峰不明顯
+ 吸菸為保護因子（但戒菸後疾病惡化之風險需與手術風險權衡）

**臨床特徵**
+ UC（非血便性腹瀉）常為首發表現
+ 疾病嚴重程度與大便次數及全身症狀相關
+ 輕度：<4 次/天，些微出血，無全身症狀
+ 中度：>4 次/天，明顯出血
+ 重度（急性重型結腸炎）：>6 次/天，血便，全身毒血症（發燒、心搏過速、貧血、ESR/CRP 升高）

**腸道外表現**：見 Table 14

**併發症**
+ Toxic megacolon：腹脹、發燒、疼痛、意識改變；立即液體復甦、NPO、靜脈皮質類固醇、廣效抗生素、緊急手術（若 24-72 小時無改善）
+ 結腸直腸癌：病程 >30% 結腸侵犯、PSC 併發；spy surveillance colonoscopy（見下）
+ 骨質疏鬆

### Ulcerative Colitis 之治療

| 疾病程度 | 治療 |
|---------|------|
| **輕度** | 5-ASA（mesalamine 直腸製劑或口服） |
| **輕-中度** | 口服皮質類固醇（budesonide 或 prednisone） |
| **中-重度** | 免疫調節劑（azathioprine、6-MP）、Biologics（infliximab、adalimumab、golimumab、vedolizumab） |
| **急性重度** | 靜脈皮質類固醇（methylprednisolone 或 hydrocortisone） |
| **難治性** | Cyclosporine 或 tacrolimus；必要時 colectomy |

**大腸癌監測**：從診斷起 8 年開始，每 1-3 年 colonoscopic surveillance；PANCA 監測無證據支持可減少癌變

### Irritable Bowel Syndrome（腸躁症，IBS）

**定義**：反覆腹痛，伴隨排便習慣改變，無結構或器官異常

**Table. Rome IV Criteria for Diagnosing IBS**
+ 復發性腹痛，平均每週至少 1 天，過去 3 個月內發病，症狀持續 ≥6 個月
+ 與排便相關
+ 伴隨糞便頻率改變
+ 伴隨糞便性狀改變

| 分型 | 糞便特徵 |
|------|----------|
| **IBS-C** | IBS 合併便祕為主（硬便 >25%，稀便 <25%） |
| **IBS-D** | IBS 合併腹瀉為主（稀便 >25%，硬便 <25%） |
| **IBS-M** | 混合型（硬便 >25%，稀便 >25%） |
| **IBS-U** | 無法分類 |

**治療**
+ 飲食調整：FODMAP 飲食、低劑量 Tricyclic antidepressants（IBS-D）、loperamide（IBS-D）
+ 便秘為主：fiber supplements、osmotic laxatives（lactulose、PEG）、lubiprostone、linaclotide
+ 疼痛為主：antispasmodics、low-dose TCAs、SSRIs

## 上消化道出血（Upper Gastrointestinal Bleeding）

**定義**：Treitz 韌帶近端出血

**病因**
+ **Peptic ulcer（消化性潰瘓）**：最常見（~50%）；Hp、NSAID、stress
+ **Esophageal varices（食道靜脈曲張）**：portal hypertension
+ **Mallory-Weiss tear**
+ **Esophagitis/Erosive disease**
+ **Neoplasm**
+ **Dieulafoy lesion**
+ **Aorto-enteric fistula**（罕見但致命）

**臨床特徵**
+ 嘔血（hematemesis）、黑便（melena）、血便（hematochezia - 活動性出血流速快時）
+ 急性：心搏過速、低血壓、暈厥
+ 慢性：貧血（缺鐵性）、虛弱、疲勞

**檢查**
+ EGD（上消化道內視鏡）：診斷及治療（止血）
+ 實驗室：CBC、凝血功能（BUN/Cr）、type and screen

**治療**
+ 復甦：2 大口徑 IVs、液體、血液（必要時）
+ 內視鏡止血
  * Injection（epinephrine）
  * Thermal coagulation（bipolar electrocoagulation、heater probe）
  * Clips（hemoclips）
  * Banding（varices）
+ PO vs NPO：取決於內視鏡發現及是否需進一步內視鏡處置
+ 高風險患者：靜脈 PPIs（peptic ulcer）、靜脈抗生素（varices - octreotide 或 terlipressin）
+ 抗凝劑/抗血小板：停用（血栓風險 vs 出血風險權衡）
+ 手術：內視鏡/介入放射學失敗時

### Peptic Ulcer Disease（消化性潰痬）

**定義**：胃或十二指腸黏膜糜爛/潰痬

**病因**
+ **H. pylori**：破壞黏膜屏障
+ **NSAIDs**：抑制 COX-1 → prostaglandins↓ → 黏液/HCO3- 分泌↓
+ **Stress**：休克、燒傷、創傷、重大手術（Curling's ulcer - 燒傷；Cushing's ulcer - 顱內病變）
+ **Zollinger-Ellison syndrome**：胃泌素瘤→胃酸過多

**臨床特徵**
+ 上腹痛：飯後痛（gastric ulcer）；飯後緩解（duodenal ulcer）
+ 飯後腹脹、嘔吐
+ 出血（最常見併發症）：黑便或嘔血
+ 穿孔：突發嚴重腹痛、板狀腹、free air

**檢查**
+ EGD：診斷及切片（Hp、惡性）
+ Hp testing：尿素呼吸測試、糞便抗原、serology（Hp IgG）

**治療**
+ **H. pylori 根除**：Bismuth quadruple therapy（PPI + bismuth + tetracycline + metronidazole）或 concomitant therapy（PPI + amoxicillin + clarithromycin + metronidazole）
+ **NSAID 相關**：停用 NSAIDs + PPI；繼續 NSAID + PPI；COX-2 selective inhibitor + PPI
+ **出血**：內視鏡止血（見上）

### Esophageal Varices（食道靜脈曲張）

**定義**：門脈高壓導致食道靜脈曲張

**治療**
+ **Primary prophylaxis（主要預防）**：無靜脈曲張出血史
  * 非選擇性 beta-blockers（propranolol、nadolol）：降低門脈壓力
  * EVL（endoscopic variceal ligation）：高風險靜脈曲張（large varices、red wale marks）
+ **Acute bleeding**：
  * 液體/血液復甦
  * 靜脈 octreotide 或 terlipressin + 廣效抗生素
  * EGD + EVL 或 sclerotherapy
  * 失敗：TIPS（transjugular intrahepatic portosystemic shunt）或手術
+ **Secondary prophylaxis（次級預防）**：復發性出血
  * EVL + non-selective beta-blocker

## 下消化道出血（Lower Gastrointestinal Bleeding）

**定義**：Treitz 韌帶遠端出血

**病因**
+ 結構性：Colitis（輻射性、感染性、缺血性）、IBD（UC>CD）、diverticular、vascular（hemorrhoids/fissure、angiodysplasia）
+ 發炎性：感染
+ 腫瘤：大的息肉、息肉切除術後、大腸癌

**臨床特徵**
+ 血便（hematochezia）
+ 貧血
+ 糞便潛血（無可見血）
+ 偶爾黑便（慢性的盲腸/右結腸病變）

**治療**
+ 血流動力學評估及復甦
+ 排除上消化道來源（EGD）
+ Colonoscopy：定位出血來源；嚴重時考慮 radionuclide imaging 或 angiography
+ 治療根本病因

### 憩室出血（Diverticular Bleeding）

+ 無痛性血便（急性）
+ 糞便可從鮮紅至暗紅褐色；常混合膠凍狀血塊
+ 80% 自發停止
+ 結腸鏡定位出血點（少見）；持續則考慮栓塞或手術

## 病毒性肝炎（Viral Hepatitis）

### 急性病毒性肝炎（一般）

**定義**：病毒性肝炎持續 <6 個月

**臨床特徵**
+ 大部分亞臨床
+ 類流感前驅症狀（黃疸前 1-2 週）：嘔吐、厭食、頭痛、疲倦、肌痛、低燒、關節痛、蕁麻疹
+ 部分進展至黃疸期（數天至數週）：灰白糞便、深色尿 1-5 天先於黃疸；肝脾腫大、RUQ 壓痛；頸部淋巴結腫大（10-20%）

**檢查**
+ AST、ALT（>10-20x正常 = 肝細胞壞死）
+ ALP 輕微上升
+ 病毒血清學（IgM 抗體）

**治療**：支持性（補液、飲食）；自限性

**預後不良指標**：共病症、膽紅素持續高（>340 μmol/L = 20 mg/dL）、INR 上升、白蛋白下降、低血糖

### Hepatitis A Virus（A 型肝炎）

+ 單股 RNA 病毒；糞口傳染；潛伏期 4-6 週
+ 診斷：transaminases 上升、anti-HAV IgM 陽性
+ 兒童：通常無症狀
+ 成人：疲倦、嘔吐、關節痛、發燒、黃疸、肝脾腫大
+ 可致急性肝衰竭（<1-5%）
+ 可復發（罕見）；從不慢性化
+ 支持治療；可疫苗預防；接觸後可用免疫球蛋白預防

### Hepatitis B Virus（B 型肝炎）

**Table 19. Hepatitis B Serology**

| 狀態 | HBsAg | Anti-HBs | HBeAg | Anti-HBe | Anti-HBc IgM | Anti-HBc IgG | 肝酶 |
|------|-------|-----------|-------|----------|--------------|--------------|------|
| **急性 HBV** | + | - | + | - | + | - | AST↑, ALT↑ |
| **慢性 HBV（HBe-Ag 陽性）** | + | - | + | - | - | + | ALT 可能正常或升高 |
| **慢性 HBV（HBe-Ag 陰性）** | + | - | - | + | - | + | ALT 可能正常或升高 |
| **已康復** | - | + | - | + | - | + | 正常 |
| **免疫（疫苗）** | - | + | - | - | - | - | 正常 |

+ HBV DNA：活動性複製指標
+ 併發症：肝硬化（5-10%/5年未治療）、HCC
+ 治療：急性 HBV（自限性，嚴重時用 tenofovir 或 entecavir）；慢性 HBV（tenofovir/entecavir 抑制複製）

### Hepatitis C Virus（C 型肝炎）

+ 急性 C 型肝炎通常無症狀；10-50% 自行清除，50-90% 慢性化
+ 診斷：anti-HCV 抗體 + HCV RNA（確診）
+ 治療：直接作用抗病毒藥物（DAA）- elbasvir/grazoprevir、ledipasvir/sofosbuvir、sofosbuvir/velpatasvir、glecaprevir/pibrentasvir
+ DAA 治療可達 >95% SVR（持續病毒學反應）

### Hepatitis D Virus（D 型肝炎）

+ 需要 HBsAg 才能複製；與 HBV 重複感染或超感染
+ 使 HBV 感染更嚴重；增加急性肝衰竭及 cirrhosis 風險

### Autoimmune Hepatitis（自體免疫性肝炎）

+ 慢性進行性肝臟疾病；女性為主（70%）
+ 類型 1：ANA、SMA 陽性；類型 2：抗 LKM-1 陽性
+ 免疫抑制治療：prednisone ± azathioprine

### Drug-Induced Liver Injury（藥物性肝損傷）

+  Acetaminophen（對乙醯胺酚）：劑量依賴性；N-acetylcysteine 解毒
+ 其他常見：isoniazid、methotrexate、valproic acid、amiodarone、statins

## 酒精相關肝病（Alcohol-Related Liver Disease）

**疾病譜**
+ 單純性脂肪肝（可逆）
+ 酒精性肝炎（酒精性肝炎）：AFL（酒精性脂肪肝）→ 酒精性肝炎（炎症）→ 纖維化 → 硬化
+ 酒精性肝硬化

**酒精性肝炎**
+ 病史：慢性 EtOH 使用（可能近期增加，或因症狀而停用數天至數週）

+ 死亡率：中重度 30-50%

## Cirrhosis（肝硬化）

**定義**：不可逆性瀰漫性肝纖維化 + 結節再生

**病因**
+ 病毒性肝炎（B、C、D）
+ 酒精
+ NAFLD/MASLD（NASH）
+ 自體免疫
+ 膽汁淤積（PBC、PSC）
+ 遺傳/代謝（hemochromatosis、Wilson's disease、α1-antitrypsin deficiency）
+ 藥物/毒素

### 肝硬化併發症

+ **Portal Hypertension（門脈高壓）**：
  * 門脈壓力梯度 >5 mmHg；臨床顯著 >12 mmHg
  * 表現：食道/胃靜脈曲張、腹水、脾腫大、colopathy
+ **Ascites（腹水）**
+ **Variceal Bleeding（靜脈曲張出血）**
+ **Hepatic Encephalopathy（肝性腦病變）**
+ **Spontaneous Bacterial Peritonitis（SBP，自發性細菌性腹膜炎）**
+ **Hepatocellular Carcinoma（HCC，肝細胞癌）**
+ **Hepatorenal Syndrome（肝腎症候群）**

### Ascites（腹水）

**病因**：門脈高壓 → 內臟血管擴張 → RAAS/SNS 活化 → 鈉水滯留

**Table 23. SAAG（Serum-Ascites Albumin Gradient）**
+ SAAG = 血清白蛋白 - 腹水白蛋白
+ SAAG ≥11 g/L：門脈高壓（敏感性 97%）
+ SAAG <11 g/L：非門脈高壓原因（惡性腹水、胰臟腹水、結核性腹膜炎）

**治療**
+ 鈉限制（<2 g/day）
+ 利尿劑：spironolactone（首選）+ furosemide
+ 大量腹水：therapeutic paracentesis（同時靜脈白蛋白補充，每抽 1L 補充 6-8 g）
+ 難治性腹水：TIPS 或 liver transplant

**SBP 預防**：既往 SBP 病史或 GI 出血 + 肝硬化：norfoxacin 或 ciprofloxacin

### Hepatic Encephalopathy（肝性腦病變）

**定義**：肝衰竭導致氨等毒素累積，影響腦功能

**病因/誘發因素**
+ 便秘、GI 出血、感染（+SBP）、腎功能不全、低血鉀、鹼血症、鎮靜劑、脫水、便秘

**臨床表現**
+ 輕度：嗜睡、計算力下降、性格改變
+ 中度：意識混亂、撲翼樣震顫（asterixis）、困倦
+ 重度：昏迷、去大腦/皮質姿勢

**治療**
+  Lactulose（酸化結腸、促進氨排泄）：劑量調整至 2-3 軟便/天
+ Rifaximin（利福昔明）： Lactulose 失敗或附加治療
+ 排除/治療誘發因素

### Spontaneous Bacterial Peritonitis（SBP，自發性細菌性腹膜炎）

+ 定義：無明確腹腔內感染源之腹水感染
+ 診斷：腹水 PMN ≥250 cells/mm³；培養通常單一菌種（E. coli、Klebsiella、Enterococcus）
+ 經驗性治療：ceftriaxone 或 cefotaxime（覆蓋 Gram-negative）；加白蛋白（1.5 g/kg 第 1 天 + 1 g/kg 第 3 天）預防 HRS
+ 預防：既往 SBP 後需 long-term prophylaxis（norfoxacin 或 trimethoprim-sulfamethoxazole）

### Jaundice（黃疸）

**定義**：膽紅素 >42 μmol/L（2.5 mg/dL）→ 皮膚/鞏膜黃染

**類型**
+ **Unconjugated hyperbilirubinemia**：溶血、Gilbert's syndrome、Crigler-Najjar、Rotor syndrome
+ **Conjugated hyperbilirubinemia**：肝細胞性或膽汁淤積性

**評估**
+ Total/direct/indirect bilirubin
+ LFTs、AST、ALT、ALP、GGT
+ 腹部超聲或 CT
+ 膽道擴張 → 膽道阻塞（結石、腫瘤、狹窄）
+ 膽道不擴張 → 肝細胞性（肝炎、藥物）或非阻塞性膽汁淤積（PBC、PSC）

### Primary Biliary Cholangitis（PBC，原發性膽道膽管炎）

+ 自身免疫性進行性膽道破壞；中年女性（90%）
+ 抗粒線體抗體（AMA）陽性（>95%）
+ 症狀：疲倦、搔癢、右上腹痛；晚期肝硬化
+ 治療：ursodeoxycholic acid（UDCA）；obeticholic acid（對 UDCA 反應不佳者）

### Primary Sclerosing Cholangitis（PSC，原發性硬化性膽管炎）

+ 膽管發炎、纖維化、狹窄；年輕男性（70%）
+ 60-70% 合併 IBD（通常 UC）
+ 診斷：MRCP 或 ERCP 顯示多處狹窄（「beaded」膽管）
+ 治療：UDCA；內視鏡擴張顯著狹窄；末期 liver transplant

## 膽結石（Gallstones）

**類型**
+ **Cholesterol stones（膽固醇結石）**（80%）：肥胖、Fibrogenic diseases、pregnancy、迴腸疾病、Crohn's disease
+ **Pigment stones（膽色素結石）**：溶血（遺傳性球形紅血球症）、膽道感染（Clonorchis sinensis）

**臨床表現**
+ **Biliary colic（膽絞痛）**：RUQ/上腹痛，飯後 30-60 分鐘，持續數小時
+ **Acute cholecystitis（急性膽囊炎）**：持續疼痛、發燒、Murphy's sign（+）；超聲可見結石、膽囊壁增厚
+ **Choledocholithiasis（膽管結石）**：黃疸、膽管炎（Charcot's triad：發燒、黃疸、腹痛）；膽石性胰臟炎

**治療**
+ 症狀性膽囊結石：cholecystectomy（膽囊切除）
+ 膽管結石：ERCP + sphincterotomy + stone extraction；必要時外科手術

## 胰臟疾病（Pancreatic Disease）

### 胰臟酶異常

**Amylase 上升原因**
+ 胰臟疾病：胰臟炎、胰管阻塞、假囊腫、膿腫、腹水、外傷、癌症
+ 非胰臟腹部：膽道疾病、腸阻塞/缺血、穿孔/穿透性潰痬、子宮外孕、主動脈瘤、慢性肝病、腹膜炎
+ 非腹部：癌症（肺、卵巢、食道等）、唾液腺病變、過食、腎移植/腎功能不足、燒傷、酮酸中毒
+ Macroamylasemia

**Lipase 上升原因**
+ 胰臟疾病：同上
+ 非胰臟腹部（輕微上升）：同上
+ 非腹部：macrolipasemia、腎功能不足

> Amylase >5x 正常：幾乎一定是胰臟炎或腎病

### 急性胰臟炎（Acute Pancreatitis）

**病因（I GET SMASHED）**
+ **I**diopathic（特發性）：可能為高血壓性括約肌或微結石
+ **G**allstones（膽結石）（45%）
+ **E**thanol（酒精）（35%）
+ **T**umours（腫瘤）：胰臟、壺腹、choledochocele
+ **S**corpion stings（蠍子蟄傷）
+ **M**icrobiological：
  * 細菌：Mycoplasma、Campylobacter、TB、M. avium intracellulare、Legionella、Leptospira
  * 病毒：mumps、rubella、varicella、viral hepatitis、CMV、EBV、HIV、Coxsackie、echovirus、adenovirus
  * 寄生蟲：ascariasis、clonorchiasis、echinococcosis
+ **A**utoimmune：IgG4-related disease、SLE、polyarteritis nodosa
+ **S**urgery/trauma：ERCP 括約肌操作、心臟手術、腹部鈍傷、穿透性消化性潰痬
+ **H**yperlipidemia（TG >11.3 mmol/L；>1000 mg/dL）、hypercalcemia、hypothermia
+ **E**mboli/ischemia
+ **D**rugs/toxins：azathioprine、mercaptopurine、furosemide、estrogens、methyldopa、H2-blockers、valproic acid、antibiotics、acetaminophen、salicylates、methanol、organophosphates、steroids

**病理生理**
+ 胰臟細胞內胰蛋白酶原活化 → 局部及全身發炎反應
+ 膽石性：結石機械性阻塞胰管
+ 酒精性：發病機制不明

**病理**
+ 輕度（間質性）：peri-pancreatic 脂肪壞死、間質水腫
+ 重度（壞死性）：廣泛性 peri/intra-pancreatic 脂肪壞死；壞死合併出血（60%）；釋放毒性因子至全身循環（多器官衰竭）

**徵候與症狀**
+ 疼痛：上腹、持續性、非絞痛、可輻射至背部
+ 前傾可緩解（包含手指徵）
+ 黃疸：膽道壓迫/阻塞
+ Cullen's sign（臍周瘀青）/ Grey Turner's sign（腰側瘀青）：重症
+ 腹部膨脹：麻痺性腸阻塞
+ 發燒（化學性，非感染性）
+ 低血容性休克、ARDS、昏迷

**檢查**
+ 血清胰臟酶：amylase、lipase（lipase 更具特異性）
+ ALT >150：特異性指向膽道原因
+ WBC↑、血糖↑、血鈣↓
+ 影像：
  * X 光：「sentinel loop」（擴張近端空腸）、「colon cut-off sign」（結腸痙攣）
  * 超聲：評估膽道（敏感性 67%、特異性 100%）
  * CT with IV contrast：>1 天後最有價值；對診斷及預後最有幫助（壞死區域不顯影）
  * ERCP/MRCP：原因不明時；評估導管結石、胰臟/壺腹腫瘤、胰臟分隔

**分類**
+ 間質水腫型 vs 壞死型
+ 輕度：無器官衰竭、無局部併發症，<20% 壞死
+ 中度：短暂器官衰竭（<48h）或局部併發症
+ 重度：持續器官衰竭（>48h）

**Table 25. 胰臟炎局部併發症（Atlanta Classification 2012修訂版）**

| | 液體 | 固體 |
|--|------|------|
| **急性** | 急性胰周液體積聚（APFC） | 急性壞死併集（ANC） |
| **慢性** | 胰臟假囊腫 | 壞死包裹（WON） |

**治療**
+ 目標：血流動力學穩定、止痛、氧氣、阻止進展、治療局部及全身併發症
+ 抗生素：僅用於感染（cephalosporins、imipenem）；不建議預防性使用
+ 抽取壞死區域液體培養；感染時引流
+ IV fluids（crystalloid or colloid）；注意 third spacing
+ NG suction（嘔吐或胃擴張時）
+ 內視鏡括約肌切開術（重症膽石性胰臟炎）
+ 營養支持：NJ feeding tube 或 TPN（無法口服時）
+ 侵入性介入：引流、壞死清除（necrosectomy）；適應症：假囊腫或 WON 感染

### 慢性胰臟炎（Chronic Pancreatitis）

**定義**：胰臟持續性發炎 → 纖維化 → 不可逆性外/內分泌功能不足

**病因**：酒精（70-80%）、胰臟阻塞（創傷、狹窄）、囊腫纖維化、遺傳性（PRSS1、SPINK1、CFTR）、特發性

**臨床特徵**
+ 反覆上腹痛（飯後加劇）
+ 脂肪痢（steatorrhea）- 外分泌不足後期出現
+ 糖尿病 - 內分泌不足

**診斷**
+ 腹部 X 光：胰臟鈣化（~30%）
+ CT/MRCP：胰管擴張、狹窄、囊腫、萎縮
+ ERP（內視鏡逆行性胰管攝影）：金標準
+ Fecal elastase <200 μg/g = 外分泌不足

**治療**
+ 戒酒、戒菸
+ 止痛（acetaminophen、NSAIDs、tramadol；避免morphine 劑量過高）
+ 胰臟酶補充（脂肪痢治療）
+ 糖尿病控制
+ 內視鏡：胰管支架、結石移除
+ 手術：Pancreaticojejunostomy（Puestow）、胰臟切除

### 胰臟癌（Pancreatic Cancer）

+ 胰管腺癌（90%）；好發於胰頭（60-70%）
+ 風險因子：吸菸、慢性胰臟炎、diabetes、obesity、familial syndromes
+ 症狀：無痛性黃疸（胰頭）、體重減輕、腹痛（胰體/尾）、新發生 diabetes
+ 診斷：CT（首選）、MRCP、ERCP（細胞學）、CA 19-9（腫瘤標記）
+ 治療：
  * 可切除：Whipple procedure（胰十二指腸切除術）
  * 局部晚期：化放療
  * 轉移性：gemcitabine + nab-paclitaxel、FOLFIRINOX
+ 預後差（5 年存活率 <10%）
