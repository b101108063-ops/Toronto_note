## 導讀摘要

本章節涵蓋耳鼻喉科學的核心內容，摘要如下：

- **眩暈與聽力障礙**：BPPV、Ménière's disease、vestibular neuronitis、acoustic neuroma 的診斷與治療；conductive vs. sensorineural hearing loss 的鑑別與聽力檢查判讀
- **耳部疾病**：otitis externa、otitis media、cholesteatoma、otosclerosis、facial nerve palsy 的臨床表徵與處理原則
- **鼻部疾病**：allergic rhinitis、vasomotor rhinitis、acute/chronic rhinosinusitis 的分類治療；epistaxis 的急救處理
- **喉部與發聲障礙**：acute/chronic laryngitis、vocal cord polyps/nodules、recurrent respiratory papillomatosis、laryngeal carcinoma 的鑑別診斷
- **頭頸部腫瘤與頸部腫塊**：H&N malignancy 的風險因子與分期；branchial cleft cyst、thyroglossal duct cyst 的診療；甲狀腺結節的評估與甲狀腺癌的分類治療

## 耳鼻喉科學概論

### 眩暈（Dizziness）的鑑別診斷

眩暈是指旋轉性、直線性或傾斜感的錯覺，為自我或環境的移動幻覺，由周邊（內耳）或中樞（腦幹—小腦）刺激所產生。臨床上區分眩暈與其他「頭暈」原因相當重要。

**周邊型與中樞型眩暈的比較**

| 症狀 | 周邊型 | 中樞型 |
|------|--------|--------|
| 失衡 | 中度至重度 | 輕度至中度 |
| 噁心嘔吐 | 重度 | 不定 |
| 聽覺症狀 | 常見 | 罕見 |
| 神經學症狀 | 罕見 | 常見 |
| 代償 | 快速 | 緩慢 |
|眼球震顫 | 單向性 | 雙向性 |
| | 水平或旋轉性 | 水平或垂直性 |

**中樞型眩暈的警示徵象**

- 急性發作且持續
- 正常 head impulse test
- 多向性眼球震顫
- Skew deviation 存在
- 椎基底動脈功能不全：drop attacks、複視、構音障礙、吞嚥困難

**Otalgia（耳痛）——牽涉性疼痛**

耳朵的感覺神經支配來自 CN V、VII、IX 和 X，因此許多來源的可引起 otalgia。

**引起 Otalgia 的 10 個 T（The 10 Ts of Referred Pain）**

1. **Teeth（牙齒）**
2. **TMD**：Temporomandibular Joint Disease（顳顎關節疾病）
3. **Tubal Area**：Eustachian tube dysfunction、nasopharynx（鼻咽，須排除腫瘤）
4. **Tonsils**：感染、腫瘤
5. **Throat**：咽部感染、腫瘤、larynx（發聲盒）
6. **Tongue**：發炎、腫瘤
7. **Trachea/Larynx**：感染、腫瘤
8. **Temporal Arteritis**：耳朵上方动脉的發炎
9. **Trauma（創傷）**

## 聽覺生理學與聽力檢查

### 正常聽覺生理學

**傳導路徑（Conductive Pathway）**

聲音的 AC 傳導：外耳道（EAC）→ 鼓膜（TM）振動 → 聽覺小骨順序振動（malleus、incus、stapes）→ stapes footplate 將放大後的振動傳至耳蝸卵圓窗 → 振動透過耳蝸液刺激基底膜產生移動

**神經路徑（Neural Pathway）**

基底膜振動刺激蓋膜（organ of Corti）上方的毛細胞 → 刺激耳蝸神經（CN VIII）之分離神經節（spiral ganglion）的雙極神經元 → 訊號傳遞至：耳蝸核 → 上橄欖核 → 外側蹄系 → 下丘 → 顳葉 Sylvian fissure

**聽神經路徑時序（ABR 各波與解剖位置對應）**

- I：第八對腦神經（CN VIII）
- II：耳蝸核（Cochlear nucleus）
- III：上橄欖核（Superior olivary nucleus）
- IV、V：外側蹄系（Lateral lemniscus）
- V：下丘（Inferior colliculus）

### 聽力損失的類型

1. **Conductive Hearing Loss（傳導性聽力損失）**
   - 聲音傳至耳蝸的傳導受損
   - 可由外耳及/或中耳疾病引起

2. **Sensorineural Hearing Loss（感音神經性聽力損失）**
   - 聲音轉換為神經訊號或訊號傳至皮質的過程缺陷
   - 可由內耳（耳蝸）、聽神經（CN VIII）、腦幹或皮質疾病引起

3. **Mixed Hearing Loss（混合性聽力損失）**
   - CHL 和 SNHL 的組合

### 聽覺敏銳度檢查

**Whispered-voice test**：遮住一耳，對另一耳輕聲說話

** Tuning fork tests（音叉測驗）**

- **Rinne test**
  - 512 Hz 音叉置於乳突測 BC，再置於耳旁測 AC
  - AC > BC → 正向 Rinne（正常）
  - BC > AC → 負向 Rinne（異常）

- **Weber test**
  - 512 Hz 音叉置於頭頂正中央
  - 聽力正常或兩側 SNHL：中央聽見（Weber 陰性）
  - 若兩耳聽力差異 >6 dB，則會偏向一側
  - **Weber 偏向同側 → 該側 CHL 或對側 SNHL**
  - Weber test 偵測 CHL 的敏感度比 Rinne test 更高

**表：音叉測驗判讀**

| 情況 | Weber | Rinne（右耳） |
|------|-------|--------------|
| 正常或兩側 SNHL | 中央 | AC>BC（+）雙側 |
| 右側 CHL，左耳正常 | 偏向右 | BC>AC（-）右側 |
| 右側 SNHL，左耳正常 | 偏向左 | AC>BC（+）雙側 |
| 右側重度 SNHL 或死耳，左耳正常 | 偏向左 | BC>AC（-）右側 |

### Pure Tone Audiometry（純音聽力檢查）

- **Threshold**：患者能在 50% 聽到刺激的最低強度
- 檢測頻率：250、500、1000、2000、4000、8000 Hz
- AC（氣導）：頭戴耳機，評估外耳、中耳、內耳及聽神經功能
- BC（骨導）：骨導振盪器，繞過外耳和中耳

**聽損程度（以 500、1000、2000 Hz 的平均閾值判定）**

| 程度 | 範圍 |
|------|------|
| Normal | -10–15 dB |
| Slight | 16–25 dB |
| Mild | 26–40 dB |
| Moderate | 41–55 dB |
| Moderately Severe | 56–70 dB |
| Severe | 71–90 dB |
| Profound | >90 dB |

**聽力圖判讀重點**

- **Conductive Hearing Loss**：BC 正常，AC 異常，空氣—骨導差距 >10 dB
- **Sensorineural Hearing Loss**：AC 和 BC 皆低於正常，差距 <10 dB（無空氣—骨導差距）
- **Noise-induced HL**：典型於 4000 Hz（"boilermaker's notch"）
- **Otosclerosis**：典型於 2000 Hz（Carhart's notch）

### Speech Audiometry

**Speech Reception Threshold（SRT）**

- 能重複 50% 雙音節詞（如 baseball、cupcake）的最低聽力級
- SRT 與 500–2000 Hz 的最佳純音閾值通常在 5 dB 內相符

**Speech Discrimination Test**

- 在 SRT 以上 40 dB 測試，50 個單音節詞的正確率
- 正常聽力或 CHL：>90%
- Rollover effect（閾值上調時分辨力下降）：典型於回歸性病變（如 acoustic neuroma）

### Impedance Audiometry

**Tympanogram（鼓室圖）**

- 測量中耳系統在不同壓力下的順應性
- 正常：峰值約在 0 mmH₂O（範圍 -100 至 +50 mmH₂O）

| 類型 | 特徵 | 常見病因 |
|------|------|----------|
| Type A | 正常壓力峰值 | 正常、中耳積液（otospongiosis 峰值仍在 0 但振幅降低） |
| Type B | 無峰值 | 鼓膜穿孔、積液、膠耳（glue ear） |
| Type C | 負壓峰值 | Eustachian tube dysfunction、早期 otitis media without effusion |

**Static Compliance**

- 正常範圍：0.3–1.6 cc

**Acoustic Stapedial Reflexes**

- 正常：在 70–100 dB（高於聽閾）
- Cochlear HL：反射閾值 25–60 dB
- Retrocochlear HL（acoustic neuroma）：反射消失或顯著反射衰減（5 秒內 >50%）

### Auditory Brainstem Response（ABR）

- 測量 5 個不同解剖部位的神經電位（波）
- 腦幹反應延遲 → 耳蝸或回歸性病變
- 不需患者主觀配合（對兒童或詐病者有用）

### Otoacoustic Emissions（OAE）

- 點擊刺激後耳蝸產生的回聲
- 來自外毛細胞（為內毛細胞功能的指標）
-常用於新生兒聽力篩檢

### Aural Rehabilitation

**助聽器類型**

- **BTE**：掛耳式
- **ITE**：耳內式
- **ITC**：耳道式
- **CIC**：深耳道式
- **BAHA**：骨錨式助聽器（骨導）
- **CROS**：對側訊號路由

## 周邊眩暈疾病

### Benign Paroxysmal Positional Vertigo（BPPV）

**定義**

- 短暫性（<1 分鐘）旋轉性眩暈的急性發作，由特定頭位變化所引發，伴隨 torsion（旋轉性）眼球震顫（geotropic = 快相朝向地板）
- 最常見的姿勢性眩暈形式（50% 的周邊前庭功能障礙患者有 BPPV）

**病因**

- Canalithiasis（耳石游離飄浮於半規管內淋巴中）或 cupulolithiasis（耳石附著於半規管 cupula）
- >90% 影響後半規管
- 病因：頭部外傷、病毒感染（URTI）、退化性疾病、特發性

**診斷**

- Dix-Hallpike maneuver（敏感度 82%，特異度 71%）
- 患者從坐位快速躺下，頭部懸於床沿，向一側轉 45°，頸部後仰 20°，維持 20 秒
- 出現眩暈和旋轉性眼球震顫 → 該側陽性を

**治療**

- 粒子重新定位手法：Epley maneuver、Brand-Daroff exercises
- 止吐劑
- 藥物抑制前庭系統會延遲康復，故不建議使用

### Ménière's Disease（內淋巴水腫）

**定義**

- 發作性眩暈、耳鳴、聽力損失、耳悶感，持續分鐘至數小時

**病因**

- 內淋巴吸收不足 → 內淋巴水腫（過度堆積）→ 膜性迷路變形

**診斷標準（確定性）**

- 眩暈發作 2 次或以上，每次 20 分鐘至 12 小時
- 聽力學確認的 SNHL（低至中頻）
- 波動性耳鳴和/或耳悶感

**臨床特徵**

- 發作性眩暈、波動性低頻 SNHL、耳鳴、耳悶感、± drop attacks（Tumarkin crisis）、± 噁心嘔吐
- 眩暈會消失（分鐘至小時），但 SNHL 持續
- 晚期：持續性耳鳴、進行性 SNHL
- 誘發因素：高鹽、咖啡因、壓力、尼古丁、酒精

**治療**

- 急性：臥床休息、止吐劑、抗眩暈藥（如 betahistine、meclizine、diphenhydramine）、抗膽鹼劑（如 scopolamine）
- 長期：低鹽飲食、利尿劑、過敏控制、betahistine 預防
- 對側耳需監測（35% 為雙側）
- 頑固性：選擇性前庭神經切除術、迷路切除術

### Vestibular Neuronitis / Labyrinthitis

**定義**

- 急性發作的失能性眩暈，常伴隨噁心嘔吐和失衡，無聽力損失，數天內緩解，但殘留失衡持續數天至數週
- Vestibular neuronitis：CN VIII 前庭部分的發炎
- Labyrinthitis：前庭和耳蝸部分皆有發炎

**病因**

- 病毒感染（如 measles、mumps、herpes zoster）或感染後症候群
- Labyrinthitis 可作為 AOM、慢性中耳炎、細菌性腦膜炎、cholesteatoma 及顳骨骨折的併發症

**臨床特徵**

- 急性期：嚴重眩暈伴噁心嘔吐，持續 1–5 天；眼球震顫朝向患病側；患者傾向朝患側偏移
- 康復期：失衡和暈動病持續數天至數週；自發性眼球震顫遠離患側

**治療**

- 急性期：臥床休息、前庭抑制藥、皮質類固醇 + 抗病毒藥
- 康復期：漸進活動、前庭康復訓練

### Acoustic Neuroma（Vestibular Schwannoma）

**定義**

- CN VIII 前庭部分的 Schwannoma

**臨床特徵**

- 通常以單側 SNHL（慢性）或耳鳴表現
- 眩暈和不平衡可能存在，但因腫瘤生長緩慢允許代償，典型眩暈罕見
- 面部神經麻痺和 trigeminal（V1）感覺缺陷為晚期併發症

**診斷**

- MRI with gadolinium（gold standard）
- Audiogram：SNHL 伴言語分辨力相對差
- ABR：第 V 波潛時延長

**治療**

- 小腫瘤或老年人：觀察
- 明確治療：手術切除
- 其他選項：gamma knife、放射治療

## 耳部疾病

### 外耳疾病

#### Cerumen Impaction（耳垢嵌塞）

- **病因**：耳垢為 ceruminous 和 pilosebaceous 腺體分泌物、表皮鱗屑、灰塵和碎屑的混合物
- **風險因子**：毛髮多或耳道窄、助聽器、棉花棒使用、骨疣
- **臨床特徵**：CHL、耳鳴、悶脹感、癢、耳痛、引流、臭味、咳嗽
- **治療**：觀察、cerumenolytic 製劑、灌洗、手動移除

#### Exostoses（外耳道骨質增生）

- 由層狀骨組成的外耳道骨質突起
- 與冷水游泳可能相關
- 通常為偶然發現
- 治療：無症狀不需治療

#### Otitis Externa（外耳炎）

**定義**

- 外耳道或耳廓的發炎

**病因**

- 細菌性（90%）：Pseudomonas aeruginosa、E. coli、S. aureus
- 真菌性：Candida albicans、Aspergillus niger

**風險因子**

- 解剖異常：耳道狹窄、骨疣、毛髮多
- 耳道阻塞：耳垢、異物、皮脂囊腫
- 表皮完整性受損：耳垢移除、耳塞、助聽器、搔抓
- 皮膚病：濕疹、牛皮癬、脂漏
- 耳道進水：游泳

**臨床特徵**

- 急性：耳痛、癢、悶脹感、± CHL；耳道疼痛在咀嚼時加劇；拉耳廓極度疼痛；耳道水腫、紅斑、± 滲出、± 區域淋巴結炎
- 慢性：外耳慢性搔癢；表皮襯裡萎縮和鱗屑，± 滲出、± CHL；開口寬大，但 auricle 移動時無疼痛

**治療**

- 微清創
- 局部抗菌 + 局部抗生素 + 局部類固醇
- 抗綠膿桿菌製劑（如 ciprofloxacin）
- 耳毒性局部製劑（如 gentamicin、neomycin）不用於穿孔 TM
- 保持耳道乾燥
- 口服抗生素（感染擴散至耳道外時）

#### Malignant Otitis Externa（惡性/壞死性外耳炎）

**定義**

- 乳突或顳骨的骨髓炎

**流行病學**

- 老年患者、DM、免疫抑制患者

**病因**

- OE 的罕見併發症
- 最常見：Pseudomonas aeruginosa

**臨床特徵**

- 頑固性 otalgia 和化膿性耳漏
- 耳道底部肉芽組織或壞死組織

**併發症**

- 腦神經麻痺（最常見 CN VII > CN X > CN XI）
- 全身性感染、死亡

**治療**

- 影像學：高分辯率顳骨 CT、gadolinium 增強 MRI
- 住院、静脈抗生素、清創

### 中耳疾病

#### Acute Otitis Media（AOM）

詳見《小兒耳鼻喉科學》章節。

#### Chronic Otitis Media

- **慢性漿液性 OM**：中耳持續性漿液（稻草色）液體
- **慢性化膿性 OM**：持續性（>6 週）化膿性引流通過穿孔 TM 或通氣管

#### Cholesteatoma（膽脂瘤）

**定義**

- 由角化脫屑上皮細胞組成，發生於中耳、乳突和顳骨

**分類**

- **先天性**：表現為完整 TM 後方的「小白珠」（前內側於 malleus）或 CHL；與中耳炎或 Eustachian tube dysfunction 無關
- **後天性**（更常見）：
  - 原發性：常與 pars flaccida、pars tensa 的回縮口袋相關
  - 續發性：由 TM 邊緣穿孔後上皮遷徙

**臨床特徵**

- 進行性 CHL（顯著傳導性，晚期可能有 SNHL）
- 耳痛、耳悶、發燒
- TM 回縮口袋含角化碎屑；TM 穿孔；肉芽組織、息肉；單側惡臭耳漏

**併發症**

- 局部：聽小骨侵蝕、內耳侵蝕（SNHL、眩暈、迷宮炎）、顳骨感染（乳突炎、岩部炎）、面部麻痺
- 顱內：腦膜炎、硬膜外/硬膜下/小腦膿腫、乙狀竇血栓

**治療**

- 手術：乳突切除術 + 鼓室成形術 + 聽小骨重建

#### Mastoiditis（乳突炎）

**定義**

- 乳突氣房的感染（通常為骨膜下），最常見於 AOM 未治療或治療不當後約兩週

**病因**

- 與 AOM 相同病原：S. pneumoniae、H. influenzae、M. catarrhalis、S. pyogenes、S. aureus、P. aeruginosa

**臨床特徵**

- 耳漏
- 乳突壓痛
- 耳後腫脹伴耳廓突出
- 發燒、CHL、± TM 穿孔（晚期）

**治療**

- 靜脈抗生素 + 鼓膜切開術和通氣管（急性期通常足夠）
- 可能需額外切開引流耳後膿腫
- 皮質乳突切除術

#### Otosclerosis（耳硬化症）

**定義**

- stapes footplate 融合於卵圓窗，無法振動

**病因**

- 體染色體顯性，變異滲透率約 40%
- 女 > 男，懷孕期間進展（激素反應性）

**臨床特徵**

- 青少年或二十歲出頭首次注意到的進行性 CHL（可能進展為 SNHL）
- 非搏動性耳鳴
- TM 正常 + 粉紅色 Blush（Schwartz's sign）與骨硬化新血管化相關
- 聽力圖在 2000 Hz 有特徵性凹陷（Carhart's notch）

**治療**

- 觀察（若能應對聽損）
- 助聽器（BAHA）
- Stapedectomy 或 stapedotomy（雷射或電鑽）→ 明確治療

## 內耳疾病

### Congenital Sensorineural Hearing Loss（先天性感音神經性聽力損失）

**遺傳缺陷**

- 非症候群性（70%）：通常為特發性，體隱性；connexin 26（GJB2 基因）最常見
- 症候群性（30%）：
  - Waardenburg：白色額髮、異色虹膜、寬鼻樑、內眼角距離增加
  - Pendred：甲狀腺功能正常的甲狀腺腫、SLC26A4 基因、擴大的前庭水管
  - Treacher-Collins：第一和第二鰓裂異常
  - Alport：遺傳性腎炎

**風險因子**

- 家族聽力損失史、顱面異常、產前感染（TORCH）、產後感染（細菌性腦膜炎、腮腺炎、麻疹）、NICU 停留 >2 天、極早產、溶血需要換血、ototoxic 藥物

**治療**

- 有風險因子的嬰兒：在離開 NICU 前和糾正年齡 3 個月時進行 ABR 檢查
- 早期康復改善語言和學校表現

### Presbycusis（老年性聽力損失）

**定義**

- 與老化相關的 SNHL（始於 50-60 歲）

**臨床特徵**

- 進行性、雙側聽力退化，早期為高頻，漸及中低頻
- 言語分辨力減退（尤其在背景噪音下）——患者描述別人像在喃喃自語
- Recruitment 現象：無法忍受大聲音
- 耳鳴

**治療**

- 助聽器（若功能困難、HL >30–35 dB 且言語分辨良好）
- 唇讀、聽力訓練、聽覺輔具

### Sudden Sensorineural Hearing Loss（突發性感音神經性聽力損失）

**病因**

- 通常為特發性（80–90%）；需排除其他原因
  - 自體免疫、感染（EBV、HSV、herpes-zoster、HIV、Lyme disease、腦膜炎、梅毒）
  - 創傷、血管（腦血管疾病）、腫瘤

**臨床特徵**

- 突然顯著 SNHL（通常單側）± 耳鳴、眩暈、耳悶

**治療**

- 治療根本原因
- MRI（排除腫瘤）或 CT（排除缺血/出血性中風）
- 特發性：耳內或口服皮質類固醇（prednisone 1 mg/kg/d，7–14 天）。在發病後 3 天內（最理想）至 14 天內開始

**預後**

- 70% 在 10–14 天內緩解
- 20% 部分緩解
- 10% 永久性聽力損失

### Drug Ototoxicity（藥物耳毒性）

**Aminoglycosides**

- Streptomycin 和 gentamicin（前庭毒性）；kanamycin 和 tobramycin（耳蝸毒性）
- 經任何途徑皆對毛細胞有毒性：口服、靜脈、局部（若 TM 穿孔）
- 破壞感覺毛細胞：先外毛細胞，後內毛細胞
- 高頻聽力損失最早出現
- 毒性在治療後數天至數週出現
- 必須監測 peak 和 trough 濃度
- 建議 q24h 給藥（由 creatinine clearance 決定劑量）

**止痛退燒藥**

- Acetaminophen、NSAIDs、salicylates：聽力損失伴耳鳴，停藥可逆

### Noise-Induced Sensorineural Hearing Loss（噪音性感音神經性聽力損失）

**致病機制**

- 85–90 dB 持續數月或數年、單次聲音脈衝 >135 dB 或重複振動損傷
- 雙側 SNHL，早期且最顯著於 4000 Hz（顳骨共振頻率），稱為「boilermaker's notch」

**分期**

- 暫時性閾值偏移：移除噪音後聽力恢復正常
- 永久性閾值偏移：聽力不再恢復

**預防**

- 耳保護器（耳罩、耳塞）
- 限制噪音暴露頻率
- 定期聽力追蹤

### Temporal Bone Fractures（顳骨骨折）

| 特徵 | 涉及耳囊 | 不涉及耳囊 |
|------|----------|------------|
| 延伸至 | 骨迷路和內聽道 | 中耳 |
| 發生率 | 10–20% | 70–90% |
| 病因 | 前額—枕部創傷 | 側面撞擊創傷 |
| 聽神經麻痺 | 60% | 10–20% |
| 聽力損失 | SNHL（直接耳蝸損傷） | CHL（聽小骨損傷） |
| 前庭症狀 | 突發眩暈 | 罕見 |

**顱底骨折徵象**

- Battle's sign：乳突瘀斑
- Raccoon eyes：眼眶瘀斑
- CSF rhinorrhea/otorrhea
- Hemotympanum

## Facial Nerve（CN VII）麻痺

### 周邊型面部麻痺

**病因（KITTENS）**

- **K**：先天性
- **I**：感染/特發性
- **T**：創傷/毒素
- **T**：腫瘤
- **E**：內分泌
- **N**：神經學
- **S**：系統性

**鑑別：Bell's Palsy vs. Ramsay Hunt Syndrome**

| 特徵 | Bell's Palsy | Ramsay Hunt Syndrome |
|------|-------------|---------------------|
| 病因 | 特發性（可能 HSV） | 水痘—帶狀皰疹病毒 |
| 發生率 | 80–90% 的周邊型面部麻痺 | 10% 的周邊型面部麻痺 |
| 聽力症狀 | 感音神經性聽力損失（少見） | SNHL（常見） |
| 皮疹 | 無 | 耳廓、外耳道皰疹 |
| 預後 | >80% 完全康復 | 較差；22% 完全康復 |

**治療**

- 依病因治療
- 提供角膜保護：人工淚液、夜間眼瞼貼合、tarsorrhaphy
- 特發性：嚴重至完全麻痺時皮質類固醇 + 抗病毒藥

## 鼻部疾病

### Rhinitis（鼻炎）的分類

| 類型 | 範例 |
|------|------|
| 過敏性 | 季節性、常年性 |
| 非過敏性 | 血管運動性、萎缩性、藥物性 |
| 感染性 | 病毒性、細菌性、真菌性 |
| 內分泌性 | 懷孕、雌激素、甲狀腺 |
| 誘發性 | 灰塵、化學物質、污染 |

### Allergic Rhinitis（過敏性鼻炎）

**定義**

- 對外來過敏原的 IgE 媒介過敏反應

**臨床特徵**

- 鼻塞、鼻子癢、流鼻水（水性）、打噴嚏、嗅覺減退
- ± 過敏性結膜炎
- 季節性：因花粉（樹、草、豚草）
- 常年性：因塵蟎糞便、蟑螂殘留物、動物皮屑、黴菌、菸草煙霧

**診斷**

- 病史、鼻窺檢查（鬱血灰/藍色鼻甲）、過敏測試

**治療**

- 過敏原識別和避免
- 鼻腔鹽水沖洗
- 口服抗組織胺
- **鼻腔類固醇（主要治療）**
- 組合製劑（類固醇 + 抗組織胺）
- 白三烯受體拮抗劑
- 過敏原免疫療法

### Vasomotor Rhinitis（血管運動性鼻炎）

**定義**

- 由傷害感受器和自主神經失調導致血管通透性增加引起的鼻炎

**病因**

- 溫度變化、酒精、灰塵、菸霧、壓力、焦慮

**臨床特徵**

- 慢性間歇性鼻塞（兩側交替）
- 需排除鼻腔過敏

**治療**

- 刺激物消除
- 以鼻塞為主：鼻腔抗組織胺 + 口服去充血劑（注意 rhinitis medicamentosa）
- 以流鼻水為主：鼻腔抗膽鹼劑（如 ipratropium）

### Rhinosinusitis（鼻竇炎）

**分類**

- 急性：<4 週
- 亞急性：4–12 週
- 慢性：>12 週

**急性細菌性鼻竇炎**

**定義**

- 鼻竇和鼻腔的細菌感染，持續 >7 天

**病因**

- 細菌：S. pneumoniae（35%）、H. influenzae（35%）、M. catarrhalis、S. aureus、厭氧菌（牙齒性）
- 上頜竇最常受影響

**臨床特徵**

- 突然發作：鼻塞/充血、膿性鼻漏或後鼻滴漏、± 面部疼痛或壓力、± 嗅覺減退、± 喉痛
- 持續 >10 天或惡化 >5 天或持續膿性分泌物 3–4 天伴高燒（≥39°C）
- 鼻腔鏡：紅色黏膜、中鼻道膿性分泌物

**診斷標準（主要症狀需 ≥2 項，且至少一項為 O 或 D）**

| 字母 | 症狀 |
|------|------|
| P | 面部疼痛/壓力/脹滿感 |
| O | 鼻塞 |
| D | 膿性/變色鼻漏 |
| S | 嗅覺減退/失嗅（Smell） |

**管理**

- 輕度—中度：INCS（鼻腔類固醇）
- 重度：INCS + 抗生素
- 抗生素第一線：amoxicillin × 10 天（penicillin 過敏者用 TMP-SMX 或 macrolide）

**急性鼻竇炎併發症（需住院）**

- 眼眶：Chandler's 分類（術前蜂窩組織炎 → 眼眶蜂窩組織炎 → 骨膜下膿腫 → 眼眶膿腫 → 海綿竇血栓）
- 顱內：腦膜炎、膿腫
- 骨：額骨骨膜下膿腫（Pott's puffy tumour）、骨髓炎
- 神經：眶上裂症候群、眶尖症候群

**慢性鼻竇炎**

**定義**

- 鼻竇和鼻腔黏膜發炎 >12 週

**管理**

- 確認並處理促成因素
- 抗生素 3–6 週
- 有息肉：INCS、口服類固醇 + 抗生素 → 轉介耳鼻喉科
- 無息肉：INCS、抗生素、鹽水沖洗、口服類固醇（嚴重時）
- 藥物治療失敗：功能性鼻竇內視鏡手術（ESS）、balloon sinuplasty

### Epistaxis（鼻出血）

**解剖**

- 90% 的鼻出血發生在鼻中隔前下部（Little's area）
- Kiesselbach's plexus：上唇動脈、鼻中隔前後篩狀动脉的吻合

**治療**

1. **初步處理**
   - 讓患者身體前傾
   - 穩定加壓鼻軟骨部分（不是骨性鼻錐）15–20 分鐘

2. **確認出血位置**
   - 鼻腔窺鏡
   - 含 lidocaine + 去充血劑的棉拭子幫助識別

3. **止血**
   - 第一線：局部去充血劑
   - 失敗且可視：硝酸銀燒灼（單側，否則有穿孔風險）
   - **前出血**：前鼻塞（Merocel、 Rapid Rhino）或可吸收填塞物
   - **後出血**：後鼻塞（Foley 導管、Epistat 氣球）→ 住院 3 天

4. **預防**
   - 保濕、避免刺激物、控制高血壓和凝血病

## 喉部疾病

### Hoarseness（聲音嘶啞）的鑑別診斷

| 類別 | 範例 |
|------|------|
| 感染性 | 急性/慢性 laryngitis |
| 發炎性 | Laryngotracheobronchitis（croup）|
| 創傷性 | 聲帶息肉/結節、吸煙、慢性酒精使用 |
| 外部喉部創傷 | 內視鏡/氣管插管（如插管肉芽腫）|
| 腫瘤 | 良性腫瘤、乳頭狀瘤（HPV）、minor salivary gland 腫瘤 |
| 囊腫 | 保留囊腫 |
| 內分泌 | 甲狀腺功能減退 |
| 神經性 | 腦血管中風（聲帶麻痺）、創傷性 |
| 先天性 | Laryngomalacia、喉部蹼 |

> **警示**：吸煙者聲音嘶啞 >2 週 → 必須進行 laryngoscopy 排除惡性腫瘤

### Vocal Cord Paralysis（聲帶麻痺）

- **單側**：聲帶位於旁正中位置，發聲時聲門關閉不全 → 微弱、氣息性聲音。通常隨時間內收，發聲和誤吸改善
- **雙側**：聲帶靜止於正中位置，聲音不變但呼吸功能受損（可能為喘鳴）
- 肺癌是聲帶麻痺最常見的原因

### Acute Laryngitis（急性喉炎）

**定義**

- 接觸誘發因素後，喉黏膜 <2 週的發炎變化

**病因**

- 感染性（最常見）：病毒（流感、腺病毒、HSV）、細菌（A 群鏈球菌）、黴菌
- 機械性：急性發聲過度 → 黏膜下出血 → 聲帶水腫 → 嘶啞
- 環境：有毒氣體吸入

**臨床特徵**

- URTI 症狀、嘶啞、失聲、咳嗽發作
- 聲帶充血/水腫伴血管注射，活動正常

**治療**

- 通常自限性，1–2 週內緩解
- 聲音休息、保濕、補液
- 避免刺激物
- 有細菌性咽炎共存時抗生素治療
- 有胃食道逆流證據時質子泵抑制劑治療

### Chronic Laryngitis（慢性喉炎）

**定義**

- 喉黏膜 >3 週的發炎變化

**病因**

- 反覆急性喉炎發作、慢性發聲過度、菸酒、GERD、甲狀腺功能減退

**臨床特徵**

- 慢性發聲障礙、咳嗽、globus 感覺（咽喉異物感）
- Laryngoscopy：聲帶充血增厚伴潰瘍/肉芽組織

**治療**

- 消除刺激物
- 治療相關疾病（如逆流病的抗分泌治療）
- 語言治療搭配聲音休息

### Vocal Cord Polyps（聲帶息肉）

**定義**

- 聲帶刺激的結構表現
- 急性：極度發聲時黏膜下毛細血管損傷

**臨床特徵**

- 主要症狀：發聲障礙 + 息肉大時呼吸困難
- 單側、不對稱、軟、光滑、紡錘形或帶蒂

**治療**

- 避免刺激物
- 語言治療可改善聲音
- 持續性或惡性風險高：內視鏡顯微手術切除

### Vocal Cord Nodules（聲帶結節）

**定義**

- 聲帶繭，雙側且對稱
- 又稱「screamer's」或「singer's」結節

**臨床特徵**

- 一天結束時嘶哑最嚴重
- Laryngoscopy：雙側對稱結節，位於聲帶前 1/3 和後 2/3 交界處

**治療**

- 主要治療：聲音休息和語言治療
- 補水、避免刺激物
- 頑固性才考慮手術

### Recurrent Respiratory Papillomatosis（復發性呼吸道乳頭狀瘤病）

**定義**

- 呼吸道的小良性疣狀生長（乳頭狀瘤）

**病因**

- 最常見 HPV 6、11 型

**臨床特徵**

- 進行性嘶哑、喘鳴、呼吸窘迫
- 可能植入氣管支氣管樹
- 對完全切除高度抵抗，復發傾向高
- 可能惡性轉化為鱗狀細胞癌

**治療**

- CO₂ 或 KTP 雷射顯微喉鏡懸吊切除
- 高復發患者：系統性輔助治療（HPV 重組疫苗、bevacizumab、cidofovir）

## 唾液腺疾病

### Sialadenitis（唾液腺炎）

**定義**

- 唾液腺的發炎

**病因**

- 病毒最常見（腮腺炎）
- 細菌：A. aureus、S. pneumoniae、H. influenzae

**臨床特現**

- 急性疼痛和口水腺（腮腺或頜下腺）水腫 ± 發燒
- ± 白血球增加、腺體排出孔化膿性引流

**治療**

- 按摩、止痛/抗生素、催涎劑、熱敷/補水
- 細菌性：cloxacillin + 膿腫引流

### Sialolithiasis（唾液腺結石）

**定義**

- 導管結石（主要為成年人羥基磷灰石，兒童為沙/淤泥），導致慢性唾液腺炎
- 80% 在頜下腺，<20% 在腮腺

**臨床特徵**

- 患側疼痛和壓痛
- 與進食相關的間歇性腫脹

**治療**

- 可能自發緩解
- 催涎、手動表達、止痛、抗生素、催涎劑（如檸檬）
- 內視鏡或手術移除

### Salivary Gland Neoplasms（唾液腺腫瘤）

| 位置 | 比例 |
|------|------|
| 腮腺 | 70–85% |
| 頜下腺 | 8–15% |
| 舌下腺 | 1% |
| 小唾液腺 | 5–8% |

- 腮腺：80% 良性（最常見：pleomorphic adenoma），20% 惡性（最常見：mucoepidermoid）
- 雙側腮腺腫瘤 → 考慮良性過程（如 Warthin's tumour）或淋巴瘤

**治療**

- 所有唾液腺腫瘤的手術為首選
- Pleomorphic adenoma 因惡性轉化風險需切除
- 腮腺手術併發症：血腫、感染、唾液瘻、面部部分/完全麻痺、Frey's syndrome（味覺性出汗）、sialocele

## 頸部腫塊

### 頸部腫塊的評估

**年齡相關 differential diagnosis**

| 年齡 | 常見原因 |
|------|----------|
| <20 歲 | 先天性 |
| 20–40 歲 | 發炎性 |
| >40 歲 | 腫瘤性 |

### 先天性頸部腫塊

#### Branchial Cleft Cysts/Sinuses/Fistulae（鰓裂囊腫/竇道/瘻管）

**胚胎學**

- 第二鰓裂畸形最常見
- 囊腫：無外口的光滑、無痛、緩慢增大的側頸腫塊（URTI 後常見增大）
- 竇道/瘻管：嬰兒期顯現，SCM 肌前緣小開口

**治療**

- 囊腫或竇道/瘻管手術移除
- 若感染：待感染控制後再手術（可能需要抗生素）

#### Thyroglossal Duct Cysts（甲狀舌管囊腫）

**胚胎學**

- 甲狀腺從舌底盲孔向下遷移過程中的殘留遺跡

**臨床特徵**

- 最常見的先天性頸部囊腫
- 通常在童年或 20–40 歲顯現
- 中線囊腫，隨 URTI 增大，吞嚥和舌頭伸出時上升

**治療**

- Sistrunk 手術：囊腫完整切除 + 管道組織至舌根 + 舌骨中央部分切除

#### Lymphatic/Venous Malformations（淋巴/靜脈/混合淋巴靜脈畸形）

**臨床特徵**

- 通常 2 歲前顯現
- Macro cystic：軟、可壓縮的腫塊
- Micro cystic：軟、不可壓縮伴黏膜或皮膚囊泡

**治療**

- 感染後可能自發消退（手術推遲至感染後數月）
- Macro cystic：手術切除或硬化治療（doxycycline）
- Micro cystic：困難，可減積或硬化治療（bleomycin）

## 頭頸部腫瘤

### 癌前病變

| 病變 | 特徵 | 惡性轉化風險 |
|------|------|-------------|
| Lichen planus | 口腔黏膜白色花邊樣線 | 5–10% |
| Leukoplakia | 無法擦除的白斑 | 5–20% |
| Erythroplakia | 鄰近正常黏膜的紅色斑塊 | ~40% 有原位癌或侵襲性腫瘤 |

### Head and Neck 惡性腫瘤概述

**風險因子**

- 吸菸、酒精（與吸菸有協同作用）
- 輻射、職業/環境暴露
- 口腔 HPV 感染（與吸菸和酒精無關）
- 癌症家族史

**常見病理類型**

- 鼻口腔：95% 鱗狀細胞癌（SCC）
- 口咽：SCC（HPV 相關性增加）
- 喉：SCC 最常見

**治療原則**

- 口腔 cavity 惡性腫瘤：首選手術，放射治療保留作為 salvage 或不良預後指標
- Nasopharynx、oropharynx、hypopharynx、larynx 惡性腫瘤：首選放射治療，手術保留用於 salvage
- 化學治療作為誘導治療

### 甲狀腺癌

**分類**

| 類型 | 發生率 | 特徵 |
|------|--------|------|
| Papillary（乳頭狀） | 80–90% | 最多見、預後最好 |
| Follicular（濾泡狀） | 5–15% | 血性傳播 |
| Medullary（髓質癌） | 5% | 可能分泌 calcitonin、與 MEN II 相關 |
| Anaplastic（未分化） | <5% | 老年人、迅速增大、預後差 |

**甲狀腺結節評估**

- 所有甲狀腺結節患者需評估血清 TSH 和甲狀腺超聲
- **Bethesda 細胞學分類系統**

| Bethesda 分類 | 惡性風險 |
|---------------|----------|
| 非診斷性 | 1–4% |
| 良性 | 0–3% |
| 意義不明的異型性/不典型（AUS/FLUS） | 5–15% |
| 濾泡性腫瘤/可疑 | 15–30% |
| 可疑惡性 | 60–75% |
| 惡性 | 97–99% |

**治療**

- Papillary：早期 → 甲狀腺全切除或近全切除；晚期 → 全甲狀腺切除 + 術後碘治療
- Medullary：甲狀腺全切除 + 頸部淋巴結清掃 + calcitonin 追蹤
- Anaplastic：氣管切開術、放射治療、化學治療、標靶治療

## 小兒耳鼻喉科學

### Acute Otitis Media（AOM）

**定義**

- 中耳空間感染，同時有 MEE/MEI 和急性發病

**流行病學**

- 兒科就診最常見診斷，6–15 個月為高峰期

**病因**

- 細菌：S. pneumoniae、non-typeable H. influenzae、M. catarrhalis、A 群鏈球菌、S. aureus
- 病毒：RSV、流感、腺病毒
- 常為細菌—病毒共同感染

**臨床特徵**

- 發燒、耳痛（幼兒可能無特異性症狀：拉耳朵、躁動、嘔吐、腹瀉）
- Otoscopy：充血、膨隆（充滿膿液）、骨性標誌消失

**管理**

- 支持治療：止痛、退燒
- 觀察：>6 個月、單側、非重度、懷疑 AOM 且無 MEE 或 MEE 但非膨隆或輕度充血的健康兒童
- 抗生素適應症：<6 個月、或 >6 個月有中重度症狀、發燒 >39°C 或症狀 >48 小時、免疫抑制、TM 穿孔伴化膿性引流

**治療**

- 第一線（無 penicillin 過敏）：amoxicillin 80–90 mg/kg/d
- Penicillin 過敏：azithromycin、clarithromycin
- 第二線：amoxicillin-clavulanate
- 反覆發作或頑固性：鼓膜切開術 + 通氣管

**併發症**

- 顱外：CHL 和言語發育遲緩、TM 穿孔、進展至乳突炎、cholesteatoma
- 顱內：腦膜炎、腦/硬膜外/硬膜下膿腫、乙狀竇血栓

### Otitis Media with Effusion（積液性中耳炎）

**定義**

- 中耳有液體但無感染徵象或症狀

**臨床特徵**

- CHL ± 耳鳴
- Otoscopy：TM 變色（琥珀色或暗灰色）、液平、氣泡、回縮

**治療**

- 期待療法：90% 在 3 個月內緩解
- 手術：鼓膜切開術 + 通氣管 + 腺樣體切除術（>4 歲建議）

### Adenoid Hypertrophy（腺樣體肥大）

**定義**

- 腺樣體增大的阻塞性疾病

**臨床特徵**

- 鼻塞、口呼吸、打鼾、腺樣體面容（張口、高拱形顎、牙擁擠）
- 慢性鼻竇炎/鼻炎、睡眠呼吸暫停
- 中耳功能障礙：急性中耳炎、慢性漿液性中耳炎

**治療**

- 自發緩解（青春期退化）
- 抗生素（感染時）
- 反覆/持續性阻塞或感染症狀：腺樣體切除術

### Sleep-Disordered Breathing in Children（兒童睡眠呼吸障礙）

**定義**

- 從打鼾到阻塞性睡眠呼吸暫停（OSA）的睡眠呼吸異常範圍

**臨床特徵**

- 夜間：重打鼾、呼吸暫停、睡眠姿勢異常、遺尿
- 白天：口呼吸、過度嗜睡、行為/學習問題、ADHD 樣症狀、早晨頭痛

**治療**

- 非手術：睡眠衛生、CPAP、減重
- 藥物：鼻腔類固醇、白三烯受體拮抗劑
- 手術：雙側扁桃體切除術 + 腺樣體切除術（首選）

### Peritonsillar Abscess（扁桃體周圍膿腫 / Quinsy）

**定義**

- 扁桃體囊外軟組織的蜂窩組織炎，延伸至軟顎

**臨床特徵（三聯徵）**

- Trismus（牙關緊閉）
- 發燒和脫水
- 咽痛、吞嚥困難、吞嚥痛、流口水

**治療**

- 確保氣道通暢
- 手術引流（切開或針吸）+ 培養
- 經驗性口服抗生素 14 天
- 扁桃體切除術（康復後或第二次發作後考慮）

### Airway Problems in Children（兒童氣道問題）

**年齡相關 Differential Diagnosis**

**新生兒（強制鼻呼吸者）**

- **喉外**：鼻竇孔狹窄、鼻中隔偏斜、後鼻孔閉鎖、舌下垂
- **喉部**：Laryngomalacia（兒童喘鳴最常見原因）、聲帶麻痺、喉部裂、聲門下狹窄

**2–3 個月嬰兒**

- 先天性：laryngomalacia、血管性（聲門下血管瘤、雙主動脈弓）、乳頭狀瘤
- 後天：聲門下狹窄（插管後）、氣管肉芽（插管後）

**兒童和成人（急性）**

- 感染：Ludwig's angina、扁桃體周圍/咽旁膿腫、頸後膿腫
- 腫瘤：SCC、淋巴瘤
- 創傷：喉部骨折、燒傷、誤吸異物

**氣道阻塞徵象**

- Stridor（喘鳴）：吸氣性（聲門或上方）、雙相性（聲門、聲門下）、呼氣性（遠端氣管）
- 呼吸窘迫：鼻翼震顫、氣管牽扯、胸骨凹陷

### Acute Laryngotracheobronchitis（Croup）

**定義**

- 聲門下空間和氣管—支氣管樹的發炎

**病因**

- 病毒：副流感病毒 I 型（最常見）、II 型、III 型、流感 A/B、RSV
- 年齡：6 個月–5 歲

**臨床特徵**

- 前驅 URTI 症狀
- 通常夜間惡化
- 吸氣性或雙相性喘鳴、croupy cough（海獅吠叫樣咳嗽）
- 胸骨/肋間凹陷
- AP 頸部 X 光：「steeple sign」（聲門下狹窄）

**治療**

- 霧化 epinephrine（MDI q1–2h）
- 皮質類固醇（如 dexamethasone 0.5 mg/kg）
- 充足補液、濕化氧氣
- 若無改善：考慮 alternate 診斷（如 bacterial tracheitis）

### Acute Epiglottitis（急性會厭炎）

**定義**

- 喉部聲門上結構的急性發炎，不涉及聲帶

**臨床特徵**

- 任何年齡，常見 1–4 歲
- 快速進展、中毒性表現、發燒、厭食、躁動
- 坐位偏好（「triped」姿勢）、張口、流口水、喉痛、吞嚥困難
- 側頸 X 光：「thumb sign」（會厭腫脹）

**治療**

- **確保氣道**（優先！）
- 靜脈通路、補液
- 抗生素：cefuroxime、cefotaxime、ceftriaxone（10–14 天）
- 注意：管理時不要激動兒童，可能導致完全阻塞

### Laryngomalacia（喉軟化）

**定義**

- 聲門上組織先天的軟化，導致組織塌陷至聲門和吸氣性喘鳴

**臨床特徵**

- 1–2 週出現高音調吸氣性喘鳴
- 仰臥、餵食、哭鬧時加劇
- 通常輕度，但嚴重時可伴紫紺或餵食困難

**治療**

- 觀察 + 質子泵抑制劑（打破酸逆流循環）→ 足夠，>90% 在 12–18 個月自發緩解
- 嚴重（10%）：聲門上成形術

### Foreign Body（異物）

**誤吸**

- 通常卡在右主支氣管
- 花生、硬糖果、葡萄、蘋果核、爆米花、氣球
- 表現：單側「氣喘」、喘鳴、減弱呼吸音
- 診斷：吸氣—呼氣胸部 X 光、支氣管鏡檢查

**誤吞**

- 通常卡在環咽肌
- 硬幣、玩具、電池（緊急！）
- 流口水、吞嚥困難、喘鳴（大時）

> **警示**：紐扣電池必須排除——可在 X 光上形成暈輪徵（halo sign），能腐蝕食道，極度危險

### Deep Neck Space Infection（深頸部空間感染）

**定義**

- 源自下頜牙齒（成人最常見）、扁桃體（兒童最常見）、唾液腺、深頸部淋巴結的感染

**臨床特徵**

- 咽痛或疼痛 + trismus、吞嚥困難/吞嚥痛、喘鳴和呼吸困難
- 面部/頸部腫脹、發燒、淋巴結病

**治療**

- 確保氣道
- 源頭控制（手術引流、牙齒拔除、感染骨清創）
- 最大劑量靜脈抗生素
