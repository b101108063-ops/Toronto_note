## 導讀摘要

本章節涵蓋老年醫學的核心內容，摘要如下：

- **老年人評估（Comprehensive Geriatric Assessment, CGA）**：老年醫學的核心工具，系統性評估高齡患者的功能狀態、認知、情緒、營養、用藥與社會支持
- **Frailty（衰弱）**：臨床上可識別的狀態，反映老年人對急性壓力的儲備能力下降，與多重生理系統的功能衰退有關，是住院死亡、術後不良事件及依賴照護的重要預測因子
- **跌倒（Falls）**：老年人發病與死亡的主要原因之一，屬多因素導致，需進行多專科、多領域的風險評估與介入，包括肌力訓練、平衡復健、環境改造與藥物調整
- **老年常見問題**：incontinence（大小便失禁）、malnutrition（營養不良）、pressure injuries（壓力性損傷）、polypharmacy（多重用藥）等老年症候群
- **老年藥理學與安全處方**：老年人藥物動力學與藥效學改變、Beers Criteria、STOPP/START 準則，避免不適當用藥與藥物不良反應

## 老年人評估（Comprehensive Geriatric Assessment, CGA）

### 導論

+ CGA 是跨專科團隊進行的系統性評估，用於識別老年人的醫療、功能、心理與社會需求
+ 目的：建立整合性照護計畫，優化整體健康狀態與生活品質
+ CGA 評估項目：過去病史、用藥、過敏史、社會史、功能狀態，以及老年醫學系統回顧（cognition、mood、sleep、pain、nutrition、falls、continence、vision/hearing、skin、safety）
+ 身體檢查
+ 檢驗檢查： CBC、electrolytes、TSH、vitamin B12、vitamin D、LFTs、extended electrolytes

### 功能狀態評估

+ **BADLs（Basic Activities of Daily Living）**：進食、穿衣、洗澡、移位、如廁、控制排尿/便
+ **IADLs（Instrumental Activities of Daily Living）**：理財、用藥、購物、烹飪、使用交通工具
+ 功能狀態下降是老年人的重要預後指標

## 跌倒（Falls）

### 定義

+ 非預期性地接觸地面，造成創傷或潛在創傷的事件

### 流行病學

+ 老年人中，30% 的社區居住者每年至少跌倒一次
+ 跌倒是老年人創傷相關死亡的主要原因
+ 跌倒後的恐懼（fear of falling）會導致活動力下降與進一步衰弱

### 風險因子

**內在因子（Intrinsic）：**
+ 認知障礙（cognitive impairment）
+ 骨質疏鬆（osteoporosis）
+ 視力/聽力障礙
+ 神經系統疾病（stroke、Parkinson's disease、周邊神經病變）
+ 心血管疾病（arrhythmia、orthostatic hypotension）
+ 肌肉骨骼疾病（arthritis、足部問題）
+ 藥物（psychoactive drugs、polypharmacy）
+ 衰弱（frailty）

**外在因子（Extrinsic）：**
+ 環境危害（不平坦的地面、光線不足、地毯鬆動）
+ 不適當的鞋子
+ 輔具使用不當

### 臨床評估

+ 如有需要，訪談時應有照護者在場
+ 理學檢查：orthostatic BP、創傷篩檢、心臟、視力、足部與鞋子檢查、gait 評估、Timed Up-and-Go Test、肌肉骨骼系統、神經系統

### 檢驗檢查

+ CGA 找出潛在原因
+ 檢驗應根據病史與身體檢查量身訂製，可能包括：
  = CBC、electrolytes、BUN、creatinine、glucose、Ca²⁺、TSH、vitamin B12、urinalysis、cardiac enzymes、ECG
  = CT head（依據病史與身體檢查指示）
  = coagulation profile
+ 所有女性與男性 >65 歲應接受 bone densitometry（dual-energy x-ray absorptiometry）篩檢骨質疏鬆

### 介入措施

介入措施取決於已識別的內在與外在風險因子。首先處理導致跌倒的急性疾病，並治療任何創傷或併發症。

**實證介入：**
+ 社區中多專科、多因素、健康與環境風險因子評估及介入計畫
+ 肌力訓練、平衡復健（如太極）搭配適當輔具，以及團體運動計畫
+ 居家危害評估與改善，與職業治療合作（如移除鬆動地毯與絆倒危害、加裝淋浴扶手與樓梯扶手、改善照明）
+ 量身訂製的 gait aid（助行器）
+ 心理藥物之逐步減量或停用
+ 姿勢性低血壓、心跳與心律異常的處理
+ 視力（白內障手術）與鞋子優化
+ 靜脈瘀滯水腫時穿著壓迫襪
+ 髖關節保護器
+ 若 vitamin D 儲備不足，處方 vitamin D 1000 IU 每日
+ 若有骨質疏鬆風險，建議飲食中每日攝取 1200 mg calcium supplement

### 臨床病史重點：SPLATT

| 縮寫 | 意義 |
|------|------|
| S | Symptoms（症狀） |
| P | Previous falls（過去跌倒史） |
| L | Location（跌倒地點） |
| A | Activity at time of fall（跌倒時的活動） |
| T | Time of fall（跌倒時間） |
| T | Trauma（創傷） |

### 藥物對跌倒風險的影響（Odds Ratios）

| 藥物類別 | OR |
|----------|------|
| Antidepressants（抗憂鬱藥） | 1.68 |
| Neuroleptics/Antipsychotics（抗精神病藥） | 1.59 |
| Benzodiazepines（苯二氮平類） | 1.57 |
| Sedatives/Hypnotics（鎮靜劑/安眠藥） | 1.47 |
| Antihypertensive agents（抗高血壓藥） | 1.24 |
| NSAIDs | 1.21 |
| Diuretics（利尿劑） | 1.07 |
| Plotelets（血小板抑制劑） | 1.01 |

## 衰弱（Frailty）

### 定義

+ **Frailty（衰弱）**：臨床上可識別的狀態，反映老年人儲備能力下降，對急性壓力的脆弱性增加，由於多個生理系統的功能衰退所致
+ **功能衰退（Functional decline）**：執行 BADLs 與 IADLs 能力之進行性限制
+ 衰弱與加護病房住院死亡、不良事件、住院天數、再入院率及出院後新發依賴之風險升高有關

### Rockwood Clinical Frailty Scale

| 等級 | 描述 |
|------|------|
| 1 | Very Fit（非常健康）：活躍、有活力的銀髮族，定期運動，在同齡中屬最健康者 |
| 2 | Well（健康）：無活躍疾病症狀，但比 category 1 少運動或不常活動 |
| 3 | Managing Well（尚可）：內科疾病控制良好，可能有症狀但不影響日常活動 |
| 4 | Very Mild Frailty（非常輕度衰弱）：過去被認為「脆弱」，由完全獨立過渡到依賴的轉換期 |
| 5 | Mild Frailty（輕度衰弱）：更明顯的減速，需要 ADLs 的協助（如理財、交通）；可能影響購物與家事準備 |
| 6 | Moderate Frailty（適度衰弱）：需要外界活動與家務的協助，樓梯有問題，洗澡與穿衣服可能需要協助 |
| 7 | Severe Frailty（嚴重衰弱）：完全依賴他人照護，無論身體或認知原因；接近生命終點 |
| 8 | Very Severe Frailty（非常嚴重衰弱）：完全依賴個人照護，接近生命終點，即使輕微疾病也無法恢復 |
| 9 | Terminally Ill（末期）：預期壽命 <6 個月，否則處於嚴重失能狀態 |

**認知功能與衰弱量表之對照：**
+ Mild Dementia（輕度失智）
+ Moderate Dementia（中度失智）
+ Severe Dementia（重度失智）
+ Very Severe Dementia（非常重度失智）

### 衰弱模型

**Physical Frailty Phenotype（Fried et al.）**

Frail：符合 ≥3 項標準；at-risk 或 pre-frail：符合 1-2 項標準

1. **Shrinking（體重減輕）**：非刻意性體重下降（基線：過去一年 >10 lbs 或體重 5%）
2. **Weakness（肌力減弱）**：握力在最低 20%（依性別、BMI 調整）
3. **Poor Endurance（耐力不足）**：自我報告有 exhaustion 現象
4. **Slowness（緩慢）**：15 英尺行走時間在最慢 20%（依性別、身高調整）
5. **Low Activity（活動量低）**：每週千卡攝取量在最低 20%（男性：<383 kcals/wk；女性：<270 kcals/wk）

**Cumulative Deficit Approach（Rockwood et al.）**

+ 評估資產（如健康、態度、資源、照護者）與缺失（如疾病、失能、依賴、照護者負荷）之間的平衡
+ 衰弱指數（Frailty Index）= 存在的缺失數 / 可能缺失總數

### 衰弱之病因學

| 病因 | 機轉 |
|------|------|
| 老化之生理變化 | Sarcopenia（年齡相關骨骼肌與肌力流失）、器官質量減少與硬度增加、系統儲備能力下降 |
| 免疫系統 | 循環 interleukin 6、C-reactive protein、WBC 與單核球升高與骨骼肌減少有關；凝血因子升高（factor VIII、fibrinogen、D-dimer）活化凝血途徑；慢性發炎 |
| 內分泌系統 | 透過 sarcopenia 導致衰弱：生長激素與 IGF1 減少、皮質醇增加、DHEAS 減少、25(OH) vitamin D 減少 |
| 壓力系統失調 | 自律神經系統失調；年齡相關 renin-angiotensin 系統與粒線體變化影響 sarcopenia 與發炎 |

### 衰弱老年患者之實證處理

+ **CGA**
+ 實體活動計畫、營養優化、多因素介入
+ 跨專科基層照護
+ 住院衰弱患者轉介至急性老年照護單位（ACE unit）
+ 藥物優化
+ 照護者支持

## 活動力障礙（Mobility Disability）

### 定義

+ 身體或一個或多個下肢之獨立、自主運動受限，伴隨失能、衰弱與跌倒風險增加、生活品質下降

### 病因與風險因子

多因素導致；功能評估與完整病史採集、跨專科照護方式至關重要。

**心理因素：**
+ 跌倒恐懼、動機下降、depression

**身體變化：**
+ MSK 疾病：髖或腿骨折病史、骨質疏鬆、arthritis
+ 神經疾病：stroke、Parkinson's disease、嚴重 dementia、周邊神經病變
+ 心血管疾病：CHF、冠狀动脉疾病引起之心絞痛、周邊血管疾病引起之間歇性跛行
+ 感覺障礙：視力不良、周邊感覺/本體感覺下降

**社會人際因素：**
+ 環境變化

**醫源性因素：**
+ 醫療機構內之環境危害
+ 長期臥床導致之活動力下降（deconditioning）
+ 輔具不足
+ 控制不良之慢性或急性疼痛

### 併發症

+ **心血管**：orthostatic hypotension、靜脈血栓、embolism
+ **呼吸**：換氣下降、肺擴張不全、pneumonia
+ **胃腸**：厭食、constipation、大小便失禁、脫水、營養不良
+ **泌尿生殖**：感染、尿滯留、膀胱/腎結石、大小便失禁
+ **肌肉骨骼**：萎縮、攣縮、骨質流失
+ **皮膚**：pressure injuries
+ **心理**：感覺剝奪、delirium、depression

## 大便失禁（Fecal Incontinence）

### 定義

+ 非自願或不當地排出糞便，影響社交功能或衛生
+ 嚴重程度從無意中排氣到完全排空腸道內容物
+ 三種亞型：
  1. **被動失禁（Passive incontinence）**：未察覺下非自願排出糞便或氣體
  2. **急迫失禁（Urge incontinence）**：儘管主動嘗試忍住仍排出糞便
  3. **糞便滲漏（Fecal seepage）**：正常排便後糞便滲漏

### 流行病學

+ 發生率因設置而異：社區（17-36%）、醫院（16%）、護理之家（33-65%）
+ 風險因子：constipation、年齡 >80 歲、女性、urinary incontinence、活動障礙、dementia、神經系統疾病

### 病因

+ 年齡 >80 歲之生理變化（如 external sphincter strength 下降、internal sphincter resting tone 下降、anal squeeze 減弱、直腸順應性增加、anal sensation 受損）
+ 創傷（如陰道分娩、pudendal nerve 損傷、cauda equina）
+ 醫源性：
  = 手術（如直腸肛門手術、lateral internal sphincterotomy、痔瘡切除術、大腸切除術）
  = 放射治療（如骨盆腔放射治療）
+ 神經性（如神經病變、stroke、MS、糖尿病神經病變）
+ 直腸/大腸疾病（如直腸脫垂、痔瘡、IBD、rectocele、癌症）
+ 藥物（如 laxatives、抗膽鹼能藥物、抗憂鬱藥、caffeine、肌肉鬆弛劑）
+ 認知功能（如 dementia、伴隨精神病的故意弄髒）
+ 便秘/糞便嵌塞

### 短暫性大便失禁之病因：DIAPERS

| 縮寫 | 意義 |
|------|------|
| D | Delirium |
| I | Infection（泌尿道感染等） |
| A | Atrophic urethritis/vaginitis |
| P | Pharmaceuticals（藥物） |
| E | Excessive urine output（多尿） |
| R | Restricted mobility（活動受限） |
| S | Stool impaction（糞便嵌塞） |

### 檢驗檢查

+ 區分真正失禁與頻率/急迫感
+ 糞便檢查
+ 直腸內超聲波（endorectal ultrasound）
+ 大腸鏡、sigmoidoscopy、anoscopy
+ 直腸肛門測壓/功能測試

### 處理

+ **生理變化**：藥物管理（抗胃腸蠕動藥物如 loperamide、飲食/增量大便體積制劑）、增加液體攝取、biofeedback、骨盆底肌肉再訓練、手術
+ **創傷**：直接手術修復或 sphincter 增強
+ **醫源性**：手術修復、人工 sphincter
+ **神經性**：藥物管理、腹部按摩、digitial stimulation、biofeedback 與行為訓練、預防脊髓損傷之自律神經反射障礙
+ **直腸/大腸疾病**：治療根本原因（優化 IBD 藥物）、手術（如腫塊切除、脫垂修復、痔瘡切除、colostomy）
+ **藥物相關**：停用 laxatives、降低劑量或停用任何致病藥物
+ **認知功能**：建立規律排便計畫（dementia 患者）、精神科會診（優化藥物與認知功能）
+ **便秘/糞便嵌塞**：移除嵌塞物、預防嵌塞、增加水合、鼓勵活動、laxatives、必要時停用致便祕藥物、enema 或直腸沖洗
+ **安全評估**：評估廁所距離、跌倒預防策略、是否需要床邊便椅、認知障礙患者提供馬桶標示、必要時會診職業治療

## 尿失禁（Urinary Incontinence）

*參見 Urology, U6*

### 定義

+ 任何非自願性漏尿之主訴
+ 四種亞型：
  1. **Stress incontinence（應力性尿失禁）**：與身體用力相關之漏尿
  2. **Urge incontinence（急迫性尿失禁）**：與膀胱過度敏感及強烈排尿衝動相關之漏尿
  3. **Overflow incontinence（溢流性尿失禁）**：與膀胱排空不良相關之漏尿
  4. **Functional incontinence（功能性尿失禁）**：因疾病或失能而非泌尿系統問題導致之漏尿

### 流行病學

+ 盛行率：社區老年人 15-30%，機構照護者至少 50%
+ 罹病率：蜂窩性組織炎、pressure injuries、泌尿道感染、骨折跌倒、睡眠剝奪、社交退縮、depression、性功能障礙
+ 不會增加死亡率

### 風險因子

活動障礙、跌倒、藥物、depression、TIA/stroke、dementia、CHF、obesity

### 病因

+ 老年生理變化（如膀胱容量減少）
+ 泌尿生殖系統疾病（如 cystitis、urethritis、BPH）
+ 神經性（如 cauda equina syndrome、stroke、MS）
+ 醫源性（如攝護腺手術）
+ 創傷（如骨盆腔創傷創傷性脊髓損傷）
+ 藥物（如酒精、loop diuretics、SGLT-2s、sedative hypnotics、GABAergic agents）
+ 認知功能（如 dementia、depression）
+ 功能障礙（如 arthritis、視力不良）

### 檢驗檢查

+ 實驗室：urinalysis 與 urine culture、血清 creatinine、BUN
+ 影像：post-void residual、腎臟超聲波
+ 其他：排尿日誌（voiding diary）、墊片測試（pad test）

### 處理

+ **生活型態修正**：避免過量液體攝取與酒精
+ **藥物**：β-adrenergic agonists 減少非自願性膀胱收縮
+ **老年生理變化**：骨盆肌肉運動、膀胱訓練、biofeedback
+ **泌尿生殖系統疾病**：治療根本原因（cystitis 經驗性抗菌治療、BPH 之 α-blockers/5-α reductase inhibitors）
+ **功能障礙**：尿失禁墊片、環境改造、個人協助
+ **安全評估**：評估廁所距離、跌倒預防策略、是否需要床邊便椅、必要時會診職業治療

## 營養不良（Malnutrition）

### 定義

+ 老年人沒有統一的 malnutrition 定義。2018 Global Leadership Initiative on Malnutrition 提供之定義需要一個表現型與一個病因學發現的組合：

**表現型（Phenotype）：**
+ 體重下降：過去 6 個月內 >5% 或超過 6 個月 >10%
+ Low BMI
+ 肌肉量減少（以 DXA、BIA、CT 或 MRI 測量）

**病因學（Etiology）：**
+ 食物攝取減少
+ 發炎：急性疾病/傷害或慢性疾病相關

**其他定義包括：**
+ Hypocholesterolemia（<4.1 mmol/L）
+ Hypoalbuminemia（社區：<38 g/L；住院：<35 g/L）
+ 能量攝取不足、體液堆積（如水腫）、皮下脂肪流失、手部握力下降

### 病因

+ **營養性**：
  = 同化能力下降：胃腸道過境受損、消化不良、吸收不良
  = 攝取減少：經濟因素、精神疾病（depression）、認知障礙、慢性疾病相關厭食、功能障礙（如難以購物、備餐或因功能障礙無法自行進食）、物質使用
+ **壓力**：急性或慢性疾病/感染、慢性發炎、腹痛
+ **機械性**：牙齒問題、dysphagia
+ **年齡相關變化**：口渴感下降、嗅覺/味覺下降、胃排空延遲導致早期飽足感、ghrelin 產量減少

### 老年人營養不良病因：MEALS ON WHEELS

| 縮寫 | 意義 |
|------|------|
| M | Medications（藥物） |
| E | Emotional problems（情緒問題，如 depression） |
| A | Anorexia（厭食） |
| L | Late-life paranoia（老年偏執） |
| S | Swallowing disorders（吞嚥障礙） |
| O | Oral problems（口腔問題） |
| N | Nosocomial infections（院內感染） |
| W | Wandering/dementia related activity（遊蕩/失智相關活動） |
| H | Hyperthyroid/hypercalcemia/hypoadrenalism（甲狀腺功能亢進/高血鈣/腎上腺功能低下） |
| E | Enteric disorders（腸道疾病） |
| E | Eating problems（進食問題） |
| L | Low-salt/low-fat diet（低鹽/低脂飲食） |
| S | Stones（結石） |

### 臨床表徵

**病史：**
+ 檢查前 6 個月的體重減輕
+ 近期或慢性疾病
+ 全身症狀（如體重減輕）
+ 飲食攝取與平常模式之關係
+ Depression、GI 症狀（厭食、噁心、嘔吐、腹瀉）
+ 功能障礙：ADLs 與 IADLs 受損、認知下降（「忘記吃飯」）
+ 社會因素：經濟障礙、牙齒問題與居住情形（如獨居）
+ 物質使用（如酒精、吸菸、靜脈或娛樂性藥物使用）

**理學檢查：**
+ BMI <23.5（男性）與 <22.0（女性）應提高警覺
+ 肌肉耗損、太陽穴凹陷、三頭肌皮褶存在與否
+ 皮下脂肪流失
+ 踝部或薦骨水腫、腹水
+ 評估認知功能

### 檢驗檢查

+ CBC、electrolytes、Ca²⁺/albumin、Mg²⁺、PO₄³⁻、creatinine、LFTs（INR、bilirubin）、vitamin B12、folate、TSH、lipid profile
+ 如評估指示，可考慮 urinalysis、ESR、CXR

### 治療

+ 直接治療根本原因，鼓勵與家人、朋友或照護者一起用餐（「社交進食」）
+ 飲食修正：高熱量食物、高蛋白口服營養補充
+ 特定患者之營養替代產品（如 Ensure™、Glucerna™、Nepro™）、維生素/礦物質（如 vitamin B12、calcium、vitamin D、thiamine）
+ 轉介：語言病理學家進行吞嚥評估、營養師

## 壓力性損傷（Pressure Injuries）

*參見 Plastic Surgery, PL17*

### 定義

+ 又稱 pressure ulcers/injuries、decubitus ulcers
+ 任何因持續受壓導致下方組織損傷的病灶；通常發生在骨突處

### 風險因子

+ **外因性**：摩擦、壓力、剪切力、濕氣
+ **內因性**：活動力受限、營養不良、共病症（如 DM、PVD、血管炎、免疫缺陷、CHF）、感覺喪失
+ **老年相關**：年齡相關皮膚變化、臥床、認知障礙、慢性病

### NPIAP 壓力性損傷分期系統

| 分期 | 描述 |
|------|------|
| **Stage 1** | 完整皮膚出現局部非發白性紅斑（深色皮膚可能呈現不同顏色變化）；感覺、溫度或硬度變化可能先於視覺變化出現；顏色變化不包括紫色或栗色（可能表示深層組織穿透性損傷） |
| **Stage 2** | 部分厚度皮膚缺失，露出真皮；傷口床呈粉紅色或紅色、濕潤，可能呈現為血清填充水皰；可見脂肪組織與更深層組織 |
| **Stage 3** | 全層皮膚缺失；可見脂肪組織；可能出現 slough 和/或焦痂；常見肉芽組織與捲邊（epibole） |
| **Stage 4** | 全層皮膚與組織缺失；可見或可直接觸及筋膜、肌肉、肌腱、韌帶、軟骨或骨；傷口床某些部分可能出現 slough 或焦痂；常見 epibole、undermining 與/或隧道 |
| **Unstageable Pressure Injury** | 全層皮膚與組織缺失；由於 slough 或焦痂阻塞，無法確定組織損傷程度 |
| **Deep Tissue Pressure Injury** | 完整或不完整皮膚，出現局部非發白性栗色或紫色變化或表皮分離，露出深色傷口床或血皰；疼痛與溫度變化可能先於皮膚顏色變化出現；損傷由骨-肌肉介面處的強烈與/或持續壓力與剪切力造成 |

### 併發症

+ **非感染性**：amyloidosis、異位骨形成、會陰尿道瘻管、假性動脈瘤、Marjolin ulcer、局部治療之全身併發症、口服/靜脈治療併發症
+ **感染性**：菌血症/敗血症、蜂窩性組織炎、骨髓炎、敗血性關節炎、竇道、膿胸、心內膜炎、腦膜炎

### 預防

+ 薦骨區域使用屏障乳膏
+ 減壓：
  = 頻繁翻身（床上每 2 小時、椅子上每 1 小時）
  = 支援設備（交替壓力床墊/覆蓋物、低氣壓床）
+ 優化營養狀態、鼓勵活動、控制大小便失禁
+ 對有皮膚破損風險者，入院時使用經驗證的壓力性損傷風險評估工具（從頭到腳）進行評估
+ 高風險患者每日重新評估

### 治療

+ 優化營養狀態
+ 傷口減壓
+ 止痛
+ 所有伴隨壞死的潰傷需要清創（機械性、酶性與自溶性清創為非緊急形式，而尖銳清創因敗血症或蜂窩性組織炎風險需緊急執行）
+ 敷料應用（吸收滲液、減少摩擦之屏障產品）
+ 維持濕潤傷口環境以促進再上皮化
+ 傷口感染治療（topical gentamicin、silver sulfadiazine、mupirocin）
+ 臨床改善不佳之傷口進行 C&S  swab；慢性傷口切片排除惡性腫瘤
+ 轉介傷口照護或整型外科
+ 考虑其他治療選項：
  = 負壓傷口治療/vacuum-assisted closure
  = 生物製劑：fibroblast growth factor 或 platelet-derived growth factor 應用於傷口
  = 非接觸性體溫傷口治療
  = 電刺激治療

## 駕駛能力（Driving Competency）

### 強制通報義務

+ 在加拿大，除魁北克、Nova Scotia 與 Alberta（為酌情決定）外，所有省份與領地均強制要求醫師向交通部通報
+ British Columbia、Ontario：>80 歲必須轉介重新考試
+ 美國：各州規定不同

### 可能影響駕駛之疾病

| 疾病類別 | 駕駛限制說明 |
|----------|-------------|
| **酒精** | 酒精依賴或酒精使用障礙：若有疑慮，應建議不要駕駛；酒精戒斷癲癇：必須（1）在治療後獲得成癮顧問的正面報告，且（2）康復或戒斷 ≥12 個月 |
| **血壓異常** | HTN：收縮壓 >170/110 應仔細評估；低血壓：若暈厥，應在治療並可預防前停止駕駛 |
| **心血管疾病** | 無症狀 CAD 或穩定心絞痛：無限制；STEMI、NSTEMI 伴顯著 LV 損傷、冠狀动脉繞道手術：出院後 1 個月不可駕駛；STEMI 伴輕微 LV 損傷、不穩定心絞痛：若無 PCI 则 7 天，若有 PCI 则 48 小時 |
| **腦血管疾病** | TIA：直至完成醫學評估前不可駕駛；Stroke：至少 1 個月不可駕駛；若功能恢復、無臨床顯著運動、認知、感知或視力缺陷、無明顯復發風險、根本原因適當治療、無術後癲癇，可恢復駕駛 |
| **認知障礙/失智** | 輕中度障礙：無限制；需要補充氧氣的中度或重度障礙：攜帶氧氣進行道路測試；中度至重度失智是駕駛禁忌，定義為「無法獨立執行 >1 項 IADL 或任何 basic ADL」；輕度失智若有指示應進行評估，每 6-12 個月重新評估；MMSE 表現不佳、clock drawing 或 Trails B 提示需進一步調查駕駛能力；MSE 分數本身不足以判斷駕駛適任性 |
| **糖尿病** | 飲食控制或口服降血糖藥物：若無可能影響駕駛之糖尿病併發症（視網膜病變、腎病變、神經病變、心血管或腦血管疾病），無限制；胰島素使用：若無上述併發症且過去 6 個月無嚴重低血糖事件，可駕駛 |
| **藥物** | 注意：止痛劑、抗膽鹼能藥物、抗癲癇藥、抗憂鬱藥、抗精神病藥、類鴉片、鎮靜劑與興奮劑；功能障礙程度各異，應警告患者藥物/戒斷對駕駛的影響 |
| **聽力障礙** | 聽力障礙對安全駕駛能力的影響存在爭議 |
| **肌肉骨骼疾病** | 醫師角色為通報病因、預後與障礙程度（疼痛、關節活動度、協調性、肌力）；門診手術、鎮靜：24 小時內不可駕駛；門診手術、全身麻醉：≥24 小時不可駕駛 |
| **癲癇** | 癲癇：若無癲癇發作 6 個月、服用不影響駕駛能力之藥物、醫師對患者依從性有洞察力，可駕駛（Ontario 準則）；首次、單次、非誘發性癲癇：完成神經科檢查、EEG、CT head 前 3 個月不可駕駛 |
| **睡眠障礙** | 若患者因無症狀睡眠障礙被認為有風險，但拒絕睡眠檢查或拒絕適當治療，不得駕駛 |
| **視力障礙** | 視力：雙眼同時測量最佳視力 <20/50 禁止駕駛；視野：雙眼同時測量水平子午線 <120° 且注視點上下各 15° 連續範圍內 <120° 禁止駕駛 |

## 醫療照護機構（Healthcare Institution）

### 醫療服務與機構分類

| 機構類型 | 服務說明 |
|----------|---------|
| **Home and Community Support Services（居家與社區支援服務）** | 提供給在家獨立生活或在家人照顧下生活的患者之到家支援服務。包括專業醫療服務、個人照護與支援（ADL 協助、家務 ADL 協助）以及社區支援服務（如交通、餐點配送、日間計畫、照護者喘息、安全檢查） |
| **Rehabilitation（復健）** | 在機構中提供之醫療服務，以優化患者功能、獨立性與生活品質 |
| **Residential（居住型）** | 分為短期（60-90 天）與長期（不限）住宿 |
| **① 老年人平價住宅（Older Adult Affordable Housing）** | 老年人獨立生活並自理，但偏好與其他老年人就近居住；通常有可及性設施；租金根據收入調整 |
| **② 退休之家（Retirement Home）** | 居民相當獨立，只需最少 ADLs 與 IADLs 協助；通常為私立 |
| **③ 支援性住宅（Supportive Housing）** | 居民在獨立生活的同時需要少量至中等日常活動協助；通常為公寓內的租賃單位；可能提供物理治療與復健服務 |
| **④ 長期照護/護理機構（Long-term Care/Skilled Nursing Facility）** | 全天候護理與隨叫隨到醫師；通常提供職能治療、物理治療、呼吸治療與復健服務；可用於照護者喘息之短期入住或支持性患者照護以在出院後恢復體力與信心 |
| **⑤ 安寧療護（Hospice）** | 獨立機構或在醫院或護理之家之指定樓層，照護末期患者及其家屬；以生活品質為主，通常要求預後 <3 個月 |

**備註：**
+ 社區醫療機構名稱、設施類型與提供之服務因地理位置而異
+ 轉介社區服務與機構時需考慮之因素：所需支援之層次與類型、收入/社會經濟狀況、社會支援與/或社會隔離程度、其他可能造成照護障礙之健康決定因素

## 老年藥理學（Geriatric Pharmacology）

### 年齡相關藥物動力學（Pharmacokinetics）

| 參數 | 年齡相關變化 | 臨床意義 |
|------|-------------|---------|
| **吸收（影響較小）** | 胃液 pH 值升高、內臟血流減少、GI 吸收表面積與皮膚血管減少、胃排空延遲；然而健康老年人除具有廣泛首過代謝之藥物外，多數口服藥物之適當吸收可維持；吸收減少可能與患者共病症有關 | 共病症、藥物-藥物、藥物-食物交互作用更可能影響吸收 |
| **分布** | 體脂肪增加 → 親脂性藥物分布體積增大；去脂體重與總水量減少 → 親水性藥物分布體積減少；α-glycoprotein 增加 → 鹼性藥物結合增加；白蛋白減少 → 酸性藥物結合減少 |
| **代謝（老化影響較小）** | 肝臟質量與肝血流減少；第一相反應（氧化系統）受損 | 可能需要較低劑量即可達到療效 |
| **排除** | 腎血流、腎絲球濾過率、腎小管分泌減少；腎功能整體減少 30-50% | 可能需要較低劑量即可達到療效 |

### 藥效學（Pharmacodynamics）

**藥物敏感性：**
+ 藥物動力學變化以及內在敏感性改變導致藥物反應改變
+ 對 warfarin、鎮靜劑、抗精神病藥、抗膽鹼能藥物、digoxin、類鴉片之敏感性增加
+ 對 β-blockers 與 β-adrenergic stimulants 之敏感性降低（但可能有敏感性增加）

**體內平衡能力下降：**
+ 補償機制較差，導致更多不良反應（如 NSAIDs/抗凝血劑引起之出血、抗膽鹼能/交感神經/抗帕金森藥物引起之意識狀態改變）

## 多重用藥（Polypharmacy）

### 定義

+ 處方、管理或使用超過臨床適應症所需之藥物數量

### 流行病學

+ 加拿大 >60% 的老年人報告使用 >5 種藥物
+ 住院老年人入院時平均接受 10 種藥物

### Polypharmacy 之風險因子

**患者層面：** 年齡、女性、認知障礙、健康素養低、frailty、精神健康狀況、多種慢性病、缺乏基層照護醫師、居住在長期照護機構、多家藥房

**系統層面：** 多位處方醫師、文件系統不佳、自動化補充系統、缺乏系統性藥物回顧

### 不依從性之風險因子

+ 藥物數量越多（1 種藥物順從性為 80%，但 >6 種降至 25%）
+ 服藥頻率增加、容器設計複雜、藥物療程複雜、經濟限制、認知障礙

### 藥物不良反應（Adverse Drug Reactions, ADRs）

+ 任何在預防或治療劑量下發生的海默或非預期藥物反應
+ 老年人之風險因子：
  = 內在：共病症（>5 種）、年齡 >85、低 BMI、年齡相關藥物動力學與藥效學變化、CrCl <50 mL/min
  = 外在：藥物數量（>9 種藥物、>12 次/日劑量）、多位處方醫師、不可靠的藥物史、先前 ADR

**新藥物治療原則：Start Low, Go Slow！避免同時開始 2 種藥物。**

**老年人藥物不良反應可能以以下形式表現：** delirium、falls、fractures、urinary incontinence/retention 或 fecal incontinence/impaction。任何老年人之新症狀都可能是藥物相關，直至證明為止。

**處方 cascade：** 將 ADR 誤解為新醫療狀況，然後開立新藥物治療初始藥物引起的事件。醫療提供者應問自己：
+ 新藥物是否為了解決先前處方藥物治療之不良事件而開立？
+ 初始藥物治療是否真的需要，特別是如果導致藥物 cascade？
+ 初始藥物治療的益處是否超過危害？

### 預防 Polypharmacy

+ 考量藥物：更安全的副作用特徵、方便之給藥時程、方便途徑、療效
+ 考量患者：其他藥物、臨床適應症、醫療共病症
+ 考量患者-藥物交互作用之 ADR 風險因子
+ 定期回顧藥物清單，刪除無臨床適應症或有毒性的藥物
+ 避免用另一種藥物治療 ADR

## 老年人之不適當處方（Inappropriate Prescribing in Older Adults）

### 流行病學

+ 估計潛在不當處方的盛行率為 12-40%

### Beers Criteria

+ 65 歲以上成年人應避免之藥物清單（基於安全考量）
+ 2024 更新列出大多數老年人不適當的藥物、在特定情況下應通常避免的藥物、應谨慎使用的藥物、藥物-藥物交互作用、以及根據腎功能調整藥物劑量
+ 範例：長效 benzodiazepines、強效抗膽鹼能藥物、高劑量鎮靜劑

### STOPP/START 準則

+ 另一個用於老年人潛在不當處方之篩檢工具
+ **STOPP：Screening Tool of Older Person's Prescriptions**：65 歲以上人群在診斷背景下禁忌之藥物系統列表
+ **START：Screening Tool to Alert physicians to Right Treatment**：65 歲以上人群在診斷背景下有適應症之藥物系統列表
+ 老年人常受到治療不足（ACEI、ASA、β-blockers、thrombolytics、口服抗凝血劑）

### 老年人處方原則：CARED

| 縮寫 | 意義 |
|------|------|
| C | Caution/Compliance（謹慎/順從性） |
| A | Age（根據年齡調整劑量） |
| R | Review regimen regularly（定期回顧療程） |
| E | Educate（衛教） |
| D | Discontinue unnecessary medications（停用不必要的藥物） |

## 老年醫學重要臨床試驗

### Frailty

| 試驗名稱 | 參考文獻 | 研究內容 |
|----------|----------|---------|
| **Gait Speed and Survival in Older Adults** | JAMA 2011;305:50-58 | 目的：評估 gait speed 與存活率之關係。方法：9 個世代研究之匯總分析，納入 >65 歲有基線 gait speed 資料之成年人，追蹤 6-21 年。主要結局為存活與預期壽命。结果：5 年整體存活率 84.8%，10 年存活率 59.7%。Gait speed 與所有研究之存活相關（pooled HR per 0.1 m/s：0.88；95% CI 0.87-0.90）。結論：Gait speed 與老年人 10 年存活相關 |
| **Frailty in Older Adults: Evidence for a Phenotype** | Fried et al. 2001, J Gerontol A Biol Sci Med Sci 2001;56(3):M146-156 | 目的：發展 frailty 作為臨床症候群之表現型。方法：對原始世代 4735 名參與者與後續招募之 582 名非裔美國人參與者，進行基線與年度追蹤，結果為常見疾病、住院、跌倒、失能與死亡。結論：社區居住老年人衰弱可定義為符合三項以上：非刻意體重減輕（過去一年 10 lbs）、自我報告倦怠、握力下降、行走速度緩慢、低身體活動 |
| **REHABAF** | NEJM 2021;385:203-216 | 目的：研究針對急性失償性心衰竭住院老年人之物理復健介入。方法：多中心、隨機對照試驗，評估過渡性、量身訂製、漸進性復健介入。結論：老年急性失償性心衰竭患者接受此復健計畫治療可改善臨床結局 |

### Delirium

| 試驗名稱 | 參考文獻 | 研究內容 |
|----------|----------|---------|
| **Delirium is a Strong Risk Factor for Dementia in the Oldest-Old** | Davis et al. 2012, Brain 2012;135(9):2809-16 | 目的：確定 delirium 是否為 incident dementia 與認知退化之風險因子。方法：553 名年齡 >85 歲個體評估 delirium 與 incident dementia 之關聯，以及 MMSE 分數之退化。結論：Delirium 是老年人 incident dementia 與認知退化之強風險因子 |
| **A Multicomponent Intervention to Prevent Delirium in Hospitalized Older Patients** | Inouye et al. 1999, NEJM 1999;340:669-676 | 目的：評估多因素策略對住院老年人預防 delirium 之有效性。方法：852 名 ≥70 歲住院患者。介入單位採用多因素方法處理認知障礙、睡眠剝奪、活動力受限、視力障礙、聽力障礙與脫水。結論：針對住院老年人 delirium 風險因子之多因素介入模式可有效減少 delirium 發生率與持續時間 |

### Falls

| 試驗名稱 | 參考文獻 | 研究內容 |
|----------|----------|---------|
| **PROFET** | Lancet 1999;353:93-97 | 目的：評估結構性跨專科評估對跌倒者之益處。方法：>65 歲至急診就診之跌倒患者，随機分組至介入組（詳細醫學與職能治療評估，若有指示則轉介）或對照組（僅常規照護）。結論：跨專科方法可顯著減少老年人未來跌倒之風險與功能障礙 |

### Neurocognitive Disorders

| 試驗名稱 | 參考文獻 | 研究內容 |
|----------|----------|---------|
| **Donepezil and Memantine for Moderate-to-Severe Alzheimer's Disease** | Howard et al. 2012, NEJM 2012;366:893-903 | 目的：評估 cholinesterase inhibitors 對中度至重度 Alzheimer's disease 長期治療之益處。方法：295 名接受 donepezil 之社區居住中度至重度 Alzheimer's disease 患者，随機分配至繼續 donepezil、停用 donepezil 並開始 memantine，或繼續 donepezil 並加 memantine。結論：持續 donepezil 治療 12 個月與中度或重度 Alzheimer's disease 患者之認知益處相關 |
| **SMARRT** | JAMA Intern Med. 2024;184(1):54-62 | 目的：評估個人化多領域風險降低介入是否改善老年人之認知與失智風險 profile。方法：172 名失智風險升高之成年人（70-89 歲）隨機分配至個人化風險降低介入組或健康教育對照組。結論：可改變之風險降低策略應針對失智風險升高之成年人 |

### Hypertension in the Elderly

| 試驗名稱 | 參考文獻 | 研究內容 |
|----------|----------|---------|
| **SPRINT Revisited** | Hypertension 2023;78(6):1701-1710 | 目的：回顧 SPRINT 對臨床意涵之最新證據。结果：原始 SPRINT 結果顯示心血管死亡減少 43%（P=0.005），急性失償性心衰竭減少 38%（P=0.002）。結論：更積極的血壓控制可帶來顯著健康益處 |

### Inappropriate Prescribing in the Elderly

| 試驗名稱 | 參考文獻 | 研究內容 |
|----------|----------|---------|
| **EMPOWER** | JAMA Intern Med. 2014;174:890-898 | 目的：比較直接消費者教育與常規照護對老年人停用 benzodiazepines 之效果。方法：303 名 65-95 歲長期使用 benzodiazepines 者，隨機分配至教育介入或對照組。結論：直接說明 benzodiazepines 風險之消費者教育與逐步減量方案可有效促使共同決策與停用對老年人有害之藥物 |
| **STOPP and START** | Gallagher et al. 2008, Int J Clin Pharmacol Ther 2008;46(2):72-83 | 目的：驗證老年人處方之新篩檢工具（STOPP）與適當處方警示工具（START）。結果：STOPP 包含 65 項臨床上顯著之潛在不當處方標準；START 包含 22 項實證處方指示。結論：STOPP/START 是有效、可靠且全面之篩檢工具 |
